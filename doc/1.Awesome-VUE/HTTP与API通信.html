HTTP 客户端 ​

  • Axios ⭐ 108k — 基于 Promise 的 HTTP 客户端，支持浏览器和 Node.js，提供请求/响应拦截器、自动 JSON 转换、请求取消、超时控制、XSRF 防护和上传下载进度监控，是 Vue 生态中最常用的 HTTP 请求库
  • SuperAgent ⭐ 16.4k — 轻量级渐进式 HTTP 客户端，兼容浏览器和 Node.js，提供优雅的链式 API、自动 JSON 解析、文件上传和 multipart 表单提交，支持插件扩展
  • Got ⭐ 15.6k — Node.js 环境下功能强大的 HTTP 请求库，内置分页、缓存、重试、钩子系统、流式响应和 HTTP/2 支持，适合服务端复杂 HTTP 场景
  • Ky ⭐ 13.8k — 基于 Fetch API 的轻量级 HTTP 客户端，体积仅约 3KB，支持超时、自动重试、拦截器、Schema 校验和 TypeScript 类型推断，适用于浏览器和 Node.js
  • Vue Resource ⭐ 10.5k — Vue.js 早期官方 HTTP 客户端插件（已归档停维，推荐迁移至 Axios），提供拦截器、请求/响应转换和基于 Promise 的 API，曾是 Vue 1/2 时代的标配
  • ofetch ⭐ 5.9k — 基于原生 Fetch API 的智能封装，自动解析 JSON、智能处理错误、支持自动重试和拦截器，Nuxt 3 内置使用，适用于 Node.js、浏览器和 Worker 环境
  • Wretch ⭐ 5.1k — 基于 Fetch API 的超轻量封装（gzip 后约 1.8KB），提供不可变链式 API、中间件系统、错误处理辅助方法和 TypeScript 支持，兼容浏览器、Node.js、Deno 和 Bun
  • Zodios ⭐ 3.2k — 基于 Zod 和 Axios 的类型安全 API 客户端，提供端到端类型校验、请求/响应自动验证、完整的 IDE 自动补全和插件系统
  • Restfox ⭐ 2.7k — 基于 Vue 3 的离线优先 HTTP/WebSocket 测试客户端，支持环境变量、请求历史、插件扩展和 PWA 部署，可用作 Postman 的轻量级替代品
  • vue-axios ⭐ 2.5k — Axios 的 Vue 插件封装，将 Axios 实例注入 Vue 应用上下文，支持 Vue 2/3，提供简洁的全局 HTTP 请求方案
  • Unfetch ⭐ 5.7k — 超轻量级 fetch 封装（~500B），兼容浏览器和 Node.js，API 与原生 fetch 一致，Vue 项目中替代 Axios 的极简 HTTP 方案
  • Cross Fetch ⭐ 4.5k — 跨平台 fetch 实现，统一浏览器、Node.js 和 React Native 的 HTTP 请求接口，Vue SSR 项目中保持一致请求体验

API 开发与管理平台 ​

  • Hoppscotch ⭐ 67k — 基于 Vue 3 构建的开源 API 开发生态平台，支持 REST/GraphQL/WebSocket/MQTT/SSE，提供 Tauri 桌面客户端和 CLI 工具，是 Postman 的主流开源替代方案
  • Swagger UI ⭐ 30.5k — 业界标准的 OpenAPI 文档可视化工具，从 OpenAPI 规范动态生成交互式 API 文档，支持在线调试和请求测试
  • Redoc ⭐ 23k — 基于 OpenAPI 规范的 API 文档生成工具，提供三栏响应式布局和深度搜索功能，Vue 项目常用作文档展示方案
  • Scalar ⭐ 21.0k — 现代化的 API 文档与交互式参考工具，支持从 OpenAPI/Swagger 规范生成美观的文档界面，提供 Vue 组件可直接嵌入项目
  • Swagger Editor ⭐ 8.8k — Swagger 官方 OpenAPI 可视化编辑器，支持实时 YAML/JSON 编辑与预览，帮助开发者快速设计和编写 API 规范

GraphQL 与类型安全 API ​

  • Apollo Client ⭐ 19.3k — 业界领先的 GraphQL 客户端，支持 React/Vue/Angular/Svelte 等多框架，提供零配置缓存、TypeScript 优先设计和声明式数据管理
  • graphql-request ⭐ 11.5k — 最小化的 GraphQL 客户端，API 简洁直观，支持浏览器和 Node.js，内置 TypeScript 类型支持
  • graphql-code-generator ⭐ 11k — 基于 GraphQL Schema 自动生成 TypeScript 类型和 Vue Composition 函数，大幅提升 Vue + GraphQL 开发体验和类型安全
  • urql ⭐ 9.7k — 高度可扩展的 GraphQL 客户端，支持 Vue 集成，提供灵活的缓存策略、分页处理和订阅功能
  • Vue Apollo ⭐ 3.0k — Apollo GraphQL 的官方 Vue.js 集成库，支持查询、变更和订阅操作，提供智能缓存、DevTools 集成和 TypeScript 类型生成
  • graphql-tag ⭐ 2.3k — Apollo 出品的 GraphQL 查询模板字面量解析工具，支持 .gql/.graphql 文件直接在 Vue SFC 中内联编写查询语句
  • villus ⭐ 850 — 专为 Vue 3 设计的小巧 GraphQL 客户端，体积小于 4KB，支持 Composition API、Suspense 和 TypeScript 类型推断

数据获取与缓存管理 ​

  • TanStack Query (Vue) ⭐ 49.0k — TanStack Query 的 Vue 3 绑定（原 React Query），强大的异步状态管理与服务端数据同步方案，内置缓存、自动刷新、乐观更新、分页/无限滚动和离线优先策略
  • VueUse ⭐ 22.5k — Vue 组合式工具集，内置 useFetch 提供响应式 Fetch API，支持请求中止、URL 变化自动重取、自定义配置和类型推断，是 Vue 3 生态必备工具库
  • Pinia ⭐ 14.6k — Vue.js 官方推荐的状态管理库，基于 Composition API 设计，类型安全、轻量灵活，支持 DevTools 调试、插件扩展和模块化 Store，适合管理 API 数据状态
  • Alova ⭐ 4.7k — 新一代轻量级请求策略库，API 极简，内置请求缓存、请求共享、重试机制、进度追踪和工作流编排，支持 Vue/React/Svelte/小程序等多平台
  • unplugin-auto-import ⭐ 3.8k — 通用构建工具插件，可按需自动导入 VueUse、Alova 等库的组合式函数，减少手动 import 样板代码
  • swrv ⭐ 3.0k — Kong 开源的 stale-while-revalidate 缓存策略 Vue 3 实现，支持数据缓存、自动重新验证、乐观更新和错误重试
  • Vue API Query ⭐ 1.8k — 声明式 REST API 查询构建器，为 Vue 项目提供 Eloquent 风格的 API 查询语法，简化 RESTful 接口调用和数据管理
  • Vue Request ⭐ 1.4k — 受 SWR 启发的 Vue 数据请求库，支持缓存、重试、防抖节流、轮询和分页等高级特性，兼容 Vue 2/3

BaaS / 后端即服务 ​

  • Appwrite ⭐ 56k — 开源 Firebase 替代方案，提供数据库、认证、存储、云函数和实时功能等完整后端服务，支持自部署和多平台 SDK
  • Directus ⭐ 34.0k — 开源 Headless CMS 和数据平台，可将任何 SQL 数据库即时转换为 REST/GraphQL API，提供完整的 Vue 集成方案
  • Firebase JS SDK ⭐ 4.8k — Firebase 官方 JavaScript SDK，提供认证、数据库、存储、云函数等完整的 Firebase 服务端能力，是 Vuefire 的底层依赖
  • Supabase JS ⭐ 4.2k — Supabase 官方 JavaScript SDK，提供数据库查询、实时订阅、文件存储和身份验证等功能，是 Firebase 的开源替代方案
  • Vuefire ⭐ 3.1k — Vue.js 官方 Firebase 绑定库，以声明式方式将 Firestore 和 Realtime Database 数据绑定到 Vue 组件，自动处理数据同步和状态更新
  • PocketBase JS SDK ⭐ 2.5k — 轻量级开源 BaaS PocketBase 的官方 JS SDK，支持认证管理、数据库操作和文件存储，与 Vue 生态配合良好

实时通信 (WebSocket/SSE) ​

  • Socket.IO Client ⭐ 15.2k — Socket.IO 官方 JavaScript 客户端，提供实时双向事件驱动通信、自动重连、命名空间和房间功能
  • SockJS Client ⭐ 8.6k — SockJS 浏览器客户端，在浏览器和服务器之间建立实时双向通道，不支持 WebSocket 时自动降级到其他传输方式
  • MQTT.js ⭐ 7.1k — MQTT 协议 JavaScript 客户端，适用于物联网设备通信和消息队列场景，支持 QoS 等级、持久化会话和 WebSocket/WSS 传输
  • fetch-event-source ⭐ 3.3k — 微软开源的 SSE 客户端库，基于 Fetch API 实现，支持自动重连、流式响应处理和身份验证，适用于 AI 对话流式输出等场景
  • crossws ⭐ 1.6k — 跨平台 WebSocket 库，支持 Node.js、Deno、Bun 和浏览器，提供统一的 WebSocket API 和适配器模式
  • Vue Socket.io ⭐ 1.5k — Socket.io 的 Vue 集成库，提供声明式事件绑定和全局 Socket 实例管理，支持 Vue 2/3
  • EventSource Polyfill ⭐ 1.5k — SSE (Server-Sent Events) Polyfill 实现，为不支持 EventSource API 的浏览器提供兼容层
  • vue-websocket ⭐ 1.2k — Vue 原生 WebSocket 插件，通过 $socket API 和声明式事件订阅简化实时通信开发，支持自动重连和心跳检测
  • vue-native-websocket ⭐ 1.0k — 原生 WebSocket 的 Vue 实现，支持 Vue 2/3，提供声明式事件绑定、自动重连、心跳检测、Vuex 集成和二进制数据传输
  • STOMP.js ⭐ 880 — STOMP 协议的 JavaScript 客户端，常与 WebSocket/SockJS 配合使用，实现面向消息的发布/订阅通信模式

文件上传 ​

  • Uppy ⭐ 28k — 业界领先的开源文件上传组件，支持拖拽、分片上传、断点续传，提供 @uppy/vue 官方 Vue 组件和丰富的插件生态
  • vue-cropper ⭐ 3.5k — Vue 图片裁剪上传组件，基于 cropperjs，支持裁剪预览、缩放控制、旋转和移动端适配，配置选项丰富
  • vue-upload-component ⭐ 2.3k — 功能完善的 Vue 文件上传组件，支持拖拽上传、文件预览、多文件上传、进度追踪和自定义上传请求
  • vue-dropzone ⭐ 2k — Dropzone.js 的 Vue 封装，提供优雅的拖拽上传界面和文件预览功能，支持多文件上传和队列管理
  • vue-simple-uploader ⭐ 1.5k — 基于 simple-uploader.js 的 Vue 上传组件，支持断点续传、分片上传、文件夹上传、队列管理和文件校验

Mock 数据与测试 ​

  • json-server ⭐ 75.3k — 零代码 30 秒创建完整 REST API 的 Mock 工具，仅需一个 JSON 文件即可模拟增删改查、分页、排序和过滤等完整 API 功能
  • msw ⭐ 20.5k — Mock Service Worker，通过 Service Worker 拦截网络层请求实现无侵入式 API Mock，同时支持浏览器和 Node.js 测试环境
  • Faker.js ⭐ 12k — 大规模生成模拟数据的工具库，支持中文等多种语言，可与 json-server 配合在 Vue 项目中快速构建逼真的 Mock 数据集
  • Nock ⭐ 12k — Node.js HTTP 拦截与 Mock 库，适合 Vue SSR（Nuxt）或 Vitest 服务端测试场景，支持条件匹配和请求断言
  • Mirage JS ⭐ 5.3k — 客户端 API Mock 框架，可在浏览器端模拟完整 API 服务器，让 Vue 前端无需后端即可独立开发和测试
  • Axios Mock Adapter ⭐ 2.6k — Axios 请求模拟适配器，用于单元测试中拦截 Axios 请求并返回 Mock 数据，无需修改业务代码即可完成前后端分离测试
  • vitest-fetch-mock ⭐ 520 — Vitest 专用的 Fetch API Mock 工具，兼容 jest-fetch-mock API，支持条件 Mock 和请求断言

本地数据存储 ​

  • localforage ⭐ 26.0k — 改进的浏览器离线存储方案，以简洁 API 封装 IndexedDB/WebSQL/localStorage，提供类似 localStorage 的异步存储体验
  • PouchDB ⭐ 16.8k — 支持与 CouchDB 同步的浏览器端数据库，适用于 Vue 离线优先应用，提供强大的数据同步和冲突解决能力
  • Dexie.js ⭐ 12k — IndexedDB 极简封装，API 接近 MongoDB 风格，是 Vue 项目中浏览器端本地数据持久化的首选方案
  • idb ⭐ 6.5k — 微型 IndexedDB Promise 封装，TypeScript 原生支持，API 简洁，是 Vue 项目轻量本地存储的首选库
  • jsonapi-vuex ⭐ 800 — JSON:API 规范的 Vuex 集成库，自动将 JSON:API 响应转换为 Vuex Store 状态，支持关系数据加载和缓存

第三方服务与类型安全集成 ​

  • tRPC ⭐ 40.2k — 端到端类型安全的 RPC 框架，无需 Schema 或代码生成即可实现全自动类型推断和 IDE 补全，通过社区适配器可与 Vue 3 集成使用
  • vue-contentful ⭐ 1.5k — Contentful 无头 CMS 的 Vue 集成组件，支持富文本渲染、资源管理和内容类型映射
  • strapi-sdk-javascript ⭐ 1.2k — Strapi 官方 JavaScript SDK，提供完整的 REST/GraphQL API 客户端，方便 Vue 项目对接 Strapi 无头 CMS
  • @vue-stripe/vue-stripe ⭐ 1.1k — Stripe 官方 Vue 3 集成库，提供 Checkout 和 Elements 组件，支持 40+ 支付方式和完整 TypeScript 类型
  • OpenAPI TypeScript ⭐ 5.8k — 从 OpenAPI 规范自动生成 TypeScript 类型，与 Vue 项目的 Axios/Fetch 客户端完美配合，实现端到端类型安全
  • @hey-api/openapi-ts ⭐ 3.2k — 现代化的 OpenAPI TypeScript 代码生成器，从 OpenAPI 规范自动生成类型安全的 HTTP 客户端代码，Vue 项目类型安全 API 调用首选
  • Orval ⭐ 5.2k — 从 OpenAPI/Swagger 规范自动生成 Vue/React TypeScript HTTP 客户端，集成 TanStack Query/Pinia，支持 MSW mock 和 Zod 验证

API网关与代理 ​

  • Kong ⭐ 41.7k — 开源 API 网关，提供认证、限流、日志和监控插件，Vue 全栈项目中对前端 API 请求的统一入口管理和安全防护
  • Traefik ⭐ 55.2k — 云原生反向代理和负载均衡器，自动发现服务和 HTTPS 证书管理，Vue Docker 部署时的 API 路由和代理方案
  • Nginx Proxy Manager ⭐ 25.5k — Nginx 的 Web 管理界面，支持 SSL 自动续期和反向代理配置，Vue 项目自托管部署时的 API 代理管理利器
  • Vite Proxy ⭐ 73.6k — Vite 内置开发代理功能，通过 vite.config.ts 配置代理规则，Vue 开发环境中轻松解决跨域 API 调用问题

请求监控与日志 ​

  • Sentry Vue ⭐ 8.4k — Sentry 前端错误监控 SDK，自动捕获 Vue 组件的 HTTP 请求错误、Promise 异常和性能瓶颈，提供完整的错误追踪和回放
  • OpenTelemetry JS ⭐ 3.1k — OpenTelemetry JavaScript 实现，为 Vue 应用的 HTTP 请求添加分布式追踪，可视化微服务间的 API 调用链路
  • Vue DevTools API Monitor ⭐ 1k — Vue HTTP 请求监控面板，记录所有 API 调用的耗时、状态码和响应数据，开发调试时快速定位接口问题

API性能测试 ​

  • K6 ⭐ 28.3k — Grafana 开源的性能测试工具，用 JavaScript 编写测试脚本，对 Vue 后端 API 进行负载测试和压力测试
  • Artillery ⭐ 8.9k — 云原生的负载测试工具，通过 YAML 配置发起 HTTP/WebSocket 并发测试，Vue 全栈应用的 API 性能基准测试方案
  • Postman CLI ⭐ 7.1k — Postman 集合命令行运行器，CI/CD 中自动执行 Vue 项目的 API 测试集合并生成报告，实现接口测试自动化

  • Vue Request Cache ⭐ 1.1k — Vue HTTP 请求缓存插件，支持内存/IndexedDB 缓存、缓存过期策略和手动失效，减少重复 API 请求

SSE与实时推送 ​

  • Vue SSE ⭐ 1.3k — Vue 3 Server-Sent Events 封装，提供 useEventSource composable 的声明式 SSE 连接管理和自动重连
