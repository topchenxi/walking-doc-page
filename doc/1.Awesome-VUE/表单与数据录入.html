数据验证库 ​

  • Zod ⭐ 40.6k — TypeScript 优先的 Schema 验证库，提供强大的类型推断和验证规则，可与 VeeValidate、FormKit 等表单库无缝集成
  • Valibot ⭐ 15k — 轻量级 TypeScript Schema 验证库，体积仅为 Zod 的三分之一，支持模块化导入和完整的类型推断，适合 Vue 3 项目
  • Formily ⭐ 12.5k — 阿里巴巴开源的跨平台表单解决方案，支持 React/React Native/Vue 2/Vue 3，提供 JSON Schema 驱动的动态表单、联动逻辑和校验引擎
  • ArkType ⭐ 12k — TypeScript 优先的类型验证库，提供编译时和运行时类型检查，性能优于 Zod，适合高性能表单场景
  • Regle ⭐ 1k — 无头模型验证库，Vuelidate 的现代替代品，完整 TypeScript 类型推断、支持 Zod/Valibot/ArkType Schema，专为 Vue 3 设计
  • vorms ⭐ 800 — 基于 Vue 3 Composition API 的表单状态管理库，受 React Hook Form 启发，提供高性能的表单验证和状态管理
  • Vue Reactive Form ⭐ 600 — 轻量级、类型安全的 Vue 3 表单验证库，利用 Vue 响应式系统，支持 Standard Schema(Zod/Yup/Valibot)，无头 UI 设计
  • Yup ⭐ 23k — 经典的 Object Schema 验证库，VeeValidate 等 Vue 表单库的主力 Schema 引擎，支持链式验证、条件验证和自定义消息
  • Validator.js ⭐ 24k — 强大的字符串验证和清理库，支持 200+ 验证规则，可用于 Vue 表单自定义验证逻辑，广泛应用于后端和前端验证场景

低代码表单生成框架 ​

  • X Render ⭐ 8k — 阿里巴巴开源的中后台「表单/表格/图表/流程编排」开箱即用解决方案，JSON Schema 驱动渲染，支持可视化设计器
  • Form Create ⭐ 7k — 强大的低代码动态表单组件，通过 JSON 数据驱动表单渲染，适配移动端，支持可视化设计器
  • Vue Form Making ⭐ 5.5k — 开源的 Vue 表单设计器，支持拖拽方式快速生成表单，提供丰富的组件、灵活的布局和强大的表单验证功能
  • SurveyJS ⭐ 4.7k — 开源 Vue.js 表单和调查构建器，支持拖拽式设计、条件逻辑分支、CSS 主题编辑器和动态 JSON Schema 驱动
  • Everright-formEditor ⭐ 2k — 可视化低代码表单设计器/编辑器/生成器，支持拖拽操作，适配 Element-Plus 和 Vant
  • Avue Form Design ⭐ 1.2k — 基于 Avue 的可视化表单设计器，通过拖拽操作快速构建表单，支持自定义字段和丰富的配置选项

表单完整解决方案 ​

  • VueFormulate ⭐ 2k — 全功能的 Vue 表单处理库，提供声明式表单语法、内置验证、错误处理和丰富的表单元素类型
