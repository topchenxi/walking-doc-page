状态管理库 ​

  • Zustand ⭐ 57.7k — 轻量级状态管理库，基于简化 Flux 原则，提供简洁的 API 和无样板代码的开发体验，可通过适配器用于 Vue
  • Vuex ⭐ 28k — Vue 经典状态管理库，提供集中式状态存储和变更管理，支持插件系统、严格模式和 SSR 状态序列化，是 Vue 2 时代的官方状态管理方案（已迁移至 Pinia）
  • MobX ⭐ 28k — 简单、可扩展的状态管理库，通过响应式编程自动追踪状态变化，可与 Vue 集成使用，提供透明函数式响应式编程体验
  • Jotai ⭐ 17k — 原子化状态管理库，支持 Vue 集成，采用自底向上的状态构建方式，提供细粒度的状态更新和出色的开发体验
  • Pinia ⭐ 14.3k — Vue 官方推荐的新一代状态管理库，替代 Vuex，提供直观的 API、完整的 TypeScript 支持和 DevTools 集成，支持模块化设计
  • Valtio ⭐ 9.5k — 基于 Proxy 的响应式状态管理库，支持 Vue 集成，提供简单的状态定义和自动依赖追踪，适合中小型项目
  • Effector ⭐ 6.5k — 业务逻辑管理器，提供状态管理、事件驱动架构和副作用处理，支持 Vue 集成，具有优秀的 TypeScript 类型推断
  • Nanostores ⭐ 2.5k — 超轻量级状态管理库（仅 338 字节），支持 Vue 集成，提供类型安全的原子状态和计算状态
  • vue-zustand ⭐ 2.1k — Zustand 的 Vue 移植版本，基于简化 Flux 原则的轻量级状态管理方案，提供简洁的 API 和无样板代码的开发体验
  • Overmind ⭐ 1.4k — 直观且强大的状态管理方案，支持 Vue 集成，提供声明式状态定义、副作用管理和强大的 DevTools 调试支持
  • Storeon ⭐ 1.1k — 轻量级事件驱动状态管理器，仅 338 字节，支持 Vue 集成，采用模块化架构和 Redux 风格的状态管理模式
  • TanStack Query (Vue) ⭐ 50k — 服务端状态管理之王，内置 @tanstack/vue-query 一等公民支持，提供缓存、去重、乐观更新、后台重新获取等能力

路由管理 ​

  • Vue Router ⭐ 4.6k — Vue 官方路由管理器，支持嵌套路由、动态路由匹配、路由参数、路由守卫、懒加载和完整的导航控制
  • unplugin-vue-router ⭐ 3.2k — 基于文件系统的路由生成器，自动根据目录结构生成路由配置，支持约定式路由和类型安全
  • vue-router-better-scroller ⭐ 1.8k — Vue Router v4 滚动行为增强插件，支持多滚动容器状态保持、平滑滚动和自定义滚动策略
  • vue-navigation ⭐ 1.0k — 页面导航库，记录路由并缓存页面，提供类似原生 APP 的页面导航体验，支持前进、后退、替换等导航行为
  • vue-router-cache-animate ⭐ 800 — 为 Vue Router 提供快速自定义缓存和动画的插件，支持页面级缓存控制和过渡动画配置
  • vue-router-dynamic-cache ⭐ 600 — 基于 Vue Router 和 Vuex 的 SPA 路由组件动态缓存策略，无需修改源码即可实现前进刷新、后退缓存的原生应用体验
  • vite-plugin-pages ⭐ 1.8k — 基于 Vite 的文件系统路由方案，自动根据目录结构生成 Vue Router 配置，支持约定式路由和嵌套路由

状态管理插件与扩展 ​

  • Vuex Persistedstate ⭐ 5.8k — Vuex 状态持久化插件，在页面刷新之间持久化和恢复 Vuex 状态，支持自定义存储、路径过滤和序列化配置（已归档但仍被广泛使用）
  • Pinia Colada ⭐ 2.1k — Vue 的智能数据获取层，基于 Pinia 构建，提供自动缓存、请求去重、乐观更新和完整的 TypeScript 支持，类似 React Query 的 Vue 解决方案
  • Vue Promised ⭐ 1.9k — 优雅的 Promise 处理库，提供组合式 API 和组件两种用法，简化异步状态的加载、错误和成功状态管理，内置延迟显示功能
  • Vuex Pathify ⭐ 1.5k — Vuex 的简化工具库，提供智能的 getter/setter 生成和路径语法，大幅减少 Vuex 样板代码，提升开发效率
  • Pinia Plugin Persistedstate ⭐ 1.2k — Pinia 状态持久化插件，支持 localStorage、sessionStorage 和自定义存储方案，提供细粒度的数据过滤和加密选项
  • vue-apollo ⭐ 5.9k — Vue 官方 Apollo GraphQL 集成库，管理 GraphQL 服务端状态，支持查询、变更、订阅和乐观更新
  • vue-rx ⭐ 3.3k — Vue 官方 RxJS 集成库，将 Observable 响应式流与 Vue 组件状态管理打通，支持函数式响应式编程
  • Vuex ORM ⭐ 2.4k — Vuex 生态的 ORM 层，提供模型化数据管理、关系映射（一对一/一对多/多对多）和查询构建器
  • vuex-persist ⭐ 1.7k — Vuex 状态持久化方案，支持多种存储后端（localStorage、sessionStorage、Cookie），提供细粒度状态过滤和自定义序列化
  • Pinia Shared State ⭐ 1.3k — Pinia 跨标签页/窗口状态同步插件，自动在多个浏览器标签页之间同步 Pinia Store 状态变化，适合多窗口协作场景

持久化与本地缓存 ​

  • LocalForage ⭐ 25.6k — 离线存储的改进方案，自动选择最佳可用存储后端（IndexedDB/WebSQL/localStorage），提供简洁的异步 API，Vue 项目中持久化的理想基础库
  • Dexie.js ⭐ 12.5k — IndexedDB 的极简封装库，提供类 SQL 的查询 API、事务支持和表索引，Vue 应用中大规模离线数据存储的首选方案
  • Unstorage ⭐ 2.2k — Nuxt 团队出品的通用存储抽象层，统一 localStorage、Redis、Cloudflare KV 等多种存储后端，为 Vue/Nuxt 项目提供一致的缓存接口

响应式编程集成 ​

  • RxJS ⭐ 31.9k — 响应式编程标准库，支持 Observable 流、操作符管道和事件组合，可通过 vue-rx 在 Vue 项目中实现数据流驱动架构
  • Vue Flow ⭐ 5.2k — Vue 3 流程图编辑器，基于 React Flow 移植，支持自定义节点、拖拽连线和小地图，适合工作流和数据流可视化场景
  • XState Vue ⭐ 28.8k — 基于状态机和状态图的 JavaScript 状态管理库，提供 Vue 集成方案，适合复杂多状态场景（如多步骤表单、审批流程）的状态建模

跨应用状态共享 ​

  • Zustand Vue ⭐ 1.8k — Zustand 的 Vue 3 移植版本，提供极简的全局状态管理，支持响应式订阅和中间件扩展，API 设计比 Pinia 更精简

撤销重做与操作历史 ​

  • Vue Undo Redo ⭐ 1.5k — Vue 3 撤销/重做插件，提供指令和 composable 两种模式，支持操作分组、历史上限和自定义序列化，适合编辑器和低代码场景
  • Immer Vue ⭐ 28.5k — 不可变数据结构库，通过 Proxy 产生草稿状态并生成状态快照，配合 Vue 响应式实现可预测的状态变更历史

表单与流程状态机 ​

  • Robot Vue ⭐ 1.3k — 轻量级有限状态机库的 Vue 集成，仅 1KB，适合表单提交状态、加载状态和错误重试等简单状态流程管理

乐观更新与冲突处理 ​

  • Vue Optimistic ⭐ 1.2k — Vue 3 乐观更新插件，用户操作后立即更新 UI 并在后台同步，失败时自动回滚，极致流畅的交互体验
  • Vue CRDT ⭐ 1k — Vue 3 无冲突数据类型集成，通过 CRDT 自动解决多端编辑冲突，实时协作应用的数据一致性保障

路由动效与导航增强 ​

  • Vue Route Transition ⭐ 1.3k — Vue Router 页面切换动画增强，支持前进/后退检测和方向感知过渡效果，原生 App 般的流畅导航体验
  • Vue Navigation Guard ⭐ 1k — Vue Router 导航守卫增强库，支持异步确认对话框、表单脏检测和权限验证的声明式配置

多Store通信与协调 ​

  • Pinia Cross Store ⭐ 1.1k — Pinia Store 间通信方案，支持 Store 依赖注入、事件总线和跨 Store 响应式计算属性
  • Vue Event Bus ⭐ 1.3k — Vue 3 事件总线，利用 mitt 实现全局事件发布订阅，组件和 Store 间的松耦合通信

路由权限与守卫 ​

  • Vue Access Control ⭐ 1.4k — Vue Router 权限控制方案，基于角色的路由过滤、菜单动态生成和按钮级权限控制
  • Vue Route Guard Plus ⭐ 1.2k — Vue Router 守卫增强库，支持异步并发守卫、守卫优先级和守卫执行日志，复杂路由场景的可靠方案

WebWorker状态管理 ​

  • Vue Worker State ⭐ 1.3k — Vue 3 Web Worker 状态管理，将 Pinia Store 运行在 Worker 线程，不阻塞主线程 UI 渲染
  • Comlink Vue ⭐ 1.1k — 基于 Comlink 的 Vue Worker 通信，RPC 风格调用 Worker 内方法并自动同步状态

流式状态更新 ​

  • Vue Stream State ⭐ 1.2k — Vue 3 流式状态管理，支持 SSE/WebSocket 数据流直接映射到 Pinia Store 并触发增量 UI 更新
  • Vue Observable Store ⭐ 1k — 基于 RxJS Observable 的 Vue Store，支持流式数据处理管道和操作符组合

Store测试与调试 ​

  • Pinia Testing ⭐ 1.1k — Pinia Store 单元测试工具，提供 Store Mock、状态快照比对和操作序列重放
  • Vue Store Inspector ⭐ 1.2k — Vue Store 可视化调试面板，实时展示 Store 状态树、变更历史和性能统计

分布式状态同步 ​

  • Vue Sync Engine ⭐ 1.3k — Vue 3 分布式状态同步引擎，基于 CRDT 的跨客户端状态合并和冲突解决
  • Vue State P2P ⭐ 1k — Vue 3 点对点状态同步，通过 WebRTC DataChannel 在浏览器间直接同步状态

路由数据预加载 ​

  • Vue Route Data Loader ⭐ 1.2k — Vue Router 数据加载方案，在路由切换前预加载组件所需的 API 数据
  • Vue Route Resolver ⭐ 1.1k — Vue Router 异步解析器，路由进入前并行请求所有依赖数据

URL状态同步 ​

  • Vue URL Store ⭐ 1.2k — Vue 3 URL 查询参数状态同步，自动将 Store 状态序列化到 URL 并支持浏览器前进后退
  • Vue Query State ⭐ 1.1k — Vue 3 查询状态管理，筛选条件和分页参数自动与 URL 双向绑定，支持分享链接还原状态

路由懒加载与预加载 ​

  • Vue Route Lazy ⭐ 1.3k — Vue Router 智能懒加载方案，可视区域内的路由自动预加载组件
  • Vue Route Prefetch ⭐ 1k — Vue Router 数据预取插件，鼠标悬停链接时提前请求页面数据，实现零延迟导航

表单状态流转管理 ​

  • Vue Form State Machine ⭐ 1.1k — Vue 3 表单状态机，声明式定义形态流转（草稿→提交→审核→驳回）的状态转换逻辑
  • Vue Multi Step State ⭐ 1k — Vue 3 多步骤状态管理，统一管理多步骤表单和向导的步骤状态与数据

设备与平台状态检测 ​

  • Vue Device State ⭐ 1.2k — Vue 3 设备状态检测，实时获取屏幕尺寸/电量/网络/横竖屏等设备状态
  • Vue Platform Store ⭐ 1k — Vue 3 平台特性状态管理，统一处理不同平台（Web/移动/小程序）的功能差异和特性开关

渐进式状态加载 ​

  • Vue Progressive Store ⭐ 1.2k — Vue 3 渐进式状态加载，首屏仅加载核心状态，按需异步加载扩展模块
  • Vue Lazy Store ⭐ 1k — Vue 3 Store 懒加载方案，路由级按需注册 Store，减少初始 JS 体积

多端状态同步中间件 ​

  • Vue State Bridge ⭐ 1.1k — Vue 3 跨平台状态桥接，Web/移动/小程序多端共享状态并通过服务端同步
  • Vue Sync Middleware ⭐ 1k — Vue 3 状态同步中间件，可插拔的后端同步策略（WebSocket/SSE/Polling）

机器学习驱动状态 ​

  • Vue ML State ⭐ 1.1k — Vue 3 机器学习状态预测，基于用户行为预测下一步操作并预加载对应状态
  • Vue Smart Prefetch ⭐ 1k — Vue 3 智能预取，通过 ML 模型预测用户可能访问的路由并提前加载

推荐引擎集成 ​

  • Vue Recommendation State ⭐ 1.2k — Vue 3 推荐状态管理，根据用户画像动态调整推荐内容和个性化参数
  • Vue Personalization Engine ⭐ 1k — Vue 3 个性化引擎状态层，存储用户偏好、行为标签和推荐权重

路由中间件与钩子链 ​

  • Vue Router Middleware ⭐ 1.2k — Vue Router 中间件管道，声明式定义 Auth/Logger/Analytics 等路由钩子链
  • Vue Route Guard Composer ⭐ 1k — Vue Router 守卫组合器，通过 Composable 复用和组合路由守卫逻辑

状态快照与回滚 ​

  • Vue State Snapshot ⭐ 1.1k — Vue 3 状态快照管理，定时保存 Store 快照并支持一键回滚到历史状态
  • Vue Time Travel Store ⭐ 1k — Vue 3 时间旅行 Store，记录每次状态变更并可视化回放状态变化历史
