React 面试题目 ​

一、React 基础 ​

  1. 谈谈你对 React 的理解？有哪些特性？
  2. React 与 Vue 的异同点有哪些？
  3. JSX 是什么？JSX 的本质是什么？
  4. JSX 如何转换成真实 DOM？
  5. JSX 编译规则是什么？（小写字母原生 DOM，大写字母自定义组件）

二、组件与 Props ​

  1. 函数组件与类组件的区别是什么？
  2. Props 和 State 有什么区别？
  3. Props 有什么特点？（只读性）
  4. 如何设置 Props 默认值和验证？
  5. 组件间通信的方式有哪些？

三、State 与生命周期 ​

  1. setState 的原理和使用注意事项是什么？
  2. setState 是同步还是异步？在什么场景下是同步/异步？
  3. React 生命周期方法有哪些？
  4. 挂载阶段的生命周期有哪些？（constructor、componentDidMount 等）
  5. 更新阶段的生命周期有哪些？（shouldComponentUpdate、componentDidUpdate 等）
  6. 卸载阶段的生命周期有哪些？（componentWillUnmount）
  7. getDerivedStateFromProps 和 getSnapshotBeforeUpdate 的作用是什么？

四、事件处理 ​

  1. React 事件处理有什么特点？
  2. 什么是合成事件？与原生事件有什么区别？
  3. React 事件机制是怎样的？（事件委托）
  4. 如何解决 this 绑定问题？

五、列表与 Keys ​

  1. key 的作用是什么？
  2. 为什么列表渲染需要 key？
  3. 使用 index 作为 key 有什么问题？
  4. key 的最佳实践是什么？

六、表单处理 ​

  1. 什么是受控组件？
  2. 什么是非受控组件？
  3. 受控组件与非受控组件的区别是什么？

七、Context API ​

  1. Context API 是什么？有什么应用场景？
  2. React.createContext、Provider、Consumer 如何使用？
  3. useContext Hook 如何使用？
  4. Context 有什么性能问题？

八、React Router ​

  1. React Router 的基本使用方法是什么？
  2. BrowserRouter 和 HashRouter 的区别是什么？
  3. Route、Link、NavLink、Switch、Redirect 的作用是什么？
  4. 路由传参的方式有哪些？
  5. useHistory、useLocation、useParams、useRouteMatch 的作用是什么？
  6. React Router v6 有哪些变化？

九、状态管理 ​

  1. Redux 的核心概念有哪些？（Store、Action、Reducer、Dispatch）
  2. Redux 的工作流程是什么？
  3. Redux 中间件有哪些？（redux-thunk、redux-saga）
  4. React Redux 的 connect 和 Provider 如何使用？
  5. useSelector 和 useDispatch 如何使用？
  6. MobX 的核心概念有哪些？
  7. MobX 与 Redux 的区别是什么？
  8. Redux 与 Vuex 的区别是什么？

十、React Hooks ​

  1. React Hooks 有哪些优势？
  2. useState 如何使用？
  3. useEffect 如何使用？与生命周期如何对应？
  4. useEffect 的依赖数组如何设置？
  5. useEffect 的清理函数有什么作用？
  6. useContext 如何使用？
  7. useReducer 如何使用？
  8. useCallback 和 useMemo 的区别是什么？
  9. useRef 如何使用？
  10. useImperativeHandle 如何使用？
  11. useLayoutEffect 与 useEffect 的区别是什么？
  12. 如何自定义 Hook？
  13. Hooks 使用规则有哪些？

十一、React 原理 ​

  1. 什么是虚拟 DOM？有什么优势？
  2. React Diff 算法是如何工作的？
  3. Fiber 架构是什么？有什么必要性？
  4. Fiber 的优化机制是什么？（优先级调度、时间切片）
  5. React 渲染流程是怎样的？
  6. React 更新流程是怎样的？
  7. React 合成事件原理是什么？

十二、Refs ​

  1. Refs 有什么作用？
  2. createRef 和 useRef 的区别是什么？
  3. forwardRef 如何使用？
  4. Refs 转发是什么？

十三、性能优化 ​

  1. React 性能优化有哪些方法？
  2. shouldComponentUpdate 的作用是什么？
  3. React.memo 和 PureComponent 的作用是什么？
  4. React.lazy 和 Suspense 如何实现懒加载？
  5. 如何避免不必要的渲染？
  6. 代码分割如何实现？

  2. Error Boundaries（错误边界）是什么？

  3. Transitions 是什么？
  4. Suspense for Data Fetching 是什么？

  2. Next.js 如何实现 SSR？
