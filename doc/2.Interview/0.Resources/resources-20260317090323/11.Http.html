HTTP 面试题目 ​

HTTP 协议基础（请求/响应） ​

  1. HTTP 协议是什么？
  2. HTTP 请求报文和响应报文的结构是什么？
  3. HTTP 请求报文由哪几部分组成（请求行、请求头、消息体）？
  4. HTTP 响应报文由哪几部分组成（状态行、响应头、消息体）？
  5. HTTP 起始行的作用是什么？
  6. HTTP 头部有哪些常见字段？
  7. HTTP 消息体的作用是什么？
  8. 完整 HTTP 事务的过程是什么（域名解析、TCP 握手、发送请求、服务器响应、TCP 挥手）？

HTTP 方法（GET、POST、PUT、DELETE 等） ​

  1. HTTP 有哪些常用方法？
  2. GET 与 POST 请求的区别是什么（传参方式、缓存、安全性、长度限制）？
  3. PUT 请求的作用是什么？
  4. DELETE 请求的作用是什么？
  5. PATCH 请求与 PUT 请求的区别是什么？
  6. OPTIONS 请求的作用是什么？
  7. HEAD 请求的作用是什么？
  8. CONNECT 请求的作用是什么？
  9. TRACE 请求的作用是什么？
  10. 什么是幂等性？哪些 HTTP 方法是幂等的？
  11. 什么是安全方法？哪些 HTTP 方法是安全的？

状态码（200、301、404、500 等） ​

  1. HTTP 状态码分为哪几类（1xx 信息性、2xx 成功、3xx 重定向、4xx 客户端错误、5xx 服务器错误）？
  2. 200 OK 表示什么？
  3. 201 Created 表示什么？
  4. 204 No Content 表示什么？
  5. 301 Moved Permanently 与 302 Found 的区别是什么？
  6. 304 Not Modified 表示什么？
  7. 307 Temporary Redirect 与 302 的区别是什么？
  8. 308 Permanent Redirect 与 301 的区别是什么？
  9. 400 Bad Request 表示什么？
  10. 401 Unauthorized 与 403 Forbidden 的区别是什么？
  11. 404 Not Found 表示什么？
  12. 405 Method Not Allowed 表示什么？
  13. 500 Internal Server Error 表示什么？
  14. 502 Bad Gateway 表示什么？
  15. 503 Service Unavailable 表示什么？
  16. 504 Gateway Timeout 表示什么？

请求头与响应头 ​

  1. 常见的 HTTP 请求头有哪些（Content-Type、User-Agent、Accept、Authorization、Cookie 等）？
  2. 常见的 HTTP 响应头有哪些（Set-Cookie、Cache-Control、ETag、Location 等）？
  3. Content-Type 的作用是什么？
  4. Content-Length 的作用是什么？
  5. Content-Encoding 的作用是什么？
  6. Accept 与 Content-Type 的区别是什么？
  7. Accept-Encoding 的作用是什么？
  8. User-Agent 的作用是什么？

  12. Authorization 头部的作用是什么？
  13. WWW-Authenticate 头部的作用是什么？

Cookie 与 Session ​

  1. Cookie 是什么？有哪些属性？
  2. Session 是什么？如何管理？
  3. Cookie 与 Session 的区别是什么（存储位置、安全性、大小限制）？
  4. Cookie 的作用域如何设置？
  5. HttpOnly 属性的作用是什么？

  7. SameSite 属性的作用是什么？

  4. SSL 与 TLS 的区别是什么？
  5. 数字证书是什么？CA 证书的作用是什么？

  7. 混合加密的原理是什么？
  8. 数字签名的作用是什么？
  9. 证书链是什么？
