NodeJS 面试题目 ​

Node.js 基础与模块系统 ​

  1. Node.js 是什么？它有哪些特点？
  2. Node.js 的优缺点是什么？
  3. Node.js 的应用场景有哪些（如 SSR、工具链、高并发 I/O 等）？
  4. Node.js 模块系统是什么？CommonJS 规范是什么？
  5. require 的原理是什么？文件查找的优先级和策略是怎样的？
  6. module.exports 与 exports 的区别是什么？
  7. 模块缓存机制是怎样的？
  8. 模块加载机制是怎样的？
  9. 循环依赖如何处理？
  10. Node.js 有哪些全局对象？global 与浏览器 window 的区别是什么？

异步 I/O 与事件循环 ​

  1. 什么是异步 I/O？Node.js 如何实现非阻塞 I/O？
  2. Node.js 事件循环机制是什么？与浏览器事件循环有何区别？
  3. Node.js 事件循环有哪几个阶段？每个阶段的作用是什么？
  4. timers 阶段的作用是什么？
  5. I/O callbacks 阶段的作用是什么？
  6. idle、prepare 阶段的作用是什么？
  7. poll 阶段的作用是什么？
  8. check 阶段的作用是什么？
  9. close callbacks 阶段的作用是什么？
  10. setImmediate 与 setTimeout 的区别和执行顺序是什么？
  11. process.nextTick 与 setImmediate 的区别是什么？
  12. process.nextTick 的作用是什么？它属于事件循环的哪个阶段？
  13. Node.js 中宏任务和微任务分别有哪些？执行顺序是怎样的？

Buffer ​

  1. Node.js 中的 Buffer 是什么？有哪些应用场景？
  2. Buffer.from() 和 Buffer.alloc() 的区别是什么？
  3. Buffer 与字符串之间如何转换？编码不一致会出现什么问题？
  4. Buffer 在 I/O 操作、加密解密、zlib 压缩中如何使用？

Stream（流） ​

  1. Node.js 中的 Stream 是什么？有哪几种类型？
  2. 可读流、可写流、双工流、转换流分别是什么？
  3. pipe 管道的作用是什么？如何使用？
  4. Stream 的应用场景有哪些（如大文件传输、打包工具底层操作等）？

文件系统操作 ​

  1. fs 模块的作用是什么？有哪些常用方法？
  2. fs.readFile 与 fs.readFileSync 的区别是什么？
  3. fs.writeFile 与 fs.appendFile 的区别是什么？
  4. fs.createReadStream 与 fs.createWriteStream 如何使用？
  5. 同步与异步文件操作各有什么优缺点？
  6. 文件描述符（fd）是什么？
  7. fs 模块的权限位（mode）和标识位（flag）分别是什么含义？

HTTP 服务器 ​

  1. http 模块如何创建 HTTP 服务器？
  2. http.createServer 的用法是什么？
  3. request 对象和 response 对象分别有哪些常用属性和方法？
  4. 如何在 Node.js 中实现路由？
  5. 如何实现静态文件服务？

Express/Koa 框架 ​

  1. Express 框架的特点和基本使用方式是什么？
  2. Express 路由如何配置？
  3. Express 中间件的原理和使用方式是什么？
  4. Express 如何进行错误处理？
  5. Koa 框架的特点和基本使用方式是什么？
  6. Koa 中间件的洋葱模型是什么？与 Express 中间件有何区别？
  7. Koa 与 Express 的区别是什么？
  8. koa-router、koa-bodyparser、koa-static 的作用分别是什么？

中间件机制 ​

  1. 中间件的概念是什么？Node.js 中间件的本质是什么？
  2. 中间件的原理和实现方式是什么？
  3. 中间件的执行顺序是怎样的？
  4. 应用级中间件、路由级中间件、错误处理中间件分别是什么？
  5. 如何封装一个 Node.js 中间件（如 token 校验、日志模块）？

JWT 鉴权 ​

  1. JWT（JSON Web Token）是什么？由哪几部分组成？
  2. JWT 的生成和校验流程是怎样的？
  3. JWT 的优缺点是什么？
  4. 如何在 Koa 中使用 koa-jwt 实现鉴权？

文件上传 ​

  1. 如何在 Node.js 中实现文件上传？
  2. multipart/form-data 的格式和作用是什么？
  3. koa-body 和 koa-multer 如何解析上传的文件？

分页功能设计 ​

  1. 如何设计一个分页功能？前后端如何交互？
  2. 分页查询中 LIMIT 和 OFFSET 的计算方式是什么？

  1. 如何在 Node.js 中连接和操作 MySQL？
  2. MySQL 的增删改查（CRUD）操作如何实现？
  3. MySQL 事务如何使用？
  4. 如何在 Node.js 中连接和操作 MongoDB？
  5. Mongoose 的 Schema 和 Model 是什么？
  6. Redis 的数据类型有哪些？如何在 Node.js 中使用 Redis 缓存？

NPM 包管理 ​

  1. NPM 是什么？package.json 的作用是什么？
  2. npm install 的模块安装机制是怎样的（依赖解析、缓存、扁平化等）？
  3. npm install、npm update、npm uninstall 的区别是什么？
  4. npm scripts 的作用是什么？如何发布一个 npm 包？
  5. npx 的作用是什么？
  6. yarn 和 pnpm 与 npm 的区别是什么？
  7. package-lock.json 和 yarn.lock 的作用是什么？

进程与线程 ​

  1. 进程与线程的区别是什么？
  2. Node.js 中的 child_process 模块有哪些方法（fork、spawn、exec、execFile）？各有什么区别？
  3. cluster 模块的作用是什么？如何实现多进程？
  4. 进程间通信（IPC）如何实现？
  5. worker_threads 模块的作用是什么？如何实现多线程？
  6. 什么是守护进程？如何实现进程守护？
  7. process 对象有哪些常用属性和方法（如 process.env、process.argv、process.nextTick、process.cwd()）？

EventEmitter（事件驱动） ​

  1. Node.js 中的 EventEmitter 是什么？如何使用？
  2. EventEmitter 的常用方法有哪些（on、emit、once、removeListener 等）？
  3. 如何手动实现一个 EventEmitter？

性能优化与调试 ​

  1. Node.js 性能优化有哪些方式（使用最新版本、正确使用 Stream、代码层面优化、内存管理优化等）？
  2. Node.js 如何进行性能监控（CPU、内存、I/O、网络）？
  3. 内存泄漏的原因有哪些？如何排查和解决？
  4. V8 的内存管理机制是什么（新生代、老生代）？

  6. 如何捕获未处理的异常（uncaughtException、unhandledRejection）？
  7. 日志管理工具（如 Winston）如何使用？
