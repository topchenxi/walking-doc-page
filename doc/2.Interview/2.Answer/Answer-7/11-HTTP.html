HTTP 答案 ​

一、HTTP 协议基础 ​

1-3. HTTP 协议与报文结构 ​

问题：HTTP 协议是什么？请求报文和响应报文的结构是什么？

答案：

核心定义：HTTP（超文本传输协议）是应用层协议，基于 TCP/IP，用于客户端和服务器之间传输超文本。

请求报文：

GET /api/users HTTP/1.1    ← 请求行（方法 + URL + 版本）
Host: example.com          ← 请求头
User-Agent: Mozilla/5.0
Accept: application/json
                           ← 空行
                           ← 消息体（GET 无）

响应报文：

HTTP/1.1 200 OK            ← 状态行
Content-Type: application/json
Content-Length: 123
                           ← 空行
{"users": [...]}           ← 消息体

二、HTTP 方法 ​

4-9. HTTP 请求方法与幂等性 ​

问题：GET 与 POST 的区别是什么？什么是幂等性？

答案：

GET vs POST 对比：

维度GETPOST
用途获取资源创建资源
数据位置URL 参数请求体
可缓存✅❌
可收藏✅❌
幂等✅❌

幂等性：多次相同请求的结果与一次请求相同。

  • ✅ 幂等：GET、PUT、DELETE
  • ❌ 不幂等：POST

三、HTTP 状态码 ​

10-14. 状态码分类 ​

问题：HTTP 状态码分为哪几类？常见状态码有哪些？

答案：

分类含义常见状态码
2xx成功200 OK、201 Created、204 No Content
3xx重定向301 永久、302 临时、304 未修改、307 临时
4xx客户端错误400 错误请求、401 未授权、403 禁止、404 未找到
5xx服务器错误500 内部错误、502 网关错误、503 不可用、504 超时

四、HTTP 头部 ​

15-18. 常见 HTTP 头部 ​

问题：常见的请求头/响应头有哪些？Content-Type 有哪些值？

答案：

常见请求头：

  • Content-Type：请求体类型
  • Accept：期望的响应类型
  • Authorization：认证信息
  • Cookie：携带的 Cookie

Content-Type 常见值：

  • application/json
  • application/x-www-form-urlencoded
  • multipart/form-data
  • text/html

五、Cookie 与 Session ​

19-24. Cookie、Session、Token ​

问题：Cookie 和 Session 的区别是什么？JWT 是什么？

答案：

对比表格：

维度CookieSessionJWT
存储客户端服务器客户端
安全性较低较高高
扩展性差差好

Cookie 属性：

  • HttpOnly：禁止 JS 访问（防 XSS）
  • Secure：仅 HTTPS 传输
  • SameSite：限制跨域发送

JWT 结构：Header.Payload.Signature

六、HTTP 缓存 ​

25-29. HTTP 缓存机制 ​

问题：什么是强缓存？什么是协商缓存？区别是什么？

答案：

对比表格：

维度强缓存协商缓存
判断方式Cache-Control、ExpiresETag、Last-Modified
状态码200 (from cache)304 Not Modified
请求服务器否是

缓存流程：

强缓存命中 → 返回 200 (from cache)
强缓存未命中 → 发送请求 → 协商缓存命中 → 返回 304
                            → 协商缓存未命中 → 返回 200 + 新资源

七、HTTPS ​

30-35. HTTPS 工作原理 ​

问题：HTTPS 与 HTTP 的区别是什么？SSL/TLS 握手过程是怎样的？

答案：

HTTPS = HTTP + SSL/TLS 加密

TLS 握手过程：

  1. 客户端发送 ClientHello（支持的加密套件）
  2. 服务器返回 ServerHello + 数字证书
  3. 客户端验证证书，生成会话密钥，用公钥加密
  4. 服务器用私钥解密，双方使用会话密钥通信

加密方式：

  • 非对称加密：交换会话密钥（RSA、ECDHE）
  • 对称加密：传输数据（AES）

九、跨域 ​

40-47. 跨域解决方案 ​

问题：什么是同源策略？跨域解决方案有哪些？CORS 是什么？

答案：

同源策略：协议、域名、端口都相同。

CORS 配置：

javascript
// 服务器设置响应头
Access-Control-Allow-Origin: *
Access-Control-Allow-Methods: GET, POST
Access-Control-Allow-Headers: Content-Type

简单请求：直接发送 预检请求：先发送 OPTIONS 请求，确认后再发送实际请求

十、TCP/IP ​

48-51. TCP 三次握手与四次挥手 ​

问题：TCP 与 UDP 的区别是什么？三次握手和四次挥手的过程是什么？

答案：

TCP vs UDP：

维度TCPUDP
连接面向连接无连接
可靠✅❌
速度慢快

三次握手：SYN → SYN+ACK → ACK 四次挥手：FIN → ACK → FIN → ACK

十三、安全 ​

60-62. XSS、CSRF、点击劫持 ​

问题：什么是 XSS 攻击？如何防范？什么是 CSRF 攻击？

答案：

XSS（跨站脚本攻击）：注入恶意脚本

  • 防御：转义输入、CSP、HttpOnly Cookie

CSRF（跨站请求伪造）：利用已登录身份发送请求

  • 防御：CSRF Token、SameSite Cookie、验证 Referer

点击劫持：透明 iframe 覆盖诱导点击

  • 防御：X-Frame-Options、CSP

十四、其他 ​

63. 从输入网址到页面呈现的完整过程 ​

问题：从输入网址到页面呈现的完整过程是什么？

答案：

  1. DNS 解析域名 → IP 地址
  2. TCP 三次握手建立连接
  3. TLS 握手（HTTPS）
  4. 发送 HTTP 请求
  5. 服务器处理请求，返回响应
  6. 浏览器解析 HTML → 构建 DOM 树
  7. 解析 CSS → 构建 CSSOM 树
  8. 合并为渲染树
  9. 布局（计算位置大小）
  10. 绘制（渲染到屏幕）
