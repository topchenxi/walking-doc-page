一、复杂度分析 ​

1. 什么是时间复杂度？常见的时间复杂度有哪些？ ​

问题：什么是时间复杂度？常见的时间复杂度有哪些？

答案：

核心定义：时间复杂度是衡量算法执行时间随输入规模增长的变化趋势，用大 O 表示法。

常见时间复杂度（从优到劣）：

O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2ⁿ) < O(n!)

示例：

  • O(1)：数组索引访问 arr[i]
  • O(log n)：二分查找
  • O(n)：遍历数组
  • O(n log n)：快速排序、归并排序
  • O(n²)：冒泡排序、双重循环

2-3. 空间复杂度与大 O 表示法 ​

问题：什么是空间复杂度？什么是大 O 表示法？

答案：

空间复杂度：算法占用内存空间随输入规模增长的变化趋势。

大 O 表示法：忽略常数项和低阶项，只保留最高阶项。

javascript
// O(n) 空间复杂度
function copyArray(arr) {
  return [...arr] // 创建新数组，空间与输入成正比
}

// O(1) 空间复杂度
function reverseInPlace(arr) {
  let left = 0, right = arr.length - 1
  while (left < right) {
    [arr[left], arr[right]] = [arr[right], arr[left]]
    left++, right--
  }
  return arr // 原地修改，不需要额外空间
}

5-8. 数组与链表 ​

问题：数组与链表的区别是什么？单向链表、双向链表、循环链表的区别是什么？

答案：

对比表格：

维度数组链表
内存布局连续不连续
随机访问O(1)O(n)
插入/删除O(n)O(1)（已知位置）
扩容需要不需要

链表类型：

  • 单向链表：每个节点只有一个指向下一个的指针
  • 双向链表：每个节点有前驱和后继指针
  • 循环链表：尾节点指向头节点
javascript
// 链表节点定义
class ListNode {
  constructor(val) {
    this.val = val
    this.next = null
  }
}

// 反转链表
function reverseList(head) {
  let prev = null, curr = head
  while (curr) {
    const next = curr.next
    curr.next = prev
    prev = curr
    curr = next
  }
  return prev
}

13-20. 树 ​

问题：二叉树的特点是什么？遍历如何实现？二叉搜索树、平衡二叉树、红黑树的特点是什么？

答案：

二叉树遍历：

javascript
// 前序遍历（根左右）
function preorder(root) {
  if (!root) return
  console.log(root.val)
  preorder(root.left)
  preorder(root.right)
}

// 中序遍历（左根右）→ BST 中序遍历得到有序序列
function inorder(root) {
  if (!root) return
  inorder(root.left)
  console.log(root.val)
  inorder(root.right)
}

// 层序遍历（BFS）
function levelOrder(root) {
  if (!root) return []
  const queue = [root], result = []
  while (queue.length) {
    const level = []
    for (let i = queue.length; i > 0; i--) {
      const node = queue.shift()
      level.push(node.val)
      if (node.left) queue.push(node.left)
      if (node.right) queue.push(node.right)
    }
    result.push(level)
  }
  return result
}

树的类型：

  • 二叉搜索树（BST）：左子树 < 根 < 右子树
  • 平衡二叉树（AVL）：左右子树高度差 ≤ 1
  • 红黑树：自平衡二叉搜索树，用于 Map/Set
  • B/B+ 树：多路搜索树，用于数据库索引
  • 字典树（Trie）：前缀树，用于字符串匹配

// DFS（深度优先）
function dfs(graph, start, visited = new Set()) {
  visited.add(start)
  console.log(start)
  for (const neighbor of graph[start]) {
    if (!visited.has(neighbor)) dfs(graph, neighbor, visited)
  }
}

// BFS（广度优先）
function bfs(graph, start) {
  const queue = [start], visited = new Set([start])
  while (queue.length) {
    const node = queue.shift()
    console.log(node)
    for (const neighbor of graph[node]) {
      if (!visited.has(neighbor)) {
        visited.add(neighbor)
        queue.push(neighbor)
      }
    }
  }
}

三、排序算法 ​

31-38. 排序算法详解 ​

问题：快速排序、归并排序的原理和实现是什么？各排序算法的复杂度是什么？

答案：

排序算法对比：

算法平均时间最坏时间空间稳定性
冒泡O(n²)O(n²)O(1)✅
快速O(n log n)O(n²)O(log n)❌
归并O(n log n)O(n log n)O(n)✅

快速排序：

javascript
function quickSort(arr) {
  if (arr.length <= 1) return arr
  const pivot = arr[arr.length >> 1]
  const left = arr.filter(x => x < pivot)
  const mid = arr.filter(x => x === pivot)
  const right = arr.filter(x => x > pivot)
  return [...quickSort(left), ...mid, ...quickSort(right)]
}

归并排序：

javascript
function mergeSort(arr) {
  if (arr.length <= 1) return arr
  const mid = arr.length >> 1
  const left = mergeSort(arr.slice(0, mid))
  const right = mergeSort(arr.slice(mid))
  return merge(left, right)
}

function merge(left, right) {
  const result = []
  let i = 0, j = 0
  while (i < left.length && j < right.length) {
    result.push(left[i] <= right[j] ? left[i++] : right[j++])
  }
  return result.concat(left.slice(i), right.slice(j))
}

四、查找算法 ​

39-41. 二分查找 ​

问题：二分查找的原理和实现是什么？适用条件是什么？

答案：

原理：在有序数组中，每次与中间元素比较，缩小一半范围。 时间复杂度：O(log n) 适用条件：有序数组

javascript
function binarySearch(arr, target) {
  let left = 0, right = arr.length - 1
  while (left <= right) {
    const mid = left + ((right - left) >> 1)
    if (arr[mid] === target) return mid
    if (arr[mid] < target) left = mid + 1
    else right = mid - 1
  }
  return -1
}

爬楼梯：

javascript
function climbStairs(n) {
  if (n <= 2) return n
  let a = 1, b = 2
  for (let i = 3; i <= n; i++) {
    [a, b] = [b, a + b]
  }
  return b
}

最长递增子序列：

javascript
function lengthOfLIS(nums) {
  const dp = Array(nums.length).fill(1)
  for (let i = 1; i < nums.length; i++) {
    for (let j = 0; j < i; j++) {
      if (nums[i] > nums[j]) dp[i] = Math.max(dp[i], dp[j] + 1)
    }
  }
  return Math.max(...dp)
}

function twoSum(nums, target) {
  const map = new Map()
  for (let i = 0; i < nums.length; i++) {
    const complement = target - nums[i]
    if (map.has(complement)) return [map.get(complement), i]
    map.set(nums[i], i)
  }
  return []
}

74. 有效的括号 ​

javascript
function isValid(s) {
  const stack = []
  const map = { ')': '(', ']': '[', '}': '{' }
  for (const char of s) {
    if (map[char]) {
      if (stack.pop() !== map[char]) return false
    } else {
      stack.push(char)
    }
  }
  return stack.length === 0
}

78. 最大子数组和 ​

function maxSubArray(nums) {
  let max = nums[0], sum = 0
  for (const num of nums) {
    sum = Math.max(num, sum + num)
    max = Math.max(max, sum)
  }
  return max
}

86. LRU 缓存 ​

javascript
class LRUCache {
  constructor(capacity) {
    this.capacity = capacity
    this.map = new Map()
  }
  get(key) {
    if (!this.map.has(key)) return -1
    const value = this.map.get(key)
    this.map.delete(key)
    this.map.set(key, value)
    return value
  }
  put(key, value) {
    if (this.map.has(key)) this.map.delete(key)
    this.map.set(key, value)
    if (this.map.size > this.capacity) {
      this.map.delete(this.map.keys().next().value)
    }
  }
}
