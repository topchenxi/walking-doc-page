Vue ​

一、MVVM 模式 ​

1. 什么是 Vue.js？ ​

问题：什么是 Vue.js？

答案： 核心回答：Vue.js 是一个渐进式 JavaScript 框架，用于构建用户界面，采用响应式数据绑定。

代码示例：

javascript
// Vue 核心特性
// 1. 响应式数据绑定
const app = new Vue({
    el: '#app',
    data: {
        message: 'Hello Vue!'
    }
});

// 2. 组件系统
Vue.component('my-component', {
    props: ['title'],
    template: '<div>{{ title }}</div>'
});

// 3. 指令
// v-bind, v-model, v-for, v-if, v-show, v-on

2. Vue.js 的核心特性 ​

问题：Vue.js 的核心特性有哪些？

答案： 核心回答：响应式系统、组件系统、指令系统、虚拟 DOM。

代码示例：

javascript
// 响应式
const vm = new Vue({
    data: {
        count: 0
    }
});
vm.count++; // 自动更新 DOM

// 组件
const MyButton = {
    template: '<button @click="count++">{{ count }}</button>',
    data() {
        return { count: 0 };
    }
};

// 指令
Vue.directive('focus', {
    inserted: function(el) {
        el.focus();
    }
});

3. MVVM 模式的理解 ​

问题：解释 MVVM 模式及其在 Vue 中的体现

答案： 核心回答：MVVM 是 Model-View-ViewModel 架构，ViewModel 双向绑定 View 和 Model。

代码示例：

html
<!-- View -->
<div id="app">
    <input v-model="message"> <!-- 双向绑定 -->
    <p>{{ message }}</p>
</div>

<script>
// ViewModel
const vm = new Vue({
    el: '#app',
    // Model
    data: {
        message: 'Hello'
    }
});

// View 和 Model 通过 ViewModel 同步
vm.message = 'Hi'; // View 自动更新
</script>

二、Vue 实例与生命周期 ​

4. Vue 生命周期 ​

问题：Vue 生命周期有哪些？

答案： 核心回答：创建阶段（beforeCreate/created）、挂载阶段（beforeMount/mounted）、更新阶段（beforeUpdate/updated）、销毁阶段（beforeDestroy/destroyed）。

代码示例：

javascript
new Vue({
    data: { message: 'Hello' },
    beforeCreate() {
        console.log('实例创建前');
    },
    created() {
        console.log('实例创建后');
        // 可以访问 data
    },
    beforeMount() {
        console.log('挂载前');
    },
    mounted() {
        console.log('挂载后');
        // DOM 已挂载
    },
    beforeUpdate() {
        console.log('更新前');
    },
    updated() {
        console.log('更新后');
    },
    beforeDestroy() {
        console.log('销毁前');
    },
    destroyed() {
        console.log('销毁后');
    }
});

5. created 与 mounted 的区别 ​

问题：created 与 mounted 的区别

答案： 核心回答：created 在实例创建后同步调用，可访问 data；mounted 在 DOM 挂载后调用，可访问 DOM。

代码示例：

javascript
new Vue({
    data: { items: [] },
    created() {
        // 可以访问 data
        console.log(this.items); // []
        // 适合发送初始请求
        fetch('/api').then(res => this.items = res);
    },
    mounted() {
        // 可以访问 DOM
        console.log(this.$el); // DOM 元素
        // 适合 DOM 操作
        this.$refs.myInput.focus();
    }
});

三、Vue 原理 ​

6. Vue 响应式原理 ​

问题：Vue 响应式原理

答案： 核心回答：Vue2 使用 Object.defineProperty 劫持属性，Vue3 使用 Proxy 代理对象。

代码示例：

javascript
// Vue2 响应式
function defineReactive(obj, key, val) {
    Object.defineProperty(obj, key, {
        enumerable: true,
        configurable: true,
        get() {
            console.log(`获取 ${key}`);
            return val;
        },
        set(newVal) {
            console.log(`设置 ${key}`);
            if (val !== newVal) {
                val = newVal;
                // 通知更新
            }
        }
    });
}

// Vue3 响应式
const reactive = new Proxy(obj, {
    get(target, key) {
        return Reflect.get(target, key);
    },
    set(target, key, value) {
        return Reflect.set(target, key, value);
    }
});

javascript

四、Vue 组件 ​

8. Vue 组件的注册方式 ​

问题：Vue 组件的注册方式

答案： 核心回答：全局注册和局部注册。

代码示例：

javascript
// 全局注册
Vue.component('my-component', {
    template: '<div>全局组件</div>'
});

// 局部注册
const MyComponent = {
    template: '<div>局部组件</div>'
};

new Vue({
    components: {
        'my-component': MyComponent
    }
});

// 单文件组件
import MyComponent from './MyComponent.vue';
export default {
    components: { MyComponent }
}

9. 组件通信方式 ​

问题：组件通信方式

答案： 核心回答：props/$emit、事件总线、Vuex、provide/inject、$attrs/$listeners。

代码示例：

javascript
// 父子通信
// 父 -> 子：props
// 子 -> 父：$emit

// 父组件
<ChildComponent :message="msg" @update="handleUpdate" />

// 子组件
props: ['message'],
methods: {
    send() {
        this.$emit('update', 'new value');
    }
}

// 事件总线
const bus = new Vue();
bus.$on('event', handler);
bus.$emit('event', data);

// provide/inject
// 祖先提供
provide() {
    return { theme: this.theme };
}
// 后代注入
inject: ['theme'];

10. v-model 的原理 ​

问题：v-model 的原理

答案： 核心回答：v-model 是:value 和 @input 的语法糖。

代码示例：

html
<!-- 文本输入 -->
<input v-model="message">
<!-- 等价于 -->
<input :value="message" @input="message = $event.target.value">

<!-- 复选框 -->
<input type="checkbox" v-model="checked">
<!-- 等价于 -->
<input type="checkbox" :checked="checked" @change="checked = $event.target.checked">

<!-- 自定义组件 v-model -->
// 子组件
props: ['value'],
methods: {
    update() {
        this.$emit('input', 'new value');
    }
}

11. v-if 与 v-show 的区别 ​

问题：v-if 与 v-show 的区别

答案： 核心回答：v-if 条件渲染（销毁/重建），v-show 控制 display（始终渲染）。

代码示例：

html
<!-- v-if -->
<div v-if="show">条件渲染</div>
<!-- 条件为 false 时，元素从 DOM 中移除 -->

<!-- v-show -->
<div v-show="show">显示控制</div>
<!-- 等价于 -->
<div :style="{ display: show ? 'block' : 'none' }">
    显示控制
</div>

<!-- 性能 -->
<!-- v-if: 切换成本高，初始渲染成本低 -->
<!-- v-show: 切换成本低，初始渲染成本高 -->
<!-- 频繁切换用 v-show -->

12. v-for 与 v-if 的优先级 ​

问题：v-for 与 v-if 的优先级

答案： 核心回答：v-for 优先级更高，但不建议同时使用。

代码示例：

html
<!-- 不推荐：每次渲染都重新创建列表 -->
<li v-for="item in items" v-if="item.active">
    {{ item.name }}
</li>

<!-- 推荐：使用计算属性过滤 -->
<li v-for="item in activeItems" :key="item.id">
    {{ item.name }}
</li>

// 计算属性
computed: {
    activeItems() {
        return this.items.filter(item => item.active);
    }
}

五、计算属性与侦听器 ​

13. 计算属性 ​

问题：计算属性

答案： 核心回答：计算属性基于响应式依赖缓存计算结果。

代码示例：

javascript
computed: {
    // 只读计算属性
    fullName() {
        return this.firstName + ' ' + this.lastName;
    },
    
    // getter/setter
    fullName2: {
        get() {
            return this.firstName + ' ' + this.lastName;
        },
        set(value) {
            const [first, last] = value.split(' ');
            this.firstName = first;
            this.lastName = last;
        }
    }
}

14. computed 与 watch 的区别 ​

问题：computed 与 watch 的区别

答案： 核心回答：computed 用于计算属性，watch 用于监听数据变化执行异步操作。

代码示例：

javascript
// computed
computed: {
    doubleCount() {
        return this.count * 2;
    }
}

// watch
watch: {
    // 监听单个属性
    count(newVal, oldVal) {
        console.log(`count: ${oldVal} -> ${newVal}`);
    },
    
    // 深度监听对象
    user: {
        handler(newVal) {
            console.log('user changed');
        },
        deep: true
    },
    
    // 立即执行
    message: {
        handler(newVal) {
            this.saveMessage(newVal);
        },
        immediate: true
    }
}

六、Vuex 状态管理 ​

15. Vuex 的核心概念 ​

问题：Vuex 的核心概念

答案： 核心回答：State、Getter、Mutation、Action、Module。

代码示例：

javascript
// Store
const store = new Vuex.Store({
    state: {
        count: 0
    },
    
    getters: {
        doubleCount: state => state.count * 2
    },
    
    mutations: {
        INCREMENT(state) {
            state.count++;
        }
    },
    
    actions: {
        asyncIncrement({ commit }) {
            return new Promise(resolve => {
                setTimeout(() => {
                    commit('INCREMENT');
                    resolve();
                }, 1000);
            });
        }
    },
    
    modules: {
        user: {
            state: { name: '张三' },
            mutations: {
                SET_NAME(state, name) {
                    state.name = name;
                }
            }
        }
    }
});

// 使用
store.state.count;
store.getters.doubleCount;
store.commit('INCREMENT');
store.dispatch('asyncIncrement');

16. Vue 插槽 ​

问题：Vue 插槽

答案： 核心回答：插槽用于组件内容分发。

代码示例：

html
<!-- 父组件 -->
<MyComponent>
    <template v-slot:header>
        <h1>标题</h1>
    </template>
    
    <template #default>
        <p>默认内容</p>
    </template>
    
    <template #footer="slotProps">
        <p>{{ slotProps.user }}</p>
    </template>
</MyComponent>

<!-- 子组件 MyComponent -->
<div class="container">
    <slot name="header"></slot>
    <slot></slot>
    <slot name="footer" :user="user"></slot>
</div>

<!-- 作用域插槽 -->
<!-- 父组件 -->
<ScopedList>
    <template #default="props">
        <div>{{ props.item }}</div>
    </template>
</ScopedList>

17. 动态组件与异步组件 ​

问题：动态组件与异步组件

答案： 核心回答：动态组件用 <component :is=""> 切换，异步组件懒加载。

代码示例：

html

<component :is="currentComponent"></component>

<!-- keep-alive 缓存 -->
<keep-alive include="Home,About">

<!-- 异步组件 -->
const AsyncComponent = () => ({

九、Mixins 与组合式 API ​

18. Mixins ​

问题：Mixins 的使用

答案： 核心回答：Mixins 允许复用组件选项。

代码示例：

javascript
// mixin
const myMixin = {
    data() {
        return {
            shared: 'shared data'
        };
    },
    methods: {
        sharedMethod() {
            console.log('shared method');
        }
    }
};

// 使用
const Comp = {
    mixins: [myMixin],
    data() {
        return {
            own: 'own data'
        };
    }
};

// 合并策略
// data: 组件数据优先
// 生命周期: 都执行，mixin 先执行
// methods: 合并后都有
