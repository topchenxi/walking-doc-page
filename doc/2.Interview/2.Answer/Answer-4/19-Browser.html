一、浏览器渲染过程 ​

1. 浏览器渲染过程 ​

问题：浏览器渲染过程

答案： 核心回答：浏览器渲染过程包括 DOM 构建、CSSOM 构建、Render Tree、Layout、Paint。

代码示例：

渲染流程：
HTML → DOM Tree
CSS   → CSSOM Tree
      ↓
Render Tree（渲染树）
      ↓
Layout（布局/回流）
      ↓
Paint（绘制）
      ↓
Composite（合成）

2. 重绘与回流 ​

问题：重绘与回流

答案： 核心回答：回流重新计算布局（几何属性变化），重绘只改变外观（颜色等）。

类型触发条件性能
回流宽高、位置变化高
重绘颜色、visibility变化低

代码示例：

javascript
// 触发回流的操作
element.style.width = '200px';
element.style.padding = '20px';
element.style.display = 'none';

// 只触发重绘
element.style.background = 'red';
element.style.color = '#fff';

// 使用 transform/opacity 不触发回流重绘
element.style.transform = 'translateX(100px)';
element.style.opacity = '0.5';

二、浏览器缓存 ​

3. 浏览器缓存机制 ​

问题：浏览器缓存机制

答案： 核心回答：浏览器缓存分为强缓存和协商缓存。

代码示例：

javascript
// 强缓存
// 响应头
Cache-Control: max-age=3600  // 1小时
Expires: Wed, 21 Oct 2026 07:28:00 GMT

// 协商缓存
// 请求/响应头
Last-Modified: Wed, 21 Oct 2026 07:28:00 GMT
If-Modified-Since: Wed, 21 Oct 2026 07:28:00 GMT

ETag: "33a64df5"
If-None-Match: "33a64df5"

// 缓存优先级
// 1. Memory Cache（内存缓存）
// 2. Service Worker Cache（SW缓存）
// 3. Disk Cache（磁盘缓存）

4. Cookie、SessionStorage、LocalStorage ​

问题：Cookie、SessionStorage、LocalStorage

答案： 核心回答：Cookie 随请求发送有大小限制，Storage 存储空间大不随请求发送。

特性CookielocalStoragesessionStorage
大小~4KB~5MB~5MB
生命周期可设置永久会话结束
随请求发送是否否
访问限制所有窗口所有窗口当前窗口

代码示例：

javascript
// Cookie
document.cookie = 'name=value; expires=date; path=/';
// 读取
console.log(document.cookie);

// localStorage
localStorage.setItem('key', 'value');
localStorage.getItem('key');
localStorage.removeItem('key');
localStorage.clear();

// sessionStorage
sessionStorage.setItem('key', 'value');
sessionStorage.getItem('key');
sessionStorage.removeItem('key');
sessionStorage.clear();

四、浏览器安全 ​

5. 同源策略 ​

问题：同源策略

答案： 核心回答：同源策略限制不同源之间的资源访问，防止 XSS、CSRF。

代码示例：

javascript
// 同源：协议+域名+端口相同
// https://example.com:443

// 跨域解决方案
// 1. CORS
app.use((req, res, next) => {
    res.header('Access-Control-Allow-Origin', 'https://allowed.com');
    res.header('Access-Control-Allow-Methods', 'GET,POST');
    res.header('Access-Control-Allow-Credentials', 'true');
    next();
});

// 2. JSONP（仅 GET）
// 3. 代理服务器
// 4. postMessage
window.postMessage('message', 'https://target.com');

五、浏览器 API ​

6. Web Worker ​

问题：Web Worker

答案： 核心回答：Web Worker 在后台线程执行 JavaScript，不阻塞主线程。

代码示例：

javascript
// main.js
const worker = new Worker('worker.js');

worker.postMessage({ type: 'start', data: 1000 });

worker.onmessage = function(e) {
    console.log('收到 worker 消息:', e.data);
};

worker.onerror = function(e) {
    console.error('Worker 错误:', e);
};

worker.terminate();

// worker.js
self.onmessage = function(e) {
    const result = heavyComputation(e.data);
    self.postMessage(result);
};

function heavyComputation(n) {
    // 复杂计算
    return n * 2;
}

7. 事件循环 ​

问题：浏览器事件循环

答案： 核心回答：浏览器事件循环不断从任务队列取出任务执行，微任务在每个阶段前执行。

代码示例：

javascript
console.log('1');

setTimeout(() => console.log('2'), 0);

Promise.resolve()
    .then(() => console.log('3'))
    .then(() => console.log('4'));

queueMicrotask(() => console.log('3.5'));

console.log('5');

// 输出顺序: 1, 5, 3, 3.5, 4, 2

8. requestAnimationFrame ​

问题：requestAnimationFrame

答案： 核心回答：requestAnimationFrame 在下次重绘前调用回调，用于动画。

代码示例：

javascript
// 动画示例
function animate() {
    element.style.transform = `translateX(${x}px)`;
    x += 5;
    if (x < 100) {
        requestAnimationFrame(animate);
    }
}
requestAnimationFrame(animate);

// 替代 setInterval（更流畅）
let lastTime = 0;
function tick(timestamp) {
    if (timestamp - lastTime >= 16) { // ~60fps
        update();
        lastTime = timestamp;
    }
    requestAnimationFrame(tick);
}
requestAnimationFrame(tick);

// 取消
const id = requestAnimationFrame(callback);
cancelAnimationFrame(id);

六、性能优化 ​

9. 浏览器性能优化 ​

问题：浏览器性能优化

答案： 核心回答：减少重排重绘、使用 GPU 加速、懒加载、代码分割。

代码示例：

javascript
// 减少重排重绘
// 批量修改 DOM
const fragment = document.createDocumentFragment();
items.forEach(item => fragment.appendChild(item));
container.appendChild(fragment);

// 使用 transform/opacity
element.style.willChange = 'transform';
element.style.transform = 'translateX(100px)';

// 懒加载图片
<img src="placeholder.jpg" data-src="real-image.jpg" class="lazy">

<script>
const observer = new IntersectionObserver((entries) => {
    entries.forEach(entry => {
        if (entry.isIntersecting) {
            const img = entry.target;
            img.src = img.dataset.src;
            observer.unobserve(img);
        }
    });
});
document.querySelectorAll('.lazy').forEach(img => observer.observe(img));
</script>

// 防抖/节流
function debounce(fn, delay) {
    let timer = null;
    return function(...args) {
        clearTimeout(timer);
        timer = setTimeout(() => fn.apply(this, args), delay);
    };
}
