Linux 答案 ​

一、文件系统 ​

bash
ls -la                # 列出所有文件（含隐藏），详细
cd /path              # 切换目录
pwd                   # 当前路径
mkdir -p a/b/c        # 递归创建目录
rm -rf dir            # 强制递归删除（⚠️ 危险）
cp -r src dest        # 递归复制
mv old new            # 移动/重命名
cat / head / tail     # 查看文件内容
find . -name "*.js"   # 查找文件

二、权限管理 ​

bash
# r=4, w=2, x=1 → rwx = 7, rw- = 6, r-x = 5
chmod 755 script.sh   # owner:rwx, group:r-x, others:r-x
chown user:group file # 更改所有者

drwxr-xr-x: d(目录), rwx(所有者权限), r-x(组权限), r-x(其他人权限)

三、进程管理 ​

bash
ps aux                # 查看所有进程
kill -9 PID           # 强制终止进程
top / htop            # 实时进程监控
nohup cmd &           # 后台运行，无视终端关闭
jobs                  # 查看后台任务

四、Shell 脚本 ​

bash
#!/bin/bash
NAME="world"
echo "Hello, $NAME"

if [ "$NAME" = "world" ]; then
  echo "Match"
fi

for i in 1 2 3; do echo $i; done

五、管道与重定向 ​

bash
# | 管道：前一个命令的输出作为后一个的输入
cat file.txt | grep "error" | wc -l    # 统计 error 行数

# > 覆写 >> 追加  < 输入
echo "line" > file.txt                  # 覆盖写入
echo "line" >> file.txt                 # 追加

六、文本处理 ​

bash
grep "pattern" file           # 搜索匹配行
grep -i "pattern" file        # 忽略大小写
sed 's/old/new/g' file        # 替换文本
awk '{print $1}' file         # 提取第一列

七、网络 ​

bash
ping host                     # 连通性测试
curl -X GET url               # HTTP 请求
wget url                      # 下载文件
netstat -tlnp                 # 查看端口占用
ssh user@host                 # 远程连接
scp file user@host:/path      # 远程复制

八、系统信息 ​

bash
uname -a                      # 系统信息
df -h                         # 磁盘使用
free -h                       # 内存使用
du -sh *                      # 目录文件大小

九、用户与组 ​

bash
whoami                        # 当前用户
sudo cmd                      # 管理员执行
useradd name                  # 新建用户

十、Docker 基础 ​

bash
docker build -t name .        # 构建镜像
docker run -d -p 80:80 name   # 运行容器
docker ps                     # 查看运行容器
docker images                 # 查看镜像
docker exec -it container sh  # 进入容器
docker-compose up -d          # 编排启动

Dockerfile 示例：

dockerfile
FROM node:18-alpine
WORKDIR /app
COPY package*.json ./
RUN npm ci --production
COPY . .
EXPOSE 3000
CMD ["node", "server.js"]

十一、CI/CD（Jenkins 基础概念） ​

CI/CD 流水线：代码提交 → 构建 → 测试 → 部署

Jenkins 通过 Pipeline（Jenkinsfile）定义自动化流程，触发构建后自动拉代码 → 安装依赖 → 跑测试 → 打包 → 部署到服务器。
