一、前端工程化 ​

1. 什么是前端工程化？ ​

问题：什么是前端工程化？

答案：

核心定义 ​

前端工程化是将软件工程的最佳实践应用于前端开发，通过工具化、标准化、规范化的方式提高开发效率和代码质量。

四个维度 ​

维度内容工具
模块化JS/CSS 模块化开发ES Module、CommonJS
组件化UI 组件复用Vue、React 组件
规范化代码规范、提交规范ESLint、Prettier、Husky
自动化构建、测试、部署Webpack、CI/CD

2. 什么是 CI/CD？ ​

问题：什么是 CI/CD？

答案：

核心定义 ​

  • CI（持续集成）：频繁将代码合并到主干，自动构建和测试
  • CD（持续交付/部署）：自动将代码部署到生产环境

流程 ​

代码提交 → 自动构建 → 自动测试 → 自动部署
   ↓           ↓          ↓          ↓
 Git Push   npm build   npm test   Deploy

常用工具 ​

  • Jenkins、GitLab CI、GitHub Actions、Travis CI

二、前端监控 ​

3. 前端监控方案包含哪些内容？ ​

问题：前端监控方案包含哪些内容？

答案：

监控维度 ​

维度内容指标
性能监控页面加载速度FCP、LCP、TTI、CLS
异常监控JS 错误、接口异常错误率、错误堆栈
用户行为页面访问、点击PV、UV、点击热图
资源监控资源加载失败404、超时

实现方式 ​

javascript
// 1. JS 错误监控
window.addEventListener('error', (e) => {
  reportError({
    message: e.message,
    stack: e.error?.stack,
    url: window.location.href
  });
});

// 2. Promise 错误
window.addEventListener('unhandledrejection', (e) => {
  reportError({ message: e.reason });
});

// 3. 性能监控（Performance API）
const perf = performance.getEntriesByType('navigation')[0];
console.log('FCP:', perf.domContentLoadedEventEnd - perf.startTime);

// 4. 接口监控（拦截 fetch）
const originalFetch = window.fetch;
window.fetch = async function(...args) {
  const start = Date.now();
  try {
    const response = await originalFetch.apply(this, args);
    reportApi({ url: args[0], status: response.status, time: Date.now() - start });
    return response;
  } catch (e) {
    reportApi({ url: args[0], error: e.message, time: Date.now() - start });
    throw e;
  }
};

四、微前端 ​

5. 什么是微前端？ ​

问题：什么是微前端？

答案：

核心定义 ​

微前端是将前端应用拆分为多个可独立开发、部署的子应用的架构模式。

优势 ​

  • 技术栈无关：子应用可使用不同框架
  • 独立部署：子应用可独立发布
  • 渐进式升级：逐步迁移老系统
  • 团队自治：不同团队独立开发

实现方案 ​

方案说明
qiankun基于 single-spa 的微前端框架
iframe最简单但通信困难
Web Components标准组件化方案
Module FederationWebpack 5 模块联邦

五、SEO 优化 ​

6. 前端如何优化 SEO？ ​

问题：前端如何优化 SEO？

答案：

优化方法 ​

方法说明
SSR服务端渲染，返回完整 HTML
SSG静态站点生成，预渲染
Meta 标签设置 title、description、keywords
语义化 HTML使用正确的 HTML 标签

<meta property="og:image" content="分享图片">

六、PWA ​

7. 什么是 PWA？ ​

问题：什么是 PWA？

答案：

核心定义 ​

PWA（Progressive Web App） 是一种利用 Web 技术提供类原生应用体验的应用形式。

三大核心 ​

特性说明
Service Worker离线缓存、后台同步
Manifest添加到桌面、启动画面
HTTPS安全传输

优势 ​

  • 离线可用
  • 可添加到桌面
  • 推送通知
  • 类原生体验

七、低代码 ​

8. 什么是低代码/无代码平台？ ​

问题：什么是低代码/无代码平台？

答案：

核心定义 ​

低代码平台是通过可视化拖拽方式快速构建应用的开发模式。

核心能力 ​

能力说明
可视化编排拖拽组件搭建页面
逻辑编排可视化配置业务逻辑
数据源接入连接 API、数据库
代码生成导出可运行代码
部署发布一键部署

技术要点 ​

  • 组件 schema 设计（JSON 描述组件）
  • 拖拽引擎
  • 渲染引擎（JSON → DOM）
  • 表达式解析

补充说明：

前端进阶知识包括：工程化、监控、安全、微前端、SEO、PWA、低代码等。这些是现代前端工程师需要了解的领域扩展方向。
