1. CSS 是什么？有什么作用？ ​

问题：CSS 是什么？有什么作用？

答案：

CSS（Cascading Style Sheets，层叠样式表）是一种用于描述HTML或XML文档外观和格式的样式语言。

CSS的主要作用：

  1. 结构与表现分离

    • HTML负责结构
    • CSS负责表现
    • 职责清晰，利于维护

  2. 样式控制

    • 字体、颜色、间距
    • 布局定位
    • 动画效果

  3. 响应式设计

    • 媒体查询
    • 适配不同设备

  4. 可维护性

    • 样式复用
    • 统一管理
    • 易于修改

代码示例：

css
/* 定义样式规则 */
h1 {
    /* 字体样式 */
    font-size: 24px;
    font-family: 'Microsoft YaHei', sans-serif;
    
    /* 颜色 */
    color: #333;
    
    /* 间距 */
    margin-bottom: 16px;
    
    /* 边框 */
    border-bottom: 1px solid #eee;
}

补充说明：

  • CSS3引入了动画、过渡、弹性盒等强大功能
  • 预处理器（Sass、Less）增强了CSS的编程能力

2. CSS 有哪些选择器？选择器的优先级如何计算？ ​

问题：CSS 有哪些选择器？选择器的优先级如何计算？

答案：

CSS选择器类型：

选择器类型示例说明
元素选择器p选择所有p元素
类选择器.box选择class="box"的元素
ID选择器#header选择id="header"的元素
属性选择器[type="text"]选择指定属性的元素
伪类:hover元素特定状态
伪元素::before元素的特定部分
后代选择器.parent .child嵌套元素
子选择器.parent > .child直接子元素
相邻兄弟.a + .b紧邻的兄弟元素
通用兄弟.a ~ .b后面的所有兄弟
通配符*所有元素

选择器优先级计算：

优先级由四位数表示：(a, b, c, d)

优先级等级值说明
内联样式1000style="..."
ID选择器0100#id
类/属性/伪类0010.class [attr] :hover
元素/伪元素0001p ::before
通配符/组合0000* > + ~

优先级计算示例：

css
/* 优先级: 0,0,1,0 = 10 */
.foo { }

/* 优先级: 0,0,2,0 = 20 */
.foo.bar { }

/* 优先级: 0,1,0,0 = 100 */
#header { }

/* 优先级: 0,1,1,0 = 110 */
#header.nav { }

/* 优先级: 0,0,0,1 = 1 */
div { }

/* 优先级: 0,0,1,1 = 11 */
div.foo { }

!important规则：

css
/* 优先级最高，但慎用 */
.box {
    color: red !important;
}

补充说明：

  • 建议使用低优先级的选择器，便于覆盖
  • !important会破坏样式可预测性

3. 什么是盒模型？标准盒模型与 IE 盒模型的区别是什么？ ​

问题：什么是盒模型？标准盒模型与 IE 盒模型的区别是什么？

答案：

盒模型概念：

  • 每个HTML元素都被视为一个矩形盒子
  • 包含：内容(content)、内边距(padding)、边框(border)、外边距(margin)

盒模型结构：

┌────────────────────────────┐
│        margin (外边距)     │
│  ┌──────────────────────┐  │
│  │   border (边框)      │  │
│  │  ┌────────────────┐  │  │
│  │  │ padding        │  │  │
│  │  │ ┌────────────┐ │  │  │
│  │  │ │  content   │ │  │  │
│  │  │ │  (内容)    │ │  │  │
│  │  │ └────────────┘ │  │  │
│  │  └────────────────┘  │  │
│  └──────────────────────┘  │
└────────────────────────────┘

标准盒模型 vs IE盒模型：

盒模型width/height包含计算方式
标准盒模型只含内容总宽度 = width + padding + border + margin
IE盒模型内容 + padding + border总宽度 = width + margin

代码示例：

css
/* 标准盒模型（默认） */
.box {
    box-sizing: content-box;
    width: 200px;
    padding: 20px;
    border: 5px solid #333;
    /* 实际占用宽度 = 200 + 20*2 + 5*2 = 250px */
}

/* IE盒模型 */
.box {
    box-sizing: border-box;
    width: 200px;
    padding: 20px;
    border: 5px solid #333;
    /* 实际占用宽度 = 200px（内容自动缩减为150px） */
}

全局设置：

css
/* 推荐：全局使用border-box */
*, *::before, *::after {
    box-sizing: border-box;
}

补充说明：

  • 现代开发推荐使用border-box
  • content-box在实际布局中难以计算

答案：

box-sizing属性值：

padding-boxwidth包含内容+padding（Firefox旧版本支持）

css
/* 内容盒：width = 内容 */
.content-box {
    box-sizing: content-box;
    width: 200px;
    padding: 20px;
    border: 10px solid #333;

}

/* 边框盒：width = 内容+padding+border */
.border-box {
    box-sizing: border-box;
    width: 200px;
    padding: 20px;
    border: 10px solid #333;
    /* 内容区域: 200-40-20=140px, 实际占用: 200px */
}

5. 如何实现元素水平垂直居中？（至少 5 种方法） ​

问题：如何实现元素水平垂直居中？（至少 5 种方法）

答案：

方法一：Flex布局

css
/* 父容器 */
.container {
    display: flex;
    justify-content: center;  /* 水平居中 */
    align-items: center;       /* 垂直居中 */
    height: 400px;
}

方法二：Grid布局

css
/* 父容器 */
.container {
    display: grid;
    place-items: center;  /* 水平+垂直居中 */
    height: 400px;
}

/* 或分开写 */
.container {
    display: grid;
    justify-content: center;
    align-content: center;
    height: 400px;
}

方法三：绝对定位 + transform

css
/* 父容器 */
.container {
    position: relative;
    height: 400px;
}

/* 子元素 */
.box {
    position: absolute;
    left: 50%;
    top: 50%;
    transform: translate(-50%, -50%);
}

方法四：绝对定位 + margin负值

css
/* 父容器 */
.container {
    position: relative;
    height: 400px;
}

/* 子元素 */
.box {
    position: absolute;
    left: 50%;
    top: 50%;
    margin-left: -100px;  /* 宽度的一半 */
    margin-top: -50px;    /* 高度的一半 */
    width: 200px;
    height: 100px;
}

方法五：绝对定位 + margin:auto

css
/* 父容器 */
.container {
    position: relative;
    height: 400px;
}

/* 子元素 */
.box {
    position: absolute;
    left: 0;
    right: 0;
    top: 0;
    bottom: 0;
    margin: auto;
    width: 200px;
    height: 100px;
}

方法六：行内块 + 伪元素（父级）

css
/* 父容器 */
.container {
    text-align: center;
    height: 400px;
}

/* 父容器的伪元素，辅助垂直居中 */
.container::after {
    content: '';
    display: inline-block;
    height: 100%;
    vertical-align: middle;
}

/* 子元素 */
.box {
    display: inline-block;
    vertical-align: middle;
}

方法七：table-cell（表格布局）

css
/* 父容器 */
.container {
    display: table-cell;
    text-align: center;
    vertical-align: middle;
    width: 400px;
    height: 400px;
}

/* 子元素 */
.box {
    display: inline-block;
}

补充说明：

  • 推荐使用Flex/Grid（方法一、二），代码简洁
  • 绝对定位适用于已知尺寸的元素

6. 行内元素的 margin、padding 设置是否有效？ ​

问题：行内元素的 margin、padding 设置是否是否有效？

答案：

行内元素的盒模型特性：

属性水平方向垂直方向
margin-left/right✅ 有效❌ 无效
padding-left/right✅ 有效❌ 无效
padding-top/bottom✅ 有效（会占据空间）⚠️ 视觉有效，但不影响布局

代码示例：

html
<span class="inline">行内元素</span>
css
.inline {
    /* 水平方向有效 */
    margin-left: 20px;
    margin-right: 20px;
    padding-left: 10px;
    padding-right: 10px;
    
    /* 垂直方向：margin无效 */
    margin-top: 20px;      /* 不生效 */
    margin-bottom: 20px;   /* 不生效 */
    
    /* 垂直方向：padding有效但有问题 */
    padding-top: 10px;     /* 视觉上生效，但可能影响行高 */
    padding-bottom: 10px;  /* 视觉上生效，但可能影响行高 */
}

问题说明：

css
/* 行内元素设置padding-top/bottom会：
   1. 背景色会渲染
   2. 但不会影响行高
   3. 可能与上下元素重叠
*/
.inline {
    background: red;
    padding: 10px 20px;
    /* 背景会渲染，但行高不变 */
}

/* 解决方案：使用line-height或设置display */
.inline {
    display: inline-block;  /* 变为行内块，margin/padding都有效 */
}

实际应用注意：

css
/* 按钮等行内元素设置padding的正确方式 */
button {
    display: inline-block;  /* 或 */
    line-height: 1;          /* 配合调整 */
    padding: 10px 20px;
}

/* 行内元素的安全做法 */
a {
    display: inline-block;  /* 转为行内块 */
    padding: 10px 20px;
}

补充说明：

  • 行内非替换元素（如span）的垂直margin不参与布局计算
  • 行内替换元素（如img、input）的盒模型行为类似块级元素

7. 什么是外边距合并？如何避免？ ​

问题：什么是外边距合并？如何避免？

答案：

外边距合并（Margin Collapsing）：

  • 两个或多个相邻的垂直外边距会合并为一个外边距
  • 取合并外边距的最大值

发生场景：

  1. 相邻兄弟元素

    html
    <div class="box1"></div>
<div class="box2"></div>
    css
    .box1 { margin-bottom: 20px; }
.box2 { margin-top: 30px; }
/* 实际间距 = max(20px, 30px) = 30px */

  2. 父子元素（无border/padding/inline内容隔开）

    html
    <div class="parent">
    <div class="child"></div>
</div>
    css
    .parent { margin-top: 20px; }
.child { margin-top: 30px; }
/* 实际间距 = max(20px, 30px) = 30px */

  3. 空元素（自身上下margin合并）

    html
    <div class="empty"></div>
    css
    .empty {
    margin-top: 20px;
    margin-bottom: 30px;
}
/* 实际间距 = max(20px, 30px) = 30px */

避免外边距合并的方法：

  1. 使用padding代替margin

    css
    .parent {
    padding-top: 1px;  /* 阻止合并 */
}

  2. 使用border隔开

    css
    .parent {
    border-top: 1px solid transparent;  /* 阻止合并 */
}

  3. 使用overflow

    css
    .parent {
    overflow: hidden;  /* BFC，阻止合并 */
}

  4. 使用Flex/Grid布局

    css
    .parent {
    display: flex;
    flex-direction: column;
}
.child { margin: 30px 0; }  /* 不合并 */

  5. 使用display: flow-root

    css
    .parent {
    display: flow-root;  /* 创建BFC，阻止合并 */
}

  6. 使用display: inline-block

    css
    .parent {
    display: inline-block;  /* 阻止合并 */
    width: 100%;
}

水平外边距：

  • 水平方向的margin不会合并
  • 水平margin会累加

补充说明：

  • 外边距合并是CSS规范的一部分
  • 设计目的是为了排版美观（段落间距）

8. display 属性有哪些常见值？ ​

问题：display 属性有哪些常见值？

答案：

display属性常见值：

值说明
none不显示，不占用空间
block块级元素
inline行内元素
inline-block行内块元素
flex弹性盒容器
inline-flex行内弹性盒
grid网格容器
inline-grid行内网格
table表格
table-row表格行

list-item列表项
run-in插入框（实验性）

display值分类：

css
/* 外部显示类型 - 决定元素如何参与布局 */
.block { display: block; }
.inline { display: inline; }
.inline-block { display: inline-block; }
.flex { display: flex; }
.grid { display: grid; }

/* 内部显示类型 - 决定元素内部如何布局 */
.flex { display: flex; }
.grid { display: grid; }
.table { display: table; }

/* 单一值 */
.none { display: none; }  /* 隐藏 */

/* 实验性值 */
.flow-root { display: flow-root; }  /* 创建BFC */
.contents { display: contents; }    /* 移除盒子 */

/* 多重值 */
.inline-flex { display: inline-flex; }
.inline-grid { display: inline-grid; }

display:none vs visibility:hidden：

css
.none { display: none; }
/* 完全不显示，不占用空间 */

.hidden { visibility: hidden; }
/* 隐藏但占用空间 */

contents值：

html
<div class="outer">
    <span>内容</span>
</div>
css
.outer {
    display: contents;
    /* 效果：outer元素盒子消失，
       span直接成为outer的父元素的子元素 */
}

补充说明：

  • Flex和Grid是现代布局的核心
  • display属性可配合JS动态切换布局方式

9. position 属性有哪些值？各自的特点是什么？ ​

问题：position 属性有哪些值？各自的特点是什么？

答案：

position属性值：

值说明定位基准
static默认值，正常流无
relative相对定位自身原始位置
absolute绝对定位最近的定位祖先
fixed固定定位视口
sticky粘性定位视口/父容器

各值详解：

css
/* 1. static - 正常文档流 */
.static {
    position: static;
    /* 正常布局，top/right/bottom/left无效 */
}

/* 2. relative - 相对定位 */
.relative {
    position: relative;
    top: 20px;      /* 向下偏移 */
    left: 10px;     /* 向右偏移 */
    /* 仍占据原位置 */
}

/* 3. absolute - 绝对定位 */
.parent {
    position: relative;  /* 必须设置定位基准 */
}
.absolute {
    position: absolute;
    top: 0;
    right: 0;
    /* 相对于parent定位，脱离文档流 */
}

/* 4. fixed - 固定定位 */
.fixed {
    position: fixed;
    top: 0;
    left: 0;
    /* 相对于视口定位，常用于固定导航 */
}

/* 5. sticky - 粘性定位 */
.sticky {
    position: sticky;
    top: 10px;
    /* 滚动到阈值前正常，超过阈值后固定 */
}

定位特性对比：

特性staticrelativeabsolutefixedsticky
脱离文档流否否是是否
占据空间是是否否是
定位基准无自身祖先元素视口视口/父容器
top/left等无效有效有效有效有效

补充说明：

  • absolute常配合relative使用
  • fixed常用于固定导航栏
  • sticky是CSS3新增，兼容性较好

10. absolute 和 relative 的定位参照物是什么？ ​

问题：absolute 和 relative 的定位参照物是什么？

答案：

定位参照物说明：

css
/* relative - 相对于自身原始位置定位 */
.parent {
    position: relative;
    top: 20px;    /* 相对于原始位置向下偏移20px */
    left: 10px;   /* 相对于原始位置向右偏移10px */
    /* 元素仍占据原空间 */
}

/* absolute - 相对于最近定位祖先元素 */
.grandparent {
    position: relative;  /* 可作为基准 */
}
.parent {
    position: relative;  /* 最近的定位祖先 */
}
.child {
    position: absolute;
    top: 0;
    left: 0;
    /* 相对于.parent定位，而非.grandparent */
}

定位参照物查找规则：

html
<!-- 示例结构 -->
<div class="level1">  <!-- 无定位 -->
    <div class="level2">  <!-- position: relative -->
        <div class="level3">  <!-- 无定位 -->
            <div class="target">  <!-- position: absolute -->
                找谁定位？
            </div>
        </div>
    </div>
</div>
css
/* 
 * .target的定位参照物查找过程：
 * 1. 先看.level3 → 无定位 → 继续
 * 2. 再看.level2 → 有position → 找到！
 * 3. 相对于.level2定位
 */

无定位祖先时的行为：

css
/* 如果所有祖先都没有定位：
   - absolute 相对于 body（初始包含块）
   - 实际上取决于html的设置
*/

/* html默认不是定位元素，但浏览器行为如下： */
html {
    position: relative;  /* 可以让absolute相对于html */
}

实战技巧：

css
/* 居中定位常用写法 */
.center-box {
    position: absolute;
    left: 50%;
    top: 50%;
    transform: translate(-50%, -50%);
}

/* 父容器记得设置定位 */
.parent {
    position: relative;  /* 关键 */
    width: 300px;
    height: 200px;
}

补充说明：

  • relative不脱离文档流，适合微调
  • absolute脱离文档流，不占据空间

11. fixed 和 absolute 的区别是什么？ ​

问题：fixed 和 absolute 的区别是什么？

答案：

fixed与absolute对比：

特性fixedabsolute

12. z-index 的作用是什么？什么情况下会失效？ ​

问题：z-index 的作用是什么？什么情况会失效？

答案：

z-index作用：

  • 控制重叠元素的堆叠顺序
  • 数值越大，层级越高

使用前提：

  • z-index只对定位元素有效（position: relative/absolute/fixed/sticky）
  • 对static定位的元素无效

代码示例：

css
.box1 {
    position: relative;
    z-index: 1;
}
.box2 {
    position: relative;
    z-index: 2;  /* 更高，堆叠在上面 */
}
.box3 {
    position: relative;
    z-index: 0;   /* 默认值 */
}

失效情况：

  1. 父元素z-index更低

    css
    /* 父元素层级低，子元素无法超越 */
.parent1 { position: relative; z-index: 1; }
.parent2 { position: relative; z-index: 2; }

.child1 { position: absolute; z-index: 100; }
.child2 { position: absolute; z-index: 50; }
/* child1仍然在child2下面，因为parent2 > parent1 */

  2. 未设置position

    css
    /* 无效 - 没有定位 */
.box { z-index: 100; }

/* 有效 */
.box { position: relative; z-index: 100; }

  3. opacity < 1时创建新的层叠上下文

    css
    /* 创建层叠上下文 */
.box {
    position: relative;
    z-index: 1;
    opacity: 0.5;  /* 创建层叠上下文 */
}
.child { position: absolute; z-index: 999; }
/* child的z-index受父元素影响 */

  4. transform不为none时创建层叠上下文

    css
    .parent {
    transform: scale(1);  /* 创建层叠上下文 */
}

层叠上下文触发条件：

属性示例
position非static + z-indexposition: relative; z-index: 1
opacity < 1opacity: 0.5
transform非nonetransform: scale(1)
filter非nonefilter: blur(1px)
position: fixed任何情况
will-changewill-change: transform

补充说明：

  • 理解层叠上下文才能正确使用z-index
  • 避免z-index数值过大（9999等）

13. 什么是 BFC？触发条件有哪些？应用场景有哪些？ ​

问题：什么是 BFC？触发条件有哪些？应用场景有哪些？

答案：

BFC（Block Formatting Context，块级格式化上下文）：

  • CSS渲染的一部分
  • 独立的容器，内部的布局不影响外部

触发BFC的条件：

css
/* 1. 根元素 */
html { }

/* 2. float不为none */
.float { float: left; }

/* 3. position为absolute或fixed */
.absolute { position: absolute; }
.fixed { position: fixed; }

/* 4. display为inline-block、table-cell、table-caption、flex、inline-flex、grid、inline-grid */
.inline-block { display: inline-block; }
.flex { display: flex; }
.grid { display: grid; }

/* 5. overflow不为visible */
.hidden { overflow: hidden; }
.scroll { overflow: scroll; }
.auto { overflow: auto; }

/* 6. display: flow-root（最纯粹） */
.flow-root { display: flow-root; }

/* 7. fieldset元素 */
fieldset { }

BFC特性：

css
/* 1. 内部的Box垂直排列 */
.bfc {
    display: flow-root;
}
.bfc .child {
    margin-bottom: 20px;
}

/* 2. 垂直方向margin会合并 */
.bfc .box1 { margin-bottom: 20px; }
.bfc .box2 { margin-top: 30px; }
 /* 合并为30px */

/* 3. 不与float元素重叠 */
.bfc {
    display: flow-root;
}
.float { float: left; width: 100px; }
.bfc-content {
    /* 自动避开float元素 */
    margin-left: 100px;
}

/* 4. 内部float元素参与高度计算 */
.bfc {
    display: flow-root;
}
.bfc .float {
    float: left;
}

应用场景：

  1. 阻止margin合并

    css
    .container {
    display: flow-root;  /* 阻止父子margin合并 */
}
.child { margin-top: 20px; }

  2. 两栏布局（float + BFC）

    css
    .container {
    display: flow-root;
}
.sidebar {
    float: left;
    width: 200px;
}
.content {
    overflow: hidden;  /* 创建BFC */
}

  3. 清除浮动

    css
    .clearfix {
    display: flow-root;  /* 清除子元素float */
}

  4. 防止文字环绕

    css
    .box {
    display: flow-root;
}
.float { float: left; }
.text {
    /* 不会环绕float元素 */
}

补充说明：

  • BFC是CSS布局的重要概念
  • flow-root是最干净的BFC创建方式

14. 什么是层叠上下文？ ​

问题：什么是层叠上下文？

答案：

层叠上下文（Stacking Context）：

  • HTML元素在三维空间中的层叠层次
  • 决定了元素重叠时的显示顺序

层叠等级（从低到高）：

等级说明示例
1负z-indexz-index: -1
2块级盒子<div>
3浮动盒子float
4行内盒子<span>
5z-index: 0z-index: 0
6正z-indexz-index: 1

层叠顺序图：

┌─────────────────────────────┐
│        正z-index            │  ← 最高
├─────────────────────────────┤
│        z-index: 0           │
├─────────────────────────────┤
│        行内元素             │
├─────────────────────────────┤
│        float元素           │
├─────────────────────────────┤
│        块级元素             │
├─────────────────────────────┤
│        负z-index            │
├─────────────────────────────┤
│        背景/边框            │  ← 最低
└─────────────────────────────┘

创建层叠上下文：

css
/* 根元素html自动创建 */
html { }

/* 定位元素 + z-index */
.positive { position: relative; z-index: 1; }
.negative { position: relative; z-index: -1; }

/* opacity < 1 */
.opacity { opacity: 0.5; }

/* transform不为none */
.transform { transform: rotate(0deg); }

/* filter不为none */
.filter { filter: blur(1px); }

/* -webkit-overflow-scrolling: touch */
.scroll { -webkit-overflow-scrolling: touch; }

/* position: fixed */
.fixed { position: fixed; }

/* will-change */
.will-change { will-change: transform; }

层叠上下文示例：

css
/* 父元素创建层叠上下文 */
.parent1 {
    position: relative;
    z-index: 1;  /* 创建层叠上下文 */
}
.child1 {
    position: absolute;
    z-index: 100;  /* 实际层级受parent1限制 */
}

.parent2 {
    position: relative;
    z-index: 2;  /* 更高 */
}
.child2 {
    position: absolute;
    z-index: 1;  /* 比child1低，但parent2更高 */
}
/* 结果：child2 在 child1 之上 */

补充说明：

  • 层叠上下文是BFC在z轴的扩展
  • 理解层叠上下文才能正确使用z-index

16. Flex 布局有哪些常用属性？Flex:1 代表什么含义？ ​

问题：Flex 布局有哪些常用属性？Flex:1 代表什么含义？

Flex容器属性：

css
/* 1. 主轴方向 */

    flex-direction: row;           /* 主→右（默认） */
    flex-direction: row-reverse;   /* 主←右 */

    flex-wrap: nowrap;    /* 不换行（默认） */
    flex-wrap: wrap;       /* 换行 */
    flex-wrap: wrap-reverse; /* 反向换行 */
}

/* 3. 主轴对齐 */

    justify-content: flex-start;     /* 起点对齐 */
    justify-content: flex-end;        /* 终点对齐 */
    justify-content: center;          /* 居中 */
    justify-content: space-between;    /* 两端对齐 */
    justify-content: space-around;    /* 等距分布 */
    justify-content: space-evenly;    /* 等距（CSS3） */
}

/* 4. 交叉轴对齐 */
.container {
    align-items: stretch;        /* 拉伸（默认） */
    align-items: flex-start;      /* 起点对齐 */
    align-items: flex-end;        /* 终点对齐 */
    align-items: center;          /* 居中 */
    align-items: baseline;        /* 基线对齐 */
}

/* 5. 多行对齐 */
.container {
    align-content: flex-start;    /* 多行起点 */
    align-content: flex-end;      /* 多行终点 */
    align-content: center;        /* 多行居中 */
    align-content: space-between; /* 多行两端 */
    align-content: space-around;  /* 多行等距 */
    align-content: stretch;       /* 拉伸（默认） */
}

Flex项目属性：

css
/* 1. 伸缩性 */
.item {
    flex-grow: 1;     /* 放大比例，默认0 */
    flex-shrink: 1;   /* 缩小比例，默认1 */
    flex-basis: 200px; /* 基础宽度 */
}

/* 简写 */
.item {
    flex: 1;          /* flex: 1 1 0% */
    flex: 1 1 auto;   /* 完整写法 */
    flex: 0 0 200px;  /* 不伸缩 */
}

/* 2. 对齐覆盖 */
.item {
    align-self: auto;      /* 继承 */
    align-self: flex-start;
    align-self: flex-end;
    align-self: center;
    align-self: baseline;
    align-self: stretch;
}

/* 3. 顺序 */
.item {
    order: 0;  /* 数值越小越靠前，可为负 */
}

flex:1的含义：

css
/* flex: 1 是以下三者的简写 */
.item {
    flex-grow: 1;     /* 项目如何放大：等比分配剩余空间 */
    flex-shrink: 1;   /* 项目如何缩小：等比收缩 */
    flex-basis: 0%;   /* 项目基准尺寸：0% */
}

/* 效果：
   - 所有flex:1的项目等分容器宽度
   - 类似于"均分"布局
*/

/* 对比 */
.item1 { flex: 1; }   /* 分配所有剩余空间 */
.item2 { flex: 2; }   /* item1:item2 = 1:2 */
.item1 { flex: 1; }
.item2 { flex: 0; }   /* 不参与分配 */

  • Flex是现代布局的首选
  • flex:1常用于均分布局

    const html = document.documentElement;
    const width = html.getBoundingClientRect().width;

    width: 10vw;  /* 视口10% */
    font-size: 2vw;
}

32. nth-child() 和 nth-of-type() 的区别是什么？ ​

问题：nth-child() 和 nth-of-type() 的区别是什么？

答案：

nth-child() vs nth-of-type()：

css
/* nth-child: 计数所有子元素，包括不同类型 */
li:nth-child(2) { }  /* 第二个子元素，且是li */

/* nth-of-type: 只计数同类型元素 */
li:nth-of-type(2) { }  /* 第二个li元素 */

对比示例：

html
<div class="container">
    <span>第1个span</span>    <!-- nth-child(1), nth-of-type(1) -->
    <p>第1个p</p>            <!-- nth-child(2), nth-of-type(1) -->
    <span>第2个span</span>   <!-- nth-child(3), nth-of-type(2) -->
    <p>第2个p</p>            <!-- nth-child(4), nth-of-type(2) -->
    <span>第3个span</span>   <!-- nth-child(5), nth-of-type(3) -->
</div>
css
/* nth-child(2): 选中 第1个p */
.container p:nth-child(2) { color: red; }

/* nth-of-type(2): 选中 所有p的第二个，即第2个p */
.container p:nth-of-type(2) { color: red; }

nth-child参数：

css
/* 数字 */
li:nth-child(3) { }  /* 第3个 */

/* 关键字 */
li:nth-child(odd) { }   /* 奇数 */
li:nth-child(even) { }  /* 偶数 */

/* 公式 */
li:nth-child(2n) { }    /* 偶数 */
li:nth-child(2n+1) { }  /* 奇数 */
li:nth-child(3n) { }    /* 3的倍数 */
li:nth-child(3n+1) { }  /* 3的倍数+1 */

/* 倒数 */
li:nth-last-child(1) { }  /* 最后一个 */
li:nth-last-child(2) { }  /* 倒数第2个 */

使用场景：

css
/* 斑马纹 */
tr:nth-child(even) { background: #f5f5f5; }

/* 前3个特殊样式 */
li:nth-child(-n+3) { color: red; }

/* 从第3个开始 */
li:nth-child(n+3) { }

34. 什么是回流（reflow）和重绘（repaint）？哪些操作会导致重绘和回流？如何减少？ ​

问题：什么是回流（reflow）和重绘（repaint）？哪些操作会导致重绘和回流？如何减少？

答案：

概念解释：

  • 回流（Reflow）：布局变化，需要重新计算元素位置和尺寸
  • 重绘（Repaint）：样式变化，不需要重新布局，只重新绘制

触发回流的操作：

javascript

document.body.appendChild(div);

// 2. 改变元素尺寸
element.style.width = '100px';
element.style.height = '100px';

// 3. 改变元素位置
element.style.margin = '20px';

// 4. 改变元素内容
element.innerHTML = 'new content';

// 5. 获取布局信息（强制回流）
const width = element.offsetWidth;
const height = element.clientHeight;
const scrollTop = element.scrollTop;
window.getComputedStyle(element).width;

// 6. 改变字体大小
element.style.fontSize = '20px';

// 7. 改变display
element.style.display = 'none';

触发重绘的操作：

javascript
// 不改变布局的属性
element.style.color = 'red';
element.style.backgroundColor = 'blue';
element.style.border = '1px solid black';
element.style.visibility = 'visible';

减少回流/重绘：

javascript
// 1. 使用transform/opacity（不触发回流）
element.style.transform = 'translateX(100px)';
element.style.opacity = '0.5';

// 2. 批量修改样式
// 不好
element.style.width = '100px';
element.style.height = '100px';
element.style.color = 'red';

// 好：使用cssText
element.style.cssText += ';width:100px;height:100px;color:red';

// 好：使用class
element.classList.add('active');

// 3. 缓存布局信息
const width = element.offsetWidth;  // 读取一次
const height = element.offsetHeight;

// 4. 使用DocumentFragment
const fragment = document.createDocumentFragment();
for(let i = 0; i < 100; i++) {
    fragment.appendChild(createElement());
}
document.body.appendChild(fragment);  // 只触发一次

// 5. 绝对定位脱离文档流
.animated {
    position: absolute;
    will-change: transform;  // 提示浏览器优化
}

CSS优化：

css
/* 使用GPU加速 */
.gpu {
    transform: translateZ(0);
    will-change: transform;
}

/* 减少使用table */
table {
    table-layout: fixed;
}

补充说明：

  • 回流比重绘消耗更大
  • 现代浏览器会自动批量处理

42. CSS 加载会阻塞 DOM 渲染吗？ ​

问题：CSS 加载会阻塞 DOM 渲染吗？

答案：

CSS加载对渲染的影响：

浏览器渲染流程：
HTML解析 → DOM构建 → CSSOM构建 → 渲染树 → 布局 → 绘制

CSS加载的影响：
- CSSOM构建需要CSS文件下载完成
- DOM可以与CSSOM并行构建
- 但渲染树需要DOM + CSSOM都完成

阻塞情况：

  1. CSS阻塞渲染

    • 浏览器会等待CSSOM构建完成才开始渲染
    • 这是为了避免FOUC（无样式闪烁）

  2. CSS不阻塞DOM构建

    • DOM可以边解析边构建
    • 但渲染需要等待CSSOM

  3. JS阻塞CSSOM

    • JS执行会阻塞CSSOM
    • JS会等待CSS加载完成

优化策略：

html
<!-- CSS放head，尽快开始加载 -->
<head>
    <link rel="stylesheet" href="main.css">
</head>

<!-- 非关键CSS异步加载 -->
<link rel="preload" href="print.css" as="style" 
      onload="this.onload=null;this.rel='stylesheet'" media="print">

<!-- 关键CSS内联 -->
<head>
    <style>
        /* 首屏CSS */
    </style>
</head>

补充说明：

  • CSS是渲染的关键资源
  • 首屏CSS应尽量精简

问题：如何理解 CSS 的层叠性？什么是继承？哪些属性可以继承？

答案：

层叠性：

  • 同一元素多个规则冲突
  • 按优先级和应用顺序决定

继承：

  • 子元素自动继承父元素某些属性

可继承属性：

分类属性
字体font, font-family, font-size, font-weight, font-style
文本color, line-height, text-align, text-indent
列表list-style, list-style-type
其他visibility, cursor

不可继承：

  • 布局属性：width, height, margin, padding
  • 边框：border
  • 背景：background

补充说明：

  • inherit关键字可强制继承
  • 某些属性默认不继承

53. 如何重置 CSS 样式？normalize.css 与 reset.css 的区别是什么？ ​

问题：如何重置 CSS 样式？normalize.css 与 reset.css 的区别是什么？

答案：

Reset CSS：

  • 完全重置所有样式
  • 从零开始
css
* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}

Normalize CSS：

  • 保留有用的默认样式
  • 修复浏览器不一致
css
/* normalize.css核心理念：
   - 保留浏览器默认样式
   - 修复跨浏览器差异
   - 提供有用的默认值
*/

对比：

特性reset.cssnormalize.css
理念完全重置标准化差异
样式无保留默认
维护自行维护社区维护
体积小较大

使用方式：

html
<!-- 引入normalize -->
<link rel="stylesheet" href="normalize.css">

<!-- 或使用reset + 自定义 */
<link rel="stylesheet" href="reset.css">
<style>
    /* 自定义 */
    body { font-family: sans-serif; }
</style>

补充说明：

  • 现代开发推荐normalize
  • 或使用Tailwind等框架内置reset

54. 什么是原子化 CSS？ ​

问题：什么是原子化 CSS？

答案：

原子化CSS概念：

  • 每个类只对应一个CSS规则
  • 如同原子一样组合使用

示例：

css
/* 原子化类 */
.flex { display: flex; }
.flex-col { flex-direction: column; }
.items-center { align-items: center; }
.justify-center { justify-content: center; }
.p-4 { padding: 1rem; }
.m-4 { margin: 1rem; }
.text-center { text-align: center; }
.text-red { color: red; }

/* 使用 */
<div class="flex flex-col items-center p-4">
    内容
</div>

工具：

  • Tailwind CSS
  • UnoCSS
  • Windi CSS

优势：

  • 无需手动写CSS
  • 类名语义化
  • 按需生成，体积小

补充说明：

  • 原子化CSS是现代CSS框架的趋势
  • Tailwind是最流行的实现
