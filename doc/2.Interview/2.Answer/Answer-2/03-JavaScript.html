1. JavaScript 的数据类型有哪些？基本数据类型和引用类型有什么区别？ ​

问题：JavaScript 的数据类型有哪些？基本数据类型和引用类型有什么区别？

答案：

JavaScript数据类型：

基本数据类型（原始类型）：

类型说明示例
Number数字（整数和浮点数）123, 3.14
String字符串'hello', "world"
Boolean布尔值true, false
Undefined未定义undefined
Null空值null
Symbol唯一标识符（ES6）Symbol('id')
BigInt大整数（ES2020）BigInt(123)

引用数据类型：

  • Object（对象）
  • Array（数组）
  • Function（函数）
  • Date（日期）
  • RegExp（正则）
  • Map/WeakMap
  • Set/WeakSet

基本类型与引用类型的区别：

特性基本类型引用类型
存储位置栈（Stack）堆（Heap）
赋值方式值的拷贝引用地址拷贝
比较方式值比较引用比较
可变性不可变可变
内存占用固定大小不固定

代码示例：

javascript
// 基本类型
let a = 10;
let b = a;  // 值拷贝
b = 20;
console.log(a);  // 10，a不变
console.log(b);  // 20

// 引用类型
let obj1 = { name: 'Tom' };
let obj2 = obj1;  // 引用地址拷贝
obj2.name = 'Jerry';
console.log(obj1.name);  // 'Jerry'，obj1也被修改

// 比较
let num1 = 10;
let num2 = 10;
console.log(num1 === num2);  // true，值相等

let arr1 = [1, 2, 3];
let arr2 = [1, 2, 3];
console.log(arr1 === arr2);  // false，引用不同

补充说明：

  • JavaScript中基本类型赋值是值传递
  • 引用类型赋值是引用传递
  • 理解这个区别有助于避免常见bug

2. 如何判断数据类型？typeof、instanceof、Object.prototype.toString 的区别是什么？ ​

问题：如何判断数据类型？typeof、instanceof、Object.prototype.toString 的区别是什么？

答案：

判断数据类型的方法：

1. typeof运算符

javascript
typeof 123;           // 'number'
typeof 'hello';       // 'string'
typeof true;          // 'boolean'
typeof undefined;     // 'undefined'
typeof null;          // 'object'  ⚠️ 历史bug
typeof {};            // 'object'
typeof [];            // 'object'  ⚠️ 数组也是object
typeof function(){};  // 'function'
typeof Symbol('id');  // 'symbol'
typeof BigInt(1);     // 'bigint'

2. instanceof运算符

javascript
// 检查原型链
[] instanceof Array;              // true
{} instanceof Object;              // true
new Date() instanceof Date;        // true
function Person() {}
new Person() instanceof Person;    // true

// 继承关系
[] instanceof Object;  // true，数组是Object的实例

3. Object.prototype.toString

javascript
// 最准确的类型判断
Object.prototype.toString.call(123);      // '[object Number]'
Object.prototype.toString.call('hello'); // '[object String]'
Object.prototype.toString.call(true);    // '[object Boolean]'
Object.prototype.toString.call(undefined); // '[object Undefined]'
Object.prototype.toString.call(null);     // '[object Null]'
Object.prototype.toString.call({});       // '[object Object]'
Object.prototype.toString.call([]);       // '[object Array]'
Object.prototype.toString.call(function(){}); // '[object Function]'

// 封装工具函数
function getType(data) {
    return Object.prototype.toString.call(data).slice(8, -1);
}
getType([]);    // 'Array'
getType({});    // 'Object'
getType(null);  // 'Null'

三种方法对比：

方法优点缺点
typeof简单快速null判断不准确，数组返回object
instanceof能判断继承关系不能判断基本类型，受原型影响
toString最准确写法繁琐

补充说明：

  • 推荐封装一个工具函数统一处理
  • Array.isArray()可专门判断数组

javascript
// undefined 场景

4. == 与 === 的区别是什么？ ​

问题： == 与 === 的区别是什么？

答案：

== 与 === 的区别：

运算符名称特点
==宽松相等会进行类型转换
===严格相等不会进行类型转换

类型转换规则（==）：

javascript
// 1. 数字和字符串比较
'1' == 1;      // true，字符串转数字
'1' == true;   // true，两者都转成1
'' == 0;       // true，空字符串转0

// 2. null和undefined
null == undefined;  // true
null == 0;          // false
undefined == 0;     // false

// 3. 对象比较
[1] == 1;          // true
[1] == '1';        // true
[1, 2] == '1,2';  // true
{} == '[object Object]'; // true

// 4. NaN
NaN == NaN;  // false，NaN不等于任何值包括自身

严格相等 ===：

javascript
// 类型不同直接返回false
'1' === 1;     // false
true === 1;    // false
null === undefined; // false

// 类型相同才比较值
1 === 1;           // true
'hello' === 'hello'; // true

推荐实践：

javascript
// 使用 === 避免隐式转换带来的问题
if (value === null) { }  // 检查null
if (value !== undefined) { }  // 检查非undefined

// == 只在明确知道比较语义时使用
// 例如：允许空字符串等于0
if (value == '' || value == 0) { }

// 常见错误
if (input.value == '') { }  // 输入空字符串或0都会进入
if (input.value === '') { } // 只匹配空字符串

补充说明：

  • 严格推荐使用===
  • ==的隐式转换容易产生意想不到的结果

5. NaN 是什么？如何检测？ ​

问题：NaN 是什么？如何检测？

答案：

NaN概念：

  • Not-a-Number，非数字
  • 表示无效的数值运算结果

产生NaN的情况：

javascript
// 1. 数值运算失败
Number('abc');     // NaN
parseInt('abc');   // NaN
0 / 0;             // NaN
Math.sqrt(-1);     // NaN

// 2. 不确定结果
NaN + 1;           // NaN
NaN - 1;           // NaN
NaN * 2;           // NaN

// 3. undefined参与运算
undefined + 1;      // NaN

NaN特性：

javascript
// 1. NaN 不等于任何值，包括自身
NaN === NaN;  // false

// 2. typeof NaN 是 'number'
typeof NaN;   // 'number'

// 3. NaN 是全局对象的属性
window.NaN;   // NaN
globalThis.NaN; // NaN

检测NaN的方法：

javascript
// 方法1：Number.isNaN()（推荐）
Number.isNaN(NaN);        // true
Number.isNaN(0 / 0);      // true
Number.isNaN('abc');       // false，只对真正的NaN返回true

// 方法2：isNaN()（有副作用）
isNaN(NaN);     // true
isNaN('abc');   // true，'abc'被转成NaN
isNaN('123');   // false

// 方法3：自己判断
function isNaNValue(value) {
    return typeof value === 'number' && isNaN(value);
}

// 方法4：比较自身
function isNaNSelf(value) {
    return value !== value;
}

最佳实践：

javascript
// 推荐使用 Number.isNaN
if (Number.isNaN(result)) {
    console.error('计算错误');
}

// 或使用 Object.is（ES6）
Object.is(NaN, NaN);  // true

// 判断数值是否有效
function isValidNumber(value) {
    return typeof value === 'number' && !Number.isNaN(value);
}

补充说明：

  • Number.isNaN()是ES6新增，更准确
  • 旧版浏览器可能需要polyfill

问题：JavaScript 数据类型转换方式有哪些？什么是隐式类型转换？

显式类型转换：

javascript
// 1. Number()
Number('123');     // 123
Number('12.3');    // 12.3
Number('');        // 0
Number('abc');     // NaN
Number(true);      // 1
Number(false);     // 0
Number(null);      // 0

// 2. parseInt() / parseFloat()
parseInt('123');     // 123
parseInt('123abc');  // 123，遇到非数字停止

// 3. String()
String(123);        // '123'

// 4. Boolean()
Boolean(1);         // true

// 5. toString()

true.toString();      // 'true'
null.toString();      // ❌ 报错

// 6. + 运算符
+'123';        // 123
+'';           // 0
+true;         // 1

javascript
// 1. 算术运算符（+ - * / %）

// 5. 解构赋值
const [a, b] = 'ab';  // a='a', b='b'

问题：var、let、const 的区别是什么？

答案：

var、let、const对比：

特性varletconst
作用域函数作用域块级作用域块级作用域

代码示例：

javascript
// 1. 作用域
function test() {
    if (true) {
        var a = 1;
        let b = 2;
        const c = 3;
    }
    console.log(a);  // 1，var是函数作用域
    console.log(b);  // ❌ ReferenceError
    console.log(c);  // ❌ ReferenceError
}

// 2. 变量提升
console.log(a);  // undefined（变量提升）
var a = 1;

// console.log(b);  // ❌ ReferenceError
let b = 1;

// 3. 重复声明
var a = 1;
var a = 2;  // OK

let b = 1;
// let b = 2;  // ❌ SyntaxError

// 4. 暂时性死区（TDZ）
{
    // console.log(a);  // ❌ ReferenceError
    let a = 1;
    // const同理
}

// 5. const常量
const PI = 3.14159;
PI = 3.14;  // ❌ TypeError

// 但对象可以修改属性
const obj = { name: 'Tom' };
obj.name = 'Jerry';  // OK

// 冻结对象
Object.freeze(obj);
obj.name = 'Cat';  // ❌ TypeError

使用建议：

javascript
// 1. 优先使用const
const API_URL = 'https://api.example.com';
const config = { timeout: 3000 };

// 2. 需要重新赋值使用let
let count = 0;
count++;

// 3. 避免使用var
// var的变量提升和函数作用域容易产生bug

  • ES6+推荐const优先
  • var是旧语法，存在很多问题

8. 什么是变量提升？什么是暂时性死区（TDZ）？ ​

问题：什么是变量提升？什么是暂时性死区（TDZ）？

答案：

变量提升（Hoisting）：

javascript
// var的变量提升
console.log(a);  // undefined
var a = 1;

// 相当于
var a;           // 声明提升
console.log(a);  // undefined
a = 1;

// 函数声明提升
sayHello();  // 'Hello'
function sayHello() {
    console.log('Hello');
}

let和const的暂时性死区（TDZ）：

javascript
// let/const在声明前使用会报错
{
    // TDZ开始
    // console.log(b);  // ❌ ReferenceError
    let b = 'hello';
    // TDZ结束
    console.log(b);  // 'hello'
}

// const同样有TDZ
{
    // console.log(c);  // ❌ ReferenceError
    const c = 'world';
}

// TDZ的实际影响
function test() {
    // 这里形成了TDZ
    // typeof不安全的例子
    // typeof x;  // ❌ ReferenceError，不是undefined
    let x;
    typeof x;  // 'undefined'
}

var vs let/const 对比：

javascript
// var - 变量提升
console.log('var:', typeof varA);  // undefined
var varA = 1;

// let - 暂时性死区
// console.log('let:', typeof letA);  // ❌ ReferenceError
let letA = 1;

// 函数作用域 vs 块级作用域
function varDemo() {
    if (true) {
        var functionScope = 'function';
    }
    console.log(functionScope);  // 'function'
}

function letDemo() {
    if (true) {
        let blockScope = 'block';
    }
    // console.log(blockScope);  // ❌ ReferenceError
}

补充说明：

  • let/const解决了var的变量提升问题
  • TDZ强制要求先声明后使用

9. JavaScript 中的作用域有哪些类型？什么是作用域链？ ​

问题：JavaScript 中的作用域有哪些类型？什么是作用域链？

答案：

作用域类型：

javascript
// 1. 全局作用域
var globalVar = 'global';
let globalLet = 'global';
// 在任何地方都能访问

// 2. 函数作用域
function functionScope() {
    var functionVar = 'function';
    let functionLet = 'function';
    // 只在函数内部可访问
}

// 3. 块级作用域
{
    var blockVar = 'block';
    let blockLet = 'block';
    const blockConst = 'block';
    // let/const只在块内可访问
}

// 4. 词法作用域（静态作用域）
const outer = 'outer';
function outerFunc() {
    const inner = 'inner';
    function innerFunc() {
        console.log(inner);  // 能访问外层的inner
    }
    innerFunc();
}

// 5. 动态作用域（JavaScript不使用，但概念了解）
// this是动态绑定的

作用域链：

javascript
// 作用域链示例
const global = 'global';

function outer() {
    const outerVar = 'outer';
    
    function middle() {
        const middleVar = 'middle';
        
        function inner() {
            const innerVar = 'inner';
            console.log(innerVar);  // 1. 先找自身
            console.log(middleVar); // 2. 找外层
            console.log(outerVar); // 3. 继续外层
            console.log(global);   // 4. 最后找全局
        }
        
        inner();
    }
    
    middle();
}

outer();

// 查找过程形成链：inner → middle → outer → global

补充说明：

  • 作用域在函数定义时确定
  • 理解作用域链有助于闭包和性能优化

10. 为什么需要块级作用域？ ​

问题：为什么需要块级作用域？

答案：

块级作用域解决的问题：

javascript
// 问题1：循环中的var
for (var i = 0; i < 3; i++) {
    setTimeout(() => console.log(i), 100);
}
// 输出: 3, 3, 3（var是函数作用域，i被共享）

// 解决：使用let
for (let i = 0; i < 3; i++) {
    setTimeout(() => console.log(i), 100);
}
// 输出: 0, 1, 2（let是块级作用域，每次循环创建新i）
javascript
// 问题2：变量泄露
if (false) {
    var leakedVar = 'leaked';
}
console.log(leakedVar);  // undefined，var泄露到全局

// 解决：使用let
{
    let blockVar = 'block';
    // console.log(blockVar);  // ReferenceError
}
javascript
// 问题3：内层变量覆盖外层
var tmp = 'outer';

function test() {
    console.log(tmp);  // undefined，因为变量提升
    if (false) {
        var tmp = 'inner';
    }
}
test();

// 使用let不会有这个问题
let tmp2 = 'outer';
function test2() {
    // console.log(tmp2);  // ReferenceError
    let tmp2 = 'inner';
}

块级作用域的优势：

javascript
// 1. 变量不泄露
{
    let temp = 'temp';
}
// temp不可访问

// 2. 循环私有变量
for (let i = 0; i < 3; i++) {
    // 每次循环i都是新的
}

// 3. 更好的代码组织
if (condition) {
    let result = compute();
    // 只在这个块内使用
}
// result不可访问

补充说明：

  • let/const提供了块级作用域
  • 提高了代码的可预测性和可维护性

11. 全局变量与局部变量有什么区别？如何避免全局变量污染？ ​

问题：全局变量与局部变量有什么区别？如何避免全局变量污染？

答案：

全局变量 vs 局部变量：

javascript
// 全局变量
var globalVar = 'global';  // 在函数外定义
let globalLet = 'global';

function test() {
    // 局部变量
    var localVar = 'local';
    let localLet = 'local';
    console.log(globalVar);  // 可访问
}
console.log(localVar);  // ❌ ReferenceError

全局污染问题：

javascript
// 问题：多个脚本可能定义相同变量
// script1.js
var config = { debug: true };

// script2.js  
var config = { debug: false };  // 覆盖

// 全局对象污染window
var myVar = 'test';
window.myVar === myVar;  // true

避免全局污染的方法：

javascript
// 方法1：使用IIFE
(function() {
    var private = '私有';
    // 内部代码
})();

// 方法2：使用模块
const MyModule = (function() {
    const _private = '私有';
    
    return {
        publicMethod: function() { }
    };
})();

// 方法3：使用ES6模块
// module.js
const privateVar = '私有';
export function publicMethod() { }

// 方法4：命名空间
const MyApp = {
    version: '1.0',
    config: { },
    init: function() { }
};

// 方法5：let/const（不会添加到window）
let letVar = 'let';
window.letVar;  // undefined

最佳实践：

javascript
// 1. 尽量使用IIFE或模块
(function() {
    'use strict';
    // 严格模式避免隐式全局变量
})();

// 2. 统一管理配置
const AppConfig = {
    API_BASE: 'https://api.example.com',
    DEBUG: true
};

// 3. 使用构建工具打包
// Webpack会自动处理模块化

补充说明：

  • 现代开发推荐使用ES6模块
  • 构建工具可以避免全局污染

问题：函数声明与函数表达式的区别是什么？

// 柯里化函数
function curry(fn) {
    return function curried(...args) {
        if (args.length >= fn.length) {

            return curried.apply(this, args.concat(args2));
        };
    };
}

18. 函数组合是什么？如何实现？ ​

问题：函数组合是什么？如何实现？

答案：

函数组合概念：

  • 将多个函数组合成新函数
  • 从右到右执行

基础实现：

javascript
// compose: 从右到左执行
function compose(...fns) {
    return function(x) {
        return fns.reduceRight((acc, fn) => fn(acc), x);
    };
}

// pipe: 从左到右执行
function pipe(...fns) {
    return function(x) {
        return fns.reduce((acc, fn) => fn(acc), x);
    };
}

// 使用
const add = x => x + 1;
const multiply = x => x * 2;
const subtract = x => x - 3;

const composed = compose(subtract, multiply, add);
const piped = pipe(add, multiply, subtract);

// add(5) = 6
// multiply(6) = 12
// subtract(12) = 9
composed(5);  // 9
piped(5);     // 9

实际应用：

javascript
// 数据处理管道
const trim = str => str.trim();
const toLower = str => str.toLowerCase();
const split = str => str.split(',');
const map = fn => arr => arr.map(fn);
const join = arr => arr.join('-');

const processString = pipe(
    trim,
    toLower,
    split,
    map(trim),
    join
);

processString('A, B, C');  // 'a-b-c'

// 表单验证
const isRequired = val => val !== undefined && val !== null;
const isString = val => typeof val === 'string';
const isNotEmpty = val => val.trim().length > 0;

const validateName = pipe(
    isRequired,
    isString,
    isNotEmpty
);

validateName('Tom');   // true
validateName('');      // false
validateName(null);    // false

  • 函数组合是函数式编程的核心
  • pipe比compose更符合自然阅读顺序

答案：

尾调用概念：

  • 函数的最后一步是调用另一个函数
  • 不保留当前函数的调用栈
javascript
// 尾调用

    return fn2();  // 尾调用
}

// 非尾调用
function fn1() {
    const result = fn2();  // 需要返回result
    return result + 1;
}

function fn1() {
    return 1 + fn2();  // 需要计算1 + 结果
}

尾调用优化：

javascript
// 优化前：调用栈累积
function factorial(n) {
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}

// 调用栈: factorial(5) -> factorial(4) -> factorial(3)...

// 优化后：尾调用
function factorial(n, acc = 1) {
    if (n <= 1) return acc;
    return factorial(n - 1, n * acc);
}
factorial(5);
// 调用栈只有一层，因为是尾调用

// 实际示例
// 阶乘
function tailFactorial(n, total = 1) {
    if (n === 1) return total;
    return tailFactorial(n - 1, n * total);
}

// 斐波那契
function fibonacci(n, a = 1, b = 1) {
    if (n <= 1) return b;
    return fibonacci(n - 1, b, a + b);
}

补充说明：

  • ES6尾调用优化是语言层面的改进
  • 可以大幅减少调用栈，降低内存消耗

// 基础版深拷贝
function deepClone(obj) {
    // 处理null和基本类型
    if (obj === null || typeof obj !== 'object') {
        return obj;
    }
    
    // 处理Date
    if (obj instanceof Date) {
        return new Date(obj);
    }
    
    // 处理RegExp
    if (obj instanceof RegExp) {
        return new RegExp(obj);
    }
    
    // 处理数组
    if (Array.isArray(obj)) {
        return obj.map(item => deepClone(item));
    }
    
    // 处理对象
    const cloned = {};
    for (const key in obj) {
        if (obj.hasOwnProperty(key)) {
            cloned[key] = deepClone(obj[key]);
        }
    }
    return cloned;
}

// 完整版深拷贝（处理循环引用）
function deepClone(obj, hash = new WeakMap()) {
    // 处理null和基本类型
    if (obj === null || typeof obj !== 'object') {
        return obj;
    }
    
    // 处理循环引用
    if (hash.has(obj)) {
        return hash.get(obj);
    }
    
    // 处理Date
    if (obj instanceof Date) {
        return new Date(obj.getTime());
    }
    
    // 处理RegExp
    if (obj instanceof RegExp) {
        return new RegExp(obj.source, obj.flags);
    }
    
    // 处理Map
    if (obj instanceof Map) {
        const cloned = new Map();
        hash.set(obj, cloned);
        obj.forEach((value, key) => {
            cloned.set(key, deepClone(value, hash));
        });
        return cloned;
    }
    
    // 处理Set
    if (obj instanceof Set) {
        const cloned = new Set();
        hash.set(obj, cloned);
        obj.forEach(value => {
            cloned.add(deepClone(value, hash));
        });
        return cloned;
    }
    
    // 处理数组和对象
    const cloned = Array.isArray(obj) ? [] : {};
    hash.set(obj, cloned);
    
    for (const key in obj) {
        if (obj.hasOwnProperty(key)) {
            cloned[key] = deepClone(obj[key], hash);
        }
    }
    return cloned;
}

// 使用

    name: 'Tom',
    date: new Date(),
    regex: /abc/gi,
    map: new Map([['key', 'value']]),
    set: new Set([1, 2, 3])
};
const cloned = deepClone(original);

        return () => release();
    }

62. AMD、CMD、UMD 是什么？ ​

问题：AMD、CMD、UMD 是什么？

答案：

模块规范：

javascript
// AMD (Asynchronous Module Definition)
// RequireJS
define(['dep'], function(dep) {
    return function() { };
});

// CMD (Common Module Definition)
// SeaJS
define(function(require, exports, module) {
    var dep = require('dep');
    module.exports = function() { };
});

// UMD (Universal Module Definition)
// 同时支持AMD和CommonJS
(function(root, factory) {
    if (typeof define === 'function' && define.amd) {
        define(['jquery'], factory);
    } else if (typeof exports === 'object') {
        module.exports = factory(require('jquery'));
    } else {
        root.MyModule = factory(root.$);
    }
}(this, function($) {
    return { };
}));

  • AMD/CMD是前端模块化的历史方案
  • 现代推荐ES6 Module
