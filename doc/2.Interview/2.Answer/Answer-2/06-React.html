React 答案 ​

一、React 基础 ​

1. React 是什么？有什么特点？核心特性有哪些？ ​

问题：React 是什么？有什么特点？核心特性有哪些？

答案：

React是用于构建用户界面的JavaScript库。

核心特点：

  • 组件化开发
  • 虚拟DOM
  • 单向数据流
  • JSX语法
  • Hooks

2. JSX 是什么？与 HTML 的区别是什么？ ​

问题：JSX 是什么？与 HTML 的区别是什么？

答案：

JSX是JavaScript的语法扩展，看起来像HTML。

jsx
// JSX
const element = <div className="box">Hello</div>;

// 与HTML区别：
// 1. className vs class
// 2. style是对象
// 3. 事件用驼峰
// 4. 必须闭合标签

3. React 组件如何定义？函数组件与类组件的区别是什么？ ​

问题：React 组件如何定义？函数组件与类组件的区别是什么？

答案：

jsx
// 函数组件
function Welcome(props) {
    return <h1>Hello, {props.name}</h1>;
}

// 类组件
class Welcome extends React.Component {
    render() {
        return <h1>Hello, {this.props.name}</h1>;
    }
}

区别：

  • 函数组件更简洁
  • Hooks替代类组件状态管理
  • 类组件有生命周期

4. props、state 的作用是什么？ ​

问题：props、state 的作用是什么？

答案：

  • props：父组件传入的属性，只读
  • state：组件内部状态，可变

二、Hooks ​

5-17. Hooks相关 ​

useState：

jsx
const [count, setCount] = useState(0);

useEffect：

jsx
useEffect(() => {
    // 副作用
    return () => cleanup; // 清理
}, [dependencies]); // 依赖

useCallback/useMemo：

  • useCallback：缓存函数
  • useMemo：缓存计算结果

三-十二、组件通信与状态管理 ​

Context API：

jsx
const ThemeContext = React.createContext('light');

function App() {
    return (
        <ThemeContext.Provider value="dark">
            <Child />
        </ThemeContext.Provider>
    );
}

Redux：

  • Store：单一数据源
  • Action：描述行为
  • Reducer：纯函数处理状态

十三-十五、测试与工程化 ​

测试工具：

  • Jest：测试运行器
  • React Testing Library：React测试
  • Cypress：E2E测试

总结 ​

React是Facebook推出的UI库，核心特点是虚拟DOM和组件化。Hooks的引入使得函数组件可以完全替代类组件，推荐使用函数组件+Hooks开发。
