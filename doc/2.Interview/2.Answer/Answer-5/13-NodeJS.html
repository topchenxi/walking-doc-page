Node.js 答案 ​

Node.js 基础（1-5 题） ​

1. Node.js 是什么？ ​

答案： Node.js：基于 Chrome V8 引擎的 JavaScript 运行时。

特点：

  • 异步非阻塞 I/O
  • 事件驱动
  • 单线程
  • 适合高并发场景

6. Node.js 的事件循环机制是什么？ ​

答案： Event Loop 阶段：

   ┌───────────────────────┐
┌─>│        timers         │
│  └──────────┬────────────┘
│  ┌──────────┴────────────┐
│  │     pending callbacks │
│  └──────────┬────────────┘
│  ┌──────────┴────────────┐
│  │     idle, prepare     │
│  └──────────┬────────────┘      ┌───────────────┐
│  ┌──────────┴────────────┐      │   incoming:   │
│  │         poll          │<─────┤  connections, │
│  └──────────┬────────────┘      │   data, etc.  │
│  ┌──────────┴────────────┐      └───────────────┘
│  │        check          │
│  └──────────┬────────────┘
│  ┌──────────┴────────────┐
└──┤    close callbacks    │
   └───────────────────────┘

11. CommonJS 模块规范是什么？ ​

答案：

javascript
// 导出
module.exports = { a: 1 };
exports.b = 2;

// 导入
const module = require('./module');

// 与 ES6 模块区别
// CommonJS：运行时加载，值拷贝
// ES6：编译时加载，引用

文件系统（16-20 题） ​

16. Node.js 文件系统模块 fs 的常用方法有哪些？ ​

答案：

javascript
const fs = require('fs');

// 同步读取
const data = fs.readFileSync('file.txt', 'utf8');

// 异步读取
fs.readFile('file.txt', 'utf8', (err, data) => {});

// Promise 方式
const fsPromises = require('fs').promises;
const data = await fsPromises.readFile('file.txt', 'utf8');

HTTP 服务器（21-25 题） ​

21. 如何使用 Node.js 创建 HTTP 服务器？ ​

答案：

javascript
const http = require('http');

const server = http.createServer((req, res) => {
  res.statusCode = 200;
  res.setHeader('Content-Type', 'text/plain');
  res.end('Hello World\n');
});

server.listen(3000, () => {
  console.log('Server running at http://localhost:3000/');
});

Express/Koa 框架（26-31 题） ​

26. Express 框架的特点是什么？ ​

答案：

  • 简洁灵活
  • 中间件机制
  • 路由强大
  • 生态丰富
javascript
const express = require('express');
const app = express();

app.get('/', (req, res) => {
  res.send('Hello World');
});

app.listen(3000);
