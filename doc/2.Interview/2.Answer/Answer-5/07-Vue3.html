Vue3 答案 ​

一、Vue3 概述与对比（1-7 题） ​

1. Vue 3 相比 Vue 2 有哪些主要改进？ ​

答案： 主要改进：

  1. 性能提升：

    • 打包体积减少 41%
    • 初次渲染快 55%
    • 更新渲染快 133%

  2. Composition API：

    • 更好的代码组织
    • 逻辑复用更简单
    • TypeScript 支持更好

  3. 响应式系统升级：

    • 使用 Proxy 替代 Object.defineProperty
    • 支持数组和对象的新增/删除检测
    • 性能更好

  4. 新特性：

    • Fragments（多根节点）
    • Teleport（传送门）
    • Suspense（异步组件）
    • 新的生命周期

2. Vue3 与 Vue2 的主要区别是什么？ ​

答案：

特性Vue 2Vue 3
API 风格Options APIComposition API
响应式Object.definePropertyProxy
多根节点✗✓（Fragments）
TypeScript支持一般优秀
体积较大更小（Tree-shaking）
生命周期标准新增钩子
javascript
// Vue 2 Options API
export default {
  data() { return { count: 0 }; },
  methods: { inc() { this.count++; } }
}

// Vue 3 Composition API
import { ref } from 'vue';
export default {
  setup() {
    const count = ref(0);
    const inc = () => count.value++;
    return { count, inc };
  }
}

二、Composition API 核心概念（8-18 题） ​

8. Composition API 与 Options API 的区别是什么？ ​

答案： Options API：

javascript
export default {
  data() { return { count: 0 }; },
  methods: { inc() { this.count++; } },
  computed: { double() { return this.count * 2; } }
}

Composition API：

javascript
import { ref, computed } from 'vue';

export default {
  setup() {
    const count = ref(0);
    const inc = () => count.value++;
    const double = computed(() => count.value * 2);
    
    return { count, inc, double };
  }
}

优势：

  • 逻辑按功能组织，而非选项
  • 更容易抽离和复用
  • TypeScript 推断更好

9. Composition API 比 Options API 好在哪？ ​

答案： 1. 逻辑复用：

javascript
// Composable 函数
function useCounter(initialValue = 0) {
  const count = ref(initialValue);
  const increment = () => count.value++;
  return { count, increment };
}

// 多个组件复用
const { count, increment } = useCounter();

2. 代码组织：

javascript
// 相关逻辑放在一起
setup() {
  // 搜索相关
  const searchQuery = ref('');
  const searchResults = ref([]);
  
  // 分页相关
  const currentPage = ref(1);
  const totalPages = ref(10);
  
  return { searchQuery, searchResults, currentPage, totalPages };
}

3. TypeScript 支持：更好的类型推断

10. setup 函数有什么作用？执行时机是什么？ ​

答案： setup 函数：Composition API 的入口。

执行时机：

  • beforeCreate 之前
  • props 解析之后
javascript
export default {
  props: ['title'],
  setup(props, context) {
    console.log(props.title);
    
    context.attrs;     // 属性
    context.slots;     // 插槽
    context.emit;      // 触发事件
    
    return { /* 暴露给模板 */ };
  }
};

11. <script setup> 语法糖的作用是什么？ ​

答案： 简化写法：

vue
<!-- 传统 -->
<script>
export default {
  setup() {
    const count = ref(0);
    return { count };
  }
}
</script>

<!-- script setup -->
<script setup>
import { ref } from 'vue';
const count = ref(0);
</script>

优势：

  • 更少的样板代码
  • 自动导入返回值
  • 更好的 TypeScript 支持

12. ref 和 reactive 的区别与使用场景是什么？ ​

答案：

特性refreactive
类型基本类型 + 对象仅对象
访问.value直接访问
替换可替换整个对象不可替换
用途通用复杂对象
javascript
import { ref, reactive } from 'vue';

// ref
const count = ref(0);
count.value++;

const user = ref({ name: 'Alice' });
user.value = { name: 'Bob' };  // ✓ 可替换

// reactive
const state = reactive({ count: 0 });
state.count++;

const obj = reactive({ name: 'Alice' });
obj = { name: 'Bob' };  // ✗ 不能替换

使用建议：

  • 基本类型用 ref
  • 对象可用 ref 或 reactive
  • 统一使用 ref 更一致

13-18. 其他响应式 API ​

javascript
// toRefs / toRef
const state = reactive({ x: 1, y: 2 });
const { x, y } = toRefs(state);  // 保持响应式

// shallowRef / shallowReactive
const shallow = shallowRef({});
shallow.value = {};  // ✓ 内部不响应式

// readonly / shallowReadonly
const original = reactive({ x: 1 });
const readOnlyCopy = readonly(original);

// isRef / isReactive
isRef(ref(0));      // true
isReactive({});     // false

// markRaw / toRaw
const rawObj = markRaw({});  // 非响应式
const plain = toRaw(reactive({}));  // 原始对象

三、响应式系统原理（19-24 题） ​

19. Vue3 的响应式原理是什么？ ​

答案： Proxy 实现：

javascript
function reactive(target) {
  return new Proxy(target, {
    get(target, key, receiver) {
      track(target, key);  // 收集依赖
      return Reflect.get(target, key, receiver);
    },
    set(target, key, value, receiver) {
      const result = Reflect.set(target, key, value, receiver);
      trigger(target, key);  // 触发更新
      return result;
    }
  });
}

对比 Vue 2：

  • 支持数组索引修改
  • 支持对象属性新增/删除
  • 性能更好

20. 为什么 Vue3 弃用 Object.defineProperty？ ​

答案： 限制：

  1. 无法检测对象属性的添加或删除
  2. 无法监控数组索引和长度变化
  3. 需要递归遍历所有属性

示例：

javascript
// Vue 2 问题
this.obj.newProp = 'value';  // 不会触发更新
this.arr[0] = 'new';         // 不会触发更新

// 解决方案
Vue.set(this.obj, 'newProp', 'value');
this.$set(this.arr, 0, 'new');

// Vue 3 自动支持
obj.newProp = 'value';  // ✓ 触发更新
arr[0] = 'new';         // ✓ 触发更新

四、生命周期钩子（25-27 题） ​

25. Vue3 生命周期钩子的变化有哪些？ ​

答案： 新增钩子：

javascript
import { 
  onBeforeMount,
  onMounted,
  onBeforeUpdate,
  onUpdated,
  onBeforeUnmount,
  onUnmounted,
  onErrorCaptured
} from 'vue';

export default {
  setup() {
    onMounted(() => {
      console.log('mounted');
    });
    
    onUpdated(() => {
      console.log('updated');
    });
  }
};

映射关系：

  • beforeCreate → setup()
  • created → setup()
  • beforeMount → onBeforeMount
  • mounted → onMounted
  • beforeUpdate → onBeforeUpdate
  • updated → onUpdated

五、Teleport 与 Suspense（31-33 题） ​

31. Teleport 组件的作用是什么？如何使用？ ​

答案： Teleport：将组件内容传送到指定位置。

vue
<template>
  <teleport to="body">
    <div class="modal">
      <slot></slot>
    </div>
  </teleport>
</template>

<!-- 实际渲染到 body 下 -->
<body>
  <div class="modal">...</div>
</body>

应用场景：

  • 模态框
  • Toast 提示
  • 全屏组件

32. Suspense 组件的作用是什么？ ​

答案： Suspense：处理异步组件的加载状态。

vue
<template>
  <suspense>
    <template #default>
      <AsyncComponent />
    </template>
    <template #fallback>
      <div>Loading...</div>
    </template>
  </suspense>
</template>

<script setup>
import { defineAsyncComponent } from 'vue';
const AsyncComponent = defineAsyncComponent(
  () => import('./Comp.vue')
);
</script>

40. Vue3 的性能优化手段有哪些？ ​

答案： 1. 编译时优化：

2. 运行时优化：

  • Proxy 响应式更快
  • 虚拟 DOM 重写
  • 更小的包体积

3. 开发优化：

  • Tree-shaking 支持
  • 按需导入
