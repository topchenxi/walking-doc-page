浏览器答案 ​

浏览器架构（1-4 题） ​

1. 浏览器的渲染引擎有哪些？ ​

答案：

  • WebKit：Safari
  • Blink：Chrome（WebKit 分支）
  • Gecko：Firefox
  • EdgeHTML：旧 Edge
  • Trident：旧 IE

5. 浏览器渲染页面的流程是什么？ ​

答案：

HTML → DOM Tree
CSS → CSSOM Tree
     ↓
Render Tree（渲染树）
     ↓
Layout（布局/回流）
     ↓
Paint（绘制/重绘）
     ↓
Composite（合成）

渲染原理（5-12 题） ​

10. 什么是重绘（Repaint）和回流（Reflow）？ ​

答案： 重绘：外观改变（颜色、背景），不影响布局。 回流：几何属性改变（尺寸、位置），重新计算布局。

性能影响：回流 > 重绘

事件循环（13-17 题） ​

13. 浏览器的事件循环机制是什么？ ​

答案： Event Loop：

执行同步代码（调用栈）
   ↓
异步任务 → 任务队列
   ↓
清空微任务
   ↓
执行下一个宏任务

任务分类：

  • 宏任务：setTimeout, setInterval
  • 微任务：Promise.then, MutationObserver

垃圾回收（18-22 题） ​

18. 浏览器的垃圾回收机制是什么？ ​

答案： 回收算法：

  1. 标记清除：标记可达对象，清除不可达
  2. 引用计数：计数为 0 时回收（有循环引用问题）

存储机制（23-27 题） ​

23. Cookie、LocalStorage、SessionStorage 的区别是什么？ ​

答案：

特性CookieLocalStorageSessionStorage
大小4KB5MB5MB
有效期可设置永久会话级
发送随请求不发送不发送

安全机制（31-35 题） ​

31. XSS 攻击的原理和防范方法是什么？ ​

答案： XSS：跨站脚本攻击。

防范：

  1. 转义用户输入
  2. 设置 HttpOnly
  3. CSP 内容安全策略
javascript
// 转义 HTML
function escapeHtml(str) {
  return str.replace(/[&<>"']/g, tag => ({
    '&': '&amp;',
    '<': '&lt;',
    '>': '&gt;',
    '"': '&quot;',
    "'": '&#39;'
  }[tag]));
}

同源策略与跨域（36-40 题） ​

36. 同源策略是什么？ ​

答案： 同源策略：协议、域名、端口必须相同。

跨域解决方案：

  1. CORS
  2. JSONP
  3. 代理
  4. postMessage
