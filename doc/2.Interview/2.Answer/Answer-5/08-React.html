React 答案 ​

一、React 基础概念（1-4 题） ​

1. 谈谈你对 React 的理解，以及它的工作原理 ​

答案： React：用于构建用户界面的 JavaScript 库。

核心特性：

  1. 组件化：UI 拆分为独立可复用组件
  2. 声明式：描述 UI 应该是什么样子
  3. 虚拟 DOM：高效的 DOM 操作
  4. 单向数据流：数据从父到子流动
  5. JSX：JavaScript + XML

工作原理：

State/Props 变化 
→ Virtual DOM 更新 
→ Diff 算法对比 
→ 最小化真实 DOM 操作

2. React 有哪些核心特性？ ​

答案：

  1. Virtual DOM：内存中的 DOM 表示
  2. 组件系统：函数组件/类组件
  3. 单向数据流：props 向下传递
  4. 声明式编程：关注状态而非过程
  5. Hooks：让函数组件有状态

3. React 与 Vue.js 的相似性和差异性是什么？ ​

答案：

特性ReactVue
语法JSX模板语法
数据流单向双向绑定
状态管理Redux/MobXVuex/Pinia
学习曲线陡峭平缓
灵活性高中等
生态庞大完善

二、JSX 语法（5-8 题） ​

5. JSX 是什么？其本质是什么？ ​

答案： JSX：JavaScript XML，语法糖。

本质：React.createElement() 的语法糖。

javascript
// JSX
<div className="box">Hello</div>

// 编译后
React.createElement(
  'div',
  { className: 'box' },
  'Hello'
);

6. JSX 与 JS 的区别是什么？ ​

答案：

javascript
// 1. class → className
<div class="box"></div>  // ✗ HTML
<div className="box"></div>  // ✓ JSX

// 2. for → htmlFor
<label for="name"></label>  // ✗
<label htmlFor="name"></label>  // ✓

// 3. 表达式用 {}
const name = 'Alice';
<div>Hello, {name}</div>

// 4. 内联样式
<div style={{ color: 'red', fontSize: '14px' }}></div>

// 5. 自闭合标签
<img src="logo.png" />

三、组件与 Props（9-13 题） ​

9. 函数组件与类组件有什么区别？ ​

答案： 类组件：

javascript
class Welcome extends React.Component {
  constructor(props) {
    super(props);
    this.state = { count: 0 };
  }
  
  render() {
    return <h1>{this.props.text}</h1>;
  }
}

函数组件：

javascript
function Welcome(props) {
  const [count, setCount] = useState(0);
  return <h1>{props.text}</h1>;
}

区别：

  • 类组件：有生命周期、this、状态
  • 函数组件：简洁、无 this、使用 Hooks

10. Props 是什么？如何使用？ ​

答案： Props：组件的输入参数。

javascript
// 父组件
<Welcome name="Alice" age={25} />

// 子组件接收
function Welcome(props) {
  return <h1>{props.name}, {props.age}</h1>;
}

// 解构
function Welcome({ name, age }) {
  return <h1>{name}, {age}</h1>;
}

// 默认值
Welcome.defaultProps = {
  age: 18
};

四、State 与生命周期（14-22 题） ​

14. State 是什么？如何使用？ ​

答案： State：组件的内部状态。

类组件：

javascript
class Counter extends React.Component {
  constructor(props) {
    super(props);
    this.state = { count: 0 };
  }
  
  increment = () => {
    this.setState({ count: this.state.count + 1 });
  };
  
  render() {
    return <div>{this.state.count}</div>;
  }
}

函数组件：

javascript
function Counter() {
  const [count, setCount] = useState(0);
  
  return (
    <button onClick={() => setCount(count + 1)}>
      {count}
    </button>
  );
}

15. State 与 Props 的区别是什么？ ​

答案：

特性PropsState
来源父组件传入组件内部
修改只读可修改
用途配置组件管理状态
数据流自上而下内部维护

16. setState 是同步还是异步的？ ​

答案： 异步（批处理）。

javascript
this.setState({ count: this.state.count + 1 });
this.setState({ count: this.state.count + 1 });
this.setState({ count: this.state.count + 1 });

// 结果：+1 而非 +3

// 正确写法
this.setState((prev) => ({ count: prev.count + 1 }));

原因：性能优化，合并多次更新。

17. setState 的合并机制是什么？ ​

答案： 浅合并：

javascript
state = { a: 1, b: 2 };

this.setState({ a: 2 });  // 只更新 a
// state = { a: 2, b: 2 }

// 对象展开
this.setState({ ...state, c: 3 });

五、React Hooks（44-51 题） ​

44. React Hooks 是什么？为什么要引入 Hooks？ ​

答案： Hooks：让函数组件使用状态和生命周期。

优势：

  1. 逻辑复用更简单
  2. 代码更简洁
  3. 更好的 TypeScript 支持
  4. 避免 this 问题

45. useState 如何使用？ ​

答案：

javascript
import { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);
  
  return (
    <button onClick={() => setCount(count + 1)}>
      {count}
    </button>
  );
}

// 多个状态
const [name, setName] = useState('');
const [age, setAge] = useState(0);

46. useEffect 如何使用？ ​

答案：

javascript
import { useState, useEffect } from 'react';

function Example() {
  const [data, setData] = useState(null);
  
  // 类似 componentDidMount + componentDidUpdate
  useEffect(() => {
    fetchData();
    
    // 清理函数（componentWillUnmount）
    return () => {
      cleanup();
    };
  }, [dependency]);  // 依赖数组
  
  return <div>{data}</div>;
}

依赖项：

javascript
useEffect(() => { });           // 每次渲染
useEffect(() => {}, []);        // 仅首次
useEffect(() => {}, [prop]);    // prop 变化时

47. useEffect 与生命周期的对应关系是什么？ ​

答案：

componentDidMount     → useEffect(() => {}, [])
componentDidUpdate    → useEffect(() => {})
componentWillUnmount  → useEffect(() => { return cleanup; })

48. useCallback 与 useMemo 的区别是什么？ ​

答案：

Hook用途返回值
useCallback缓存函数函数引用
useMemo缓存计算结果计算结果
javascript
// useCallback
const handleClick = useCallback(() => {
  console.log('clicked');
}, [dep]);

// useMemo
const doubled = useMemo(() => {
  return count * 2;
}, [count]);

49. useRef 如何使用？ ​

答案：

javascript
const inputRef = useRef(null);

<input ref={inputRef} />;

<button onClick={() => inputRef.current.focus()}>
  Focus
</button>

// 保存可变值
const countRef = useRef(0);
countRef.current++;  // 不触发渲染

六、虚拟 DOM 与 Diff 算法（52-57 题） ​

52. 什么是虚拟 DOM（Virtual DOM）？ ​

答案： Virtual DOM：用 JavaScript 对象描述 DOM 结构。

javascript
// 真实 DOM
<div class="box">Hello</div>

// Virtual DOM
{
  type: 'div',
  props: {
    className: 'box',
    children: 'Hello'
  }
}

优势：

  • 避免频繁操作真实 DOM
  • 通过 Diff 算法最小化更新

53. 虚拟 DOM 的优势是什么？ ​

答案：

  1. 性能：批量更新 DOM
  2. 跨平台：可渲染到不同环境
  3. 可测试性：易于单元测试

54. Diff 算法是什么？ ​

答案： Diff 算法：对比两棵树的差异。

策略：

  1. 同层比较
  2. 不同类型直接替换
  3. key 优化列表

七、性能优化（58-62 题） ​

58. React 性能优化的方法有哪些？ ​

答案：

  1. React.memo：组件记忆化
  2. useMemo/useCallback：缓存计算
  3. 代码分割：lazy + Suspense
  4. 虚拟列表：react-window
  5. 避免内联对象：使用引用
javascript
// React.memo
const MemoComp = React.memo(MyComponent);

// 代码分割
const LazyComp = React.lazy(() => import('./Comp'));
