项目经验（1-5 题） ​

1. 请介绍一下你最近参与的项目 ​

回答模板：

项目名称：XXX 管理系统
技术栈：Vue3 + TypeScript + Element Plus
我的职责：
1. 负责核心模块开发（用户管理、权限控制）
2. 性能优化（首屏加载从 3s 优化到 1s）
3. 组件库建设（封装 20+ 通用组件）
项目成果：已上线，日活用户 XXX

2. 你在项目中遇到的最大挑战是什么？如何解决的？ ​

回答示例：

挑战：大型列表渲染卡顿
解决：
1. 虚拟滚动（只渲染可见区域）
2. 时间分片（避免长任务阻塞）
3. Web Worker（复杂计算放后台）
结果：渲染性能提升 10 倍

测试（34-38 题） ​

34. 前端测试的类型有哪些？ ​

答案：

  1. 单元测试：测试单个函数/组件

    javascript
    test('add(1, 2) should return 3', () => {
  expect(add(1, 2)).toBe(3);
});

  2. 集成测试：测试模块间交互

  3. E2E 测试：端到端测试完整流程

其他技术（39-43 题） ​

39. WebAssembly 是什么？ ​

答案： WebAssembly：二进制指令格式，可在浏览器运行。

优势：

  • 接近原生性能
  • 多语言支持（C/C++/Rust）
  • 与 JS 互操作

40. GraphQL 与 REST API 的区别是什么？ ​

答案：

特性RESTGraphQL
数据获取固定端点按需查询
请求次数可能多次一次
类型系统无强类型
