Vue 答案 ​

一、Vue 基础概念（1-5 题） ​

1. Vue.js 是什么？其核心特性有哪些？ ​

答案： Vue.js：渐进式 JavaScript 框架，用于构建用户界面。

核心特性：

  1. 响应式数据绑定：数据变化自动更新视图
  2. 组件系统：可复用的组件化开发
  3. 指令系统：v-if, v-for, v-model 等
  4. 虚拟 DOM：高效的 DOM 操作
  5. 路由与状态管理：Vue Router、Vuex
  6. 渐进式增强：可逐步采用功能
javascript
// 基础示例
new Vue({
  el: '#app',
  data: { message: 'Hello Vue!' },
  methods: {
    update() { this.message = 'Updated'; }
  }
});

2. MVVM 模式的理解是什么？在 Vue 中如何体现？ ​

答案： MVVM：Model-View-ViewModel 架构模式。

  • Model：数据和业务逻辑
  • View：用户界面
  • ViewModel：连接 Model 和 View，实现双向绑定

Vue 中的体现：

javascript
// ViewModel
new Vue({
  data: {     // Model
    message: 'Hello'
  },
  template: ` // View
    <div>{{ message }}</div>
  `
});

3-5. Vue 的优缺点、渐进式特点 ​

优点：

  • 轻量级（~20KB）
  • 易上手
  • 文档友好
  • 生态完善

缺点：

  • 社区规模小于 React
  • 国内使用较多

渐进式：可从简单的页面交互到完整的 SPA 应用。

二、Vue 实例与生命周期（6-10 题） ​

6. Vue 生命周期有哪些？各阶段作用是什么？ ​

答案： 生命周期钩子：

javascript
new Vue({
  beforeCreate() {
    // 实例初始化后，数据观测之前
  },
  created() {
    // 实例创建完成，可访问数据
    // 发起异步请求
  },
  beforeMount() {
    // 模板编译/挂载之前
  },
  mounted() {
    // 挂载完成，可访问 DOM
    // 操作 DOM、定时器
  },
  beforeUpdate() {
    // 数据更新时，DOM 更新前
  },
  updated() {
    // DOM 更新完成
  },
  beforeDestroy() {
    // 实例销毁前
    // 清理定时器、事件监听
  },
  destroyed() {
    // 实例已销毁
  }
});

7. created 与 mounted 的区别是什么？ ​

答案：

钩子时机DOM用途
created实例创建完成不可访问数据初始化、请求
mounted挂载完成可访问DOM 操作、第三方库
javascript
export default {
  data() { return { list: [] }; },
  
  created() {
    this.fetchData();  // ✓ 可以
  },
  
  mounted() {
    this.$refs.input.focus();  // ✓ 可以
  }
};

8. Vue 父子组件生命周期执行顺序是什么？ ​

答案：

加载：父 beforeCreate → 父 created → 父 beforeMount 
     → 子 beforeCreate → 子 created → 子 beforeMount 
     → 子 mounted → 父 mounted

更新：父 beforeUpdate → 父 updated
     → 子 beforeUpdate → 子 updated

销毁：父 beforeDestroy → 子 beforeDestroy 
     → 子 destroyed → 父 destroyed

三、模板语法与指令系统（11-16 题） ​

11. Vue 常用指令有哪些？ ​

答案：

html
<!-- 条件渲染 -->
<div v-if="condition">显示</div>
<div v-else>隐藏</div>
<div v-show="visible">显示/隐藏</div>

<!-- 列表渲染 -->
<ul>
  <li v-for="(item, index) in list" :key="item.id">
    {{ item.name }}
  </li>
</ul>

<!-- 双向绑定 -->
<input v-model="message">

<!-- 属性绑定 -->
<img :src="imageUrl" :alt="title">

<!-- 事件绑定 -->
<button @click="handleClick">点击</button>

<!-- 其他 -->
<span v-text="text"></span>
<div v-html="<p>HTML</p>"></div>
<div v-pre>不编译</div>
<div v-once>只渲染一次</div>

12. v-if 与 v-show 的区别是什么？ ​

答案：

特性v-ifv-show
原理添加/删除 DOMdisplay 切换
开销高低
适用不频繁切换频繁切换
html
<!-- v-if：完全移除 -->
<div v-if="show">内容</div>

<!-- v-show：CSS 隐藏 -->
<div v-show="show">内容</div>

13. v-for 为什么要绑定 key？ ​

答案： 原因：帮助 Vue 识别节点，高效更新虚拟 DOM。

html
<!-- ❌ 不推荐：使用 index -->
<li v-for="(item, i) in list" :key="i">{{ item.name }}</li>

<!-- ✅ 推荐：使用唯一 ID -->
<li v-for="item in list" :key="item.id">{{ item.name }}</li>

最佳实践：

  • 使用唯一且稳定的 ID
  • 避免使用数组索引
  • 不要使用随机数

14. v-model 的原理是什么？ ​

答案： 本质：语法糖，双向绑定的简写。

html
<!-- 等价于 -->
<input :value="message" @input="message = $event.target.value">

<!-- v-model -->
<input v-model="message">

修饰符：

html
<input v-model.lazy="msg">      <!-- 失去焦点时更新 -->
<input v-model.number="age">    <!-- 转为数字 -->
<input v-model.trim="name">     <!-- 去除首尾空格 -->

四、计算属性与侦听器（17-20 题） ​

17. computed 与 methods 的区别是什么？ ​

答案：

特性computedmethods
缓存✓（依赖不变不重新计算）✗（每次调用都执行）
使用作为属性作为函数调用
异步✗✓
javascript
export default {
  data() { return { firstName: 'John', lastName: 'Doe' }; },
  
  computed: {
    fullName() {
      return this.firstName + ' ' + this.lastName;
    }
  },
  
  methods: {
    getFullName() {
      return this.firstName + ' ' + this.lastName;
    }
  }
};

18. computed 与 watch 的区别是什么？ ​

答案：

特性computedwatch
用途依赖多个数据计算新值监听单个数据变化
返回值有无
异步✗✓
缓存✓✗
javascript
export default {
  data() { return { a: 1, b: 2 }; },
  
  computed: {
    sum() { return this.a + this.b; }
  },
  
  watch: {
    a(newVal) {
      console.log('a changed:', newVal);
    }
  }
};

五、组件系统（21-28 题） ​

21. Vue 组件的定义与创建方式有哪些？ ​

答案：

javascript
// 全局组件
Vue.component('my-component', {
  template: '<div>Content</div>'
});

// 局部组件
const Child = {
  template: '<div>Child</div>'
};

new Vue({
  components: {
    'child-component': Child
  }
});

// 单文件组件
<template>
  <div>{{ message }}</div>
</template>

<script>
export default {
  data() { return { message: 'Hello' }; }
}
</script>

23. Vue 中 data 为什么必须是一个函数？ ​

答案： 原因：每个组件实例拥有独立的数据副本。

javascript
// ❌ 错误：对象引用
data: { count: 0 }

// ✅ 正确：返回新对象
data() {
  return { count: 0 };
}

解释：如果 data 是对象，所有组件共享同一个引用，修改会影响所有实例。

24. Vue 组件间通信的方式有哪些？ ​

答案： 1. 父子通信：

  • props / $emit
  • $parent / $children
  • $refs

2. 跨级通信：

  • provide / inject
  • $attrs / $listeners
  • EventBus

3. 任意组件：

  • Vuex
  • Event Bus
javascript
// Props & Emit
// Parent
<Child :msg="message" @update="handleUpdate" />

// Child
this.$emit('update', newValue);

// Provide & Inject
// Parent
provide() {
  return { theme: this.theme };
}

// Child
inject: ['theme']

六、Vue Router（32-37 题） ​

32. Vue Router 是什么及其作用？ ​

答案： Vue Router：Vue 官方的路由管理器。

作用：

  • 实现 SPA 单页应用
  • URL 与组件映射
  • 路由传参
  • 导航守卫
javascript
const router = new VueRouter({
  routes: [
    { path: '/', component: Home },
    { path: '/user/:id', component: User }
  ]
});

特性Hash 模式History 模式
URL#/path/path

// Hash

七、Vuex（38-41 题） ​

38. Vuex 有哪些核心概念？ ​

答案：

  1. State：单一状态树
  2. Getters：计算属性
  3. Mutations：同步修改 state
  4. Actions：异步操作
  5. Modules：模块化
javascript
const store = new Vuex.Store({
  state: { count: 0 },
  
  mutations: {
    increment(state) { state.count++; }
  },
  
  actions: {
    asyncIncrement({ commit }) {
      setTimeout(() => commit('increment'), 1000);
    }
  },
  
  getters: {
    doubleCount: state => state.count * 2
  }
});

八、Vue 原理（42-46 题） ​

42. Vue 的响应式原理是什么？ ​

答案： Vue 2：Object.defineProperty

javascript
function defineReactive(obj, key, val) {
  Object.defineProperty(obj, key, {
    get() {
      console.log('get');
      return val;
    },
    set(newVal) {
      console.log('set');
      val = newVal;
      notify();  // 通知更新
    }
  });
}

Vue 3：Proxy

javascript
const obj = new Proxy(data, {
  get(target, key) {
    track(target, key);
    return target[key];
  },
  set(target, key, value) {
    target[key] = value;
    trigger(target, key);
  }
});
