TypeScript 答案 ​

一、TypeScript 概述（1-3 题） ​

1. TypeScript 的优缺点是什么？ ​

答案： 优点：

  1. 类型安全：编译时检查类型错误
  2. 代码提示：IDE 智能补全
  3. 可维护性：类型定义即文档
  4. 兼容性：完全兼容 JavaScript
  5. 重构友好：安全重命名和移动

缺点：

  1. 学习曲线：需要学习类型系统
  2. 开发时间：编写类型定义增加工作量
  3. 配置复杂：需要 tsconfig.json
  4. 过度设计：简单项目可能不需要

2. TypeScript 与 JavaScript 的区别是什么？ ​

答案：

特性TypeScriptJavaScript
类型系统静态类型动态类型
编译需要编译直接运行
面向对象完整的类、接口ES6 Class
泛型支持不支持
枚举支持不支持
元组支持不支持

3. 如何集成 TypeScript？ ​

答案：

bash
# 安装
npm install -D typescript

# 初始化配置
npx tsc --init

# 编译
tsc filename.ts
tsc --watch  # 监听模式

tsconfig.json 基础配置：

json
{
  "compilerOptions": {
    "target": "ES2015",
    "module": "commonjs",
    "strict": true,
    "esModuleInterop": true,
    "outDir": "./dist"
  }
}

二、类型系统（4-10 题） ​

4. TypeScript 有哪些基础类型？ ​

答案：

typescript
// 布尔值
let isDone: boolean = false;

// 数字
let count: number = 42;
let hex: number = 0xf00d;
let binary: number = 0b1010;
let octal: number = 0o744;

// 字符串
let name: string = "Alice";
let greeting: string = `Hello, ${name}`;

// 数组
let list: number[] = [1, 2, 3];
let genericList: Array<number> = [1, 2, 3];

// 元组
let tuple: [string, number] = ["Alice", 25];

// 枚举
enum Color { Red, Green, Blue }
let c: Color = Color.Green;

// any
let notSure: any = 4;

// void
function warnUser(): void {
  console.log("Warning");
}

// null 和 undefined
let u: undefined = undefined;
let n: null = null;

// never
function error(message: string): never {
  throw new Error(message);
}

// object
let obj: object = { x: 0, y: 0 };

5. 什么是联合类型？ ​

答案： 联合类型：表示值可能是多种类型之一。

typescript
let id: string | number;
id = "ABC123";  // ✓
id = 123;       // ✓
id = true;      // ✗

// 类型保护
function printId(id: number | string) {
  if (typeof id === "string") {
    console.log(id.toUpperCase());
  } else {
    console.log(id);
  }
}

6. 什么是交叉类型？ ​

答案： 交叉类型：将多个类型合并为一个类型。

typescript
interface A { a: string; }
interface B { b: number; }

type C = A & B;

const obj: C = {
  a: "hello",
  b: 42
};

7-10. 类型相关区别 ​

any vs unknown：

typescript
let anyValue: any = "text";
let len: number = anyValue.length;  // ✓ 不安全

let unknownValue: unknown = "text";
// let len: number = unknownValue.length;  // ✗
if (typeof unknownValue === "string") {
  let len: number = unknownValue.length;  // ✓ 安全
}

void vs never：

  • void：函数无返回值
  • never：函数永不返回（抛出异常或死循环）

三、接口与类型别名（11-15 题） ​

11. Interface 接口的定义方式是什么？ ​

答案：

typescript
interface User {
  id: number;
  name: string;
  email?: string;  // 可选属性
  readonly createdAt: Date;  // 只读
  
  // 方法
  login(): Promise<void>;
  
  // 索引签名
  [key: string]: any;
}

// 实现接口
class Admin implements User {
  id: number = 1;
  name: string = "Admin";
  readonly createdAt: Date = new Date();
  
  login() {
    return Promise.resolve();
  }
}

12. 接口可以包含哪些成员？ ​

答案：

  • 属性（必需/可选/只读）
  • 方法
  • 索引签名
  • 构造函数（在类中实现）

13-15. readonly、可选属性、类型别名 ​

typescript
// readonly
interface Point {
  readonly x: number;
  readonly y: number;
}

// 可选属性
interface Config {
  mode?: "dark" | "light";
  timeout?: number;
}

// 类型别名
type ID = string | number;
type Point = { x: number; y: number; };
type Handler = (event: Event) => void;

四、泛型（16-20 题） ​

16. 什么是泛型？ ​

答案： 泛型：参数化类型，适用于多种类型。

typescript
// 泛型函数
function identity<T>(arg: T): T {
  return arg;
}

identity<string>("hello");
identity<number>(42);

// 泛型接口
interface Box<T> {
  value: T;
}

const stringBox: Box<string> = { value: "text" };
const numberBox: Box<number> = { value: 42 };

// 泛型类
class Stack<T> {
  private items: T[] = [];
  
  push(item: T) {
    this.items.push(item);
  }
  
  pop(): T | undefined {
    return this.items.pop();
  }
}

17-20. 泛型约束、默认值 ​

typescript
// 泛型约束
interface Lengthwise {
  length: number;
}

function logLength<T extends Lengthwise>(arg: T): T {
  console.log(arg.length);
  return arg;
}

logLength("text");  // ✓
logLength([1, 2]);  // ✓
logLength(42);      // ✗

// 泛型默认值
interface Response<T = any> {
  data: T;
  status: number;
}

// 使用默认值
const res: Response = { data: null, status: 200 };

五、装饰器（21-23 题） ​

21. 装饰器的作用是什么？ ​

答案： 装饰器：修改类、方法、属性的行为。

typescript
// 类装饰器
function logged(target: any) {
  console.log(`Creating ${target.name}`);
}

@logged
class UserService {}

// 方法装饰器
function enumerable(value: boolean) {
  return function(
    target: any,
    propertyKey: string,
    descriptor: PropertyDescriptor
  ) {
    descriptor.enumerable = value;
  };
}

class Person {
  @enumerable(false)
  greet() {
    return "Hello";
  }
}

六、高级类型（34-37 题） ​

34. 映射类型的定义方式是什么？ ​

答案：

typescript
// 内置映射类型
type Readonly<T> = {
  readonly [P in keyof T]: T[P];
};

type Partial<T> = {
  [P in keyof T]?: T[P];
};

type Required<T> = {
  [P in keyof T]-?: T[P];
};

type Pick<T, K extends keyof T> = {
  [P in K]: T[P];
};

// 自定义映射类型
type Mutable<T> = {
  -readonly [P in keyof T]: T[P];
};

35-37. 条件类型、infer ​

typescript
// 条件类型
type IsString<T> = T extends string ? true : false;

type A = IsString<"hello">;  // true
type B = IsString<42>;       // false

// infer
type ReturnType<T> = T extends (...args: any[]) => infer R 
  ? R 
  : any;

type Fn = () => string;
type Result = ReturnType<Fn>;  // string

七、枚举与元组（38-40 题） ​

38. 枚举类型的定义和使用是什么？ ​

答案：

typescript
// 数字枚举
enum Direction {
  Up,      // 0
  Down,    // 1
  Left,    // 2
  Right    // 3
}

// 字符串枚举
enum Status {
  Success = "SUCCESS",
  Error = "ERROR"
}

// 使用
const dir: Direction = Direction.Up;

八、函数相关（41-42 题） ​

41. 函数重载的实现方式是什么？ ​

答案：

typescript
// 重载声明
function combine(a: string, b: string): string;
function combine(a: number, b: number): number;
function combine(a: any, b: any): any;

// 实现
function combine(a: any, b: any): any {
  return a + b;
}

combine("Hello", "World");  // ✓
combine(10, 20);            // ✓

九、配置与编译（43-45 题） ​

43. tsconfig.json 的重要配置项有哪些？ ​

答案：

json
{
  "compilerOptions": {
    "target": "ES2015",
    "module": "commonjs",
    "lib": ["DOM", "ES2015"],
    "outDir": "./dist",
    "rootDir": "./src",
    "strict": true,
    "noImplicitAny": true,
    "strictNullChecks": true,
    "esModuleInterop": true,
    "skipLibCheck": true,
    "forceConsistentCasingInFileNames": true,
    "resolveJsonModule": true,
    "declaration": true,
    "sourceMap": true
  },
  "include": ["src/**/*"],
  "exclude": ["node_modules", "**/*.spec.ts"]
}

总结 ​

TypeScript 核心知识点：

  1. 类型系统（基础类型、联合、交叉）
  2. 接口与类型别名
  3. 泛型（约束、默认值）
  4. 装饰器
  5. 高级类型（映射、条件）
  6. 工具配置

面试重点：

  • 泛型的理解与应用
  • 接口 vs 类型别名
  • 工具类型（Partial, Pick, Omit 等）
  • 类型推断与断言
