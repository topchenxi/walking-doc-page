Webpack 答案 ​

核心概念 ​

1. Webpack 的核心概念有哪些？ ​

答案： 五大核心概念：

  1. Entry（入口）：打包的起点

    javascript
    module.exports = {
  entry: './src/index.js'
};

  2. Output（输出）：打包结果

    javascript
    output: {
  filename: 'bundle.js',
  path: path.resolve(__dirname, 'dist')
}

  3. Loader（加载器）：转换非 JS 模块

    javascript
    module: {
  rules: [
    { test: /\.css$/, use: ['style-loader', 'css-loader'] },
    { test: /\.js$/, use: 'babel-loader' }
  ]
}

  4. Plugin（插件）：扩展功能

    javascript
    plugins: [
  new HtmlWebpackPlugin(),
  new CleanWebpackPlugin()
]

  5. Mode（模式）：development/production

6. Loader 与 Plugin 的区别是什么？ ​

答案：

特性LoaderPlugin
用途转换模块扩展功能
执行时机打包时整个生命周期
示例babel-loader, css-loaderHtmlWebpackPlugin

Tree Shaking ​

14. Tree Shaking 的原理是什么？ ​

答案： 原理：移除未使用的 ES6 模块。

条件：

  1. 使用 ES6 模块（import/export）
  2. production 模式
  3. 无副作用代码
javascript
// utils.js
export const a = 1;
export const b = 2;

// index.js
import { a } from './utils';  // 只引入 a
console.log(a);  // b 会被摇掉

HMR 热更新 ​

16. HMR 的原理是什么？ ​

答案： 流程：

  1. 文件变化，生成新 hash
  2. 运行时对比新旧 hash
  3. 只更新变化的模块
  4. 保持应用状态
javascript
// 启用 HMR
devServer: {
  hot: true
}

// 接受更新
if (module.hot) {
  module.hot.accept('./module', () => {});
}

性能优化 ​

18. Webpack 性能优化的方法有哪些？ ​

答案： 构建速度优化：

  1. babel-loader 缓存
  2. HappyPack 多线程构建
  3. DllPlugin 预编译

打包体积优化：

  1. Tree Shaking
  2. Code Splitting
  3. 压缩代码
  4. externals 排除依赖
