1. CSS 选择器有哪些类型？请列举至少 6 种并说明具体语法和使用案例 ​

问题：CSS 选择器有哪些类型？请列举至少 6 种并说明具体语法和使用案例

答案： CSS 选择器类型：

  1. 元素选择器（Element Selector）：

    css
    p { color: blue; } /* 选择所有 <p> 元素 */
div { margin: 10px; }

  2. 类选择器（Class Selector）：

    css
    .highlight { background-color: yellow; }
.btn-primary { color: white; background: blue; }

  3. ID 选择器（ID Selector）：

    css
    #header { height: 60px; }
#main-content { padding: 20px; }

  4. 后代选择器（Descendant Selector）：

    css
    div p { color: red; } /* 选择 div 内所有 p 元素 */
.container .item { margin: 5px; }

  5. 子元素选择器（Child Selector）：

    css
    ul > li { list-style: none; } /* 只选直接子元素 */
.parent > .child { color: green; }

  6. 伪类选择器（Pseudo-class Selector）：

    css
    a:hover { text-decoration: underline; }
li:first-child { font-weight: bold; }
input:focus { border-color: blue; }
p:nth-child(2n) { background: #f0f0f0; }

  7. 属性选择器（Attribute Selector）：

    css
    [target="_blank"] { color: orange; }
input[type="text"] { border: 1px solid #ccc; }
a[href^="https"] { color: green; } /* 以 https 开头 */

  8. 相邻兄弟选择器（Adjacent Sibling）：

    css
    h1 + p { font-size: 18px; } /* 紧接 h1 的 p */
.active + .item { margin-left: 10px; }

优先级顺序：

!important > ID 选择器 > 类/属性/伪类 > 元素/伪元素

补充说明：

  • 避免过度使用 ID 选择器（优先级过高）
  • 组合使用选择器提高精确度
  • 面试点：掌握至少 6 种选择器及其优先级

2. CSS 选择器优先级如何计算？优先级规则是什么？ ​

问题：CSS 选择器优先级如何计算？优先级规则是什么？

答案： 优先级计算规则：

权重计算（从高到低）：

  1. !important：最高优先级
  2. 内联样式：1000
  3. ID 选择器：100
  4. 类/属性/伪类选择器：10
  5. 元素/伪元素选择器：1

计算示例：

css
/* 权重计算 */
#header .nav a:hover     /* 100 + 10 + 1 + 10 = 121 */
.nav ul li a             /* 10 + 1 + 1 + 1 = 13 */
body main div p          /* 1 + 1 + 1 + 1 = 4 */
#footer                  /* 100 */
.highlight               /* 10 */

优先级规则：

css
/* 示例对比 */
<style>
  .box { color: red; }           /* 权重 10 */
  #box { color: blue; }          /* 权重 100，胜出 */
  div.box { color: green; }      /* 权重 1 + 10 = 11 */
  .box.active { color: yellow; } /* 权重 10 + 10 = 20，胜出 */
</style>

<div id="box" class="box active">文本颜色？</div>
<!-- 结果：黄色（.box.active 权重 20 最高） -->

特殊情况：

  1. !important 最高：

    css
    .box { color: red !important; } /* 总是生效 */

  2. 内联样式：

    html
    <div style="color: red;"> <!-- 权重 1000 -->

  3. 继承样式：权重最低

补充说明：

  • 权重相同时，后定义的样式覆盖先定义的
  • 避免滥用 !important
  • 面试点：能准确计算任意选择器的权重

3. 哪些 CSS 属性具有继承特性？请列举至少 5 个 ​

问题：哪些 CSS 属性具有继承特性？请列举至少 5 个

答案： 可继承的 CSS 属性：

文本相关属性（可继承）：

  1. color：文本颜色
  2. font-family：字体系列
  3. font-size：字体大小
  4. font-weight：字体粗细
  5. line-height：行高
  6. text-align：文本对齐
  7. text-indent：文本缩进
  8. visibility：可见性

列表相关属性（可继承）： 9. list-style：列表样式 10. list-style-type：列表项标记类型

示例：

css
/* 父元素设置 */
.parent {
  color: #333;           /* 子元素继承 */
  font-size: 16px;       /* 子元素继承 */
  font-family: Arial;    /* 子元素继承 */
  text-align: center;    /* 子元素继承 */
}

/* 子元素自动继承这些属性 */
.child {
  /* 无需重新定义即可继承父元素的文本样式 */
}

不可继承的属性：

  • border, padding, margin
  • width, height
  • background-*
  • position, display
  • float, clear

强制继承：

css
/* 使用 inherit 关键字强制继承 */
.child {
  border: inherit; /* 即使默认不继承也可强制继承 */
}

补充说明：

  • 继承有助于减少代码重复
  • 某些属性继承可能导致问题（如链接的 color）
  • 面试点：记住常见的可继承属性

4. px 与 em 的区别是什么？ ​

问题：px 与 em 的区别是什么？

答案： 核心区别：

单位类型特点适用场景
px绝对单位固定像素值，不随父元素变化需要精确控制的场景
em相对单位相对于父元素的字体大小响应式布局、组件化开发

计算方式：

css
/* px：固定值 */
.box {
  font-size: 16px;  /* 始终 16 像素 */
  width: 200px;     /* 始终 200 像素 */
}

/* em：相对值 */
.parent {
  font-size: 16px;
}
.child {
  font-size: 1.5em; /* 16px × 1.5 = 24px */
  padding: 0.5em;   /* 24px × 0.5 = 12px (基于当前字体大小) */
}

em 的累积效应：

html
<style>
  body { font-size: 16px; }
  .parent { font-size: 1.5em; }  /* 16 × 1.5 = 24px */
  .child { font-size: 1.5em; }   /* 24 × 1.5 = 36px */
</style>

<div class="parent">
  <div class="child">字体越来越大！</div>
</div>

rem 单位（推荐）：

css
/* rem：相对于根元素（html） */
html { font-size: 16px; }
.box {
  font-size: 1rem;    /* 16px */
  padding: 0.5rem;    /* 8px */
  margin: 1rem;       /* 16px */
}

使用建议：

  • 字体大小：优先使用 rem
  • 间距：使用 rem 或 em
  • 边框：可使用 px
  • 响应式：结合媒体查询使用 rem

补充说明：

  • em 在嵌套场景中会产生累积效果
  • rem 避免了嵌套问题，更易于维护
  • 面试点：理解相对单位的计算方式

5. margin 与 padding 的使用场景区别是什么？ ​

问题：margin 与 padding 的使用场景区别是什么？

答案： 核心区别：

属性位置作用背景色影响
margin元素外部控制元素与其他元素的距离透明，显示父元素背景
padding元素内部控制内容与边框的距离显示元素自身背景

视觉差异：

css
.box {
  width: 200px;
  background-color: lightblue;
  border: 2px solid blue;
  
  /* 外边距：推开其他元素 */
  margin: 20px;
  
  /* 内边距：推开内容 */
  padding: 20px;
}

使用场景：

使用 margin：

  • 元素之间的间距
  • 元素与容器边缘的距离
  • 垂直方向的间隔
css
.card + .card {
  margin-top: 20px; /* 卡片之间的间距 */
}

使用 padding：

  • 内容与边框的内边距
  • 需要背景色填充的区域
  • 按钮内的文字间距
css
.btn {
  padding: 10px 20px; /* 按钮内部填充 */
  background: blue;
}

.content-box {
  padding: 30px; /* 内容周围留白 */
  background: white;
}

特殊情况：

css
/* margin 折叠现象 */
.box1 { margin-bottom: 20px; }
.box2 { margin-top: 30px; }
<!-- 实际间距：30px（取较大值） -->

/* padding 不会折叠 */
.box1 { padding-bottom: 20px; }
.box2 { padding-top: 30px; }
<!-- 实际间距：50px（累加） -->

补充说明：

  • margin 可以是负值，padding 不能为负
  • inline 元素的 margin/padding 上下方向无效
  • 面试点：理解 margin 折叠和 padding 的应用场景

6. CSS 属性简写规则有哪些？（如 padding、margin 等） ​

问题：CSS 属性简写规则有哪些？

答案： 常用属性简写规则：

1. margin/padding 简写：

css
/* 四个值：上 右 下 左（顺时针） */
margin: 10px 20px 15px 5px;
/* 等同于 */
margin-top: 10px;
margin-right: 20px;
margin-bottom: 15px;
margin-left: 5px;

/* 三个值：上 左右 下 */
margin: 10px 20px 15px;
/* 上=10px, 左右=20px, 下=15px */

/* 两个值：上下 左右 */
margin: 10px 20px;
/* 上下=10px, 左右=20px */

/* 一个值：四周相同 */
margin: 10px;

2. background 简写：

css
background: #fff url(image.jpg) no-repeat center center / cover fixed;
/* 顺序：color image repeat position / size attachment */

3. border 简写：

css
border: 1px solid #333;
/* 顺序：width style color */

4. font 简写：

css
font: italic bold 16px/1.5 "Helvetica", sans-serif;
/* 顺序：style weight size/line-height family */
/* 注意：必须包含 size 和 family */

5. outline 简写：

css
outline: 2px dashed red;
/* 顺序：width style color */

6. transition 简写：

css
transition: all 0.3s ease-in-out 0.1s;
/* 顺序：property duration timing-function delay */

7. animation 简写：

css
animation: slide 2s ease-in-out 1s infinite alternate;
/* 顺序：name duration timing-function delay iteration-count direction */

注意事项：

  • 未指定的值使用默认值
  • 某些属性不能简写（如 border-left-width）
  • 保持代码可读性，不要过度简写

补充说明：

  • 简写会重置未提及的子属性为默认值
  • 建议团队统一简写规范
  • 面试点：掌握常见属性的简写顺序

7. 行内元素与块级元素的差异是什么？ ​

问题：行内元素与块级元素的差异是什么？

答案： 核心差异对比：

特性行内元素（Inline）块级元素（Block）
换行不换行，同行显示独占一行
宽度由内容决定默认为父元素 100%
高度由内容决定可设置，或由内容撑开
margin左右有效，上下无效上下左右都有效
padding左右有效，上下视觉无效*上下左右都有效
包含关系只能包含文本或其他行内元素可包含行内和其他块级元素

示例对比：

html
<style>
  span { 
    background: yellow; 
    margin: 20px; 
    padding: 10px;
  }
  div { 
    background: lightblue; 
    margin: 20px; 
    padding: 10px;
  }
</style>

<!-- 行内元素：span -->
<p>文本<span>行内元素</span>更多文本</p>
<!-- margin/padding 上下不生效 -->

<!-- 块级元素：div -->
<div>块级元素</div>
<div>另一个块级</div>
<!-- margin/padding 全部生效 -->

常见元素分类：

块级元素：

div, p, h1-h6, ul, ol, li, section, article, header, footer, nav

行内元素：

span, a, strong, em, i, b, u, small, label, code

行内块元素（Inline-block）：

img, input, button, textarea

转换显示类型：

css
/* 改变元素显示类型 */
.inline-block { display: inline-block; } /* 转为行内块 */
.block { display: block; }               /* 转为块级 */
.inline { display: inline; }             /* 转为行内 */

补充说明：

  • 行内元素的 padding/margin 上下方向虽然存在，但不影响布局
  • 可通过 display 属性改变元素的显示类型
  • 面试点：理解盒模型在不同元素上的表现

8. display 属性的常用值有哪些？及其作用 ​

问题：display 属性的常用值有哪些？及其作用

答案： display 常用值及作用：

1. 块级显示：

css
display: block;      /* 块级元素，独占一行 */
display: flow-root;  /* 块级元素，创建 BFC */

2. 行内显示：

css
display: inline;     /* 行内元素，不独占一行 */

3. 行内块：

css
display: inline-block; /* 兼具 inline 和 block 特点 */

4. Flex 布局：

css
display: flex;         /* 块级 Flex 容器 */
display: inline-flex;  /* 行内 Flex 容器 */

5. Grid 布局：

css
display: grid;         /* 块级 Grid 容器 */
display: inline-grid;  /* 行内 Grid 容器 */

6. 隐藏元素：

css
display: none;  /* 完全隐藏，不占空间 */

7. 表格相关：

css
display: table;            /* 块级表格 */
display: table-row;        /* 表格行 */
display: table-cell;       /* 表格单元格 */
display: inline-table;     /* 行内表格 */

8. 列表项：

css
display: list-item;  /* 列表项（如 li） */

实际应用示例：

css
/* 水平排列图标 */
.icon {
  display: inline-block;
  width: 24px;
  height: 24px;
}

/* Flex 居中布局 */
.container {
  display: flex;
  justify-content: center;
  align-items: center;
}

/* Grid 网格布局 */
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}

/* 隐藏元素 */
.hidden {
  display: none;
}

特殊值：

css
display: contents;  /* 元素本身不渲染，子元素正常渲染 */
display: run-in;    /* 根据上下文决定是块级还是行内（支持度低） */

补充说明：

  • display: none 隐藏的元素无法被屏幕阅读器访问
  • Flex 和 Grid 是现代布局的首选
  • 面试点：掌握常用 display 值及其应用场景

9. 为什么要重置 CSS 样式？处理方法有哪些？ ​

问题：为什么要重置 CSS 样式？处理方法有哪些？

答案： 为什么要重置样式：

原因：不同浏览器对 HTML 元素有默认样式，导致页面在不同浏览器中显示不一致。

默认样式问题：

css
/* 浏览器默认样式示例 */
body { margin: 8px; }
h1 { font-size: 2em; font-weight: bold; margin: 0.67em 0; }
p { margin: 1em 0; }
ul { padding-left: 40px; }
a { color: blue; text-decoration: underline; }

处理方法：

方法 1：Reset（激进重置）：

css
/* Eric Meyer's Reset */
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

body, h1, h2, h3, p, ul, li {
  margin: 0;
  padding: 0;
}

a { text-decoration: none; color: inherit; }
ul { list-style: none; }

方法 2：Normalize（温和标准化）：

css
/* Normalize.css - 保留有用默认样式 */
/*! normalize.css v8.0.1 | MIT License */

/* 保留 HTML5 元素默认行为 */
article, aside, details, figcaption, figure, footer, header, main {
  display: block;
}

/* 修复字体大小不一致 */
body {
  font-family: system-ui, -apple-system, sans-serif;
}

/* 统一标题样式 */
h1 { font-size: 2em; margin: 0.67em 0; }

方法 3：Modern Reset（现代重置）：

css
/* 现代简约重置 */
*, *::before, *::after {
  box-sizing: border-box;
}

body {
  margin: 0;
  line-height: 1.5;
  -webkit-font-smoothing: antialiased;
}

img, picture, video, canvas, svg {
  display: block;
  max-width: 100%;
}

button, input, select, textarea {
  font: inherit;
}

方法 4：框架内置重置：

css
/* Tailwind CSS Preflight */
/* Bootstrap Reboot */

推荐做法：

  1. 小项目：使用轻量级 Reset
  2. 大项目：使用 Normalize.css
  3. 使用 UI 框架时：使用框架内置重置

补充说明：

  • Reset 会导致所有样式从头开始，工作量大
  • Normalize 保留了有用的默认样式，更友好
  • 现代浏览器默认样式已趋于一致，重置可简化
  • 面试点：理解 Reset 和 Normalize 的区别

10. 图片导出格式如何选择？（PNG-8、PNG-24/32、JPG、GIF 的适用场景） ​

问题：图片导出格式如何选择？

答案： 图片格式选择指南：

JPG/JPEG：

  • 特点：有损压缩，文件小，不支持透明
  • 适用：照片、渐变色丰富的图片
  • 不适用：需要透明背景、简单图形、文字截图
产品照片 → JPG
风景图片 → JPG
人物肖像 → JPG

PNG-8：

  • 特点：无损压缩，256 色，支持简单透明
  • 适用：颜色简单的图标、Logo
  • 不适用：渐变色、照片
简单图标 → PNG-8
单色 Logo → PNG-8

PNG-24/32：

  • 特点：无损压缩，支持数百万色和 Alpha 透明
  • 适用：需要透明背景的复杂图形、高质量截图
  • 不适用：照片（文件太大）
透明 Logo → PNG-24
UI 截图 → PNG-24
带阴影的图标 → PNG-32

GIF：

  • 特点：支持动画，仅 256 色
  • 适用：简单动画、表情包
  • 不适用：照片、复杂渐变
加载动画 → GIF
表情动图 → GIF

WebP（推荐）：

  • 特点：高压缩率，支持透明和动画
  • 适用：现代浏览器所有场景
  • 不适用：需要兼容旧浏览器
通用场景 → WebP（提供 fallback）

SVG：

2. relative（相对定位）：

css
.box { 
  position: relative; 
  top: 20px; 
  left: 30px;
}
/* 定位基准：元素自身原始位置 */
/* 特点：占据原空间，不影响其他元素 */

3. absolute（绝对定位）：

css
.box { 
  position: absolute; 
  top: 0; 
  right: 0;
}
/* 定位基准：最近非 static 的祖先元素 */
/* 若无，则相对于初始包含块（通常是视口） */
/* 特点：脱离文档流，不占空间 */

4. fixed（固定定位）：

css
.box { 
  position: fixed; 
  bottom: 20px; 
  right: 20px;
}
/* 定位基准：浏览器视口（viewport） */
/* 特点：脱离文档流，滚动时位置不变 */

5. sticky（粘性定位）：

css
.box { 
  position: sticky; 
  top: 0;
}
/* 定位基准：滚动容器 */
/* 特点：阈值前为 relative，阈值后为 fixed */

定位基准示例：

html

    right: 10px;
    /* 相对于 .parent 定位 */
  }
  
  .fixed-nav {
    position: fixed;
    top: 0;
    /* 相对于视口定位 */
  }
</style>

<div class="parent">

</div>

实际应用场景：

  left: 50%;
  transform: translate(-50%, -50%);

  position: sticky;
  top: 0;
  z-index: 100;
}

补充说明：

  • absolute 元素相对于最近的定位祖先元素
  • fixed 元素相对于视口，不受滚动影响
  • sticky 需要指定 top/bottom/left/right 之一
  • 面试点：理解各定位方式的参照物

  overflow: hidden; /* 触发 BFC，自适应剩余空间 */

四、Flexbox 布局 ​

28. Flex 布局的原理是什么？是如何工作的？ ​

问题：Flex 布局的原理是什么？

答案： Flexbox 原理：

定义：Flexible Box，弹性盒子布局，一维布局方案。

核心概念：

  • 容器（Flex Container）：设置 display: flex 的父元素
  • 项目（Flex Item）：容器的直接子元素

工作原理：

  1. 主轴（main axis）决定项目排列方向
  2. 交叉轴（cross axis）垂直于主轴
  3. 项目可自动伸缩以填充空间

基本用法：

css
.container {
  display: flex;
  justify-content: center;    /* 主轴居中 */
  align-items: center;        /* 交叉轴居中 */
  gap: 20px;                  /* 项目间距 */
}

.item {
  flex: 1;  /* 等比例分配空间 */
}

补充说明：Flexbox 是现代 CSS 布局的首选工具。

五、Grid 布局 ​

32. Grid 布局的特点是什么？ ​

问题：Grid 布局的特点是什么？

答案： Grid 布局特点：

定义：CSS Grid Layout，二维网格布局系统。

核心特点：

  1. 二维布局：同时控制行和列
  2. 显式网格：定义行列结构
  3. 隐式网格：自动创建轨道
  4. 灵活定位：项目可跨越多行多列

基本用法：

css

  grid-template-columns: repeat(3, 1fr); /* 3 列等宽 */

}

.item {
  grid-column: 1 / 3;  /* 跨 2 列 */
  grid-row: 1 / 2;     /* 占 1 行 */
}

对比 Flexbox：

  • Flex：一维（行或列）
  • Grid：二维（行和列）

补充说明：Grid 是最强大的 CSS 布局工具。

44. animation、transition、transform 的区别是什么？ ​

问题：animation、transition、transform 的区别是什么？

答案： 区别：

Transform（变换）：

  • 作用：改变元素形状/位置
  • 属性：translate, rotate, scale, skew
  • 不触发布局：性能好
css
.box {
  transform: translateX(100px) rotate(45deg);
}

Transition（过渡）：

  • 作用：状态变化的平滑过渡
  • 需要触发：hover、focus 等
css
.btn {
  transition: transform 0.3s;
}
.btn:hover {
  transform: scale(1.1);
}

Animation（动画）：

  • 作用：自动播放的连续动画
  • 关键帧：可定义多个阶段
css
@keyframes bounce {
  0%, 100% { transform: translateY(0); }
  50% { transform: translateY(-20px); }
}
.ball {
  animation: bounce 1s infinite;
}

关系：

  • transform 是变换方式
  • transition 是过渡效果
  • animation 是动画序列

补充说明：三者常配合使用。

52. 什么是重绘（Repaint）与回流（Reflow）？ ​

问题：什么是重绘与回流？

答案： 定义：

重绘（Repaint）：

  • 触发：元素外观改变（颜色、背景等）
  • 影响：不影响布局
  • 开销：较小

回流（Reflow/Relayout）：

  • 触发：元素几何属性改变（尺寸、位置）
  • 影响：重新计算布局
  • 开销：较大

触发回流的场景：

javascript
// ❌ 会触发回流
element.style.width = '200px';
element.style.margin = '10px';
element.offsetHeight;  // 读取布局信息

只触发重绘的场景：

css
/* ✅ 只重绘 */
color: red;
background: blue;
visibility: hidden;

补充说明：回流一定会重绘，重绘不一定回流。

53. 重绘与回流的触发场景有哪些？如何优化？ ​

问题：重绘与回流的触发场景有哪些？如何优化？

答案： 触发场景：

会触发回流的操作：

  1. 添加/删除 DOM 元素
  2. 改变元素尺寸（width/height/margin/padding）
  3. 改变元素位置（top/left/position）
  4. 窗口大小改变
  5. 读取布局信息（offsetWidth, clientTop 等）

只触发重绘的操作：

  1. 改变颜色（color/background）
  2. 改变可见性（visibility）
  3. 改变文本内容

优化策略：

1. 合并样式修改：

javascript
// ❌ 多次回流
el.style.width = '100px';
el.style.height = '200px';

// ✅ 一次回流
el.style.cssText = 'width: 100px; height: 200px;';

2. 使用 DocumentFragment：

javascript
const fragment = document.createDocumentFragment();
// ... 添加到 fragment
container.appendChild(fragment); // 只触发一次回流

3. 使用 transform 替代 position：

css
/* ✅ 性能好 */
transform: translate(100px, 50px);

/* ❌ 性能差 */
position: absolute;
left: 100px;

4. 使用 will-change：

css
.element {
  will-change: transform;
}

补充说明：减少回流是性能优化的关键。

54. 浏览器渲染机制是什么？如何优化重绘/回流？ ​

问题：浏览器渲染机制是什么？如何优化重绘/回流？

答案： 浏览器渲染流程：

HTML → DOM Tree
CSS → CSSOM Tree
↓
Render Tree（渲染树）
↓
Layout（布局/回流）
↓
Paint（绘制/重绘）
↓
Composite（合成）

优化策略：

1. 减少不必要的回流：

css
/* 使用 transform 替代 margin/padding */
transform: translateX(100px);

2. 批量操作 DOM：

javascript
// 先隐藏，批量修改后再显示
el.style.display = 'none';
// ... 多次修改
el.style.display = 'block';

3. 使用绝对定位：

css
/* 脱离文档流，减少对其他元素的影响 */
.positioned {
  position: absolute;
}

4. 启用 GPU 加速：

css
.gpu-accelerated {
  will-change: transform;
  transform: translateZ(0);
}

5. 避免频繁读取布局信息：

javascript
// ❌ 强制同步布局
for (let i = 0; i < 10; i++) {
  el.style.width = el.offsetWidth + 10 + 'px';
}

// ✅ 先缓存
const widths = [];
for (let i = 0; i < 10; i++) {
  widths.push(el.offsetWidth);
}
for (let i = 0; i < 10; i++) {
  el.style.width = widths[i] + 10 + 'px';
}

补充说明：理解渲染机制是性能优化的基础。

60. @import 指令的缺陷有哪些？ ​

问题：@import 指令的缺陷有哪些？

答案： @import 缺陷：

1. 加载顺序问题：

  • 延长首屏渲染时间

  • 老版本 IE 不支持
  • 部分移动浏览器支持差

4. 无法被 JavaScript 动态加载：

javascript
// ❌ 无法动态插入 @import
// ✅ 可以动态添加 <link>

5. 优先级问题：

  • @import 引入的样式优先级较低

推荐做法：

html
<!-- 始终使用 <link> -->
<link rel="stylesheet" href="style.css">
