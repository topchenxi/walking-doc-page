小程序答案 ​

小程序架构（1-4 题） ​

1. 小程序的架构是什么？ ​

答案： 双线程模型：

  • 逻辑层（AppService）：运行 JS 代码
  • 渲染层（WebView）：渲染页面
  • Native 层：提供 Native 能力

通信方式：通过 Native 中转。

4. 小程序的双线程模型是什么？ ​

答案：

逻辑层（JS Core） ←→ Native ←→ 渲染层（WebView）

优势：

  • 安全性高
  • 管控能力强
  • 性能优化空间大

生命周期（5-7 题） ​

5. 小程序的生命周期有哪些？ ​

答案： 应用生命周期：

javascript
App({
  onLaunch() {},    // 启动
  onShow() {},      // 显示
  onHide() {}       // 隐藏
})

页面生命周期：

javascript
Page({
  onLoad() {},      // 加载
  onShow() {},      // 显示
  onReady() {},     // 初次渲染完成
  onHide() {},      // 隐藏
  onUnload() {}     // 卸载
})

组件与页面（8-11 题） ​

8. 小程序页面结构是什么？ ​

答案：

page/
  ├── page.js    // 逻辑
  ├── page.json  // 配置
  ├── page.wxml  // 结构
  └── page.wxss  // 样式

API 调用（15-18 题） ​

15. 小程序网络请求 API 的使用方法是什么？ ​

答案：

javascript
wx.request({
  url: 'https://api.example.com/data',
  method: 'GET',
  success(res) {
    console.log(res.data);
  }
});

路由导航（19-21 题） ​

19. 小程序页面跳转的方式有哪些？ ​

答案：

javascript
// 新页面
wx.navigateTo({ url: '/pages/detail/detail' });

// 替换当前页
wx.redirectTo({ url: '/pages/home/home' });

// 切换 Tab
wx.switchTab({ url: '/pages/index/index' });

// 返回
wx.navigateBack();
