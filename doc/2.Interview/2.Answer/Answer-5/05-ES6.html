一、let/const 与块级作用域（1-6 题） ​

1. let、const、var 的区别是什么？ ​

答案：

特性varletconst
作用域函数级块级块级
变量提升✓✗（TDZ）✗（TDZ）
重复声明✓✗✗
初始值undefined未初始化必须初始化
修改值✓✓✗
javascript
// var 问题
for (var i = 0; i < 3; i++) {}
console.log(i);  // 3（泄漏）

// let 解决
for (let i = 0; i < 3; i++) {}
console.log(i);  // ReferenceError

// const 常量
const PI = 3.14;
PI = 3;  // TypeError

2-3. 块级作用域与暂时性死区 ​

javascript
// 块级作用域
{
  let x = 1;
  const y = 2;
}
console.log(x);  // ReferenceError

// TDZ
console.log(a);  // ReferenceError
let a = 1;

4-6. const 对象属性修改 ​

javascript
const obj = { x: 1 };
obj.x = 2;      // ✓（修改属性）
obj = {};       // ✗（重新赋值）

const arr = [1, 2];
arr.push(3);    // ✓
arr = [];       // ✗

二、箭头函数（7-11 题） ​

7. 箭头函数的特点是什么？ ​

答案：

  1. 简洁语法
  2. 不绑定 this（继承外层）
  3. 不能作为构造函数
  4. 没有 arguments
  5. 不能用作 Generator
javascript
// 简洁语法
const add = (a, b) => a + b;

// this 继承
function outer() {
  setTimeout(() => {
    console.log(this);  // 继承 outer 的 this
  });
}

8-9. 箭头函数 vs 普通函数 ​

javascript
// this 对比
const obj = {
  value: 42,
  regular() {
    console.log(this.value);  // 42
  },
  arrow: () => {
    console.log(this.value);  // undefined
  }
};

四、解构赋值（15-18 题） ​

15. 数组解构赋值的语法是什么？ ​

答案：

javascript
// 基本解构
const [a, b] = [1, 2];

// 默认值
const [x = 1, y = 2] = [3];

// 剩余元素
const [first, ...rest] = [1, 2, 3, 4];

// 嵌套
const [a, [b]] = [1, [2]];

16. 对象解构赋值的语法是什么？ ​

答案：

javascript
// 基本解构
const { name, age } = { name: "Alice", age: 25 };

// 重命名
const { name: userName } = user;

// 默认值
const { role = "user" } = data;

// 嵌套
const { user: { name } } = response;

// 函数参数
function greet({ name, age }) {
  return `${name}, ${age}`;
}

五、Symbol 与迭代器（22-26 题） ​

22. Symbol 的特点是什么？ ​

答案：

javascript
// 唯一性
const s1 = Symbol("id");
const s2 = Symbol("id");
console.log(s1 === s2);  // false

// 隐藏属性
const obj = {
  [Symbol("secret")]: "value"
};

// 全局注册
const globalSym = Symbol.for("global");
Symbol.keyFor(globalSym);  // "global"

25. 什么是可迭代对象？ ​

答案：

javascript
// 实现迭代器
const iterable = {
  [Symbol.iterator]() {
    let step = 0;
    return {
      next() {
        if (step < 3) {
          return { value: step++, done: false };
        }
        return { done: true };
      }
    };
  }
};

for (let val of iterable) {
  console.log(val);  // 0, 1, 2
}

六、Generator 函数（27-30 题） ​

27. Generator 函数的特点是什么？ ​

答案：

javascript
// 定义
function* gen() {
  yield 1;
  yield 2;
  return 3;
}

// 使用
const iterator = gen();
iterator.next();  // { value: 1, done: false }
iterator.next();  // { value: 2, done: false }
iterator.next();  // { value: 3, done: true }

七、Module 模块系统（31-33 题） ​

31. export 与 export default 的区别是什么？ ​

答案：

javascript
// export（命名导出）
export const a = 1;
export function fn() {}
import { a, fn } from './module';

// export default（默认导出）
export default class User {}
import User from './module';

// 区别
// - 一个模块只能有一个 default
// - default 导入时可任意命名

八、Set、Map 数据结构（34-37 题） ​

34. Set 数据结构的成员唯一性是什么？ ​

答案：

javascript
const set = new Set([1, 2, 2, 3]);
console.log(set.size);  // 3

set.add(4).add(4);  // 只添加一次
set.has(4);         // true
set.delete(4);

35. Map 数据结构的特点是什么？ ​

答案：

javascript
const map = new Map();
map.set("key", "value");
map.set({}, "object value");

map.get("key");      // "value"
map.has("key");      // true
map.delete("key");

// 遍历
for (let [key, value] of map) {
  console.log(key, value);
}

九、Class 类（41-46 题） ​

41. Class 的基本语法是什么？ ​

答案：

javascript
class Person {
  constructor(name) {
    this.name = name;
  }
  
  sayHi() {
    return `Hi, ${this.name}`;
  }
  
  static create(name) {
    return new Person(name);
  }
}

const p = Person.create("Alice");

43. extends 关键字的作用是什么？ ​

答案：

javascript
class Animal {
  constructor(name) {
    this.name = name;
  }
}

class Dog extends Animal {
  bark() {
    return "Woof!";
  }
}

const dog = new Dog("Buddy");
console.log(dog.name);  // Buddy

44. super 关键字的作用是什么？ ​

答案：

javascript
class Parent {
  constructor(name) {
    this.name = name;
  }
}

class Child extends Parent {
  constructor(name, age) {
    super(name);  // 调用父类构造函数
    this.age = age;
  }
  
  greet() {
    return super.name + " says hi";
  }
}

十、Proxy 与 Reflect（57-60 题） ​

57. Proxy 的用法和应用场景有哪些？ ​

答案：

javascript
// 基本用法
const target = { name: "Alice" };
const handler = {
  get(target, prop) {
    console.log(`Getting ${prop}`);
    return target[prop];
  },
  set(target, prop, value) {
    console.log(`Setting ${prop} to ${value}`);
    target[prop] = value;
    return true;
  }
};

const proxy = new Proxy(target, handler);
proxy.name;  // Getting name
proxy.name = "Bob";  // Setting name to Bob

// 应用场景
// 1. 数据验证
// 2. 日志记录
// 3. 响应式系统（Vue 3）
