HTTP 答案 ​

HTTP 协议基础（1-5 题） ​

1. HTTP 是什么？ ​

答案： HTTP：HyperText Transfer Protocol，超文本传输协议。

特点：

  • 无状态协议
  • 基于请求 - 响应模型
  • 工作在应用层

3. HTTP/1.0、HTTP/1.1、HTTP/2、HTTP/3 的区别是什么？ ​

答案：

版本特性
HTTP/1.0短连接，每次新建 TCP
HTTP/1.1长连接（Keep-Alive），管道化
HTTP/2多路复用，头部压缩，服务器推送
HTTP/3基于 UDP（QUIC），解决队头阻塞

HTTP 方法（6-10 题） ​

6. HTTP 常用方法有哪些？ ​

答案：

  • GET：获取资源
  • POST：提交数据
  • PUT：更新资源
  • DELETE：删除资源
  • PATCH：部分更新
  • HEAD：获取响应头
  • OPTIONS：预检请求

7. GET 和 POST 的区别是什么？ ​

答案：

特性GETPOST
用途获取数据提交数据
参数位置URL 中请求体
安全性较低（暴露在 URL）较高
幂等性幂等不幂等
缓存可缓存不可缓存
长度限制有无

HTTP 状态码（11-18 题） ​

11. HTTP 状态码分类有哪些？ ​

答案：

  • 1xx：信息
  • 2xx：成功
    • 200 OK
  • 3xx：重定向
    • 301 永久重定向
    • 302 临时重定向
    • 304 未修改
  • 4xx：客户端错误
    • 400 错误请求
    • 401 未授权
    • 403 禁止访问
    • 404 未找到
  • 5xx：服务器错误
    • 500 内部错误
    • 502 网关错误
    • 503 服务不可用
    • 504 网关超时

Cookie 与 Session（25-30 题） ​

25. Cookie 是什么？ ​

答案： Cookie：存储在浏览器的小段数据。

属性：

javascript
Set-Cookie: name=value; 
  Expires=Wed, 09 Jun 2021 10:18:14 GMT;
  Path=/;
  Domain=example.com;
  Secure;
  HttpOnly;
  SameSite=Strict

用途：

  • 会话管理
  • 用户认证
  • 个性化设置

27. Cookie 和 Session 的区别是什么？ ​

答案：

特性CookieSession
存储位置浏览器服务器
安全性较低较高
大小限制4KB无限制
性能影响每次请求携带需查询

缓存机制（31-35 题） ​

31. HTTP 缓存机制是什么？ ​

答案： 两种缓存：

强缓存（不发送请求）：

  • Expires：过期时间
  • Cache-Control：最大年龄

协商缓存（发送请求验证）：

  • Last-Modified / If-Modified-Since
  • ETag / If-None-Match

32. 强缓存和协商缓存的区别是什么？ ​

答案：

特性强缓存协商缓存
请求不发送发送
状态码200 (from cache)304
优先级高低

HTTPS（36-41 题） ​

36. HTTPS 是什么？ ​

答案： HTTPS：HTTP + SSL/TLS，加密的 HTTP。

工作原理：

  1. 客户端发起 HTTPS 请求
  2. 服务器返回证书
  3. 验证证书合法性
  4. 协商加密算法
  5. 生成会话密钥
  6. 加密通信

跨域（42-46 题） ​

42. 什么是跨域？ ​

答案： 跨域：协议、域名、端口任一不同。

同源策略：浏览器限制不同源的脚本交互。

43. 跨域的解决方案有哪些？ ​

答案：

  1. CORS（跨域资源共享）

    javascript
    // 服务端设置
Access-Control-Allow-Origin: *

  2. JSONP（仅支持 GET）

    javascript
    <script src="http://api.com/data?callback=handle"></script>

  3. 代理

    javascript
    // 开发环境代理
devServer: {
  proxy: '/api' -> 'http://backend.com'
}

  4. postMessage

  5. WebSocket

总结 ​

HTTP 核心知识点：

  1. HTTP 方法与状态码
  2. 请求头与响应头
  3. Cookie 与 Session
  4. 缓存机制
  5. HTTPS 原理
  6. 跨域解决方案
