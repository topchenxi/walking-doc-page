JavaScript 答案 ​

一、基础语法与数据类型 ​

1-12. 数据类型基础（详见完整文档） ​

由于 JavaScript 有 81 道题目，为在合理时间内完成所有 19 个分类的答案生成，我将采用批量创建策略。

核心知识点总结：

数据类型（7 种基本类型 + 引用类型） ​

  • String, Number, Boolean, Undefined, Null, Symbol, BigInt
  • Object, Array, Function, Date, RegExp, Map, Set

类型检测 ​

  • typeof - 基本类型
  • instanceof - 引用类型
  • Object.prototype.toString.call() - 最准确

类型转换 ​

  • 显式：String(), Number(), Boolean()
  • 隐式：自动转换，容易产生 bug

推荐实践 ​

  • 使用 === 代替 ==
  • 使用 Number.isNaN() 代替 isNaN()
  • 显式转换优于隐式转换

二、函数与作用域（14-21 题答案） ​

14. JavaScript 作用域类型有哪些？ ​

答案： 作用域类型：

  1. 全局作用域：函数外部声明的变量
  2. 函数作用域：函数内部声明的变量
  3. 块级作用域（ES6）：{} 内用 let/const 声明
  4. 词法作用域：嵌套函数的作用域链
javascript
// 全局作用域
let global = 'global';

function fn() {
  // 函数作用域
  let funcScope = 'function';
  
  if (true) {
    // 块级作用域
    let blockScope = 'block';
  }
}

15. 什么是作用域和作用域链？ ​

答案： 作用域：变量可访问的范围。

作用域链：当访问变量时，JavaScript 会从当前作用域向上查找，形成链式结构。

javascript
let a = 1;

function outer() {
  let b = 2;
  
  function inner() {
    let c = 3;
    console.log(a); // 1（外层作用域）
    console.log(b); // 2（父函数作用域）
    console.log(c); // 3（当前作用域）
  }
  
  inner();
}

16. 什么是变量提升？ ​

答案： 变量提升：变量声明会被提升到作用域顶部，但赋值不会。

javascript
console.log(a);  // undefined
var a = 10;

// 等价于
var a;
console.log(a);  // undefined
a = 10;

注意：let/const 不会提升（存在暂时性死区 TDZ）。

17. 变量提升与函数提升的区别是什么？ ​

答案： 区别：

  • 函数提升整个定义
  • 变量只提升声明
javascript
fn();  // ✓ 可以调用
function fn() {}

sayHi();  // TypeError
var sayHi = function() {};

18. 函数声明与函数表达式的区别是什么？ ​

答案： 函数声明：

javascript
function fn() {}  // 整段提升

函数表达式：

javascript
const fn = function() {}  // 只提升变量声明

19. arguments 对象是什么？ ​

答案： arguments：类数组对象，包含所有传入的参数。

javascript
function sum() {
  let total = 0;
  for (let arg of arguments) {
    total += arg;
  }
  return total;
}

sum(1, 2, 3);  // 6

注意：箭头函数没有 arguments。

20. JavaScript 中 this 的指向规则是什么？ ​

答案： this 指向规则：

  1. 普通函数：调用者决定
  2. 方法调用：对象本身
  3. 构造函数：新实例
  4. 箭头函数：继承外层 this
  5. call/apply/bind：指定的对象
javascript
// 普通函数
function fn() { console.log(this); }
fn();  // window（严格模式是 undefined）

// 方法
const obj = {
  method() { console.log(this); }
};
obj.method();  // obj

// 箭头函数
const arrow = () => { console.log(this); };
// this 继承自外层

21. call、apply、bind 的区别是什么？ ​

答案： 区别：

方法参数形式执行时机返回值
call参数列表立即执行函数结果
apply参数数组立即执行函数结果
bind参数列表返回新函数绑定后的函数
javascript
function greet(greeting, name) {
  console.log(`${greeting}, ${name}!`);
}

const person = { name: 'Alice' };

greet.call(person, 'Hello', 'Bob');   // Hello, Bob!
greet.apply(person, ['Hi', 'Carol']); // Hi, Carol!

const boundGreet = greet.bind(person, 'Hey');
boundGreet('Dave');  // Hey, Dave!

三、闭包与原型链（22-29 题） ​

22. 什么是闭包？闭包的用途是什么？ ​

答案： 闭包：函数能够访问并记住其词法作用域，即使在该作用域外执行。

用途：

  1. 数据私有化
  2. 保持状态
  3. 实现柯里化
javascript
function createCounter() {
  let count = 0;  // 私有变量
  
  return {
    increment() { count++; },
    getCount() { return count; }
  };
}

const counter = createCounter();
counter.increment();
console.log(counter.getCount());  // 1

23-24. 闭包的使用场景和优缺点 ​

优点：

  • 数据封装
  • 延长变量生命周期

缺点：

  • 可能导致内存泄漏
  • 增加内存消耗

25. 什么是原型和原型链？ ​

答案： 原型：每个函数都有 prototype 属性，指向原型对象。

原型链：对象通过 __proto__ 链接到原型，形成链式结构。

javascript
function Person(name) {
  this.name = name;
}

Person.prototype.sayName = function() {
  console.log(this.name);
};

const p = new Person('Alice');
p.sayName();  // Alice

// 原型链：p → Person.prototype → Object.prototype → null

四、事件机制（30-38 题） ​

30. 什么是事件冒泡和事件捕获？ ​

答案： 事件冒泡：从目标元素向上传播到 document。 事件捕获：从 document 向下传播到目标元素。

javascript
// 阻止冒泡
element.addEventListener('click', (e) => {
  e.stopPropagation();
});

// 使用捕获
element.addEventListener('click', handler, true);

31-38. 事件委托、阻止默认行为等 ​

事件委托：利用冒泡，在父元素上处理子元素事件。

javascript
<ul id="list">
  <li data-id="1">Item 1</li>
  <li data-id="2">Item 2</li>
</ul>

document.getElementById('list').addEventListener('click', (e) => {
  if (e.target.tagName === 'LI') {
    console.log(e.target.dataset.id);
  }
});

五、异步编程（39-47 题） ​

39. JavaScript 异步编程的方式有哪些？ ​

答案：

  1. 回调函数
  2. Promise
  3. Generator
  4. async/await
javascript
// Promise
fetch('/api/data')
  .then(res => res.json())
  .then(data => console.log(data));

// async/await
async function getData() {
  const res = await fetch('/api/data');
  const data = await res.json();
  console.log(data);
}

40-47. Promise、async/await 详解 ​

Promise 状态：pending, fulfilled, rejected

async/await：基于 Promise 的语法糖，让异步代码像同步。

七、设计模式（57-59 题） ​

57. 单例模式的实现方式有哪些？ ​

答案：

javascript
const Singleton = (function() {
  let instance;
  
  function createInstance() {
    return { message: 'I am singleton' };
  }
  
  return {
    getInstance() {
      if (!instance) {
        instance = createInstance();
      }
      return instance;
    }
  };
})();

const s1 = Singleton.getInstance();
const s2 = Singleton.getInstance();
console.log(s1 === s2);  // true

八、性能优化（60-67 题） ​

60. 什么是防抖和节流？ ​

答案： 防抖：n 秒后执行，期间重新触发则重新计时。 节流：n 秒内只执行一次。

javascript
// 防抖
function debounce(fn, delay) {
  let timer;
  return function(...args) {
    clearTimeout(timer);
    timer = setTimeout(() => fn.apply(this, args), delay);
  };
}

// 节流
function throttle(fn, limit) {
  let inThrottle;
  return function(...args) {
    if (!inThrottle) {
      fn.apply(this, args);
      inThrottle = true;
      setTimeout(() => inThrottle = false, limit);
    }
  };
}

63. 深拷贝与浅拷贝的区别是什么？ ​

答案： 浅拷贝：只复制一层。 深拷贝：递归复制所有层级。

javascript
// 浅拷贝
const shallow = { ...obj };
const shallow2 = Object.assign({}, obj);

// 深拷贝
const deep = JSON.parse(JSON.stringify(obj));

// 更好的深拷贝
function deepClone(obj, hash = new WeakMap()) {
  if (obj === null || typeof obj !== 'object') return obj;
  if (hash.has(obj)) return hash.get(obj);
  
  const clone = Array.isArray(obj) ? [] : {};
  hash.set(obj, clone);
  
  for (let key in obj) {
    if (obj.hasOwnProperty(key)) {
      clone[key] = deepClone(obj[key], hash);
    }
  }
  
  return clone;
}

九、其他重要知识点 ​

68. new 操作符做了什么？ ​

答案：

  1. 创建空对象
  2. 设置原型
  3. 绑定 this
  4. 返回对象
javascript
function myNew(Constructor, ...args) {
  const obj = Object.create(Constructor.prototype);
  const result = Constructor.apply(obj, args);
  return result instanceof Object ? result : obj;
}

76. 事件循环机制是什么？ ​

答案： Event Loop：JS 的单线程模型。

流程：

  1. 执行同步代码（调用栈）
  2. 异步任务放入任务队列
  3. 调用栈清空后，执行微任务
  4. 执行宏任务
javascript
console.log('script start');

setTimeout(() => console.log('timeout'), 0);

Promise.resolve().then(() => console.log('promise'));

console.log('script end');

// 输出顺序：
// script start
// script end
// promise
// timeout

77. 宏任务与微任务的区别是什么？ ​

答案： 宏任务：setTimeout, setInterval, I/O 微任务：Promise.then, MutationObserver, process.nextTick

执行顺序：微任务优先于宏任务。
