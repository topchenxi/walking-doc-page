3. 表单验证：防抖处理或错误提示样式缺失如何处理？ ​

问题：

  • 表单验证：防抖处理或错误提示样式缺失如何处理？

实现思路： 在事件触发 n 秒后执行，期间再次触发则重新计时。

代码实现：

javascript
function debounce(fn, wait=300){
  let t;
  return function(...args){
    clearTimeout(t);
    t = setTimeout(() => fn.apply(this, args), wait);
  };
}
window.onresize = debounce(() => console.log('resized'), 200);

javascript
function debounce(fn, wait=300){
  let t;
  return function(...args){
    clearTimeout(t);
    t = setTimeout(() => fn.apply(this, args), wait);
  };
}
