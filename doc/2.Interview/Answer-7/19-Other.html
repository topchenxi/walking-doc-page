其他 答案 ​

一、编程基础 ​

数据结构基础 ​

  • 数组：连续存储，索引 O(1)，插入/删除 O(n)
  • 链表：非连续，插入/删除 O(1)，查找 O(n)
  • 栈/队列：LIFO/FIFO
  • 树：层级结构，二叉树最常用（BST、AVL、红黑树）
  • 哈希表：键值对，O(1) 查找

算法思想 ​

  • 时间复杂度：O(1) < O(logn) < O(n) < O(nlogn) < O(n²) < O(2ⁿ)
  • 递归：终止条件 + 规模缩小
  • 分治：分→治→合
  • DP：子问题 + 最优子结构 + 状态转移

二、前端工程化 ​

脚手架 ​

  • Vue CLI / create-vue (Vite)
  • CRA (Create React App) / Vite React Template
  • Next.js / Nuxt.js

模块化演进 ​

<script>全局污染
  → IIFE 隔离作用域
    → AMD(RequireJS) / CMD(SeaJS) 异步加载
      → CommonJS(Node.js) 同步
        → ES Module(ES6) 静态+TreeShaking

lint 工具 ​

  • ESLint：JS/TS 代码规范
  • Prettier：代码格式化
  • Stylelint：CSS/SCSS 规范
  • husky + lint-staged：Git hooks 自动化

三、移动端开发 ​

适配方案 ​

  1. viewport：<meta name="viewport" content="width=device-width, initial-scale=1.0">
  2. rem：基于根字体缩放
  3. vw/vh：基于视口百分比
  4. 媒体查询：断点适配

响应式设计 ​

  • 流动布局(百分比/flex/grid)
  • 弹性图片 max-width: 100%
  • 媒体查询 @media

触摸事件 ​

javascript
el.addEventListener('touchstart', fn);
el.addEventListener('touchmove', fn);
el.addEventListener('touchend', fn);
// 触摸对象：e.touches, e.changedTouches

四、测试 ​

测试类型范围工具
单元测试函数/组件Jest, Vitest
组件测试UI 交互Testing Library
端到端(E2E)完整用户流程Playwright, Cypress
接口测试APISupertest + Jest
javascript
// Jest 示例
test('adds 1 + 2 to equal 3', () => {
  expect(add(1, 2)).toBe(3);
});

五、前沿技术 ​

技术用途
WebSocket全双工实时通信（聊天、推送）
WebRTC点对点音视频通话
WebAssembly高性能计算(C/Rust → 浏览器)
PWA渐进式 Web 应用(离线、推送、安装)
GraphQL声明式 API 查询语言
Serverless无服务器云函数

六、性能优化体系 ​

首屏加载优化 ​

  1. SSR/SSG 预渲染 → 减少白屏时间
  2. 关键 CSS 内联 + 非关键 CSS 延迟加载
  3. JS 代码分割(dynamic import) + 路由懒加载
  4. 预加载关键资源(<link rel="preload">)
  5. CDN + Gzip/Brotli 压缩

运行时优化 ​

  • 虚拟列表(react-window)
  • 防抖/节流
  • Web Worker 密集计算
  • requestAnimationFrame 动画

七、安全 ​

XSS 防范 ​

  • 输入输出转义(DOMPurify、html-entities)
  • CSP Content-Security-Policy
  • HttpOnly Cookie

CSRF 防范 ​

  • SameSite Cookie SameSite=Strict|Lax
  • CSRF Token
  • Referer/Origin 校验

其他 ​

  • HTTPS 全站加密
  • 敏感操作二次确认（支付密码等）

八、异常处理与监控 ​

前端异常捕获 ​

javascript
window.onerror = (msg, url, line, col, error) => { /* 上报 */ };
window.addEventListener('unhandledrejection', e => { /* Promise reject 未处理 */ });

前端监控体系 ​

  • 错误监控：Sentry, 自建日志平台
  • 性能监控：Lighthouse, Web Vitals API
  • 用户行为：埋点(UV/PV/点击流/转化漏斗)
  • API 监控：接口耗时、成功率

九、综合能力 ​

系统设计 ​

  • 权限系统：RBAC（用户→角色→权限）
  • 文件上传：分片、秒传、断点续传
  • 实时协作：OT/CRDT 算法

架构原则 ​

  • SOLID：单一职责、开闭原则、里氏替换等
  • KISS：Keep It Simple
  • DRY：Don't Repeat Yourself
  • YAGNI：You Aren't Gonna Need It

问题分析框架 ​

  1. 明确问题（什么是好的结果？）
  2. 拆解问题（可分解为哪些小问题？）
  3. 各维度分析（性能、安全、用户体验、成本、维护性）
  4. 制定方案并评估
