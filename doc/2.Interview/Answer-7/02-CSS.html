一、CSS 选择器与优先级 ​

1. CSS 选择器有哪些类型及具体语法和使用案例？（至少 6 种） ​

问题：CSS 选择器有哪些类型及具体语法和使用案例？（至少 6 种）

答案：

选择器类型语法示例说明
元素选择器div {}p { color: red; }选中所有指定标签
类选择器.class {}.active { font-weight: bold; }选中指定 class
ID 选择器#id {}#app { width: 100%; }选中唯一 ID，高优先级
属性选择器[attr]input[type="email"] {}根据属性匹配
后代选择器A Barticle p {}选中所有后代元素
子选择器A > Bul > li {}仅选中直接子元素
相邻兄弟A + Bh2 + p {}紧邻的下一个兄弟
通用兄弟A ~ Bh2 ~ p {}后面所有兄弟
伪类:hovera:hover {}特定状态
伪元素::before.box::before {}创建虚拟元素
通配符** { margin: 0; }选中全部元素

2. CSS 选择器有哪些？优先级如何计算？ ​

问题：CSS 选择器有哪些？优先级如何计算？

答案：

优先级计算（0,0,0,0 四位数规则）：

等级选择器类型权重值
0!important最高（慎用）
A内联样式 style=""1,0,0,0
BID 选择器 #id0,1,0,0
C类/属性/伪类 .a, [attr], :hover0,0,1,0
D元素/伪元素 div, ::before0,0,0,1
css
/* 优先级 = 0,1,2,2 */
#app .list li.active { color: red; }
/*    ID=1  类=2      元素=2   */

/* 优先级 = 0,0,0,1 */
div { color: blue; }
/* 结果：red 优先级更高，显示红色 */

注意：* 通配符权重为 0,0,0,0；继承的样式权重最低；同级比较时后面覆盖前面。

3. CSS 选择器优先级计算规则（!important > ID > 类/属性/伪类 > 元素 > 通配符） ​

问题：CSS 选择器优先级计算规则（!important > ID > 类/属性/伪类 > 元素 > 通配符）

答案：

优先级由高到低：

!important > 内联 style > #id > .class/[attr]/:pseudo > 元素/::pseudo > * > 继承
css
/* 优先级演示 */
p { color: green; }                     /* 0,0,0,1 */
.text { color: blue; }                  /* 0,0,1,0 */
#title { color: red; }                  /* 0,1,0,0 */
p#title.text { color: purple; }         /* 0,1,1,1 ← 最高 */
/* 最终颜色: purple */

面试重点：!important 除非覆盖第三方库样式，否则避免使用——它会破坏优先级体系，让后续调试变得困难。

4. 哪些 CSS 属性可以继承？（至少 5 个） ​

问题：哪些 CSS 属性可以继承？（至少 5 个，如 color、font-family、font-size、line-height、text-align）

答案：

可继承属性（文本相关为主）：

类别属性
字体font-family, font-size, font-weight, font-style, font-variant
文本color, line-height, text-align, text-indent, word-spacing, letter-spacing, text-transform, white-space
列表list-style 相关
表格border-collapse, border-spacing
其他visibility, cursor, direction

不可继承：width, height, margin, padding, border, background, position, display

可以使用 inherit 关键字强制继承，或用 initial 恢复默认值。

二、盒模型与布局 ​

5. CSS 盒模型是什么？它包含哪些部分？ ​

问题：CSS 盒模型是什么？它包含哪些部分？

答案：

盒模型是 CSS 布局的基石，每个元素都被视为一个矩形盒子。

从内到外四层：

┌─────────────────────────────────┐
│         margin（外边距）         │
│  ┌───────────────────────────┐  │
│  │     border（边框）         │  │
│  │  ┌─────────────────────┐  │  │
│  │  │  padding（内边距）   │  │  │
│  │  │  ┌───────────────┐  │  │  │
│  │  │  │  content（内容）│  │  │  │
│  │  │  └───────────────┘  │  │  │
│  │  └─────────────────────┘  │  │
│  └───────────────────────────┘  │
└─────────────────────────────────┘
部分说明
content实际内容区域，由 width/height 定义
padding内容与边框间的空白，透明
border边框，包裹 padding + content
margin盒子与其他元素的间距，透明，无背景

6. W3C 标准盒模型的组成部分是什么？ ​

问题：W3C 标准盒模型的组成部分是什么？

答案：

W3C 标准盒模型（box-sizing: content-box，默认）：

元素总宽度 = width + padding-left + padding-right + border-left + border-right
元素总高度 = height + padding-top + padding-bottom + border-top + border-bottom

width/height 仅指 content 区域。所以设置 width: 100px; padding: 10px; border: 5px solid; → 实际占用 100 + 2×10 + 2×5 = 130px。

7. Border-box 与 content-box 的区别是什么？ ​

问题：Border-box 与 content-box 的区别是什么？

答案：

维度content-box（默认）border-box（推荐）
width 范围仅 contentcontent + padding + border
总宽度计算width + padding + borderwidth 即最终宽度
直观性心智负担大直观，匹配设计师习惯
css
/* content-box: 实际宽度 140px */
.box1 {
  box-sizing: content-box;
  width: 100px;
  padding: 10px;
  border: 10px solid;
}

/* border-box: 实际宽度 100px，内容宽度 60px */
.box2 {
  box-sizing: border-box;
  width: 100px;
  padding: 10px;
  border: 10px solid;
}

最佳实践：全局设置 *, *::before, *::after { box-sizing: border-box; }

8. box-sizing 属性有哪些值？各有什么作用？ ​

问题：box-sizing 属性有哪些值？各有什么作用？

答案：

值作用
content-box默认值，width/height = 内容区
border-boxwidth/height = 内容 + padding + border
inherit继承父元素值

9. 盒模型的计算方式是什么？ ​

问题：盒模型的计算方式是什么？

答案：

与第 5、6、7 题一致。核心是理解两种模式下的宽度计算差异。

标准模式：总宽 = 内容宽 + padding + border + margin IE/怪异模式：width = 内容宽 + padding + border（margin 额外加）

10. 如何理解 CSS 盒子模型？ ​

问题：如何理解 CSS 盒子模型？

答案：

把每个 HTML 元素想象成一个包装盒子：

  • content = 商品本身
  • padding = 泡沫填充
  • border = 盒子外壳
  • margin = 盒子之间的间隙

border-box 模式下，你设置的 width 就是整个盒子（含泡沫+外壳）的尺寸，更符合直觉。

三、Flexbox 与 Grid 布局 ​

11. Flex 布局的原理、属性及应用场景是什么？ ​

问题：Flex 布局的原理、属性及应用场景是什么？

答案：

原理：Flexbox（弹性布局）是一维布局模型，沿着主轴排列项目，通过容器和项目双方配合实现灵活的空间分配。

核心概念：

容器属性（父元素）   →  控制整体排列方向和对齐
项目属性（子元素）   →  控制单个项目的伸缩行为
主轴 vs 交叉轴       →  flex-direction 决定主轴方向

容器属性：display: flex, flex-direction, justify-content, align-items, align-content, flex-wrap, gap

项目属性：flex-grow, flex-shrink, flex-basis, align-self, order

应用场景：

  • 水平/垂直居中
  • 导航栏两端对齐
  • 列表等分排列
  • 卡片网格
  • 任何需要弹性空间的场景

12. Flex 布局是如何工作的？相关属性有哪些？ ​

问题：Flex 布局是如何工作的？相关属性有哪些？

答案：

Flex 布局建立了主轴（main axis）→ 交叉轴（cross axis）的二维坐标系。

css
.container {
  display: flex;
  flex-direction: row;        /* 主轴水平，默认 */
  justify-content: space-between; /* 主轴对齐 */
  align-items: center;        /* 交叉轴对齐 */
  flex-wrap: wrap;            /* 换行 */
  gap: 16px;                  /* 间距 */
}

.item {
  flex: 1;                    /* grow:1, shrink:1, basis:0% */
  /* 等价于 */
  flex-grow: 1;               /* 扩展比例 */
  flex-shrink: 1;             /* 收缩比例 */
  flex-basis: 0%;             /* 初始大小 */
}

13. Flexbox 弹性盒布局模型的容器属性有哪些？ ​

问题：Flexbox 弹性盒布局模型的容器属性有哪些？

答案：

属性作用常用值
display: flex启动弹性布局块级；inline-flex 行内
flex-direction主轴方向row, column, row-reverse, column-reverse
flex-wrap是否换行nowrap, wrap, wrap-reverse
justify-content主轴对齐flex-start, flex-end, center, space-between, space-around, space-evenly
align-items交叉轴对齐（单行）stretch, flex-start, flex-end, center, baseline
align-content多行时交叉轴对齐同 justify-content
gap / row-gap / column-gap间距数值

14. Flexbox 的项目属性有哪些？ ​

问题：Flexbox 的项目属性有哪些？

答案：

属性作用
flex-grow放大比例，默认 0 不放大
flex-shrink缩小比例，默认 1
flex-basis初始主轴尺寸，默认 auto
flex简写：flex: grow shrink basis
align-self单个项目的交叉轴对齐，覆盖 align-items
order排列顺序，数值越小越靠前，默认 0

15. Grid 布局的特点和应用场景是什么？ ​

问题：Grid 布局的特点和应用场景是什么？

答案：

Grid 是二维布局，同时控制行和列，适合复杂页面结构。

css
.container {
  display: grid;
  grid-template-columns: 200px 1fr 1fr;
  grid-template-rows: auto 1fr auto;
  gap: 16px;
}

/* 典型页面布局：header + sidebar + main + footer */
.layout {
  display: grid;
  grid-template-areas:
    "header  header"
    "sidebar main"
    "footer  footer";
  grid-template-columns: 250px 1fr;
  grid-template-rows: auto 1fr auto;
  min-height: 100vh;
}

Flex vs Grid 选择：一维排列（导航、列表）用 Flex；二维布局（页面结构、卡片网格）用 Grid。

16. 不同的布局方式的特点及应用场景 ​

问题：不同的布局方式（如 Flex 布局、Grid 布局等）的特点及应用场景

答案：

布局方式维度特点场景
Float伪二维老方案，需清除浮动文字环绕（历史遗留）
Position-脱离文档流弹窗、悬浮组件
Flexbox一维弹性分配空间，对齐方便导航、列表、居中、表单
Grid二维行列同时控制页面结构、复杂网格、仪表盘
Table二维对齐好但笨重纯数据表格（不用 div 模拟）
Multi-column一维多列文本流报纸式排版

17. 圣杯布局和双飞翼布局如何实现？ ​

问题：圣杯布局和双飞翼布局如何实现？

答案：

两者都是三栏布局（左右固定，中间自适应），中间栏优先渲染。

圣杯布局（通过 padding + 负 margin + relative）：

html
<div class="container">
  <div class="center">中间</div>
  <div class="left">左侧</div>
  <div class="right">右侧</div>
</div>
css
.container { padding: 0 200px 0 150px; }
.center { width: 100%; float: left; }
.left { width: 150px; float: left; margin-left: -100%; position: relative; left: -150px; }
.right { width: 200px; float: left; margin-left: -200px; position: relative; right: -200px; }

双飞翼布局（多了一层 inner div 用 margin 留空，无需 relative）：

html
<div class="center">
  <div class="inner">中间</div>
</div>
<div class="left">左侧</div>
<div class="right">右侧</div>
css
.center { width: 100%; float: left; }
.inner { margin: 0 200px 0 150px; }
.left { width: 150px; float: left; margin-left: -100%; }
.right { width: 200px; float: left; margin-left: -200px; }

现代方案：直接用 Flex 或 Grid 实现，代码量减少 80%：

css
.wrapper { display: flex; }
.center { flex: 1; order: 2; }
.left { width: 150px; order: 1; }
.right { width: 200px; order: 3; }

四、响应式设计（媒体查询） ​

18. 如何实现移动端适配？常用方法有哪些？ ​

问题：如何实现移动端适配？常用方法有哪些？

答案：

  1. viewport 设置：<meta name="viewport" content="width=device-width, initial-scale=1.0">
  2. rem 适配：基于根元素字体，配合 JS 或 CSS 计算
  3. vw/vh 适配：基于视口百分比
  4. 媒体查询：断点针对性调整
  5. Flex/Grid 弹性布局
  6. postcss-pxtorem / postcss-px-to-viewport：自动转换 px
javascript
// rem 适配脚本（375 设计稿）
(function() {
  const html = document.documentElement
  const setRem = () => { html.style.fontSize = (html.clientWidth / 3.75) + 'px' }
  window.addEventListener('resize', setRem)
  setRem()
})()

19. 响应式设计如何实现？ ​

问题：响应式设计如何实现？

答案：

响应式设计 = 流动网格 + 弹性媒体 + 媒体查询

  1. 流动布局：百分比、vw、flex、grid
  2. 弹性媒体：max-width: 100%
  3. 媒体查询：根据设备特征切换
css
/* Mobile First 策略 */
.card { width: 100%; }                    /* 移动端：全宽 */

@media (min-width: 768px) {
  .card { width: calc(50% - 16px); }       /* 平板：二列 */
}

@media (min-width: 1024px) {
  .card { width: calc(33.333% - 16px); }   /* 桌面：三列 */
}

20. 媒体查询如何实现响应式设计？ ​

问题：媒体查询如何实现响应式设计？

答案：

@media 语法：检测设备特征（宽度、分辨率、设备类型等），条件满足时应用内部样式。

css
/* 基础语法 */
@media (条件) { /* 样式 */ }

/* 常用条件 */
@media (max-width: 768px) { }    /* ≤768px 时生效 */
@media (min-width: 1024px) { }   /* ≥1024px 时生效 */
@media (768px <= width <= 1024px) { } /* 区间（现代写法） */

/* 组合条件 */
@media screen and (min-width: 768px) and (orientation: landscape) { }

/* 响应式断点建议 */
/* 576 / 768 / 992 / 1200 / 1400 */

21. 媒体查询失效：断点设置不合理导致布局错乱如何处理？ ​

问题：媒体查询失效：断点设置不合理导致布局错乱如何处理？

答案：

诊断：

  1. 检查媒体查询的书写顺序（后写覆盖前写）
  2. 检查是否有 min-width/max-width 范围重叠或遗漏
  3. 检查 viewport meta 是否正确设置
  4. 使用浏览器 DevTools 的响应式模式逐断点调试

最佳实践：

  • 采用 Mobile First，用 min-width 逐层增强
  • 断点之间不留空白区间
  • 遵循断点层叠，从小到大写出
css
/* ✅ 正确：Mobile First，顺序清晰 */
.base { /* 移动端 */ }
@media (min-width: 768px) { /* 平板 */ }
@media (min-width: 1024px) { /* 桌面 */ }
@media (min-width: 1440px) { /* 大屏 */ }

/* ❌ 错误：范围重叠，顺序混乱 */
@media (max-width: 1000px) { ... }
@media (min-width: 768px) { ... } /* 在 768~1000 间可能冲突 */

五、CSS 动画与过渡 ​

22. 如何使用 CSS3 实现动画？animation、transition、transform 有什么区别？ ​

问题：如何使用 CSS3 实现动画？animation、transition、transform 有什么区别？

答案：

属性作用触发方式关键帧控制
transition简单过渡状态变化触发（hover, class 变化等）起止两态
animation复杂动画页面加载即可执行任意关键帧 @keyframes
transform变形即时（或配合 transition/animation）无
css
/* transition: 属性 时长 缓动 延迟 */
.button {
  background: blue;
  transition: background 0.3s ease, transform 0.2s;
}
.button:hover {
  background: darkblue;
  transform: scale(1.05);      /* 配合 transition 实现动画 */
}

/* animation + @keyframes */
.spinner {
  animation: spin 1s linear infinite;
}
@keyframes spin {
  from { transform: rotate(0deg); }
  to   { transform: rotate(360deg); }
}

23. CSS 动画与过渡的区别及实现方式是什么？ ​

问题：CSS 动画与过渡的区别及实现方式是什么？

答案：

维度transitionanimation
触发需要状态改变可自动播放
中间态无法控制@keyframes 精确控制
循环不支持animation-iteration-count: infinite
往返仅返回起点可设 alternate
复杂度简单适合复杂动画序列

24. CSS 动画相关的属性有哪些？如何实现一个简单动画效果？ ​

问题：CSS 动画相关的属性有哪些？如何实现一个简单动画效果？

答案：

animation 相关属性：

属性作用
animation-name绑定 @keyframes 名称
animation-duration动画时长
animation-timing-function缓动函数
animation-delay延迟时间
animation-iteration-count播放次数
animation-direction播放方向
animation-fill-mode结束状态
animation-play-state暂停/播放
css
/* 淡入 + 上移 */
.fade-in {
  animation: fadeUp 0.5s ease-out;
}
@keyframes fadeUp {
  from {
    opacity: 0;
    transform: translateY(20px);    /* 从下方 20px 处开始 */
  }
  to {
    opacity: 1;
    transform: translateY(0);       /* 回到原始位置 */
  }

八、CSS 性能优化 ​

35. CSS 的重绘（Repaint）与回流（Reflow）是什么？有什么区别？ ​

问题：CSS 的重绘（Repaint）与回流（Reflow）是什么？有什么区别？

答案：

回流（Reflow/Layout）：元素的几何属性（位置、大小）改变，浏览器重新计算布局。开销大。

重绘（Repaint）：外观改变但布局不变（颜色、背景等），浏览器重新绘制像素。开销较小。

回流一定触发重绘，重绘不一定触发回流。
触发回流触发重绘
改变 width/height改变 color
改变 margin/padding/border改变 background
改变 display改变 visibility
改变 font-size改变 box-shadow
添加/删除 DOM改变 outline
改变 position

36. 重绘与回流的触发场景及优化策略有哪些？ ​

问题：重绘与回流的触发场景及优化策略有哪些？

答案：

触发场景：

  • 页面首次渲染
  • 窗口大小改变
  • DOM 增删
  • 元素尺寸/位置改变
  • 读取某些属性（offsetWidth, scrollTop, clientWidth 等会强制回流）

优化策略：

  1. 批量 DOM 操作：用 DocumentFragment 或 display: none 先操作再展示
  2. 避免逐个修改样式：使用 classList 切换类名，一次性改多个属性
  3. 脱离文档流：动画元素用 position: absolute/fixed
  4. CSS transform + opacity 做动画：跳过回流重绘，只在合成层处理
  5. 读写分离：避免交替读 offset 和写样式（防止布局抖动）
javascript
// ❌ 布局抖动（Layout Thrashing）
elements.forEach(el => {
  const h = el.offsetHeight; // 强制回流读取
  el.style.height = h + 10 + 'px'; // 写入触发回流
})

// ✅ 读写分离
const heights = elements.map(el => el.offsetHeight) // 批量读
heights.forEach((h, i) => { elements[i].style.height = h + 10 + 'px' }) // 批量写

37. 浏览器渲染机制与重绘/回流优化 ​

问题：浏览器渲染机制与重绘/回流优化

答案：

浏览器渲染流水线：

解析 HTML → DOM 树
解析 CSS  → CSSOM 树
      ↓
    Render 树（合并）
      ↓
  Layout（布局/回流）  ← 计算位置、大小
      ↓
  Paint（绘制/重绘）   ← 填充像素
      ↓
  Composite（合成）   ← 分层合并显示

性能影响排序：Layout > Paint > Composite

使用 transform 和 opacity 的动画只触发 Composite，性能最优。

子元素全部隐藏可单独设置 visible 显示
事件不可交互不可点击（占位无响应）
过渡不支持过渡动画支持延迟但 UI 不变化
SEO爬虫可能忽略爬虫可抓取

与 opacity: 0 的区别：opacity 不脱离文档流、可点击透传、子元素可见度受父级影响、支持过渡。

54. 渐进增强与优雅降级的区别是什么？在 CSS 中如何体现？ ​

问题：渐进增强与优雅降级的区别是什么？在 CSS 中如何体现？

答案：

方向渐进增强优雅降级
起点基础体验 → 增强完整体验 → 降级
CSS 实践Mobile First (min-width)Desktop First (max-width)
css
/* 渐进增强：Mobile First */
.card { width: 100%; }

/* 优雅降级：Desktop First */
.card { width: 25%; }
@media (max-width: 768px) { .card { width: 100%; } }

55. 如何让 Chrome 浏览器显示小于 12px 的文字？ ​

问题：如何让 Chrome 浏览器显示小于 12px 的文字？

答案：

Chrome 默认最小字体 12px（可通过 chrome://settings/fonts 修改）。

突破方案：

css
.small-text {
  font-size: 10px;
  transform: scale(0.833);           /* 10px / 12px ≈ 0.833 */
  transform-origin: left top;        /* 保持对齐 */
  /* 或用 zoom 但非标准 */
}

transform: scale() 不改变元素盒模型尺寸，只是视觉缩放。需要手动调整宽高和边距。

56. CSS 变量（自定义属性）如何使用？ ​

问题：CSS 变量（自定义属性）如何使用？

答案：

CSS 自定义属性（CSS Variables）以 -- 开头，用 var() 引用。

css
:root {
  --primary-color: #3b82f6;
  --spacing-md: 16px;
  --border-radius: 8px;
}

.button {
  background: var(--primary-color);
  padding: var(--spacing-md);
  border-radius: var(--border-radius);
  /* 可以带默认值：var(--spacing-lg, 24px) */
}

/* 作用域：只在 .dark-theme 内部改变 */
.dark-theme {
  --primary-color: #1e3a5f;
}

优势：运行时动态修改（JS 可读写）；作用域控制（比 Sass 变量灵活）；支持 fallback 值。

57. 如何用 CSS 创建一个三角形？ ​

问题：如何用 CSS 创建一个三角形？

答案：

利用 border 的透明特性：

css
.triangle {
  width: 0;
  height: 0;
  border-left: 20px solid transparent;    /* 左右透明 → 尖角朝下 */
  border-right: 20px solid transparent;
  border-bottom: 20px solid #3b82f6;      /* 底部有色 */
}

原理：元素宽高为 0 时，border 形成四块三角区域，将不需要的方向设为 transparent。

css
/* 上三角形（尖角朝上） */
.top-triangle {
  width: 0; height: 0;
  border-left: 20px solid transparent;
  border-right: 20px solid transparent;
  border-bottom: 20px solid red;   /* 红色在下方 → 尖朝上 */
}

58. CSS Sprites 的原理及涉及的属性是什么？ ​

问题：CSS Sprites 的原理及涉及的属性是什么？

答案：

原理：将多张小图合并为一张大图（雪碧图），通过 background-position 定位显示需要的部分。

优点：减少 HTTP 请求 → 加载速度快

涉及属性：

css
.icon {
  background-image: url('sprite.png');    /* 雪碧图 */
  background-repeat: no-repeat;
  background-position: -20px -40px;       /* 偏移定位 */
  width: 16px;
  height: 16px;
}

background-image, background-repeat, background-position, width, height

60. CSS 属性简写规则是什么？（如 padding） ​

问题：CSS 属性简写规则是什么？（如 padding）

答案：

CSS 四值顺序记忆：上 → 右 → 下 → 左（顺时针 TRBL）

css
/* 完整写 */
padding-top: 10px;
padding-right: 20px;
padding-bottom: 15px;
padding-left: 5px;

/* 简写 */
padding: 10px 20px 15px 5px;        /* 上 右 下 左 */
padding: 10px 20px;                 /* 上下 左右 */
padding: 10px 20px 15px;            /* 上 左右 下 */
padding: 10px;                      /* 四边相同 */

同样规则适用于 margin, border-width, border-color, border-radius 等。

62. px 与 em 的区别是什么？ ​

问题：px 与 em 的区别是什么？

答案：

单位含义相对参照
px绝对像素无，固定值
em相对字号父元素 font-size
rem相对字号根元素 <html> font-size
vw/vh视口百分比视口宽/高度
css
.parent { font-size: 20px; }
.child {
  font-size: 1.5em;          /* 20px × 1.5 = 30px */
  padding: 1em;              /* 30px × 1 = 30px */
}

em 的坑：em 对于复合嵌套会造成逐层放大（连锁反应）。优先用 rem 做全局尺寸，用 em 做组件内的局部尺寸（如 icon 相对文字大小）。

66. CSS 雪碧图的作用是什么？ ​

问题：CSS 雪碧图的作用是什么？

答案：

CSS 雪碧图（CSS Sprite）的核心价值是减少 HTTP 请求数。

原理：将多张小图标合成到一张大图，用 background-position 定位需要的图标区域。

优点：

  • 减少 HTTP 请求 → 加快页面加载
  • 避免逐个图标加载时的闪烁

缺点：

  • 维护麻烦（增减图标要更新整张图 + CSS）
  • 内存占用（大图解码）

现代替代方案：SVG sprite、字体图标（iconfont） 或直接用 SVG 组件（在 Vue/React 中）。
