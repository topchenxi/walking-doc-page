Vue3 答案 ​

一、Composition API ​

1-26 Composition API 核心 ​

Composition API vs Options API：

维度Options API (Vue2)Composition API (Vue3)
组织方式按选项(data/methods/computed)按逻辑关注点
逻辑复用Mixins（来源不透明、冲突）自定义 hooks（透明）
TypeScript需要额外装饰器原生友好
代码组织同一功能散落各处同一功能代码在一起
html
<script setup>
import { ref, reactive, computed, onMounted } from 'vue';

const count = ref(0);               // ref: 基本类型，.value 访问
const state = reactive({ x: 0 });   // reactive: 对象，直接访问
const double = computed(() => count.value * 2);

function increment() { count.value++; }
onMounted(() => { console.log('mounted'); });
</script>

ref vs reactive：

维度refreactive
包装类型任意（主要基本类型）仅对象/数组
访问.value（模板中自动解）直接访问
替换✅ 可整体替换❌ 替换会丢响应式
解构不会丢响应式会丢失（需 toRefs）
javascript
// toRefs 解决 reactive 解构丢响应式
const state = reactive({ a: 1, b: 2 });
const { a, b } = toRefs(state); // 响应式保留

// shallowRef: 浅响应，仅 .value 变更触发
// markRaw: 标记对象永不为响应式
// toRaw: 获取原始对象（脱去响应）

三、响应式原理（Proxy） ​

34-40 Proxy 响应式 ​

Vue3 使用 Proxy 实现响应式：

javascript
const handler = {
  get(target, key, receiver) {
    track(target, key);   // 依赖收集
    return Reflect.get(target, key, receiver);
  },
  set(target, key, value, receiver) {
    const result = Reflect.set(target, key, value, receiver);
    trigger(target, key); // 派发更新
    return result;
  }
};
Vue2(defineProperty)Vue3(Proxy)
仅对象属性整个对象代理
新增/删除属性不监听✅ 自动监听
数组困难✅ 完整支持
需遍历每个属性一次性代理

四、watch 与 computed ​

41-45 ​

javascript
import { watch, watchEffect, computed } from 'vue';

// watch：明确监听源，懒执行
watch(count, (newVal, oldVal) => { console.log(newVal, oldVal); });
watch([count, name], ([c, n]) => { /* 多源 */ });
watch(() => state.x, (val) => {}, { deep: true, immediate: true });

// watchEffect：自动追踪内部响应式依赖，立即执行
watchEffect(() => { console.log(count.value); });

// computed
const doubled = computed(() => count.value * 2);
维度watchwatchEffect
执行懒，依赖变化才执行立即执行
依赖明确指定自动追踪
旧值✅ 可获取❌

五、Teleport 与 Suspense ​

46-52 ​

Teleport：将组件内容渲染到 DOM 树的指定位置（如 body）。

html
<Teleport to="body">
  <Modal>模态框内容</Modal>
</Teleport>

Suspense：优雅处理异步组件的加载状态。

html
<Suspense>
  <template #default><AsyncComponent /></template>
  <template #fallback><Loading /></template>
</Suspense>
javascript
import { defineAsyncComponent } from 'vue';
const AsyncComp = defineAsyncComponent(() => import('./Comp.vue'));

六、性能优化 ​

55-64 Vue3 性能优化 ​

优化说明
静态提升不会变的静态节点提升到 render 外，只创建一次
预字符串化连续静态节点直接编译为字符串，跳过虚拟 DOM
PatchFlag编译时标记节点动态部分，Diff 时跳过静态部分
缓存事件处理事件函数缓存，避免重新创建
Tree Shaking按需导入 API（ref/reactive），未用到的 tree-shake 掉
v-memo子树缓存，依赖不变则跳过渲染
html
<div v-memo="[count]">{{ complexComputation() }}</div>
<!-- 仅 count 变化时重新计算 -->

七、Vue3 新特性速览 ​

  • 多根节点：组件模板支持多个根元素
  • v-model 增强：支持多个 v-model 绑定
  • emits 选项：声明组件触发的事件
  • Fragment、Teleport、Suspense
  • 全局 API 调整：createApp 代替 new Vue，不再共享全局配置
  • 事件总线移除：$on/$off 移除（推荐 mitt 或状态管理）
  • 响应式全家桶：ref, reactive, readonly, shallowRef, markRaw 等
javascript
// 创建应用
import { createApp } from 'vue';
const app = createApp(Root);
app.use(router).use(pinia).mount('#app');
