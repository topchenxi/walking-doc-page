浏览器 答案 ​

一、浏览器架构 ​

现代浏览器（Chrome）采用多进程架构：

进程职责
浏览器主进程UI、地址栏、书签、网络请求
渲染进程解析 HTML/CSS/JS → 渲染页面（每个标签页一个）
GPU 进程加速渲染
插件进程隔离插件
网络进程网络资源加载

多进程隔离：一个标签页崩溃不影响其他标签页。

二、渲染流程 ​

HTML → HTML Parser → DOM Tree
CSS  → CSS Parser  → CSSOM Tree
         ↘        ↙
        Render Tree
            ↓
      Layout（回流）→ 计算几何信息
            ↓
      Paint（分层）
            ↓
      Composite（合成层）→ GPU 显示

三、重绘与回流 ​

概念触发条件开销
回流/重排几何属性（尺寸、位置）改变大
重绘外观属性（颜色、背景）改变小
合成transform/opacity 改变无
  • 回流必然触发重绘，重绘不一定回流
  • transform, opacity 只走合成，不触发回流/重绘 — 动画首选

四、事件循环（Event Loop） ​

同步代码全部执行完
  ↓
清空微任务队列（Promise.then, MutationObserver）
  ↓
执行一个宏任务（setTimeout, I/O, UI 渲染）
  ↓
再次清空微任务 ↓ 循环

五、垃圾回收（GC） ​

V8 GC 机制：

策略对象算法
新生代生命周期短Scavenge(复制，快)
老生代生命周期长标记清除 + 标记整理

标记清除：从根对象出发标记可达对象，清除不可达的。

六、浏览器缓存 ​

缓存类型字段行为
强缓存Cache-Control: max-age=3600不请求，直接用
协商缓存ETag / If-None-Match请求验证，304 则用缓存
启发式缓存(无明确头)浏览器自主判断

七、存储机制 ​

方案容量过期随请求发送
Cookie4KB可设✅ 自动
localStorage5MB+永久❌
sessionStorage5MB+关闭标签❌
IndexedDB大永久❌（异步 NoSQL）

八、跨域与安全 ​

同源策略：协议+域名+端口全相同。

XSS（跨站脚本攻击）：注入恶意脚本 → 对输入转义、CSP 头

CSRF（跨站请求伪造）：伪造用户请求 → Token 校验、SameSite Cookie

CSP（内容安全策略）：Content-Security-Policy HTTP 头限制资源来源

九、性能优化 ​

层面策略
网络CDN、HTTP/2、资源压缩、预加载(preload/prefetch)
资源懒加载、图片 WebP、代码分割
渲染避免回流、虚拟列表、will-change、content-visibility
缓存强缓存 + 协商缓存 + Service Worker

关键指标：

  • FP/FCP：首次绘制/内容绘制（白屏时间）
  • LCP：最大内容绘制（≤ 2.5s）
  • FID/INP：首次输入延迟 / 交互延迟
  • CLS：累积布局偏移
