Vue 答案 ​

一、Vue 基础概念 ​

1-7 Vue 核心概念 ​

什么是 Vue.js：渐进式 JavaScript 框架，用于构建用户界面。

核心特性说明
声明式渲染模板语法描述 UI，数据变化自动更新 DOM
响应式系统基于数据劫持 + 发布订阅，数据变化自动通知视图
组件化界面拆为独立可复用组件
虚拟 DOMDiff 算法最小化实际 DOM 操作
指令系统v-bind/v-if/v-for 等增强模板能力

渐进式：可逐步采用——只用核心库做视图层，再按需引入路由(Vue Router)、状态管理(Vuex/Pinia)、SSR(Nuxt)等。

javascript
// MVVM 模式在 Vue 中
// Model (data) ←→ ViewModel (Vue实例) ←→ View (模板)
new Vue({
  el: '#app',
  data: { message: 'Hello' },      // Model
  // Vue 实例 = ViewModel，负责双向绑定
})
SPA 优点SPA 缺点
无刷新体验好首屏加载慢
前后端分离SEO 不友好（需 SSR）
缓存好浏览器前进后退需手动管理

二、Vue 实例与生命周期 ​

8-16 生命周期 ​

new Vue() → 初始化事件/生命周期
  ↓
beforeCreate    ← data/methods 不可用
  ↓
初始化注入&响应式
  ↓
created         ← 可访问 data/methods，无 DOM
  ↓
编译模板 → beforeMount
  ↓
创建 vm.$el 挂载 → mounted ← DOM 可操作（请求数据推荐）
  ↓
数据变化 → beforeUpdate → 重新渲染 → updated
  ↓
vm.$destroy() → beforeDestroy → 清理 → destroyed
钩子时机典型用途
created实例创建后，无 DOM请求数据（不依赖 DOM 的）
mountedDOM 挂载完请求数据（推荐）、初始化第三方 DOM 库
beforeDestroy销毁前清除定时器、解绑事件

父子组件生命周期顺序：

  • 创建：父 beforeCreate → 父 created → 父 beforeMount → 子 beforeCreate → 子 created → 子 beforeMount → 子 mounted → 父 mounted
  • 更新：父 beforeUpdate → 子 beforeUpdate → 子 updated → 父 updated
  • 销毁：父 beforeDestroy → 子 beforeDestroy → 子 destroyed → 父 destroyed

三、模板语法与指令系统 ​

17-31 指令 ​

指令作用示例
v-bind动态绑定属性:src="url", :class="{ active: isActive }"
v-on事件绑定@click="fn", @click.stop(阻止冒泡)
v-if/v-else条件渲染(销毁/重建)切换少用
v-show条件显示(display:none)频繁切换用
v-for列表渲染v-for="item in list" :key="item.id"
v-model双向绑定语法糖：:value + @input
v-slot插槽v-slot:header 或 #header
v-pre跳过编译显示原始
v-cloak隐藏未编译模板防闪烁
v-once只渲染一次静态内容

v-if vs v-show：

维度v-ifv-show
渲染条件为假时销毁/不渲染始终渲染，仅切换 display
切换开销高（重建/销毁）低
初始开销低（假时不渲染）高（始终渲染）

v-for 的 key：给每个节点唯一标识，Diff 算法精准复用/移动节点，避免就地更新引发的 Bug。

v-for 与 v-if 同时使用时，v-for 优先级更高。不推荐在同一个元素上使用两者。

自定义指令：

javascript
Vue.directive('focus', {
  inserted(el) { el.focus(); }
});
// 钩子：bind, inserted, update, componentUpdated, unbind

四、计算属性与侦听器 ​

32-39 computed / watch ​

javascript
new Vue({
  data: { firstName: 'John', lastName: 'Doe' },
  computed: {
    fullName: {                          // getter + setter
      get() { return this.firstName + ' ' + this.lastName; },
      set(val) { const parts = val.split(' '); this.firstName = parts[0]; this.lastName = parts[1]; }
    }
  },
  watch: {
    firstName(val, oldVal) { /* 新旧值 */ },
    deepObj: { handler(val) {}, deep: true, immediate: true }
  }
});
维度computedwatchmethods
缓存✅ 依赖不变不重新算❌❌ 每次渲染都执行
异步❌✅✅
用途派生状态数据变化响应事件处理

40-54 组件 ​

data 为什么是函数：每个组件实例需要独立的数据副本，如果是对象则所有实例共享。

javascript
// 全局注册

components: { MyComponent }

组件通信（第 55-66 题）：

方式适用实现

八、Vue 响应式原理 ​

Vue2 响应式：Object.defineProperty 劫持对象属性的 getter/setter，依赖收集 + 派发更新。

getter → 收集依赖（Watcher）
setter → 通知依赖 → Watcher 更新 → 视图更新

局限：

  • 无法检测属性新增/删除（需 Vue.set/Vue.delete）
  • 数组通过重写7种方法（push/pop/splice 等）实现监听
  • 无法监听数组索引赋值和 length 变化
javascript
// 数组响应式处理
// Vue 重写：push, pop, shift, unshift, splice, sort, reverse
// 不可监听：arr[0] = x; arr.length = 0;

九、虚拟 DOM 与 Diff 算法 ​

虚拟 DOM：用 JS 对象描述真实 DOM 结构，通过对比新旧 vnode 找出最小变更。

javascript
// 虚拟 DOM 示例结构
{ tag: 'div', props: { id: 'app' }, children: [...] }

Diff 策略（同层对比）：

  1. 只同层级比较，不跨层级
  2. tag 不同 → 整体替换
  3. tag 相同 → 复用 DOM，更新属性，递归对比子节点
  4. 列表对比需 key 优化

十、keep-alive ​

<keep-alive> 缓存不活动的组件实例，避免重复渲染。

html
<keep-alive>
  <router-view v-if="$route.meta.keepAlive" />
</keep-alive>

关联生命周期：activated（激活时）、deactivated（缓存时）

十一、Vue 其他重要概念 ​

$nextTick：DOM 更新后执行回调。Vue 异步更新 DOM，数据变化后立即操作 DOM 拿不到最新值。

javascript
this.message = 'new';
this.$nextTick(() => { console.log(this.$el.textContent); }); // 'new'

mixins：分发组件中可复用的功能。选项会自动合并，同名冲突时组件内优先。缺点：来源不透明，可能冲突。

SSR（服务端渲染）：服务端渲染 Vue 组件为 HTML 字符串，发送给浏览器。优势：SEO 友好、首屏快。

slot 插槽：

html
<!-- 父组件 -->
<child>
  <template v-slot:header>Header</template>
  <template v-slot:default="slotProps">{{ slotProps.item }}</template>
</child>
<!-- 子组件 -->
<slot name="header"></slot>
<slot :item="data"></slot>

渲染函数 (render)：render(h) { return h('div', {}, this.message); }

$forceUpdate：强制重新渲染（慎用）。
