React 答案 ​

一、React 基础 ​

1. 什么是 React？ ​

React 是用于构建用户界面的 JavaScript 库，采用声明式、组件化方式。核心特征：JSX、虚拟 DOM、单向数据流、组件化。

2-4 JSX、虚拟 DOM、组件 ​

JSX：JavaScript XML，模板语法。被 Babel 编译为 React.createElement() 调用。

jsx
const el = <h1>Hello {name}</h1>;
// 编译为：
const el = React.createElement('h1', null, 'Hello ', name);

虚拟 DOM：

JSX → VDOM 树 → Diff 对比 → 最小化更新真实 DOM

组件：

类型写法状态生命周期
类组件class X extends React.Componentthis.state✅
函数组件function X(props) {}Hooks(useState)Hooks(useEffect)

二、State 与 Props ​

Props（只读，父传子）： ​

jsx
function Child({ name, age = 18 }) { return <div>{name}: {age}</div>; }
<Child name="Alice" />

State（组件内部状态）： ​

jsx
// 类组件
class Counter extends React.Component {
  state = { count: 0 };
  increment = () => this.setState({ count: this.state.count + 1 });
  // setState 异步批处理；函数式更新获取最新值
  incrementSafe = () => this.setState(prev => ({ count: prev.count + 1 }));
}

// 函数组件
function Counter() {
  const [count, setCount] = useState(0);
  return <button onClick={() => setCount(c => c + 1)}>{count}</button>;
}

三、生命周期 ​

类组件生命周期： ​

挂载：constructor → render → componentDidMount
更新：render → componentDidUpdate(prevProps, prevState)
卸载：componentWillUnmount
阶段方法用途
挂载后componentDidMount请求数据、订阅
更新后componentDidUpdate对比前后数据请求
卸载前componentWillUnmount清除订阅、定时器

四、React Hooks ​

常用 Hooks： ​

jsx
// useState：状态
const [count, setCount] = useState(0);

// useEffect：副作用（数据请求、订阅、DOM 操作）
useEffect(() => {
  fetchData();
  return () => { /* 清理 */ };      // componentWillUnmount
}, [deps]);                          // 依赖数组，空[] → 仅一次

// useCallback：缓存函数
const fn = useCallback(() => {}, [deps]);

// useMemo：缓存计算结果
const value = useMemo(() => expensiveComputation(data), [data]);

// useRef：DOM 引用 / 持久值（不触发渲染）
const inputRef = useRef(null);

// useContext：跨组件共享
const theme = useContext(ThemeContext);

// useReducer：复杂状态逻辑
const [state, dispatch] = useReducer(reducer, initialState);

Hooks 规则：

  • 只在顶层调用，不在循环/条件中
  • 只在函数组件或自定义 Hook 中调用

五、组件通信与状态管理 ​

方式场景
Props 下传 + 回调上抛父子组件
Context跨层级（主题、语言等）
Redux / Zustand全局复杂状态
状态提升兄弟组件共享数据
jsx
// Context
const ThemeContext = React.createContext('light');
<ThemeContext.Provider value="dark">
  <Child /> {/* 自动获取 value */}
</ThemeContext.Provider>

六、React Router ​

jsx
import { BrowserRouter, Routes, Route, useNavigate, useParams } from 'react-router-dom';

function App() {
  return (
    <BrowserRouter>
      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/user/:id" element={<User />} />
        <Route path="/lazy" element={<React.lazy(() => import('./Lazy')) />} />
      </Routes>
    </BrowserRouter>
  );
}

// 编程式导航
const navigate = useNavigate(); navigate('/home');
// URL 参数
const { id } = useParams();

七、性能优化 ​

策略实现
React.memo包裹函数组件，props 不变跳过渲染
PureComponent类组件，浅比较
useMemo / useCallback避免每次渲染重建对象/函数
代码分割React.lazy + Suspense
虚拟列表react-window, react-virtualized
避免匿名函数作为 props 传参时，匿名函数导致每次 new
jsx
const MemoChild = React.memo(({ name }) => <div>{name}</div>);

// Suspense + lazy 代码分割
const LazyComponent = React.lazy(() => import('./HeavyComponent'));
<Suspense fallback={<Spinner />}>
  <LazyComponent />
</Suspense>

八、受控 vs 非受控组件 ​

类型数据来源实现
受控React state<input value={val} onChange={e => setVal(e.target.value)} />
非受控DOM 自己维护<input ref={ref} defaultValue="init" />

九、Redux 基础 ​

javascript
// Store → Action → Reducer → Store（单向循环）
const reducer = (state = { count: 0 }, action) => {
  switch (action.type) {
    case 'INCREMENT': return { count: state.count + 1 };
    default: return state;
  }
};
// 现代推荐：Redux Toolkit + useSelector / useDispatch

十、Diff 算法与 Fiber ​

React Diff：Tree Diff（同层比较）+ Component Diff（同类 vs 不同类）+ Element Diff（key 列表优化）

Fiber（React 16+）：可中断的异步渲染架构。将渲染任务拆分成小工作单元，按优先级调度——高优先级用户交互可打断低优先级渲染。

十一、其他重要概念 ​

高阶组件(HOC)：const Enhanced = withAuth(WrappedComponent)，复用逻辑的包装函数。

Render Props：<DataProvider render={data => <Child data={data} />}>，通过 props 共享渲染逻辑。

错误边界：componentDidCatch + getDerivedStateFromError 捕获子组件渲染错误。

Portals：ReactDOM.createPortal(child, container)，渲染到 DOM 其他位置。

Refs 转发：React.forwardRef((props, ref) => <input ref={ref} />)

SSR：Next.js 提供 React 的服务端渲染/静态生成方案。
