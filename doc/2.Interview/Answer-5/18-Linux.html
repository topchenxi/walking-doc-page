Linux 答案 ​

一、Linux 基础命令 ​

1-8. 常用命令 ​

问题：ls、cd、pwd 的作用是什么？find、grep 的作用是什么？

答案：

命令作用示例
ls列出文件ls -la
cd切换目录cd /home
pwd显示当前路径pwd
find查找文件find . -name "*.js"
grep搜索文本grep "error" log.txt
cat查看文件cat file.txt
cp复制文件cp src dest
mv移动/重命名mv old.txt new.txt
rm删除文件rm -rf dir

二、文件系统与权限 ​

10-14. 文件权限与链接 ​

问题：文件权限如何表示？软链接和硬链接的区别是什么？

答案：

权限表示：rwx（读、写、执行），数字：r=4, w=2, x=1

bash
chmod 755 file    # rwxr-xr-x
chmod +x script   # 添加执行权限
chown user:group file  # 更改所有者

链接对比：

维度软链接硬链接
原理指向路径指向 inode
跨文件系统✅❌
删除源文件失效仍有效
bash
ln -s target link    # 软链接
ln target link       # 硬链接

四、网络配置 ​

21-25. 网络命令 ​

问题：curl、wget 的作用是什么？ssh、scp 的作用是什么？

答案：

命令作用
curl发送 HTTP 请求
wget下载文件
ssh远程登录
scp远程复制
netstat查看网络状态
ping测试网络连通性
bash
curl -X POST http://api.example.com/data
wget https://example.com/file.tar.gz
ssh user@192.168.1.100
scp file.txt user@192.168.1.100:/path/

五、文本处理 ​

26-33. awk、sed、sort、uniq ​

问题：awk、sed 的作用是什么？sort、uniq 的作用是什么？

答案：

命令作用
awk文本处理（列操作）
sed文本替换
sort排序
uniq去重
wc统计行数/字数
head查看前 N 行
tail查看后 N 行
bash
awk '{print $1}' file.txt          # 打印第一列
sed 's/old/new/g' file.txt         # 替换文本
sort -n numbers.txt                # 数字排序
uniq -c words.txt                  # 统计重复次数
tail -f log.txt                    # 实时查看日志

八、服务器部署 ​

39-45. Nginx 配置与部署 ​

问题：Nginx 如何安装和配置？反向代理和负载均衡如何配置？

答案：

Nginx 反向代理：

nginx
server {
  listen 80;
  server_name example.com;
  
  location / {
    proxy_pass http://localhost:3000;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
  }
}

负载均衡：

nginx
upstream backend {
  server 10.0.0.1;
  server 10.0.0.2;
}
server {
  location / {
    proxy_pass http://backend;
  }
}

九、Docker 基础 ​

46-50. Docker 基础 ​

问题：Docker 是什么？Dockerfile 如何编写？

答案：

核心概念：

  • 镜像：只读模板
  • 容器：镜像运行实例
  • 仓库：存储镜像

Dockerfile 示例：

dockerfile
FROM node:18
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
EXPOSE 3000
CMD ["node", "app.js"]

常用命令：

bash
docker build -t myapp .
docker run -p 3000:3000 myapp
docker ps
docker logs <container>
