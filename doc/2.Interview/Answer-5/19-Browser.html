Browser 答案 ​

一、浏览器架构 ​

1-3. 浏览器架构 ​

问题：浏览器架构是怎样的？浏览器有哪些进程？

答案：

浏览器进程：

  • 浏览器进程（Browser）：主进程，负责界面显示、用户交互、子进程管理
  • 渲染进程（Renderer）：每个 Tab 一个，负责页面渲染、JS 执行
  • GPU 进程：硬件加速
  • 网络进程：网络请求
  • 插件进程：第三方插件

多进程架构优势：

  • 安全性：一个进程崩溃不影响其他
  • 稳定性：沙箱隔离
  • 性能：并行处理

二、渲染原理 ​

4-9. 浏览器渲染流程 ​

问题：浏览器渲染流程是怎样的？什么是重排和重绘？如何减少？

答案：

渲染流程：

HTML → DOM 树
CSS → CSSOM 树
DOM + CSSOM → 渲染树（Render Tree）
渲染树 → 布局（Layout）
布局 → 绘制（Paint）
绘制 → 合成（Composite）

重排（Reflow）vs 重绘（Repaint）：

维度重排重绘
触发布局变化（尺寸、位置）样式变化（颜色、背景）
开销大小
关系重排必触发重绘重绘不触发重排

减少重排重绘：

  • 批量修改 DOM（使用 DocumentFragment）
  • 使用 CSS3 动画（transform、opacity）
  • 避免频繁读取布局属性
  • 使用 will-change 提示浏览器
javascript
// 批量修改 DOM
const fragment = document.createDocumentFragment()
items.forEach(item => {
  const li = document.createElement('li')
  li.textContent = item
  fragment.appendChild(li)
})
container.appendChild(fragment)

三、事件循环 ​

10-14. 浏览器事件循环 ​

问题：浏览器事件循环是什么？宏任务和微任务有哪些？

答案：

事件循环流程：

执行同步代码 → 清空微任务队列 → 渲染 → 
执行一个宏任务 → 清空微任务队列 → 渲染 → 循环

任务类型：

类型示例
宏任务setTimeout、setInterval、I/O、UI 渲染
微任务Promise.then、MutationObserver、queueMicrotask
javascript
console.log('1') // 同步
setTimeout(() => console.log('2'), 0) // 宏任务
Promise.resolve().then(() => console.log('3')) // 微任务
console.log('4') // 同步
// 输出：1 → 4 → 3 → 2

四、垃圾回收 ​

15-18. 浏览器垃圾回收机制 ​

问题：浏览器垃圾回收机制是什么？什么是内存泄漏？

答案：

垃圾回收算法：

  • 标记清除：标记不可达对象，然后清除
  • 引用计数：记录引用次数，为 0 时回收（循环引用问题）
  • 分代回收（V8）：新生代（Scavenge）+ 老生代（标记清除/标记整理）

内存泄漏常见场景：

  1. 未清除的定时器
  2. 未移除的事件监听器
  3. 闭包引用
  4. DOM 引用
javascript
// 避免内存泄漏
componentWillUnmount() {
  clearInterval(this.timer)
  window.removeEventListener('resize', this.handler)
}

五、浏览器缓存 ​

19-24. 浏览器缓存机制 ​

问题：浏览器缓存机制是什么？强缓存和协商缓存的区别是什么？

答案：

缓存位置（优先级从高到低）：

  1. Service Worker Cache
  2. Memory Cache
  3. Disk Cache
  4. Push Cache

强缓存：Cache-Control（max-age）、Expires协商缓存：ETag/If-None-Match、Last-Modified/If-Modified-Since

问题：什么是同源策略？跨域解决方案有哪些？XSS/CSRF 如何防御？

同源策略：协议、域名、端口相同。

攻击防御

八、性能优化 ​

35-40. 浏览器性能优化 ​

问题：浏览器性能优化有哪些方法？性能指标有哪些？

答案：

核心性能指标（Web Vitals）：

指标说明优秀标准
LCP最大内容绘制≤ 2.5s
FID首次输入延迟≤ 100ms
CLS累积布局偏移≤ 0.1

优化方法：

  • 减少 HTTP 请求
  • 使用 CDN
  • 压缩资源（Gzip）
  • 懒加载图片
  • 使用 async/defer 加载 JS
  • 优化关键渲染路径

十、其他特性 ​

46-52. Service Worker、PWA、Web Workers ​

问题：Service Worker 是什么？PWA 是什么？Web Workers 是什么？

答案：

Service Worker：后台运行的脚本，可实现离线缓存、推送通知。 PWA：渐进式 Web 应用，结合 Service Worker + Manifest。 Web Workers：在后台线程运行 JS，不阻塞主线程。

javascript
// Service Worker 注册
navigator.serviceWorker.register('/sw.js')

// Web Worker 使用
const worker = new Worker('worker.js')
worker.postMessage({ data: 'hello' })
worker.onmessage = (e) => console.log(e.data)
