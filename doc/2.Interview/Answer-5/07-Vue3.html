Vue3 答案 ​

一、Vue3 基础 ​

1. Vue 3 相比 Vue 2 有哪些主要改进？ ​

问题：Vue 3 相比 Vue 2 有哪些主要改进？

答案：

核心定义：Vue 3 是 Vue 的下一代版本，2020 年 9 月正式发布，带来了性能提升、Composition API、更好的 TypeScript 支持等重大改进。

主要改进：

维度Vue 2Vue 3
响应式系统Object.definePropertyProxy
API 风格Options APIComposition API + Options API
性能-快 1.3~2 倍，体积减小 41%
TypeScript支持有限完整支持
新特性-Teleport、Suspense、Fragment
编译优化-静态提升、PatchFlag、Tree-shaking
全局 API挂载在 Vue 构造函数createApp 工厂函数

2. Vue 3.x 有哪些新特性？ ​

问题：Vue 3.x 有哪些新特性？

答案：

  • Composition API：更灵活的逻辑复用方式
  • Teleport：将组件渲染到 DOM 其他位置
  • Suspense：处理异步组件加载状态
  • Fragment：支持多根节点
  • v-model 改进：支持多个 v-model 绑定
  • 响应式系统重构：基于 Proxy
  • 更好的 TypeScript 支持

3. Vue 3 为何引入 Composition API？ ​

问题：Vue 3 为何引入 Composition API？

答案：

问题背景：

  • Options API 在大型组件中导致逻辑分散（数据、方法、计算属性分开定义）
  • 相关功能代码散落在不同选项中，难以维护
  • Mixins 存在命名冲突、来源不清晰的问题

Composition API 优势：

  • ✅ 按功能组织代码，提高可读性
  • ✅ 更好的 TypeScript 类型推导
  • ✅ 更灵活的逻辑复用（Hooks）
  • ✅ 更好的代码压缩

4. Composition API 与 Options API 的区别是什么？ ​

问题：Composition API 与 Options API 的区别是什么？

答案：

对比表格：

维度Options APIComposition API
代码组织按选项类型（data、methods、computed）按功能逻辑组织
this 指向依赖 this不依赖 this
TypeScript类型推导困难原生支持
逻辑复用Mixins（有缺陷）Composables（Hooks）
代码压缩属性名不能压缩变量名可以压缩
学习曲线低稍高

二、Composition API ​

5. setup 函数有什么作用？执行时机是什么？ ​

问题：setup 函数有什么作用？执行时机是什么？

答案：

核心定义：setup 是 Composition API 的入口函数，在 beforeCreate 和 created 之间执行。

特点：

  • 执行时组件实例还未创建，不能使用 this
  • 不能访问 data、methods、computed 等选项
  • 返回对象中的属性会暴露给模板
javascript
export default {
  setup(props, context) {
    // props：响应式的组件属性
    // context：{ attrs, slots, emit }
    
    const count = ref(0)
    const increment = () => count.value++
    
    // 返回的对象会暴露给模板
    return { count, increment }
  }
}

6-7. setup 参数与返回值、<script setup> ​

问题：setup 函数的参数和返回值是什么？<script setup> 语法糖的作用是什么？

答案：

javascript
// 参数
setup(props, { attrs, slots, emit }) {
  // props：响应式对象
  // attrs：非响应式，包含未声明的属性
  // slots：插槽对象
  // emit：触发事件
}

// <script setup> 语法糖（编译时自动转换）
<script setup>
import { ref } from 'vue'

// 顶层绑定自动暴露给模板
const count = ref(0)
const increment = () => count.value++

// props 和 emit
const props = defineProps({ title: String })
const emit = defineEmits(['update'])
</script>

9-14. 响应式 API 详解 ​

问题：toRef/toRefs、shallowRef/shallowReactive、readonly、响应式判断方法等的作用是什么？

答案：

javascript
import { 
  ref, reactive, toRef, toRefs, 
  shallowRef, shallowReactive,
  readonly, shallowReadonly,
  isRef, isReactive, isReadonly, isProxy,
  unref, toRaw, markRaw 
} from 'vue'

// toRef：为对象属性创建 ref
const state = reactive({ count: 0 })
const countRef = toRef(state, 'count')

// toRefs：将响应式对象转为普通对象（值为 ref）
const { count } = toRefs(state)

// shallowRef/shallowReactive：浅层响应式
const shallow = shallowRef({ nested: { value: 1 } })
// 只有 .value 替换时才触发响应

// readonly：只读代理
const readOnly = readonly({ count: 0 })
readOnly.count = 1 // 警告，不会生效

// 响应式判断
isRef(countRef)        // true
isReactive(state)      // true
isReadonly(readOnly)   // true
isProxy(reactive({}))  // true

// unref：获取 ref 的值或原值
const value = unref(maybeRef) // 等价于 isRef(maybeRef) ? maybeRef.value : maybeRef

// markRaw：标记对象为不可转为响应式
const rawObj = markRaw({}) // 不会被 reactive 转换

四、响应式原理 ​

22-27. Vue3 响应式原理与 Proxy ​

问题：Vue3 的响应式原理是什么？与 Vue 2 有何不同？Proxy 的优势是什么？

答案：

核心原理：使用 Proxy 拦截对象的所有操作，实现依赖收集和派发更新。

Proxy vs Object.defineProperty 对比：

维度Object.defineProperty (Vue 2)Proxy (Vue 3)
新增属性需要 Vue.set自动拦截
删除属性需要 Vue.delete自动拦截
数组索引需要重写数组方法原生支持
对象属性递归遍历所有属性惰性代理（访问时才代理）
性能初始化慢初始化快

核心源码解读：

javascript
// 简化的 reactive 实现
function reactive(target) {
  return new Proxy(target, {
    get(target, key, receiver) {
      track(target, key) // 依赖收集
      const res = Reflect.get(target, key, receiver)
      return isObject(res) ? reactive(res) : res
    },
    set(target, key, value, receiver) {
      const result = Reflect.set(target, key, value, receiver)
      trigger(target, key) // 派发更新
      return result
    },
    deleteProperty(target, key) {
      const result = Reflect.deleteProperty(target, key)
      trigger(target, key)
      return result
    }
  })
}

五、新特性 ​

28-32. Teleport、Suspense、Fragment、v-model 变化 ​

问题：Teleport/Suspense 的作用是什么？Fragment 是什么？v-model 有什么变化？

答案：

Teleport：将组件渲染到 DOM 其他位置

javascript
<teleport to="body">
  <div class="modal">模态框内容</div>
</teleport>

Suspense：处理异步组件加载状态

javascript
<Suspense>
  <template #default>
    <AsyncComponent />
  </template>
  <template #fallback>
    <div>Loading...</div>
  </template>
</Suspense>

Fragment：多根节点

javascript
<template>
  <header>...</header>
  <main>...</main>
  <footer>...</footer>
</template>

v-model 变化：支持多个 v-model，默认 prop 改为 modelValue

javascript
// 父组件
<UserName v-model:first-name="first" v-model:last-name="last" />

// 子组件
defineProps(['firstName', 'lastName'])
defineEmits(['update:firstName', 'update:lastName'])

六、性能优化 ​

33-36. Vue3 的性能优化手段 ​

问题：Vue3 的性能优化手段有哪些？编译优化有哪些？

答案：

编译优化：

  • 静态提升（Static Hoisting）：静态节点提升到渲染函数外部
  • PatchFlag：标记动态节点，只比较变化的部分
  • Tree-shaking：按需引入 API，未使用的代码不会打包
  • v-memo：缓存子树
javascript
// v-memo：缓存依赖值不变的子树
<div v-memo="[selectedItem.id]">
  {{ selectedItem.name }}
</div>

八、组合式 API 工具 ​

41-45. watch、watchEffect、provide/inject 等 ​

问题：watch 和 watchEffect 的区别是什么？computed 在 Composition API 中如何使用？

答案：

watch vs watchEffect：

维度watchwatchEffect
依赖追踪手动指定自动收集
懒执行默认懒执行立即执行
访问新旧值支持仅新值
javascript
import { watch, watchEffect, computed, provide, inject } from 'vue'

// watch：监听特定数据源
const count = ref(0)
watch(count, (newVal, oldVal) => {
  console.log(`count changed: ${oldVal} -> ${newVal}`)
})

// watchEffect：自动追踪依赖
watchEffect(() => {
  console.log(`count is: ${count.value}`)
})

// computed
const doubleCount = computed(() => count.value * 2)

// provide/inject
provide('theme', ref('dark'))
const theme = inject('theme')

九、自定义 Hooks ​

46-48. Hooks 实现逻辑复用 ​

问题：Vue3 自定义 Hooks 如何实现？与 Mixins 的区别是什么？

答案：

javascript
// 自定义 Hook：useMouse
import { ref, onMounted, onUnmounted } from 'vue'

export function useMouse() {
  const x = ref(0)
  const y = ref(0)
  
  function update(e) {
    x.value = e.pageX
    y.value = e.pageY
  }
  
  onMounted(() => window.addEventListener('mousemove', update))
  onUnmounted(() => window.removeEventListener('mousemove', update))
  
  return { x, y }
}

// 使用
const { x, y } = useMouse()

Hooks vs Mixins：

  • ✅ Hooks：来源清晰、无命名冲突、类型友好
  • ❌ Mixins：来源不清、命名冲突、类型推导困难

十一、组件通信 ​

53-55. Vue3 组件通信方式 ​

问题：Vue3 中的组件通信方式有哪些？props 能直接解构吗？

答案：

props 不能直接解构，会丢失响应性。需使用 toRefs：

javascript
<script setup>
import { toRefs } from 'vue'

const props = defineProps(['title', 'count'])

// 正确方式：使用 toRefs 保持响应性
const { title, count } = toRefs(props)

// 或使用 withDefaults 设置默认值
const props2 = withDefaults(defineProps<{
  title: string
  count: number
}>(), {
  count: 0
})
</script>
