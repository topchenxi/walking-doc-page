CSS 答案 ​

一、CSS 基础 ​

1. CSS 盒模型是什么？ ​

问题：CSS 盒模型是什么？标准盒模型和 IE 盒模型的区别是什么？

答案：

核心定义：CSS 盒模型是浏览器渲染元素时的矩形区域模型，由内容（content）、内边距（padding）、边框（border）、外边距（margin）组成。

对比表格：

维度标准盒模型 (content-box)IE 盒模型 (border-box)
width 包含仅内容宽度内容 + padding + border
计算方式width + padding + border = 实际宽度width = 实际宽度
推荐度不推荐推荐（更直观）
css
/* 标准盒模型（默认） */
.box { box-sizing: content-box; }

/* IE 盒模型（推荐） */
.box { box-sizing: border-box; }

/* 全局设置 */
*, *::before, *::after { box-sizing: border-box; }

2. 如何通过 CSS 实现盒模型的切换？ ​

问题：如何通过 CSS 实现盒模型的切换？

答案：

通过 box-sizing 属性：

css
/* 标准盒模型 */
box-sizing: content-box;

/* IE 盒模型 */
box-sizing: border-box;

11-13. Flexbox 布局 ​

问题：Flexbox 布局是什么？容器和项目有哪些属性？

答案：

容器属性：

属性说明常用值
flex-direction主轴方向row/column
justify-content主轴对齐flex-start/center/space-between/space-around
align-items交叉轴对齐flex-start/center/stretch
flex-wrap是否换行nowrap/wrap
flex-flowflex-direction + flex-wrap-

项目属性：

css

  flex-grow: 1;   /* 放大比例 */
  flex-shrink: 0; /* 缩小比例 */
  flex-basis: auto; /* 基准大小 */
  align-self: center; /* 单独对齐 */
  order: 1;       /* 排列顺序 */
}

维度FlexboxGrid

适用场景组件级布局页面级布局
内容优先内容驱动布局布局驱动内容

  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: 100px auto;

}

四、经典布局实现 ​

18-19. 水平垂直居中 ​

问题：有哪些水平垂直居中的方法？

答案：

方法汇总：

css
/* 方法 1：Flexbox */
.parent { display: flex; justify-content: center; align-items: center; }

/* 方法 2：Grid */
.parent { display: grid; place-items: center; }

/* 方法 3：绝对定位 + transform */
.child { position: absolute; top: 50%; left: 50%; transform: translate(-50%, -50%); }

/* 方法 4：绝对定位 + margin */
.child { position: absolute; top: 0; left: 0; right: 0; bottom: 0; margin: auto; }

/* 方法 5：table-cell */
.parent { display: table-cell; text-align: center; vertical-align: middle; }

20-23. 圣杯布局与双飞翼布局 ​

问题：什么是圣杯布局？什么是双飞翼布局？

答案：

圣杯布局：三栏布局，中间栏优先渲染，左右固定宽度。

html
<div class="container">
  <div class="main">Main</div>
  <div class="left">Left</div>
  <div class="right">Right</div>
</div>
css
.container { padding: 0 200px; }
.main, .left, .right { float: left; }
.main { width: 100%; }
.left { width: 200px; margin-left: -100%; position: relative; left: -200px; }
.right { width: 200px; margin-left: -200px; }

五、BFC ​

24-28. BFC ​

问题：什么是 BFC？如何触发？应用场景有哪些？

答案：

核心定义：BFC（块级格式化上下文）是一个独立的渲染区域，内部元素的布局不受外部影响。

触发条件：

  1. float 不为 none
  2. position 为 absolute 或 fixed
  3. display 为 inline-block、table-cell、table-caption、flex、grid
  4. overflow 不为 visible

应用场景：

  • 清除浮动
  • 防止 margin 重叠
  • 自适应两栏布局

七、动画与过渡 ​

33-40. CSS 动画 ​

问题：transition 和 animation 的区别是什么？如何实现动画？

答案：

维度transitionanimation
触发方式状态变化触发自动/手动触发
关键帧只有起止可定义多个关键帧
循环不支持支持
css
/* 过渡 */
.box { transition: all 0.3s ease; }

/* 动画 */
@keyframes fadeIn {
  from { opacity: 0; }
  to { opacity: 1; }
}
.box { animation: fadeIn 0.5s ease-in-out; }

十三、CSS 性能优化 ​

55-62. CSS 性能优化 ​

问题：CSS 性能优化有哪些方法？

答案：

优化方案：

  • 避免使用通配符和深层嵌套选择器
  • 使用 transform 和 opacity 代替 left/top 动画
  • 使用 will-change 提示浏览器
  • 精简 CSS，移除未使用的样式
  • 使用 CSS 压缩

选择器性能排序：

ID > 类 > 标签 > 通配符 > 属性 > 伪类 > 伪元素

63-70. 常见问题 ​

问题：如何清除浮动？如何解决 1px 边框问题？

答案：

清除浮动：

css
.clearfix::after {
  content: '';
  display: table;
  clear: both;
}

1px 边框问题（移动端）：

css
.border-1px {
  position: relative;
}

  content: '';
  position: absolute;
  bottom: 0;
  left: 0;
  width: 100%;
  height: 1px;
  background: #ddd;
  transform: scaleY(0.5);
  transform-origin: 0 0;
}
