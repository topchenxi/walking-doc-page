Vue 答案 ​

一、Vue 基础 ​

1. 什么是 Vue.js？它的核心特性有哪些？ ​

问题：什么是 Vue.js？它的核心特性有哪些？

答案：

核心定义：Vue.js 是一套用于构建用户界面的渐进式 JavaScript 框架，由尤雨溪于 2014 年创建。

核心特性：

  • 响应式数据绑定：数据变化自动更新视图
  • 组件化开发：将 UI 拆分为独立可复用的组件
  • 指令系统：v-if、v-for、v-model 等内置指令
  • 模板语法：基于 HTML 的声明式渲染
  • 虚拟 DOM：高效的 DOM 更新机制
  • 生态系统：Vue Router、Vuex/Pinia、Vue CLI/Vite

2. 什么是 MVVM 模式？在 Vue 中如何体现？ ​

问题：什么是 MVVM 模式？在 Vue 中如何体现？

答案：

核心定义：MVVM（Model-View-ViewModel）是一种软件架构模式，通过 ViewModel 实现数据与视图的双向绑定。

Vue 中的体现：

  • Model：Vue 实例的 data 数据
  • View：模板（template）渲染的 DOM
  • ViewModel：Vue 实例，负责监听数据变化并更新视图
javascript
// Model
const data = { message: 'Hello Vue' };

// ViewModel（Vue 实例）
new Vue({
  el: '#app',
  data: data,
  // 自动建立数据与视图的绑定
});

3-4. Vue 是渐进式框架 / 与 jQuery 的区别 ​

问题：为什么说 Vue 是一个渐进式框架？Vue 与 jQuery 的区别是什么？

答案：

渐进式含义：Vue 可以从简单到复杂逐步采用：

  1. 库级别：引入单个文件，作为 jQuery 的替代品
  2. 框架级别：使用完整生态（Router、Vuex）
  3. 工程化：使用 CLI/Vite 构建大型 SPA

Vue vs jQuery 对比：

维度VuejQuery
编程范式声明式命令式
数据驱动数据变化自动更新 DOM手动操作 DOM
组件化原生支持不支持
虚拟 DOM有无
适用场景中大型应用简单页面交互

二、Vue 生命周期 ​

5. Vue 的生命周期钩子有哪些？各阶段作用是什么？ ​

问题：Vue 的生命周期钩子有哪些？各阶段作用是什么？

答案：

生命周期流程图：

beforeCreate → created → beforeMount → mounted → 
beforeUpdate → updated → 
beforeDestroy → destroyed

各阶段说明：

生命周期钩子执行时机典型用途
beforeCreate实例初始化后，数据观测之前无
created实例创建完成，数据已绑定发起 API 请求
beforeMount模板编译完成，挂载前最后一次修改数据
mountedDOM 挂载完成操作 DOM、第三方库初始化
beforeUpdate数据变化，DOM 更新前获取更新前的 DOM 状态
updatedDOM 更新完成操作更新后的 DOM
beforeDestroy实例销毁前清理定时器、事件监听器
destroyed实例已销毁无

7. Vue 父子组件生命周期执行顺序 ​

问题：Vue 父子组件生命周期执行顺序是什么？

答案：

加载渲染过程：

父 beforeCreate → 父 created → 父 beforeMount → 
子 beforeCreate → 子 created → 子 beforeMount → 子 mounted → 
父 mounted

更新过程：

父 beforeUpdate → 子 beforeUpdate → 子 updated → 父 updated

销毁过程：

父 beforeDestroy → 子 beforeDestroy → 子 destroyed → 父 destroyed

9. v-if 和 v-show 的区别是什么？ ​

10. v-for 为什么要绑定 key？key 的最佳实践是什么？ ​

问题：v-for 为什么要绑定 key？key 的最佳实践是什么？

答案：

核心原因：

  • key 是 Vue 虚拟 DOM diff 算法的唯一标识
  • 帮助 Vue 跟踪节点身份，优化渲染性能
  • 避免就地复用导致的渲染错误

最佳实践：

  • ✅ 使用唯一 ID作为 key（如数据库 ID）
  • ✅ 使用 :key="item.id"
  • ❌ 不要使用 index（会导致状态错误）
  • ❌ 不要使用随机数（每次都会重新渲染）
javascript
// ✅ 正确：使用唯一 ID
<li v-for="user in users" :key="user.id">{{ user.name }}</li>

// ❌ 错误：使用 index
<li v-for="(user, index) in users" :key="index">{{ user.name }}</li>

11. v-model 的原理是什么？ ​

问题：v-model 的原理是什么？

答案：

核心定义：v-model 是语法糖，本质是 v-bind:value + v-on:input 的组合。

javascript
// v-model 的等价写法
<input v-model="message">

// 等价于
<input 
  :value="message" 
  @input="message = $event.target.value"
>

// 自定义组件的 v-model
// 父组件
<CustomInput v-model="value" />

// 子组件实现
<template>
  <input 
    :value="value" 
    @input="$emit('input', $event.target.value)"
  />
</template>

四、计算属性与侦听器 ​

12-14. computed 与 watch/methods 的区别 ​

问题：computed 与 watch 的区别是什么？与 methods 的区别是什么？如何实现 setter 和 getter？

答案：

对比表格：

维度computedwatchmethods
返回值必须返回无返回值必须返回
缓存有（依赖不变不重新计算）无无
异步不支持支持支持
适用场景依赖其他数据计算新值数据变化执行副作用事件处理、通用逻辑
javascript
export default {
  data() {
    return {
      firstName: 'John',
      lastName: 'Doe',
      age: 25
    }
  },
  // 计算属性：有缓存
  computed: {
    fullName: {
      get() {
        return `${this.firstName} ${this.lastName}`
      },
      set(value) {
        const [first, last] = value.split(' ')
        this.firstName = first
        this.lastName = last
      }
    }
  },
  // 侦听器：监听变化执行逻辑
  watch: {
    age: {
      handler(newVal, oldVal) {
        console.log(`Age changed from ${oldVal} to ${newVal}`)
      },
      immediate: true,  // 立即执行
      deep: true        // 深度监听
    }
  }
}

五、组件系统 ​

15-17. Vue 组件基础 ​

问题：什么是 Vue 组件？如何创建？data 为什么必须是函数？

答案：

核心定义：组件是可复用的 Vue 实例，封装了模板、逻辑和样式。

data 必须是函数的原因：

  • 每个组件实例需要独立的数据副本
  • 如果 data 是对象，所有实例共享同一数据
  • 函数返回新对象，保证实例间数据隔离
javascript
// 全局组件
Vue.component('my-component', {
  template: '<div>A custom component</div>'
})

// 局部组件（推荐）
export default {
  components: {
    ChildComponent
  },
  // data 必须是函数
  data() {
    return {
      count: 0  // 每个实例独立
    }
  }
}

六、组件通信 ​

18-24. Vue 组件间通信方式 ​

问题：Vue 组件间通信的方式有哪些？父子、兄弟、跨层级组件如何通信？

答案：

组件通信方式汇总：

方式适用场景说明
props / $emit父子组件父传子用 props，子传父用 $emit
$parent / $children父子组件直接访问实例（不推荐）
$refs父访问子获取子组件实例或 DOM
provide / inject跨层级组件祖先提供给后代
$attrs / $listeners跨层级传递传递属性和事件
Event Bus兄弟组件全局事件中心
Vuex / Pinia全局状态集中式状态管理

代码示例：

javascript
// 1. props / $emit
// 父组件
<Child :message="msg" @update="handleUpdate" />

// 子组件
props: ['message'],
methods: {
  update() {
    this.$emit('update', newValue)
  }
}

// 2. provide / inject
// 祖先组件
provide() {
  return { theme: 'dark' }
}

// 后代组件
inject: ['theme']

// 3. $attrs / $listeners
// 中间组件（透传）
<GrandChild v-bind="$attrs" v-on="$listeners" />

七、插槽（Slots） ​

25-27. Vue 插槽的使用 ​

问题：什么是 Vue 的插槽？默认插槽、具名插槽、作用域插槽的区别是什么？

答案：

核心定义：插槽是组件的内容分发机制，允许父组件向子组件传递内容。

javascript
// 子组件
<template>
  <div class="card">
    <!-- 默认插槽 -->
    <slot>默认内容</slot>
    
    <!-- 具名插槽 -->
    <slot name="header"></slot>
    <slot name="footer"></slot>

  </div>

// 父组件使用
<Card>
  <!-- 默认内容 -->
  <p>Card content</p>
  
  <!-- 具名插槽 -->
  <template #header>
    <h2>Title</h2>
  </template>
  
  <!-- 作用域插槽 -->
  <template #default="{ user, count }">
    <span>{{ user.name }} - {{ count }}</span>
  </template>
</Card>

九、Vue Router ​

32-40. Vue Router 核心概念 ​

问题：什么是 Vue Router？路由模式有哪些？路由守卫有哪些类型？如何实现路由懒加载？

答案：

路由模式对比：

模式实现原理URL 格式服务端配置
hashURL hash 变化/#/home不需要
historyHTML5 History API/home需要配置

路由守卫执行顺序：

全局 beforeEach → 路由独享 beforeEnter → 
组件 beforeRouteEnter → 全局 beforeResolve → 
全局 afterEach → 组件 beforeRouteEnter 的 next 回调
javascript
// 路由配置
const router = new VueRouter({
  mode: 'history',
  routes: [
    {
      path: '/home',
      component: () => import('./Home.vue'), // 路由懒加载
      meta: { requiresAuth: true },
      beforeEnter: (to, from, next) => {
        if (isAuthenticated()) next()
        else next('/login')
      }
    }
  ]
})

// 全局前置守卫
router.beforeEach((to, from, next) => {
  if (to.meta.requiresAuth && !isAuthenticated()) {
    next('/login')
  } else {
    next()
  }
})

十、Vuex 状态管理 ​

41-47. Vuex 核心概念 ​

问题：什么是 Vuex？核心概念有哪些？如何在组件中使用？

答案：

核心概念：

  • State：单一状态树
  • Getters：从 state 派生的状态
  • Mutations：同步修改 state
  • Actions：异步操作，提交 mutations
  • Modules：模块化
javascript
const store = new Vuex.Store({
  state: { count: 0 },
  getters: {
    doubleCount: state => state.count * 2
  },
  mutations: {
    increment(state) { state.count++ }
  },
  actions: {
    asyncIncrement({ commit }) {
      setTimeout(() => commit('increment'), 1000)
    }
  }
})

// 组件中使用
export default {
  computed: {
    ...Vuex.mapState(['count']),
    ...Vuex.mapGetters(['doubleCount'])
  },
  methods: {
    ...Vuex.mapMutations(['increment']),
    ...Vuex.mapActions(['asyncIncrement'])
  }
}

十一、Vue 原理 ​

48-57. Vue 响应式原理与虚拟 DOM ​

问题：Vue 的响应式原理是什么？双向数据绑定如何实现？虚拟 DOM 和 diff 算法如何工作？

答案：

Vue 2 响应式原理：

  1. 使用 Object.defineProperty 劫持数据
  2. 依赖收集：访问 getter 时收集 Watcher
  3. 派发更新：触发 setter 时通知 Watcher 更新
javascript
// 简化版响应式实现
function defineReactive(obj, key, val) {
  const dep = new Dep()
  
  Object.defineProperty(obj, key, {
    get() {
      if (Dep.target) dep.addSub(Dep.target)
      return val
    },
    set(newVal) {
      if (newVal !== val) {
        val = newVal
        dep.notify() // 通知所有 Watcher 更新
      }
    }
  })
}

Vue diff 算法核心：

  • 同层比较，不跨级比较
  • 使用 key 优化列表 diff
  • 双端比较算法（Vue 2）

nextTick 原理：

javascript
// 异步更新队列：将 DOM 更新推迟到下一个 tick
Vue.nextTick(() => {
  // DOM 已更新
})
