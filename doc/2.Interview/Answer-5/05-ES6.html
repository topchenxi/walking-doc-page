ES6 答案 ​

一、let/const 与块级作用域 ​

1. let、const、var 的区别是什么？ ​

问题：let、const、var 的区别是什么？

答案：

核心定义：

  • var：ES5 的变量声明方式，具有变量提升，没有块级作用域
  • let：ES6 的块级作用域变量声明，不存在变量提升，有暂时性死区
  • const：ES6 的常量声明，声明时必须初始化，值不可重新赋值

对比表格：

维度varletconst
作用域函数作用域块级作用域块级作用域
变量提升是（值为 undefined）否（暂时性死区）否（暂时性死区）
重复声明允许不允许不允许
重新赋值允许允许不允许
必须初始化否否是
全局对象属性是（全局声明时）否否

代码示例：

javascript
// var：变量提升，无块级作用域
console.log(a); // undefined（变量提升）
var a = 1;

if (true) {
  var b = 2;
}
console.log(b); // 2（没有块级作用域，泄漏到外部）

// let：块级作用域，暂时性死区
if (true) {
  let c = 3;
}
console.log(c); // ReferenceError: c is not defined

// const：不可重新赋值
const d = 4;
d = 5; // TypeError: Assignment to constant variable

// 注意：const 声明的对象，属性可以修改
const obj = { name: 'Alice' };
obj.name = 'Bob'; // ✅ 可以修改属性
obj = {}; // ❌ 不能重新赋值

常见误区：

const 保证的是变量的内存地址不变，而不是值不变。对于引用类型，可以修改其内部属性。

2. 什么是块级作用域？为什么需要块级作用域？ ​

问题：什么是块级作用域？为什么需要块级作用域？

答案：

核心定义：块级作用域是指由 {}（如 if、for、while、switch 语句或代码块）创建的作用域区域。

为什么要引入块级作用域：

  1. 避免变量泄漏：ES5 只有全局作用域和函数作用域，var 声明的变量会泄漏到外层
  2. 防止循环变量泄漏：解决 for 循环中计数器变量泄漏问题
  3. 减少命名冲突：不同代码块可以使用相同变量名

代码示例：

javascript
// ES5：变量泄漏问题
for (var i = 0; i < 5; i++) {
  setTimeout(function() {
    console.log(i); // 全部输出 5
  }, 100);
}

// ES6：使用 let 解决
for (let j = 0; j < 5; j++) {
  setTimeout(function() {
    console.log(j); // 输出 0, 1, 2, 3, 4
  }, 100);
}

3. 什么是暂时性死区（TDZ）？ ​

问题：什么是暂时性死区（TDZ）？

答案：

核心定义：暂时性死区（Temporal Dead Zone）是指在块级作用域内，使用 let/const 声明的变量，从进入作用域到变量声明语句执行完成之间的区域，在此区域访问变量会抛出 ReferenceError。

执行流程：

  1. 进入块级作用域 → TDZ 开始
  2. 变量声明语句执行 → TDZ 结束
  3. 变量可正常访问

代码示例：

javascript
// TDZ 示例
console.log(x); // ReferenceError: Cannot access 'x' before initialization
let x = 10;

// 与 var 的对比
console.log(y); // undefined（var 变量提升）
var y = 20;

// TDZ 与函数参数的关系
function foo(x = x) { // ReferenceError
}
foo();

4. const 本质是什么？const 变量能否修改？ ​

问题：const 本质是什么？const 变量能否修改？

答案：

核心定义：const 声明的是一个只读引用，保证的是变量的内存地址（引用）不可改变。

  • 对于基本类型：值不可修改
  • 对于引用类型：引用不可改变，但对象/数组内部属性可以修改

代码示例：

javascript
// 基本类型不可修改
const num = 42;
num = 100; // TypeError

// 对象的属性可以修改
const obj = { a: 1 };
obj.a = 2;       // ✅ 修改属性
obj.b = 3;       // ✅ 添加属性
delete obj.a;    // ✅ 删除属性
obj = { a: 1 };  // ❌ 重新赋值

// 数组的元素可以修改
const arr = [1, 2, 3];
arr.push(4);     // ✅ 添加元素
arr[0] = 10;     // ✅ 修改元素
arr = [4, 5, 6]; // ❌ 重新赋值

// 真正冻结对象（不可修改属性）
const frozen = Object.freeze({ a: 1 });
frozen.a = 2; // 严格模式下 TypeError，非静默失败

5. const 对象的属性能否修改？ ​

问题：const 对象的属性能否修改？

答案：

可以修改。const 只保证引用地址不变，不保证对象内部属性不变。

javascript
const user = { name: 'Alice', age: 25 };

// ✅ 可以修改属性
user.name = 'Bob';
console.log(user.name); // 'Bob'

// ✅ 可以添加新属性
user.email = 'bob@example.com';

// ✅ 可以删除属性
delete user.age;

// ❌ 不能重新赋值
user = { name: 'Charlie' }; // TypeError

// 如果需要完全冻结对象，使用 Object.freeze()
const locked = Object.freeze({ name: 'Alice' });
locked.name = 'Bob'; // 静默失败或严格模式下报错

二、箭头函数 ​

6. 箭头函数与普通函数的区别是什么？ ​

问题：箭头函数与普通函数的区别是什么？

答案：

对比表格：

维度箭头函数普通函数
this 指向继承外层作用域的 this（词法作用域）取决于调用方式
arguments无，需用 ...rest 替代有 arguments 对象
prototype无有 prototype 属性
new 调用不可作为构造函数可作为构造函数
yield不能用于 Generator可用于 Generator
函数名称匿名函数可以有名称

代码示例：

javascript
// this 指向差异
const obj = {
  name: 'Alice',
  // 普通函数：this 指向调用对象
  regularFn() {
    console.log(this.name); // 'Alice'
  },
  // 箭头函数：this 继承外层（全局或 undefined）
  arrowFn: () => {
    console.log(this.name); // undefined（this 指向全局对象）
  }
};

// 不能使用 new
const Arrow = () => {};
new Arrow(); // TypeError: Arrow is not a constructor

// 没有 arguments
const arrow = (...args) => {
  console.log(args); // [1, 2, 3]
};
arrow(1, 2, 3);

7. 箭头函数的 this 指向是什么？ ​

问题：箭头函数的 this 指向是什么？

答案：

核心规则：箭头函数没有自己的 this，它的 this 继承自定义时所在的外层作用域（词法作用域），且不可改变（call、apply、bind 无效）。

javascript
const obj = {
  name: 'Alice',
  greet() {
    setTimeout(() => {
      // 箭头函数的 this 继承自 greet 方法的 this
      console.log(this.name); // 'Alice'
    }, 100);
  }
};

// 对比：普通函数需要保存 this
const obj2 = {
  name: 'Bob',
  greet() {
    const self = this;
    setTimeout(function() {
      console.log(self.name); // 'Bob'
    }, 100);
  }
};

// call/apply/bind 无法改变箭头函数的 this
const arrowFn = () => console.log(this);
arrowFn.call({ custom: 'obj' }); // 仍输出全局 this

8-11. 箭头函数的特殊限制 ​

问题：箭头函数能否作为构造函数？有 arguments 对象吗？有 prototype 属性吗？使用场景有哪些？

答案：

特性说明
构造函数❌ 不能，没有 [[Construct]] 内部方法
arguments❌ 没有，需用 ...rest 替代
prototype❌ 没有，因为不能作为构造函数

适用场景：

  • ✅ 回调函数（如 setTimeout、Array.prototype.map）
  • ✅ 需要保持外层 this 的场景
  • ✅ 简短的纯函数表达式

不适用场景：

  • ❌ 需要作为构造函数
  • ❌ 需要动态 this 的方法
  • ❌ 需要 arguments 对象
  • ❌ 对象字面量中的方法（除非需要箭头函数的 this 行为）
javascript
// 适用：回调函数保持 this
const counter = {
  count: 0,
  start() {
    setInterval(() => {
      this.count++; // this 指向 counter 对象
    }, 1000);
  }
};

// 不适用：对象方法需要动态 this
const user = {
  name: 'Alice',
  // ❌ this 不指向 user
  getName: () => this.name
};

三、模板字符串 ​

12-14. 模板字符串的特点与标签模板 ​

问题：模板字符串的特点是什么？与普通字符串的区别是什么？什么是标签模板？

答案：

核心定义：模板字符串使用反引号 ` 包裹，支持变量插值和多行字符串。

对比表格：

维度普通字符串模板字符串
引号' 或 "反引号 `
变量插值需要拼接${expression}
多行需要 \n 或 +直接换行
标签模板不支持支持

代码示例：

javascript
// 变量插值
const name = 'Alice';
const age = 25;
console.log(`My name is ${name}, I am ${age} years old.`);

// 多行字符串
const html = `
  <div class="container">
    <h1>${name}</h1>
    <p>Age: ${age}</p>
  </div>
`;

// 表达式求值
console.log(`2 + 3 = ${2 + 3}`); // 2 + 3 = 5

// 标签模板（Tagged Template）
function tag(strings, ...values) {
  console.log(strings);  // ['Hello ', ' world ', '!']
  console.log(values);   // ['Alice', 25]
  return strings.reduce((result, str, i) => {
    return result + str + (values[i] || '');
  }, '');
}

const result = tag`Hello ${name} world ${age}!`;
// result: 'Hello Alice world 25!'

// 实际应用：HTML 转义标签模板
function safeHtml(strings, ...values) {
  return strings.reduce((result, str, i) => {
    const value = String(values[i] || '');
    const escaped = value.replace(/&/g, '&amp;')
                         .replace(/</g, '&lt;')
                         .replace(/>/g, '&gt;');
    return result + str + escaped;
  }, '');
}

四、解构赋值 ​

15-20. 解构赋值的语法与应用 ​

问题：数组解构赋值的语法是什么？对象解构赋值的语法是什么？默认值如何设置？函数参数解构如何使用？应用场景有哪些？成功条件是什么？

答案：

核心定义：解构赋值允许按照一定模式，从数组或对象中提取值，对变量进行赋值。

数组解构：

javascript
// 基本语法
const [a, b, c] = [1, 2, 3];
console.log(a, b, c); // 1 2 3

// 跳过元素
const [, , third] = [1, 2, 3];
console.log(third); // 3

// 默认值
const [x = 10, y = 20] = [1];
console.log(x, y); // 1 20

// 剩余元素
const [first, ...rest] = [1, 2, 3, 4];
console.log(rest); // [2, 3, 4]

// 交换变量
let m = 1, n = 2;
[m, n] = [n, m];
console.log(m, n); // 2 1

对象解构：

javascript
// 基本语法
const { name, age } = { name: 'Alice', age: 25 };

// 重命名变量
const { name: userName, age: userAge } = { name: 'Alice', age: 25 };
console.log(userName, userAge); // Alice 25

// 默认值
const { x = 1, y = 2 } = { x: 10 };
console.log(x, y); // 10 2

// 嵌套解构
const user = {
  name: 'Alice',
  address: { city: 'Beijing', zip: '100000' }
};
const { address: { city, zip } } = user;
console.log(city, zip); // Beijing 100000

函数参数解构：

javascript
// 对象参数解构
function greet({ name, age = 18 }) {
  console.log(`Hello ${name}, age ${age}`);
}
greet({ name: 'Alice' }); // Hello Alice, age 18

// 数组参数解构
function sum([a, b]) {
  return a + b;
}
console.log(sum([1, 2])); // 3

// 完整参数解构（带默认值）
function ajax({
  url = '/',
  method = 'GET',
  data = {},
  headers = {}
} = {}) {
  console.log(`${method} ${url}`);
}
ajax(); // GET /
ajax({ url: '/api/users', method: 'POST' }); // POST /api/users

成功条件：解构赋值成功的条件是等号右边的值可以转为对象（即不是 null 或 undefined）。

javascript
// 失败情况
const { a } = null;        // TypeError
const [b] = undefined;     // TypeError
const { c } = 42;          // c 为 undefined（数字转为 Number 对象，没有 c 属性）

五、默认参数与剩余参数 ​

21-24. 默认参数、Rest 参数与扩展运算符 ​

问题：函数默认参数如何定义？Rest 参数的语法和应用是什么？与 arguments 的区别是什么？扩展运算符的应用场景有哪些？

答案：

默认参数：

javascript
function greet(name = 'Guest', message = 'Hello') {
  console.log(`${message}, ${name}!`);
}

greet();              // Hello, Guest!
greet('Alice');       // Hello, Alice!
greet('Alice', 'Hi'); // Hi, Alice!

// 默认值可以是表达式
function rand(max = Math.random() * 100) {
  return max;
}

Rest 参数 vs arguments：

维度Rest 参数 (...args)arguments
类型真正的数组类数组对象
包含内容仅未被命名的参数所有实参
箭头函数可用不可用
数组方法可直接使用需转换后使用
javascript
// Rest 参数
function sum(...numbers) {
  return numbers.reduce((total, n) => total + n, 0);
}
console.log(sum(1, 2, 3, 4)); // 10

// 与普通参数组合
function multi(first, ...rest) {
  console.log('first:', first); // first: 1
  console.log('rest:', rest);   // rest: [2, 3, 4]
}
multi(1, 2, 3, 4);

扩展运算符（Spread）：

javascript
// 数组展开
const arr1 = [1, 2];
const arr2 = [3, 4];
const combined = [...arr1, ...arr2]; // [1, 2, 3, 4]

// 对象展开
const defaults = { theme: 'light', fontSize: 14 };
const userPrefs = { fontSize: 16 };
const config = { ...defaults, ...userPrefs }; // { theme: 'light', fontSize: 16 }

// 数组拷贝（浅拷贝）
const original = [1, 2, 3];
const copy = [...original];

// 将类数组转为数组
function toArray(...args) {
  return args;
}

// 字符串转数组
const chars = [...'hello']; // ['h', 'e', 'l', 'l', 'o']

六、Symbol 与迭代器 ​

25-28. Symbol 的特点与用途 ​

问题：Symbol 的特点是什么？用途有哪些？作为属性名有什么特点？内置 Symbol 值有哪些？

答案：

核心定义：Symbol 是 ES6 引入的第七种原始数据类型，表示独一无二的值。

特点：

  • 每次调用 Symbol() 都返回唯一值
  • 不能使用 new 调用
  • 可以传入描述字符串（仅用于调试）
  • 作为对象属性名时，不会出现在 for...in、Object.keys() 中
javascript
// 创建 Symbol
const s1 = Symbol('id');
const s2 = Symbol('id');
console.log(s1 === s2); // false（即使描述相同也不相等）

// 作为对象属性名
const obj = {
  [Symbol('key')]: 'value',
  [s1]: 'unique'
};

// 不会被常规方法遍历到
console.log(Object.keys(obj));  // []
console.log(JSON.stringify(obj)); // {}

// 获取 Symbol 属性
console.log(Object.getOwnPropertySymbols(obj)); // [Symbol(key), Symbol(id)]

// Symbol.for 全局共享
const globalSym1 = Symbol.for('app.id');
const globalSym2 = Symbol.for('app.id');
console.log(globalSym1 === globalSym2); // true

// 内置 Symbol
const arr = [1, 2, 3];
console.log(arr[Symbol.iterator]); // 迭代器函数

// Symbol.hasInstance：定制 instanceof 行为
class MyArray {
  static [Symbol.hasInstance](instance) {
    return Array.isArray(instance);
  }
}
console.log([] instanceof MyArray); // true

// Symbol.toPrimitive：定制类型转换
const obj2 = {
  [Symbol.toPrimitive](hint) {
    if (hint === 'number') return 42;
    if (hint === 'string') return 'hello';
    return 'default';
  }
};
console.log(+obj2);    // 42
console.log(`${obj2}`); // hello

29-33. 迭代器与可迭代对象 ​

问题：什么是迭代器？什么是可迭代对象？迭代协议是什么？for...of 与 for...in 的区别是什么？如何自定义迭代器？

答案：

核心定义：

  • 迭代器（Iterator）：一个具有 next() 方法的对象，每次调用返回 { value, done }
  • 可迭代对象（Iterable）：具有 [Symbol.iterator] 方法的对象

对比表格：

维度for...offor...in
遍历对象可迭代对象的值对象的所有可枚举属性（包括原型链）
遍历数组元素值索引（字符串）
遍历对象不支持普通对象键名
Symbol 属性不包含不包含
原型链不包含包含
javascript
// 内置可迭代对象：Array、Map、Set、String、TypedArray、arguments

// for...of 遍历数组
const arr = ['a', 'b', 'c'];
for (const item of arr) {
  console.log(item); // 'a', 'b', 'c'
}

// for...in 遍历对象
const obj = { a: 1, b: 2, c: 3 };
for (const key in obj) {
  console.log(key); // 'a', 'b', 'c'
}

// 自定义迭代器
const myIterable = {
  data: [1, 2, 3],
  [Symbol.iterator]() {
    let index = 0;
    return {
      next: () => {
        if (index < this.data.length) {
          return { value: this.data[index++], done: false };
        }
        return { value: undefined, done: true };
      }
    };
  }
};

for (const value of myIterable) {
  console.log(value); // 1, 2, 3
}

// Generator 作为迭代器
function* gen() {
  yield 1;
  yield 2;
  yield 3;
}

for (const n of gen()) {
  console.log(n); // 1, 2, 3
}

七、Generator 函数 ​

34-39. Generator 函数的特点与应用 ​

问题：Generator 函数的特点是什么？yield 的作用是什么？与 Iterator 的关系是什么？在异步编程中的应用是什么？

答案：

核心定义：Generator 函数是 ES6 提供的异步编程解决方案，通过 function* 定义，内部使用 yield 表达式暂停执行。

特点：

  • 调用后返回迭代器对象，不会立即执行
  • yield 暂停执行，next() 恢复执行
  • next() 可传入值作为上一个 yield 的返回值
javascript
// 基本用法
function* gen() {
  console.log('start');
  const a = yield 1;
  console.log('a =', a);
  const b = yield 2;
  console.log('b =', b);
  return 'done';
}

const it = gen();

  yield 1;
  yield 2;
}
function* genB() {
  yield* genA();
  yield 3;
}
console.log([...genB()]); // [1, 2, 3]

function fetchApi(url) {
  return new Promise(resolve => {
    setTimeout(() => resolve({ data: `Data from ${url}` }), 1000);
  });
}

function* asyncGen() {
  const result1 = yield fetchApi('/api/1');
  console.log(result1);
  const result2 = yield fetchApi('/api/2');
  console.log(result2);
}

// 自动执行 Generator
function run(genFn) {
  const gen = genFn();
  function step(nextResult) {
    const result = gen.next(nextResult);
    if (result.done) return result.value;
    return Promise.resolve(result.value).then(step);
  }
  return step();
}

十、Promise ​

53-60. Promise 的状态、链式调用与错误处理 ​

问题：Promise 是什么？有几种状态？Promise.all/race/allSettled/any 的作用是什么？链式调用如何实现？错误处理如何进行？

答案：

核心定义：Promise 是异步编程的一种解决方案，有三种状态：pending（进行中）、fulfilled（已成功）、rejected（已失败）。状态一旦改变就不会再变。

状态特点：

  • 只能从 pending → fulfilled 或 pending → rejected
  • 状态改变后不会再次改变
  • then 返回新的 Promise，支持链式调用
javascript
// 基本用法
const promise = new Promise((resolve, reject) => {
  setTimeout(() => {
    const success = true;
    if (success) {
      resolve('Success!');
    } else {
      reject(new Error('Failed!'));
    }
  }, 1000);
});

promise
  .then(result => {
    console.log(result); // 'Success!'
    return result + ' processed';
  })
  .then(result => {
    console.log(result); // 'Success! processed'
  })
  .catch(error => {
    console.error(error);
  })
  .finally(() => {
    console.log('Always executed');
  });

Promise 方法对比：

方法触发条件返回值
Promise.all全部成功所有结果的数组
Promise.all任一失败第一个失败的原因
Promise.race任一完成第一个完成的结果
Promise.allSettled全部完成所有状态和值的数组
Promise.any任一成功第一个成功的结果
Promise.any全部失败AggregateError

93-99. Proxy 与 Reflect 的用法 ​

答案：

核心定义：

  • Proxy：用于定义基本操作的自定义行为（拦截器）
  • Reflect：提供与 Proxy 拦截操作对应的方法，使操作更规范

可拦截操作：get、set、has、deleteProperty、ownKeys、getOwnPropertyDescriptor、defineProperty、preventExtensions、getPrototypeOf、setPrototypeOf、isExtensible、apply、construct

javascript
// Proxy 基本用法
const target = { name: 'Alice', age: 25 };
const proxy = new Proxy(target, {
  get(obj, prop) {
    console.log(`Getting ${prop}`);
    return prop in obj ? obj[prop] : undefined;
  },
  set(obj, prop, value) {
    console.log(`Setting ${prop} = ${value}`);
    obj[prop] = value;
    return true; // 必须返回 true 表示成功
  }
});

proxy.name;         // Getting name → 'Alice'
proxy.name = 'Bob'; // Setting name = Bob

// 实现负索引数组
function createArray(...elements) {
  const handler = {
    get(target, prop) {
      const index = Number(prop);
      if (index < 0) {
        prop = String(target.length + index);
      }
      return target[prop];
    }
  };
  const arr = [...elements];
  return new Proxy(arr, handler);
}

const arr = createArray('a', 'b', 'c');
console.log(arr[-1]); // 'c'

// Reflect 与 Proxy 配合
const obj = { a: 1 };
const p = new Proxy(obj, {
  get(target, prop, receiver) {
    console.log(`Accessing ${prop}`);
    return Reflect.get(target, prop, receiver);
  },
  set(target, prop, value, receiver) {
    console.log(`Setting ${prop} to ${value}`);
    return Reflect.set(target, prop, value, receiver);
  }
});

// Vue 3 响应式原理核心
function reactive(target) {
  return new Proxy(target, {
    get(target, key) {
      // 依赖收集
      track(target, key);
      return Reflect.get(target, key);
    },
    set(target, key, value) {
      const result = Reflect.set(target, key, value);
      // 派发更新
      trigger(target, key);
      return result;
    }
  });
}

  if (n <= 1) return acc;

console.log(yRegex.exec(text)); // ['aaa']，但下次从索引 3 开始
console.log(yRegex.exec(text)); // null（索引 3 是 '_'）

// sticky 属性
const regex3 = /hello/y;
console.log(regex3.sticky); // true

// flags 属性
const regex4 = /hello/giy;
console.log(regex4.flags); // 'giy'

javascript
// 装饰器是一种函数，用于修改类或类的属性
// 目前处于 Stage 3 提案阶段，Babel 可支持

// 类装饰器
function sealed(constructor) {
  Object.seal(constructor);
  Object.seal(constructor.prototype);
}

@sealed
class Person {
  constructor(name) {
    this.name = name;
  }
}

// 方法装饰器
function readonly(target, key, descriptor) {
  descriptor.writable = false;
  return descriptor;
}

class Car {
  @readonly
  start() {
    console.log('Car started');
  }
}
