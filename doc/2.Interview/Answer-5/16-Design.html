一、设计模式基础 ​

1. 什么是设计模式？设计模式有哪些分类？ ​

问题：什么是设计模式？设计模式有哪些分类？

答案：

核心定义：设计模式是解决特定问题的可复用解决方案，是经验的总结。

分类：

  • 创建型：单例、工厂、建造者、原型
  • 结构型：代理、适配器、装饰器、外观、组合
  • 行为型：观察者、发布订阅、策略、模板方法、责任链

2. 单例模式是什么？如何实现？ ​

问题：单例模式是什么？如何实现？应用场景有哪些？

答案：

核心定义：保证一个类只有一个实例，并提供全局访问点。

javascript
// ES6 实现
class Singleton {
  static instance = null
  constructor(name) {
    if (Singleton.instance) return Singleton.instance
    this.name = name
    Singleton.instance = this
  }
}

// 应用：全局状态管理、日志器、数据库连接池

4-5. 观察者模式与发布订阅模式 ​

问题：观察者模式是什么？发布订阅模式是什么？与观察者模式的区别是什么？

答案：

区别：

  • 观察者模式：目标直接通知观察者（紧密耦合）
  • 发布订阅模式：通过事件中心解耦（订阅者互不知道）
javascript
// 发布订阅模式实现
class EventEmitter {
  constructor() { this.events = {} }
  on(event, callback) {
    (this.events[event] ||= []).push(callback)
  }
  emit(event, ...args) {
    (this.events[event] || []).forEach(cb => cb(...args))
  }
  off(event, callback) {
    this.events[event] = (this.events[event] || []).filter(cb => cb !== callback)
  }
}

二、前端架构设计 ​

12. MVC、MVP、MVVM 的区别是什么？ ​

问题：MVC、MVP、MVVM 的区别是什么？

答案：

模式数据流向View 与 Model
MVC单向View 可直接访问 Model
MVP单向View 与 Model 通过 Presenter 交互
MVVM双向ViewModel 自动同步 View 和 Model

三、设计原则 ​

18-22. SOLID 原则 ​

问题：单一职责原则、开闭原则、里氏替换原则是什么？

答案：

原则说明
单一职责一个类只做一件事
开闭原则对扩展开放，对修改关闭
里氏替换子类可替换父类
接口隔离接口尽量细化
依赖倒置依赖抽象，不依赖具体实现

五、性能优化 ​

27-32. 前端性能优化策略 ​

问题：前端性能优化有哪些策略？首屏优化有哪些方法？

答案：

优化维度：

维度方法
网络CDN、HTTP/2、Gzip、资源合并

  1. 路由懒加载
  2. 组件按需加载
  3. 骨架屏
  4. SSR/SSG
  5. 关键 CSS 内联

攻击类型原理防御

七、微前端架构 ​

37-43. 微前端 ​

问题：什么是微前端？实现方案有哪些？

答案：

核心定义：将大型前端应用拆分为多个可独立开发、部署的小应用。

实现方案：

  • iframe：简单但体验差
  • qiankun：基于 single-spa
  • Module Federation：Webpack 5 原生支持
  • Web Components：原生组件化

隔离方案：

  • 样式隔离：Shadow DOM、CSS 作用域
  • JS 隔离：Proxy、沙箱
