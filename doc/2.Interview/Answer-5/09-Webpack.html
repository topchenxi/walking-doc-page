Webpack 答案 ​

一、核心概念 ​

1. Webpack 的核心概念有哪些？ ​

问题：Webpack 的核心概念有哪些？（Entry、Output、Loader、Plugin）

答案：

四大核心概念：

概念说明
Entry（入口）指示 Webpack 从哪个文件开始构建依赖图
Output（输出）指示 Webpack 在哪里输出 bundles 以及如何命名
Loader（加载器）让 Webpack 能够处理非 JavaScript 文件（如 CSS、图片）
Plugin（插件）执行更广泛的任务，如打包优化、环境变量注入
javascript
const HtmlWebpackPlugin = require('html-webpack-plugin')

module.exports = {
  entry: './src/index.js',
  output: {
    path: path.resolve(__dirname, 'dist'),
    filename: 'bundle.js'
  },
  module: {
    rules: [
      { test: /\.css$/, use: ['style-loader', 'css-loader'] },
      { test: /\.js$/, use: 'babel-loader', exclude: /node_modules/ }
    ]
  },
  plugins: [
    new HtmlWebpackPlugin({ template: './src/index.html' })
  ]
}

2-3. Entry 与 Output 配置 ​

问题：Entry 入口文件的作用是什么？Output 输出文件如何配置？

答案：

javascript
// Entry 多种配置方式
module.exports = {
  // 单入口
  entry: './src/index.js',
  
  // 多入口
  entry: {
    app: './src/app.js',
    vendor: './src/vendor.js'
  }
}

// Output 配置
module.exports = {
  output: {
    path: path.resolve(__dirname, 'dist'),
    filename: '[name].[contenthash].js', // 多入口时
    clean: true, // Webpack 5：清理 dist 目录
    publicPath: '/' // 静态资源公共路径
  }
}

4-6. Loader 与 Plugin ​

问题：Loader 是什么？Plugin 是什么？Loader 与 Plugin 的区别是什么？

答案：

对比表格：

维度LoaderPlugin
作用转换文件类型执行更广泛的任务
处理阶段模块加载时整个构建生命周期
功能文件转换（TS→JS、SCSS→CSS）打包优化、环境变量、HTML 生成
配置方式module.rulesplugins 数组

二、模块打包原理 ​

7-10. Webpack 打包原理与构建流程 ​

问题：Webpack 打包原理是什么？构建流程是怎样的？Chunk、Bundle、Module 的区别是什么？

答案：

构建流程：

1. 初始化参数 → 2. 开始编译 → 3. 确定入口 → 4. 编译模块
→ 5. 完成编译 → 6. 输出资源 → 7. 输出完成

核心概念区别：

概念说明
Module（模块）代码库中的每个文件（JS、CSS、图片等）
Chunk（代码块）多个模块合并后的产物
Bundle（打包产物）最终输出的文件

三、代码分割与懒加载 ​

11-15. 代码分割与懒加载 ​

问题：什么是代码分割？如何实现？懒加载如何实现？SplitChunksPlugin 如何配置？

答案：

代码分割方式：

  1. 入口起点：使用多个 entry
  2. 动态导入：import() 语法
  3. SplitChunksPlugin：提取公共代码
javascript
// 动态导入（懒加载）
button.addEventListener('click', () => {
  import('./module.js').then(module => {
    module.default()
  })
})

// SplitChunksPlugin 配置
module.exports = {
  optimization: {
    splitChunks: {
      chunks: 'all',
      cacheGroups: {
        vendor: {
          test: /[\\/]node_modules[\\/]/,
          name: 'vendors',
          chunks: 'all'
        }
      }
    }
  }
}

// 魔法注释
import(/* webpackChunkName: "lodash" */ 'lodash')

四、Tree Shaking ​

16-19. Tree Shaking 原理与条件 ​

问题：什么是 Tree Shaking？原理是什么？条件是什么？

答案：

核心定义：Tree Shaking 是一种通过静态分析移除未使用代码的优化技术。

条件：

  • ✅ 使用 ES6 模块语法（import/export）
  • ✅ 设置 mode: 'production'
  • ✅ 配置 sideEffects: false 或在 package.json 中标记
javascript
// webpack.config.js
module.exports = {
  mode: 'production',
  optimization: {
    usedExports: true,
    minimize: true
  }
}

// package.json
{
  "sideEffects": ["*.css", "*.scss"]
}

五、热模块替换（HMR） ​

20-23. HMR 原理与配置 ​

问题：什么是热模块替换？原理是什么？webpack-dev-server 如何配置？

答案：

核心原理：

  1. webpack-dev-server 创建 WebSocket 连接
  2. 文件变化时，Webpack 重新编译
  3. 通过 WebSocket 通知浏览器
  4. 浏览器请求新的模块热更新补丁
  5. 运行时替换模块，不刷新页面
javascript
// webpack.config.js
module.exports = {
  devServer: {
    hot: true,
    open: true,
    port: 3000,
    proxy: {
      '/api': 'http://localhost:8080'
    }
  },
  plugins: [
    new webpack.HotModuleReplacementPlugin()
  ]
}

六、性能优化 ​

24-32. Webpack 性能优化 ​

问题：Webpack 性能优化有哪些方法？如何优化构建速度和体积？

答案：

构建速度优化：

方法说明
缓存cache: { type: 'filesystem' }（Webpack 5）
多线程thread-loader
减少解析范围module.rules.exclude
DLLDllPlugin 预编译第三方库
热更新HMR 替代全量刷新

构建体积优化：

方法说明
Tree Shaking移除未使用代码
代码分割SplitChunksPlugin
压缩TerserPlugin、CSSNano
图片压缩image-webpack-loader
外部扩展externals 排除 CDN 资源
GzipCompressionWebpackPlugin
javascript
// 外部扩展
module.exports = {
  externals: {
    react: 'React',
    'react-dom': 'ReactDOM'
  }
}

// Gzip 压缩
const CompressionPlugin = require('compression-webpack-plugin')
plugins: [
  new CompressionPlugin({
    algorithm: 'gzip',
    test: /\.(js|css)$/
  })
]

八、常用 Loader ​

36-41. 常用 Loader 配置 ​

问题：babel-loader 如何使用？css-loader 和 style-loader 的区别是什么？

答案：

javascript
module: {
  rules: [
    // JS 转译
    { test: /\.js$/, use: 'babel-loader', exclude: /node_modules/ },
    
    // CSS 处理（从右到左执行）
    { test: /\.css$/, use: ['style-loader', 'css-loader'] },
    
    // Sass 处理
    { test: /\.scss$/, use: ['style-loader', 'css-loader', 'sass-loader'] },
    
    // 图片处理
    { test: /\.(png|jpg|gif)$/, type: 'asset/resource' }, // Webpack 5
    { test: /\.svg$/, type: 'asset/inline' },
    
    // TypeScript
    { test: /\.ts$/, use: 'ts-loader' }
  ]
}

九、常用 Plugin ​

42-47. 常用 Plugin ​

问题：HtmlWebpackPlugin、CleanWebpackPlugin、CopyWebpackPlugin 的作用是什么？

答案：

Plugin作用
HtmlWebpackPlugin自动生成 HTML 并注入 bundle
CleanWebpackPlugin清理 dist 目录
CopyWebpackPlugin复制静态资源到 dist
MiniCssExtractPlugin提取 CSS 到单独文件
ProvidePlugin自动加载模块（如 jQuery）
BundleAnalyzerPlugin分析 bundle 体积

十、Webpack 5 新特性 ​

48-51. Webpack 5 新特性 ​

问题：Webpack 5 有哪些新特性？模块联邦是什么？

答案：

新特性：

  • 模块联邦（Module Federation）：多个 Webpack 构建之间共享代码
  • 持久化缓存：cache: { type: 'filesystem' }
  • Asset Modules：替代 file-loader/url-loader
  • 更好的 Tree Shaking
  • SplitChunks 优化
javascript
// Module Federation
new ModuleFederationPlugin({
  name: 'app1',
  remotes: { app2: 'app2@http://localhost:3002/remoteEntry.js' },
  shared: ['react', 'react-dom']
})
