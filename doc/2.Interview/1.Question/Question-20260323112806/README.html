主要去重类型 ​

  1. 完全重复：题目文字完全一致，保留一份
  2. 语义相似：表达不同但考查点相同，合并答案要点
  3. 包含关系：一个题目是另一个的子集，保留最完整版本

六、使用建议 ​

  1. 系统学习：按文件顺序逐个知识点学习
  2. 重点突破：优先学习标记为"高频考点"的题目
  3. 查漏补缺：使用索引快速定位薄弱知识点
  4. 面试冲刺：重点复习高频考点速查部分
