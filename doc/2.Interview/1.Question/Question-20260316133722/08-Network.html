网络面试题目 ​

一、HTTP 基础 ​

  1. HTTP 协议是什么？
  2. HTTP 请求报文和响应报文的结构是什么？起始行、头部、消息体的作用是什么？
  3. HTTP 有哪些请求方法？
  4. GET 与 POST 的区别是什么？
  5. PUT、DELETE、PATCH 的作用是什么？
  6. OPTIONS、HEAD、CONNECT、TRACE 方法的作用是什么？
  7. 什么是幂等性？哪些方法是幂等的？什么是安全方法？

二、HTTP 状态码 ​

  1. HTTP 状态码分为哪几类？
  2. 200 OK、201 Created、204 No Content 表示什么？
  3. 301 Moved Permanently、302 Found、304 Not Modified 表示什么？
  4. 400 Bad Request、401 Unauthorized、403 Forbidden、404 Not Found 表示什么？
  5. 500 Internal Server Error、502 Bad Gateway、503 Service Unavailable 表示什么？

三、HTTP 头部 ​

  1. 常见的请求头和响应头有哪些？
  2. Content-Type、Cache-Control、ETag、Last-Modified、Expires 的作用是什么？
  3. Cookie、Set-Cookie、Authorization、Referer、User-Agent 的作用是什么？
  4. Accept、Accept-Encoding、Accept-Language 的作用是什么？
  5. Connection、Keep-Alive 的作用是什么？

四、HTTPS 与安全 ​

  1. HTTPS 与 HTTP 的区别是什么？
  2. SSL/TLS 是什么？HTTPS 的工作原理是什么？
  3. 对称加密与非对称加密的区别是什么？
  4. 数字证书是什么？CA 机构是什么？
  5. 什么是中间人攻击？如何防范？
  6. 什么是公钥基础设施（PKI）？
  7. HSTS 是什么？

五、HTTP/2 与 HTTP/3 ​

  1. HTTP/2 有哪些新特性？多路复用、服务器推送、头部压缩是什么？
  2. HTTP/3 有哪些新特性？QUIC 协议是什么？
  3. HTTP/2 与 HTTP/1.1 的区别是什么？
  4. HTTP/3 与 HTTP/2 的区别是什么？

六、缓存机制 ​

  1. 浏览器缓存机制是什么？
  2. 强缓存与协商缓存的区别是什么？
  3. Cache-Control 的常用指令有哪些？max-age、no-cache、no-store、must-revalidate 的作用是什么？
  4. private 与 public 的区别是什么？
  5. ETag 是如何生成的？If-None-Match、If-Modified-Since 的作用是什么？
  6. 缓存位置有哪些？Service Worker 如何实现缓存？

七、跨域问题 ​

  1. 什么是同源策略？什么是跨域？
  2. CORS 是什么？简单请求与预检请求的区别是什么？
  3. Access-Control-Allow-Origin、Access-Control-Allow-Methods、Access-Control-Allow-Headers、Access-Control-Allow-Credentials 的作用是什么？
  4. 跨域解决方案有哪些？
  5. JSONP 的原理是什么？
  6. postMessage 如何使用？
  7. document.domain、window.name、location.hash 的应用场景是什么？
  8. 代理服务器如何解决跨域？Nginx、Node.js 如何配置代理？

八、WebSocket ​

  1. WebSocket 是什么？与 HTTP 的区别是什么？
  2. WebSocket 的连接过程是什么？
  3. WebSocket.readyState 有哪些值？
  4. WebSocket.send()、WebSocket.onmessage 如何使用？
  5. 心跳机制是什么？断线重连如何实现？
  6. Socket.IO 是什么？

九、TCP/IP ​

  1. OSI 七层模型是什么？TCP/IP 四层模型是什么？
  2. TCP 三次握手、四次挥手是什么？为什么需要三次握手和四次挥手？
  3. TIME_WAIT 状态是什么？SYN Flood 攻击是什么？
  4. UDP 与 TCP 的区别是什么？

十、其他网络概念 ​

  1. DNS 解析过程是什么？
  2. CDN 是什么？
  3. 负载均衡是什么？
  4. 反向代理与正向代理是什么？
  5. RESTful API 是什么？
  6. GraphQL 是什么？
  7. RPC、gRPC、SOAP 是什么？
  8. JWT、OAuth、SAML、OpenID Connect、SSO 是什么？
