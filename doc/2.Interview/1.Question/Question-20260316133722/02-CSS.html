CSS 面试题目 ​

一、CSS 基础 ​

  1. CSS 是什么？有什么作用？
  2. CSS 有哪些选择器？选择器的优先级如何计算？
  3. 什么是盒模型？标准盒模型与 IE 盒模型的区别是什么？
  4. box-sizing 属性有哪些值？各自的作用是什么？
  5. 如何实现元素水平垂直居中？（至少 5 种方法）
  6. 行内元素的 margin、padding 设置是否有效？
  7. 什么是外边距合并？如何避免？
  8. display 属性有哪些常见值？

二、定位与布局 ​

  1. position 属性有哪些值？各自的特点是什么？
  2. absolute 和 relative 的定位参照物是什么？
  3. fixed 和 absolute 的区别是什么？
  4. z-index 的作用是什么？什么情况下会失效？
  5. 什么是 BFC？触发条件有哪些？应用场景有哪些？
  6. 什么是层叠上下文？
  7. 如何实现三栏布局？（左右固定，中间自适应）
  8. Flex 布局有哪些常用属性？Flex:1 代表什么含义？
  9. Grid 布局有哪些常用属性？
  10. 圣杯布局与双飞翼布局的区别是什么？

三、响应式设计 ​

  1. 媒体查询（Media Query）是什么？如何使用？
  2. rem、em、px、vh、vw 的区别是什么？
  3. 如何实现移动端适配？
  4. 什么是视口（viewport）？
  5. 如何处理 Retina 屏幕的 1px 边框问题？
  6. 常见的移动端布局方案有哪些？

四、CSS3 新特性 ​

  1. CSS3 有哪些新特性？
  2. 什么是过渡（transition）？
  3. 什么是动画（animation）？
  4. transform 属性有哪些常用函数？
  5. 如何实现渐变效果？
  6. 什么是伪类和伪元素？
  7. ::before 和::after 伪元素的作用是什么？
  8. nth-child() 和 nth-of-type() 的区别是什么？

五、性能优化 ​

  1. CSS 性能优化有哪些策略？
  2. 什么是回流（reflow）和重绘（repaint）？哪些操作会导致重绘和回流？如何减少？
  3. 如何优化 CSS 选择器性能？为什么要避免使用通配符选择器？

六、预处理器 ​

  1. CSS 预处理器是什么？有什么优势？
  2. Sass/Less 有哪些常用功能？变量、嵌套、混合、继承的作用是什么？

七、CSS 工程化 ​

  1. 什么是 CSS 模块化？CSS Modules 的原理是什么？
  2. 如何解决 CSS 全局污染问题？
  3. 什么是 Critical CSS？如何提取 Critical CSS？
  4. link 与@import 的区别是什么？
  5. CSS 加载会阻塞 DOM 渲染吗？
  6. 什么是 FOUC（Flash of Unstyled Content）？如何避免？

八、CSS 技巧与概念 ​

  1. 什么是雪碧图？有什么优缺点？
  2. 如何清除浮动？（至少 3 种方法）
  3. visibility:hidden、display:none、opacity:0 的区别是什么？
  4. 如何实现一个三角形？
  5. 如何实现一个圆形？
  6. 流式布局、弹性布局、响应式布局的区别是什么？
  7. 什么是移动优先设计？
  8. 什么是渐进增强和优雅降级？
  9. 如何理解 CSS 的层叠性？什么是继承？哪些属性可以继承？
  10. 如何重置 CSS 样式？normalize.css 与 reset.css 的区别是什么？
  11. 什么是原子化 CSS？
