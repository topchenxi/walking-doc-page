一、基础语法与数据类型 ​

1. JavaScript 数据类型有哪些？ ​

问题：JavaScript 数据类型有哪些？（简单类型与复合类型）

答案：

核心定义 ​

JavaScript 数据类型分为原始类型（Primitive）和对象类型（Object）两大类。

数据类型分类 ​

原始类型（7种）：

  1. undefined - 变量已声明但未赋值
  2. null - 空值，表示"无"的对象
  3. boolean - 布尔值：true / false
  4. number - 数值（包括整数和浮点数，IEEE 754 双精度）
  5. string - 字符串（Unicode 字符序列）
  6. symbol - 唯一标识符（ES6 新增）
  7. bigint - 大整数（ES2020 新增）

对象类型：

  • object - 包括普通对象、数组、正则表达式、日期等
  • function - 函数（typeof 返回 "function"，但本质是对象）

检测示例 ​

javascript
// 原始类型
typeof undefined;     // "undefined"
typeof null;          // "object" (历史遗留 bug)
typeof true;          // "boolean"
typeof 42;            // "number"
typeof "hello";       // "string"
typeof Symbol();      // "symbol"
typeof 10n;           // "bigint"

// 对象类型
typeof {};            // "object"
typeof [];            // "object"
typeof function(){};  // "function"

// 精确检测 null
Object.prototype.toString.call(null);  // "[object Null]"

常见误区 ​

  • typeof null === "object" 是 JavaScript 的历史 bug，不能用于检测 null
  • 函数 typeof 返回 "function"，但函数本质上是可调用对象
  • 数组 typeof 返回 "object"，需要用 Array.isArray() 检测

2. 值类型与引用类型的区别是什么？ ​

问题：值类型与引用类型的区别是什么？

答案：

对比表格 ​

维度值类型（原始类型）引用类型（对象）
存储位置栈内存堆内存（栈中存引用地址）
赋值方式复制值本身复制引用地址
比较方式比较值比较引用地址
不可变性不可变（创建后不能修改）可变（可以添加/修改属性）
类型string, number, boolean, null, undefined, symbol, bigintobject, array, function
内存释放自动管理垃圾回收

代码示例 ​

javascript
// 值类型：赋值是值的拷贝
let a = 10;
let b = a;
b = 20;
console.log(a); // 10 - a 不受影响

// 引用类型：赋值是引用地址的拷贝
let obj1 = { name: "Alice" };
let obj2 = obj1;
obj2.name = "Bob";
console.log(obj1.name); // "Bob" - obj1 也被修改了

// 比较方式
let x = 10, y = 10;
console.log(x === y); // true - 值比较

let o1 = { a: 1 }, o2 = { a: 1 };
console.log(o1 === o2); // false - 引用地址不同
console.log(o1 === o1); // true - 同一引用

3. JavaScript 数据类型检测方法有哪些？ ​

问题：JavaScript 数据类型检测方法有哪些？

答案：

四种主要方法 ​

方法适用场景局限
typeof检测原始类型（除 null）typeof null === "object"
instanceof检测引用类型不能检测原始类型，跨 iframe 失效
Object.prototype.toString.call()所有类型最精确的方法
Array.isArray()专门检测数组仅适用于数组

示例 ​

javascript
// 1. typeof
typeof 42;          // "number"
typeof "hello";     // "string"
typeof true;        // "boolean"
typeof undefined;   // "undefined"
typeof null;        // "object" ❌
typeof {};          // "object"
typeof [];          // "object" ❌

// 2. instanceof
[] instanceof Array;        // true
{} instanceof Object;       // true
function(){} instanceof Function; // true

// 3. Object.prototype.toString（最精确）
Object.prototype.toString.call(42);          // "[object Number]"
Object.prototype.toString.call("hello");     // "[object String]"
Object.prototype.toString.call(null);        // "[object Null]"
Object.prototype.toString.call([]);          // "[object Array]"
Object.prototype.toString.call(/regex/);     // "[object RegExp]"
Object.prototype.toString.call(new Date());  // "[object Date]"

// 4. 封装通用检测函数
function getType(value) {
  return Object.prototype.toString.call(value)
    .slice(8, -1).toLowerCase();
}
getType([]);       // "array"
getType(null);     // "null"
getType(Promise.resolve()); // "promise"

5. typeof 与 instanceof 的区别及适用场景 ​

问题：typeof 与 instanceof 的区别及适用场景

答案：

对比表格 ​

维度typeofinstanceof
返回值字符串（类型名）布尔值
检测范围原始类型 + object/function引用类型
原理检查变量的类型标签检查原型链
null 检测返回 "object"（错误）返回 false
跨窗口可用不可用（不同窗口的构造函数不同）
适用场景快速检测原始类型检测对象是否是某构造函数的实例

代码示例 ​

javascript
// typeof 适合检测原始类型
if (typeof value === "string") { ... }
if (typeof value === "number") { ... }
if (typeof value === "boolean") { ... }
if (typeof value === "undefined") { ... }
if (typeof value === "function") { ... }

// instanceof 适合检测对象类型
if (value instanceof Array) { ... }
if (value instanceof Date) { ... }
if (value instanceof RegExp) { ... }

// 结合使用实现完整类型检测
function detectType(value) {
  if (value === null) return "null";
  if (typeof value !== "object") return typeof value;
  // 处理对象类型
  if (value instanceof Array) return "array";
  if (value instanceof Date) return "date";
  if (value instanceof RegExp) return "regexp";
  return "object";
}

7. JavaScript 隐式类型转换的规则 ​

问题：JavaScript 隐式类型转换的规则

答案：

转换规则 ​

  1. 加法运算（+）：如果任一操作数是字符串或 Symbol，执行字符串拼接；否则都转数字
  2. 减法、乘法、除法（-, *, /）：都转数字
  3. 比较运算（<, >, <=, >=）：字符串按字典序比较，其他转数字
  4. 相等比较（==）：复杂的类型转换规则
  5. 逻辑运算（&&, ||, !）：转为布尔值
  6. 条件语句（if, while）：转为布尔值

经典面试题 ​

javascript
// 字符串拼接优先
1 + "2";           // "12"
1 + 2 + "3";       // "33" (从左到右: 3 + "3")
"1" + 2 + 3;       // "123"
1 + 2 + 3 + "4";   // "64"

// 减法转数字
"5" - 3;           // 2
"5" - "3";         // 2

// 复杂表达式
[] + [];           // "" ([] → "" + "" = "")
[] + {};           // "[object Object]"
{} + [];           // 0 (在语句上下文中，{} 是空块)
{} + {};           // "[object Object][object Object]"

// 相等比较
"0" == false;      // true (false → 0, "0" → 0)
0 == false;        // true (false → 0)
"" == 0;           // true ("" → 0)
null == undefined; // true (特殊规则)
null == 0;         // false (null 只和 undefined 相等)

问题：null 和 undefined 的区别是什么？如何判断？

答案：

对比表格 ​

维度undefinednull
含义变量已声明但未赋值空值，表示"无"的对象
类型typeof → "undefined"typeof → "object"
出现场景未初始化变量、函数无返回值、对象属性不存在主动赋空值、DOM 元素不存在
转换数字NaN0
转换字符串"undefined""null"
转换布尔falsefalse

代码示例 ​

javascript
// undefined 出现的场景
let a;
console.log(a);  // undefined

function fn() {}
console.log(fn());  // undefined

const obj = {};
console.log(obj.name);  // undefined

// null 需要主动赋值
let b = null;  // 表示有意设为空值

// 判断方法
value === undefined;       // 严格检测 undefined
value === null;            // 严格检测 null
value == null;             // 同时检测 null 和 undefined
value ?? defaultValue;     // nullish 合并运算符

最佳实践 ​

javascript
// 判断是否为空值（null 或 undefined）
if (value == null) {
  // 等价于 value === null || value === undefined
}

// 使用空值合并运算符
const result = value ?? "default";  // null 或 undefined 时取默认值

// 与 || 的区别
null || "default";     // "default"
undefined || "default"; // "default"
0 || "default";        // "default" - 0 被当作 falsy
0 ?? "default";        // 0 - 0 不是 null/undefined

10. == 和 === 的区别及使用场景 ​

问题：== 和 === 的区别及使用场景

答案：

对比表格 ​

维度==（宽松相等）===（严格相等）
比较方式先类型转换再比较类型不同直接返回 false
性能较慢（需要类型转换）较快
安全性容易产生意外结果安全可靠
推荐度不推荐★★★★★

代码示例 ​

javascript
// == 类型转换
1 == "1";          // true - "1" 转为 1
0 == false;        // true - false 转为 0
"" == 0;           // true - "" 转为 0
null == undefined; // true - 特殊规则
"0" == false;      // true - 都转为 0

// === 严格比较
1 === "1";         // false - 类型不同
0 === false;       // false - 类型不同
"" === 0;          // false - 类型不同
null === undefined; // false - 类型不同

// NaN 特殊规则
NaN == NaN;        // false
NaN === NaN;       // false
Object.is(NaN, NaN); // true

// +0 和 -0
+0 === -0;         // true
Object.is(+0, -0); // false

使用建议 ​

javascript
// ✅ 推荐：始终使用 ===
if (value === undefined) { ... }
if (value === null) { ... }

// ✅ 特例：检测 null 或 undefined
if (value == null) { ... }  // 等价于 value === null || value === undefined

// ❌ 避免：使用 ==
if (value == 0) { ... }     // 可能产生意外结果

11. NaN 是什么？如何检测？ ​

问题：NaN 是什么？如何检测？isNaN() 的作用及实现原理

答案：

核心定义 ​

NaN（Not-a-Number）是 number 类型的特殊值，表示"不是一个有效数字"。

特点 ​

  • typeof NaN === "number" - NaN 是 number 类型
  • NaN !== NaN - NaN 不等于任何值，包括自身
  • 任何涉及 NaN 的运算结果都是 NaN

检测方法 ​

javascript
// 方法一：全局 isNaN（有缺陷）
isNaN("abc");        // true ❌ - "abc" 先转成 NaN
isNaN(NaN);          // true
isNaN("123");        // false - "123" 转成 123

// 方法二：Number.isNaN（推荐，ES6）
Number.isNaN("abc"); // false ✅
Number.isNaN(NaN);   // true

// 方法三：自实现
function isNaN(value) {
  return typeof value === "number" && value !== value;
}

// 方法四：Object.is
Object.is(value, NaN);  // true 仅当 value 是 NaN

产生 NaN 的常见场景 ​

javascript
0 / 0;              // NaN
Math.sqrt(-1);      // NaN
parseInt("abc");    // NaN
Number("abc");      // NaN
"abc" - 1;          // NaN
NaN + 1;            // NaN

14. 什么是作用域和作用域链？ ​

问题：什么是作用域和作用域链？

答案：

核心定义 ​

  • 作用域：变量可访问的范围
  • 作用域链：当查找变量时，从当前作用域向外层作用域逐级查找的链式结构

工作原理 ​

javascript
let global = "global";

function outer() {
  let outerVar = "outer";
  
  function inner() {
    let innerVar = "inner";
    console.log(innerVar);  // 1. 在当前作用域找到
    console.log(outerVar);  // 2. 沿着作用域链找到 outer
    console.log(global);    // 3. 继续沿着链找到 global
  }
  
  inner();
}

outer();

作用域链图示 ​

inner 作用域
  ├── innerVar
  ├── outerVar (来自 outer)
  └── global (来自全局)
       ↑
outer 作用域
  ├── outerVar
  └── global (来自全局)
       ↑
全局作用域
  └── global

15. 什么是变量提升（Hoisting）？ ​

问题：什么是变量提升（Hoisting）？请举例说明

答案：

核心定义 ​

变量提升是指 JavaScript 在执行代码前，会将变量声明和函数声明"提升"到作用域顶部的行为。

提升规则 ​

声明方式提升什么初始值
var声明提升undefined
let/const声明提升（但不可访问，TDZ）不可访问
function声明 + 定义都提升完整函数
函数表达式变量声明提升undefined

代码示例 ​

javascript
// var 提升
console.log(a);  // undefined - 声明提升但未赋值
var a = 10;
// 等价于：
// var a;
// console.log(a);
// a = 10;

// let/const 提升（TDZ - 暂时性死区）
console.log(b);  // ReferenceError
let b = 20;

// function 提升
fn();  // "hello" - 函数声明整体提升
function fn() {

18. let 与 const 作用域差异 ​

问题：let 与 const 作用域差异

答案：

核心区别 ​

let 和 const 作用域完全相同，都是块级作用域。区别在于可变性：

  • let：可重新赋值
  • const：不可重新赋值（但引用类型的内容可修改）
javascript
// 相同：块级作用域
{
  let a = 1;
  const b = 2;
}
// a 和 b 都不可访问

// 不同：可变性
let x = 1;
x = 2;      // ✅

const y = 1;
y = 2;      // ❌ TypeError

// const 引用类型
const arr = [1, 2, 3];
arr.push(4);    // ✅ 修改内容
arr = [5, 6];   // ❌ 重新赋值

19. 块级作用域是什么？为什么需要块级作用域？ ​

问题：块级作用域是什么？为什么需要块级作用域？

答案：

核心定义 ​

块级作用域是由 {} 包裹的代码块内有效的变量作用域，由 let 和 const 创建。

为什么需要块级作用域 ​

  1. 避免变量泄露：var 会泄露到外部作用域
  2. 避免循环变量冲突：let 每次迭代创建独立绑定
  3. 减少全局污染：临时变量不会污染外层
  4. 符合编程直觉：多数语言都有块级作用域

代码示例 ​

javascript
// 问题：var 没有块级作用域
{
  var temp = "temporary";
}
console.log(temp);  // "temporary" - 变量泄露

// 解决：let 有块级作用域
{
  let temp = "temporary";
}
console.log(temp);  // ReferenceError

// 循环变量隔离
for (let i = 0; i < 5; i++) {
  // 每次迭代 i 都是新的绑定
}
// i 不可访问

20. 暂时性死区（TDZ）是什么？ ​

问题：暂时性死区（TDZ）是什么？

答案：

核心定义 ​

暂时性死区（Temporal Dead Zone, TDZ） 是指从进入作用域到变量声明之间的区域，在此期间变量不可访问。

原理 ​

javascript
// TDZ 示例
console.log(a);  // ReferenceError - a 在 TDZ 中
let a = 10;
console.log(a);  // 10 - TDZ 结束

// 对比 var
console.log(b);  // undefined - var 提升且初始化为 undefined
var b = 20;

TDZ 范围 ​

进入块作用域
    ↓
[ TDZ 开始 ]  ← 变量不可访问
    ↓
let/const 声明  ← TDZ 结束
    ↓
变量可访问

常见 TDZ 场景 ​

javascript
// 函数参数默认值
let x = 1;
function fn(y = x) {  // 读取参数默认值时
  let x = 2;  // TDZ - 这里声明的 x 与默认值中的 x 冲突
}
fn();  // ReferenceError

// typeof 在 TDZ 中也报错
typeof undeclared;  // "undefined" - 安全
typeof tdz;         // ReferenceError
let tdz;

24. 箭头函数与普通函数的区别 ​

问题：箭头函数与普通函数的区别

答案：

对比表格 ​

维度普通函数箭头函数
this 绑定动态（调用时确定）静态（定义时继承外层）
arguments有无
new 调用可以不可以
prototype有无
yield不可用于 Generator不可
名称有函数名匿名（可推断 name）

代码示例 ​

javascript
// this 差异
const obj = {
  name: "Alice",
  regular: function() {
    console.log(this.name);  // "Alice"
  },
  arrow: () => {
    console.log(this.name);  // undefined - this 指向外层
  }
};

obj.regular();  // "Alice"
obj.arrow();    // undefined

// 不能作为构造函数
const Fn = () => {};
new Fn();  // TypeError: Fn is not a constructor

// 没有 arguments
function regular() {
  console.log(arguments);  // [1, 2, 3]
}
regular(1, 2, 3);

const arrow = () => {
  console.log(arguments);  // ReferenceError
};
arrow(1, 2, 3);

// 替代：使用 rest 参数
const arrow2 = (...args) => {
  console.log(args);  // [1, 2, 3]
};

使用建议 ​

  • 适合用箭头函数：回调函数、数组方法、简短函数
  • 不能用箭头函数：对象方法、构造函数、事件处理器、需要动态 this 的场景
