2. 如何查看和修改文件权限？ ​

问题：如何查看和修改文件权限？

答案：

权限表示 ​

-rwxr-xr--  1 user group  4096 Jan 1 12:00 script.sh
 ^  ^  ^  ^
 |  |  |  └── 其他用户权限 (r-- = 4)
 |  |  └── 组权限 (r-x = 5)
 |  └── 所有者权限 (rwx = 7)
 └── 文件类型 (- 文件, d 目录, l 链接)

权限值 ​

权限数值说明
r4读
w2写
x1执行
bash
# 查看权限
ls -la

# 修改权限（数字方式）
chmod 755 script.sh  # rwxr-xr-x
chmod 644 file.txt   # rw-r--r--

# 修改权限（符号方式）
chmod +x script.sh   # 添加执行权限
chmod u+w file.txt   # 所有者添加写权限
chmod -R 755 dir/    # 递归修改

二、进程与服务 ​

3. 如何查看和管理进程？ ​

问题：如何查看和管理进程？

答案：

常用命令 ​

bash
# 查看进程
ps aux                  # 查看所有进程
ps aux | grep node      # 查找 node 进程
top                     # 实时查看进程

# 查找端口占用
lsof -i :3000           # 查看 3000 端口占用
netstat -tlnp | grep 3000

# 终止进程
kill <PID>              # 正常终止
kill -9 <PID>           # 强制终止
killall node            # 终止所有 node 进程
pkill -f "npm start"    # 按名称终止

# 后台运行
nohup npm start &       # 后台运行，不挂断
npm start > log.txt 2>&1 &  # 重定向输出到文件

4. 如何在 Linux 上部署前端项目？ ​

问题：如何在 Linux 上部署前端项目？

答案：

部署流程 ​

bash
# 1. 安装 Node.js
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt-get install -y nodejs

# 2. 克隆项目
git clone https://github.com/user/project.git
cd project

# 3. 安装依赖并构建
npm install
npm run build

# 4. 配置 Nginx
sudo vim /etc/nginx/sites-available/default

# Nginx 配置示例
server {
    listen 80;
    server_name example.com;
    
    root /var/www/project/dist;
    index index.html;
    
    # SPA 路由支持
    location / {
        try_files $uri $uri/ /index.html;
    }
    
    # 静态资源缓存
    location ~* \.(js|css|png|jpg|svg)$ {
        expires 30d;
        add_header Cache-Control "public, immutable";
    }
}

# 5. 重启 Nginx
sudo nginx -t              # 测试配置
sudo systemctl restart nginx

三、Shell 脚本 ​

5. 如何编写简单的 Shell 脚本？ ​

问题：如何编写简单的 Shell 脚本？

答案：

脚本结构 ​

bash
#!/bin/bash

# 变量
APP_NAME="my-app"
DEPLOY_DIR="/var/www/$APP_NAME"

# 函数
deploy() {
  echo "开始部署 $APP_NAME..."
  cd $DEPLOY_DIR
  git pull origin main
  npm install --production
  npm run build
  echo "部署完成!"
}

# 条件判断
if [ -d "$DEPLOY_DIR" ]; then
  deploy
else
  echo "目录 $DEPLOY_DIR 不存在"
  exit 1
fi

# 循环
for i in {1..5}; do
  echo "第 $i 次"
done

执行 ​

bash
chmod +x deploy.sh
./deploy.sh

6. 常用的 Shell 脚本操作有哪些？ ​

问题：常用的 Shell 脚本操作有哪些？

答案：

常用操作 ​

bash
# 变量
NAME="world"
echo "Hello $NAME"

# 条件判断
if [ -f "file.txt" ]; then
  echo "文件存在"
elif [ -d "dir" ]; then
  echo "目录存在"
else
  echo "不存在"
fi

# 循环
for file in *.js; do
  echo "处理 $file"
done

# 读取文件
while read line; do
  echo "$line"
done < input.txt

# 函数
greet() {
  echo "Hello, $1!"
}
greet "World"

# 参数处理
echo "脚本名: $0"
echo "参数1: $1"
echo "所有参数: $@"
echo "参数个数: $#"

问题：如何压缩和解压文件？

常用压缩命令 ​

格式压缩解压
