NodeJS 答案 ​

一、NodeJS 基础 ​

1. 什么是 Node.js？有什么特点？ ​

问题：什么是 Node.js？有什么特点？

答案：

核心定义 ​

Node.js 是一个基于 Chrome V8 引擎的 JavaScript 运行时环境，让 JavaScript 可以在服务端运行。

特点 ​

  • 事件驱动：基于事件循环处理异步操作
  • 非阻塞 I/O：I/O 操作不会阻塞主线程
  • 单线程：主线程单线程，但底层使用线程池处理 I/O
  • 轻量高效：适合高并发 I/O 密集型应用
  • npm 生态：拥有世界上最大的包管理器

适用场景 ​

  • 适合：API 服务、实时应用、微服务、工具脚本、SSR
  • 不适合：CPU 密集型计算（视频编码、图像处理）

二、事件循环 ​

3. Node.js 事件循环的六个阶段是什么？ ​

问题：Node.js 事件循环的六个阶段是什么？

答案：

事件循环阶段 ​

   ┌───────────────────────────┐
┌─>│           timers          │  setTimeout/setInterval 回调
│  └─────────────┬─────────────┘
│  ┌─────────────┴─────────────┐
│  │     pending callbacks     │  系统操作回调（如 TCP 错误）
│  └─────────────┬─────────────┘
│  ┌─────────────┴─────────────┐
│  │       idle, prepare       │  内部使用
│  └─────────────┬─────────────┘
│  ┌─────────────┴─────────────┐
│  │           poll            │  I/O 回调，最重要的阶段
│  └─────────────┬─────────────┘
│  ┌─────────────┴─────────────┐
│  │           check           │  setImmediate 回调
│  └─────────────┬─────────────┘
│  ┌─────────────┴─────────────┐
└──│      close callbacks      │  close 事件回调
   └───────────────────────────┘

与浏览器事件循环对比 ​

维度浏览器Node.js
宏任务setTimeout、setInterval、MessageChanneltimers、poll、check 等阶段
微任务Promise.then、MutationObserverprocess.nextTick、Promise.then
优先级微任务 > 宏任务nextTick > 微任务 > 宏任务

4. setImmediate 与 setTimeout 的区别是什么？ ​

问题：setImmediate 与 setTimeout 的区别是什么？

答案：

对比 ​

维度setTimeout(fn, 0)setImmediate(fn)
阶段timers 阶段check 阶段
执行时机timers 阶段执行poll 阶段之后执行
确定性不确定（受系统负载影响）更确定（poll 后立即执行）

代码示例 ​

javascript
// 在主模块中执行顺序不确定
setTimeout(() => console.log('timeout'), 0);
setImmediate(() => console.log('immediate'));
// 可能输出 timeout 或 immediate

// 在 I/O 回调中，setImmediate 一定先执行
require('fs').readFile(__filename, () => {
  setTimeout(() => console.log('timeout'), 0);
  setImmediate(() => console.log('immediate'));
});
// 总是输出 immediate → timeout

语法require/module.exportsimport/export

值的拷贝值的拷贝（缓存）值的引用（live binding）

// ES Module
import fs from 'fs';
export const name = 'test';

7. 什么是流（Stream）？有哪些类型？ ​

问题：什么是流（Stream）？有哪些类型？

答案：

核心定义 ​

流是处理数据的抽象接口，允许你分段读取或写入数据，而不是一次性加载全部内容到内存。

四种类型 ​

类型说明示例
Readable可读流fs.createReadStream()
Writable可写流fs.createWriteStream()
Duplex双工流（可读可写）net.Socket
Transform转换流（读写时转换数据）zlib.createGzip()

代码示例 ​

javascript
const fs = require('fs');

// 流式读取大文件（节省内存）
const readStream = fs.createReadStream('./large-file.txt', {
  encoding: 'utf8',
  highWaterMark: 64 * 1024  // 64KB 缓冲
});

readStream.on('data', (chunk) => {
  console.log('收到数据块:', chunk.length);
});

readStream.on('end', () => {
  console.log('读取完成');
});

// 管道：可读流 → 可写流
const readStream = fs.createReadStream('./input.txt');
const writeStream = fs.createWriteStream('./output.txt');
readStream.pipe(writeStream);

五、进程管理 ​

8. process.nextTick 与 setImmediate 的区别是什么？ ​

问题：process.nextTick 与 setImmediate 的区别是什么？

答案：

对比 ​

维度process.nextTicksetImmediate
执行时机当前阶段结束后立即执行下一个 check 阶段执行
优先级最高（优于 Promise）较低
性能滥用会导致 I/O 饿死更安全
javascript
// 执行优先级：nextTick > Promise.then > setImmediate
process.nextTick(() => console.log('nextTick'));
Promise.resolve().then(() => console.log('Promise'));
setImmediate(() => console.log('setImmediate'));
// 输出：nextTick → Promise → setImmediate

Node.js 面试重点考查：事件循环机制、异步编程、流处理、进程管理、模块系统。理解事件循环的执行顺序是核心考点。
