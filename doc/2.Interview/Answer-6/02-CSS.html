一、CSS 选择器与优先级 ​

1. CSS 选择器有哪些类型及具体语法和使用案例？ ​

问题：CSS 选择器有哪些类型及具体语法和使用案例？（至少 6 种）

答案：

核心定义 ​

CSS 选择器是用于"选择" HTML 文档中需要设置样式的元素的模式。

常见选择器类型 ​

选择器类型语法示例说明
元素选择器elementp { color: red; }选择所有 <p> 元素
类选择器.classname.active { font-weight: bold; }选择所有 class="active" 的元素
ID 选择器#idname#header { background: #333; }选择 id="header" 的唯一元素
属性选择器[attr] / [attr=value]input[type="text"] { border: 1px solid; }选择具有指定属性的元素
伪类选择器:pseudo-classa:hover { color: blue; }选择元素的特定状态
伪元素选择器::pseudo-elementp::first-line { font-size: 2em; }选择元素的特定部分
后代选择器A Bdiv p { margin: 10px; }选择 A 内部所有 B 元素
子元素选择器A > Bul > li { list-style: none; }选择 A 的直接子元素 B
相邻兄弟选择器A + Bh1 + p { text-indent: 2em; }选择紧接在 A 后的 B
通用兄弟选择器A ~ Bh1 ~ p { color: gray; }选择 A 之后所有同级 B

使用案例 ​

css
/* 组合选择器示例 */
.container > .item:first-child {
  /* 选择 .container 的第一个直接子元素 .item */
  margin-top: 0;
}

/* 属性选择器 - 模糊匹配 */
a[href^="https"] {
  /* 选择 href 以 https 开头的链接 */
  color: green;
}

a[href$=".pdf"] {
  /* 选择 href 以 .pdf 结尾的链接 */
  background-image: url(pdf-icon.png);
}

/* 伪类组合 */
li:nth-child(odd) {
  /* 选择奇数位置的 li 元素 */
  background-color: #f5f5f5;
}

li:nth-child(3n+1) {
  /* 每隔3个元素选择第一个 */
  font-weight: bold;
}

常见误区 ​

  • ID 选择器优先级过高，不利于样式复用和维护
  • 过度嵌套选择器 会降低性能，建议不超过 3 层
  • 伪类用单冒号 :，伪元素用双冒号 ::（CSS3 规范）

2. CSS 选择器有哪些？优先级如何计算？ ​

问题：CSS 选择器有哪些？优先级如何计算？

答案：

优先级计算规则 ​

优先级（Specificity）是一个四位数 (a, b, c, d)：

级别含义示例
a内联样式style="..." → (1, 0, 0, 0)
bID 选择器数量#id → (0, 1, 0, 0)
c类、属性、伪类数量.class, [attr], :hover → (0, 0, 1, 0)
d元素、伪元素数量div, ::before → (0, 0, 0, 1)

计算示例 ​

css
/* (0, 0, 0, 1) - 1个元素 */
p { color: red; }

/* (0, 0, 1, 0) - 1个类 */
.text { color: blue; }

/* (0, 1, 0, 1) - 1个ID + 1个元素 */
#main p { color: green; }

/* (0, 1, 2, 1) - 1个ID + 2个类 + 1个元素 */
#main .content p.intro { color: orange; }

/* (0, 0, 3, 0) - 3个类 */
.box.card.active { color: purple; }

优先级规则 ​

  1. !important > 内联样式 > ID > 类/属性/伪类 > 元素 > 通配符
  2. 优先级相同时，后定义的样式覆盖先定义的
  3. 继承的样式优先级低于任何显式声明的样式
  4. !important 会打破正常优先级，应谨慎使用

3. CSS 选择器优先级计算规则 ​

问题：CSS 选择器优先级计算规则（!important > ID > 类/属性/伪类 > 元素 > 通配符）

答案：

完整优先级排序 ​

!important (最高)
  ↓
内联样式 style=""
  ↓
ID 选择器 (#id)
  ↓
类选择器 (.class)、属性选择器 ([attr])、伪类 (:hover)
  ↓
元素选择器 (div)、伪元素 (::before)
  ↓
通配符选择器 (*)
  ↓
继承 (最低)

关键要点 ​

  • !important：强制应用样式，但会破坏可维护性，应尽量避免
  • 相同优先级：后定义的覆盖先定义的（源顺序）
  • 通配符 * 优先级为 0，但会选中所有元素
  • 继承无优先级值，任何显式声明都会覆盖继承值

4. 哪些 CSS 属性可以继承？ ​

问题：哪些 CSS 属性可以继承？（至少 5 个）

答案：

可继承属性 ​

可继承属性主要是文本相关的属性：

属性说明
color文字颜色
font-family字体族
font-size字体大小
line-height行高
text-align文本对齐方式
visibility可见性
cursor鼠标指针样式
letter-spacing字间距
word-spacing词间距
text-transform文本转换

不可继承属性 ​

主要是盒模型、定位、布局相关属性：

  • margin, padding, border
  • width, height
  • position, top, left
  • display, overflow
  • background 系列属性

强制继承 ​

任何属性都可以使用 inherit 值强制继承：

css
/* 强制 border 继承父元素 */
.child {
  border: inherit;
}

二、盒模型与布局 ​

5. CSS 盒模型是什么？它包含哪些部分？ ​

问题：CSS 盒模型是什么？它包含哪些部分？

答案：

核心定义 ​

CSS 盒模型（Box Model）是 CSS 布局的基石，将每个 HTML 元素视为一个矩形的盒子。

组成部分（从内到外） ​

  1. Content（内容区）：元素实际内容，由 width 和 height 定义
  2. Padding（内边距）：内容与边框之间的透明区域
  3. Border（边框）：围绕 padding 和 content 的边框
  4. Margin（外边距）：边框与其他元素之间的透明区域
+---------- Margin ----------+
|  +------- Border -------+  |
|  |  +---- Padding ----+  |  |
|  |  |   Content       |  |  |
|  |  |   (width×height)|  |  |
|  |  +-----------------+  |  |
|  +-----------------------+  |
+-----------------------------+

6. W3C 标准盒模型的组成部分是什么？ ​

问题：W3C 标准盒模型的组成部分是什么？

答案：

W3C 标准盒模型（content-box） ​

在标准盒模型中，width 和 height 仅指 content 区域：

实际宽度 = width + padding-left + padding-right + border-left + border-right
实际高度 = height + padding-top + padding-bottom + border-top + border-bottom
css
/* 标准盒模型（默认） */
.box {
  box-sizing: content-box;
  width: 200px;
  padding: 20px;
  border: 5px solid black;
}
/* 实际宽度 = 200 + 20*2 + 5*2 = 250px */

7. Border-box 与 content-box 的区别是什么？ ​

问题：Border-box 与 content-box 的区别是什么？

答案：

对比表格 ​

维度content-box（标准盒模型）border-box（IE 盒模型）
width/height 含义仅 content 区域包含 content + padding + border
实际占用空间width + padding + border等于设置的 width/height
默认值CSS 默认需手动设置
布局直觉性不够直观更符合设计直觉
响应式友好度较差更好

代码对比 ​

css
/* content-box */
.box1 {
  box-sizing: content-box;
  width: 100px;
  padding: 10px;
  border: 2px solid;
}
/* 实际宽度 = 100 + 10*2 + 2*2 = 124px */

/* border-box */
.box2 {
  box-sizing: border-box;
  width: 100px;
  padding: 10px;
  border: 2px solid;
}
/* 实际宽度 = 100px（content = 100 - 10*2 - 2*2 = 76px）*/

最佳实践 ​

css
/* 全局统一使用 border-box */
*, *::before, *::after {
  box-sizing: border-box;
}

8. box-sizing 属性有哪些值？各有什么作用？ ​

问题：box-sizing 属性有哪些值？各有什么作用？

答案：

属性值 ​

值说明
content-box默认值，width/height 仅包含 content
border-boxwidth/height 包含 content + padding + border
padding-box已废弃，width/height 包含 content + padding

9. 盒模型的计算方式是什么？ ​

问题：盒模型的计算方式是什么？

答案：

content-box 计算 ​

总宽度 = margin-left + border-left + padding-left + width + padding-right + border-right + margin-right
总高度 = margin-top + border-top + padding-top + height + padding-bottom + border-bottom + margin-bottom

border-box 计算 ​

总宽度 = margin-left + width + margin-right  (width 已包含 padding 和 border)
总高度 = margin-top + height + margin-bottom
content 宽度 = width - padding-left - padding-right - border-left - border-right

10. 如何理解 CSS 盒子模型？ ​

问题：如何理解 CSS 盒子模型？

答案：

核心理解 ​

CSS 盒子模型是页面布局的基础概念，所有 HTML 元素都可以看作一个矩形盒子。理解盒模型的关键在于：

  1. 每个元素都是一个盒子，占据一定的矩形空间
  2. 盒子由四层组成：content → padding → border → margin
  3. box-sizing 决定 width/height 的计算范围
  4. margin 有折叠现象（相邻垂直 margin 取较大值）

可视化理解 ​

                ← margin →  ← border → ← padding → ← content →
元素顶部 ───────────────────────────────────────────────────────
            │ 外边距区域(透明) │
            │  ┌──────────┐  │ ← border 外边缘
            │  │ 边框区域  │  │
            │  │ ┌──────┐ │  │ ← padding 外边缘
            │  │ │内边距│ │  │
            │  │ │区域  │ │  │ ← content 区域
            │  │ │(内容)│ │  │
            │  │ └──────┘ │  │
            │  └──────────┘  │
            └────────────────┘

三、Flexbox 与 Grid 布局 ​

11. Flex 布局的原理、属性及应用场景是什么？ ​

问题：Flex 布局的原理、属性及应用场景是什么？

答案：

核心定义 ​

Flexbox（弹性盒子布局）是一种一维布局模型，用于在容器内灵活分配空间和对齐项目。

原理 ​

Flex 容器通过设置 display: flex 或 display: inline-flex 激活，其直接子元素自动成为 Flex 项目。Flex 布局的核心思想是：

  • 自动分配剩余空间
  • 灵活调整项目大小
  • 轻松实现对齐

容器属性 ​

css
.container {
  display: flex;                  /* 启用 flex 布局 */
  flex-direction: row;            /* 主轴方向：row | column | row-reverse | column-reverse */
  flex-wrap: nowrap;              /* 是否换行：nowrap | wrap | wrap-reverse */
  justify-content: flex-start;    /* 主轴对齐：flex-start | flex-end | center | space-between | space-around | space-evenly */
  align-items: stretch;           /* 交叉轴对齐：flex-start | flex-end | center | baseline | stretch */
  align-content: flex-start;      /* 多行对齐（需换行）*/
  gap: 10px;                      /* 项目间距 */
}

项目属性 ​

css
.item {
  order: 0;                       /* 排列顺序，默认 0 */
  flex-grow: 0;                   /* 放大比例，默认 0（不放大）*/
  flex-shrink: 1;                 /* 缩小比例，默认 1 */
  flex-basis: auto;               /* 基础大小，默认 auto */
  /* flex 简写：flex-grow flex-shrink flex-basis */
  flex: 1;                        /* 等价于 flex: 1 1 0% */
  align-self: auto;               /* 单独对齐，覆盖 align-items */
}

应用场景 ​

  • 导航栏布局：水平排列，自动分配空间
  • 居中布局：justify-content: center; align-items: center;
  • 等高列布局：align-items: stretch
  • 响应式卡片布局：配合 flex-wrap: wrap
css
/* 经典居中方案 */
.center {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 100vh;
}

12. Flex 布局是如何工作的？相关属性有哪些？ ​

问题：Flex 布局是如何工作的？相关属性有哪些？

答案：

工作原理 ​

  1. 确定主轴和交叉轴：由 flex-direction 决定
  2. 收集 Flex 项目：容器的直接子元素
  3. 计算项目基础尺寸：由 flex-basis、width/height 或内容决定
  4. 分配空间：
    • 空间不足时按 flex-shrink 比例缩小
    • 空间富余时按 flex-grow 比例放大
  5. 对齐排列：根据 justify-content 和 align-items 排列

空间分配计算 ​

剩余空间 = 容器尺寸 - 所有项目 flex-basis 之和
项目实际尺寸 = flex-basis + (剩余空间 × flex-grow / flex-grow 总和)

14. Flexbox 的项目属性有哪些？ ​

问题：Flexbox 的项目属性有哪些？

答案：

六大项目属性 ​

属性值默认值说明

15. Grid 布局的特点和应用场景是什么？ ​

问题：Grid 布局的特点和应用场景是什么？

答案：

核心特点 ​

Grid 是二维布局系统，可以同时控制行和列：

  • 行和列同时控制：与 Flex 的一维布局不同
  • 显式网格和隐式网格：可以定义网格轨道，也可自动创建
  • 区域命名：可以给网格区域命名，提高可读性
  • 项目可以重叠：支持 z-index 层叠

基本语法 ​

css
.container {
  display: grid;
  /* 定义列：3列，分别为 1fr 200px 1fr */
  grid-template-columns: 1fr 200px 1fr;
  /* 定义行：自动高度，最小 100px */
  grid-template-rows: auto minmax(100px, auto);
  /* 定义命名区域 */
  grid-template-areas:
    "header  header  header"
    "sidebar main    aside"
    "footer  footer  footer";
  gap: 20px;  /* 行和列间距 */
}

.item1 {
  grid-area: header;    /* 使用命名区域 */
}

.item2 {
  grid-column: 1 / 3;   /* 跨第1到第3列 */
  grid-row: 2;          /* 在第2行 */
}

应用场景 ​

  • 页面整体布局：header / sidebar / main / footer
  • 卡片网格布局：图片画廊、产品展示
  • 复杂表单布局：多列表单字段排列
  • 响应式网格：配合 auto-fit 和 minmax
css
/* 响应式卡片网格 - 自动适应 */
.grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
  gap: 20px;
}

16. 不同的布局方式的特点及应用场景 ​

问题：不同的布局方式（如 Flex 布局、Grid 布局等）的特点及应用场景

答案：

布局方式对比 ​

布局方式维度特点适用场景
Flex一维单行/列灵活分配空间导航栏、按钮组、居中、对齐
Grid二维行列同时控制页面框架、卡片网格、复杂布局
浮动一维文本环绕、脱离文档流传统多列布局（已过时）
定位绝对脱离文档流精确控制弹窗、fixed 导航、徽标
多列一维文本分列报纸式文本布局

选择策略 ​

  • 一维布局（内容排成一行或一列）→ Flex
  • 二维布局（同时需要控制行和列）→ Grid
  • 内容优先（内容决定大小）→ Flex
  • 布局优先（布局决定大小）→ Grid
  • 兼容老浏览器→ 浮动 + 清除浮动
  • 实际开发中：Grid 定义整体框架，Flex 处理组件内部布局

17. 圣杯布局和双飞翼布局如何实现？ ​

问题：圣杯布局和双飞翼布局如何实现？

答案：

概念 ​

圣杯布局和双飞翼布局都是三列布局，要求左右栏宽度固定，中间栏自适应且优先渲染。

圣杯布局（Holy Grail Layout） ​

使用浮动 + padding + 相对定位：

html
<div class="container">
  <div class="main">中间内容</div>
  <div class="left">左侧</div>
  <div class="right">右侧</div>
</div>
css
.container {
  padding: 0 200px; /* 为左右栏留出空间 */
  overflow: hidden; /* 清除浮动 */
}

.main, .left, .right {
  float: left;
  min-height: 200px;
}

.main {
  width: 100%;
}

.left {
  width: 200px;
  margin-left: -100%;  /* 拉到左侧 */
  position: relative;
  left: -200px;        /* 定位到左边缘 */
}

.right {
  width: 200px;
  margin-left: -200px; /* 拉到右侧 */
  position: relative;
  right: -200px;       /* 定位到右边缘 */
}

双飞翼布局 ​

使用浮动 + 嵌套 div：

html
<div class="container">
  <div class="main">
    <div class="main-inner">中间内容</div>
  </div>
  <div class="left">左侧</div>
  <div class="right">右侧</div>

22. 如何使用 CSS3 实现动画？animation、transition、transform 有什么区别？ ​

概念定义 ​

  • transform：变换属性，用于元素的几何变换（位移、旋转、缩放、倾斜）
  • transition：过渡，定义属性从一个值变化到另一个值的动画效果
  • animation：动画，使用 @keyframes 定义复杂的多步动画

对比表格 ​

维度transformtransitionanimation
功能几何变换状态间过渡关键帧动画
触发方式即时应用属性值变化时触发自动或手动触发
状态无中间状态需要起始和结束状态可定义多个关键帧
循环不支持不支持（一次性）支持循环（iteration-count）
控制无可暂停可暂停、播放、反向
性能GPU 加速GPU 加速（变换属性）GPU 加速（变换属性）

代码示例 ​

animation 属性详解 ​

css
.element {
  animation-name: slideIn;      /* 动画名称 */
  animation-duration: 0.5s;     /* 持续时间 */
  animation-timing-function: ease; /* 速度曲线 */
  animation-delay: 0.2s;        /* 延迟时间 */
  animation-iteration-count: 3; /* 播放次数，infinite 为无限 */

八、CSS 性能优化 ​

35. CSS 的重绘（Repaint）与回流（Reflow）是什么？有什么区别？ ​

问题：CSS 的重绘（Repaint）与回流（Reflow）是什么？有什么区别？

答案：

概念定义 ​

  • 回流（Reflow/Relayout）：当 DOM 变化影响元素的几何属性（宽、高、位置）时，浏览器需要重新计算元素的位置和大小，然后重新渲染
  • 重绘（Repaint）：当元素的外观发生变化但不影响布局时（如颜色、背景），浏览器只需重新绘制该元素

对比表格 ​

维度回流（Reflow）重绘（Repaint）
触发原因几何属性变化（尺寸、位置、内容）外观变化（颜色、背景、边框样式）
影响范围自身及后代元素，可能影响整个页面仅当前元素
性能开销大（需要重新计算布局）小（只需重新绘制像素）
示例修改 width/height、添加/删除 DOM修改 color、background、visibility
关系回流必然触发重绘重绘不一定触发回流

触发回流的常见操作 ​

javascript
// 1. DOM 操作
element.appendChild();
element.removeChild();

// 2. 样式变化
element.style.width = '100px';
element.style.margin = '10px';

// 3. 获取布局信息（强制回流）
element.offsetHeight;
element.clientWidth;
window.getComputedStyle(element);

// 4. 窗口大小变化
window.resize;

触发场景 ​

操作类型说明
添加/删除 DOM 节点回流布局改变
修改元素尺寸/位置回流宽、高、边距变化

37. 浏览器渲染机制与重绘/回流优化 ​

问题：浏览器渲染机制与重绘/回流优化

答案：

渲染管线 ​

HTML → 解析 → DOM 树
CSS → 解析 → CSSOM 树
DOM + CSSOM → 合并 → Render Tree（渲染树）
Render Tree → 布局（Layout/Reflow）→ 确定位置和大小
布局 → 绘制（Paint/Repaint）→ 像素渲染
绘制 → 合成（Composite）→ 屏幕显示

优化原则 ​

  1. 使用 GPU 加速属性：transform、opacity、filter
  2. 脱离文档流：使用 position: fixed/absolute 的元素变化影响较小
  3. 批量读写：避免"读-写-读-写"交替
  4. 使用 DocumentFragment：批量 DOM 操作
  5. will-change 提示：提前告知浏览器优化目标
css
/* will-change 提示浏览器优化 */
.animated {
  will-change: transform, opacity;
}

/* 注意：不要过度使用 will-change */

38. 如何减少重绘与回流？ ​

问题：如何减少重绘与回流？（至少 3 种方法）

答案：

优化方法 ​

  1. 使用 CSS3 动画（transform + opacity）
css
/* 使用 transform 代替 top/left */
.good {
  transition: transform 0.3s;
}
.good:hover {
  transform: translateX(10px);  /* 不触发回流 */
}
  1. 批量 DOM 操作
javascript
// 差 - 每次修改都触发回流
for (let i = 0; i < items.length; i++) {
  items[i].style.width = '100px';
}

// 好 - 使用 DocumentFragment
const fragment = document.createDocumentFragment();
for (let i = 0; i < items.length; i++) {
  const clone = items[i].cloneNode(true);
  fragment.appendChild(clone);
}
parent.appendChild(fragment);  // 只触发一次回流
  1. 使用 visibility 替代 display
css
/* display: none 触发回流 */
.hidden { display: none; }

/* visibility: hidden 只触发重绘 */
.hidden { visibility: hidden; }
  1. 避免频繁读取布局属性
javascript
// 差 - 读写交替导致多次回流
el.style.width = '100px';
const h = el.offsetHeight;  // 强制回流
el.style.height = h + 'px';

// 好 - 先读后写
const w = el.offsetWidth;
const h = el.offsetHeight;
el.style.width = '100px';
el.style.height = h + 'px';
  1. 使用 BFC 隔离回流影响
css
.container {
  overflow: hidden;  /* 创建 BFC，内部回流不影响外部 */
}

43. position 属性有哪些值？ ​

问题：position 属性有哪些值？relative、absolute、fixed 的定位基准分别是什么？

答案：

position 值对比 ​

值脱离文档流定位基准说明
static否无默认值，忽略 top/right/bottom/left
relative否自身原始位置相对自身偏移，原位置保留
absolute是最近的非 static 祖先元素相对定位祖先，无则相对 <html>
fixed是浏览器视口固定在视口，滚动时不动
sticky部分滚动容器跨越 relative 和 fixed，到达阈值时固定

示例 ​

css
/* relative - 相对于自身 */
.box {
  position: relative;
  top: 20px;   /* 向下偏移 20px */
  left: 30px;  /* 向右偏移 30px */
}

/* absolute - 相对于最近的定位祖先 */
.parent {
  position: relative;  /* 成为定位上下文 */
}
.child {
  position: absolute;
  top: 0;
  right: 0;  /* 定位到父元素右上角 */
}

/* fixed - 相对于视口 */
.navbar {
  position: fixed;
  top: 0;
  width: 100%;  /* 固定在页面顶部 */
}

/* sticky - 粘性定位 */
.header {
  position: sticky;
  top: 0;  /* 滚动到顶部时固定 */
}

44. 浮动与清除浮动的方法有哪些？ ​

问题：浮动与清除浮动的方法有哪些？（至少 3 种）

答案：

浮动原理 ​

浮动元素会脱离正常文档流，向左或向右移动，直到碰到包含框或其他浮动元素。

css
.float-left {
  float: left;   /* 左浮动 */
}
.float-right {
  float: right;  /* 右浮动 */
}

清除浮动方法 ​

方法一：额外元素 clear

html
<div class="container">
  <div class="float-left">左</div>
  <div class="float-right">右</div>
  <div style="clear: both;"></div>  <!-- 清除浮动 -->
</div>

方法二：父元素 overflow

css
.container {
  overflow: hidden;  /* 或 auto */
}

方法三：伪元素 clearfix（推荐）

css
.clearfix::after {
  content: '';
  display: table;
  clear: both;
}

/* 使用 */
<div class="container clearfix">
  <div class="float-left">左</div>
  <div class="float-right">右</div>
</div>

方法四：Flex 布局替代

css
.container {
  display: flex;
}
/* 完全不需要浮动和清除浮动 */

46. BFC（块级格式化上下文）是什么？ ​

问题：BFC 是什么？触发条件有哪些？有什么作用？

答案：

核心定义 ​

BFC（Block Formatting Context）是一个独立的渲染区域，内部元素的布局不会影响外部元素。

触发条件 ​

方式CSS 属性
根元素<html>
浮动float: left 或 float: right
绝对定位position: absolute 或 fixed
溢出隐藏overflow: hidden / auto / scroll
弹性容器display: flex
网格容器display: grid
表格单元格display: table-cell

BFC 的作用 ​

  1. 清除浮动：包含浮动元素
  2. 防止 margin 折叠：相邻兄弟元素的垂直 margin 不合并
  3. 阻止元素被浮动覆盖：与浮动元素并排显示

示例：解决 margin 折叠 ​

html
<!-- margin 折叠 -->
<div class="parent">
  <div class="child" style="margin-top: 20px;">子元素</div>
</div>
<!-- 子元素的 margin-top 会"穿透"到父元素 -->

<!-- 创建 BFC 解决 -->
<div class="parent" style="overflow: hidden;">
  <div class="child" style="margin-top: 20px;">子元素</div>
</div>
<!-- margin-top 作用于子元素内部 -->

59. @import 指令的缺陷有哪些？ ​

问题：@import 指令的缺陷有哪些？

答案：

缺陷 ​

  1. 串行加载：@import 引入的 CSS 文件会在主 CSS 文件下载完成后才开始下载，造成阻塞加载
  2. 增加请求次数：每个 @import 都会产生额外的 HTTP 请求
  3. 无法并行下载：浏览器无法并行下载 @import 的 CSS 文件
  4. JavaScript 无法控制：不能通过 JS 动态操作 @import

对比 ​

html
<!-- 推荐：使用 link 标签并行加载 -->
<link rel="stylesheet" href="a.css">
<link rel="stylesheet" href="b.css">

<!-- 不推荐：@import 串行加载 -->
<style>
  @import url('a.css');
  @import url('b.css');
</style>

62. px 与 em 的区别是什么？ ​

问题：px 与 em 的区别是什么？

答案：

对比表格 ​

维度pxemrem
类型绝对单位相对单位相对单位
参照物无父元素字体大小根元素（html）字体大小
继承性不继承继承并累积不累积
响应式固定灵活灵活
适用场景边框、固定尺寸局部相对大小全局响应式适配

示例 ​

css
html { font-size: 16px; }

.parent { font-size: 20px; }
.child {
  font-size: 1.5em;   /* 20px × 1.5 = 30px（相对于父元素）*/
  padding: 1em;       /* 30px × 1 = 30px（相对于自身 font-size）*/
}

/* rem 相对于根元素 */
.element {
  font-size: 1.5rem;   /* 16px × 1.5 = 24px */
  padding: 1rem;       /* 16px */
  margin: 0.5rem;      /* 8px */
}

使用建议 ​

  • 固定尺寸（边框、图标）→ px
  • 局部相对（组件内部间距）→ em
  • 全局响应式（字号、间距）→ rem
