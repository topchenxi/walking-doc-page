浏览器答案 ​

一、浏览器渲染机制 ​

1. 从输入 URL 到页面显示发生了什么？ ​

问题：从输入 URL 到页面显示发生了什么？

答案：

完整流程 ​

1. DNS 解析
   浏览器缓存 → 操作系统缓存 → 路由器缓存 → ISP DNS 服务器
   域名 → IP 地址

2. TCP 连接
   三次握手建立 TCP 连接
   （HTTPS 还需 TLS 握手）

3. 发送 HTTP 请求
   浏览器构造请求报文并发送

4. 服务器处理并返回响应

5. 浏览器渲染页面（关键渲染路径）
   a. 解析 HTML → 构建 DOM 树
   b. 解析 CSS → 构建 CSSOM 树
   c. 合并 DOM + CSSOM → 渲染树（Render Tree）
   d. 布局（Layout/Reflow）→ 计算节点位置和大小
   e. 绘制（Paint/Repaint）→ 填充像素
   f. 合成（Composite）→ 分层合成显示

6. 加载异步资源
   JavaScript、图片、视频等

7. 连接关闭或保持（Keep-Alive）

2. 浏览器的重绘与回流是什么？ ​

问题：浏览器的重绘与回流是什么？如何优化？

答案：

概念定义 ​

类型触发条件影响范围性能开销
回流（Reflow）元素几何属性变化（尺寸、位置）自身及后续元素大
重绘（Repaint）外观变化（颜色、背景）仅当前元素小

触发回流的操作 ​

  • 修改 width、height、margin、padding
  • 添加/删除 DOM 节点
  • 浏览器窗口大小变化
  • 读取 offsetWidth、clientHeight 等布局属性

优化策略 ​

javascript
// ❌ 差：多次读写交替，导致多次回流
el.style.width = '100px';
const h = el.offsetHeight;  // 强制回流
el.style.height = h + 'px';

// ✅ 好：先读后写
const w = el.offsetWidth;
const h = el.offsetHeight;
el.style.width = '100px';
el.style.height = h + 'px';

// ✅ 使用 transform 替代位置变化
// 差：触发回流
element.style.left = '100px';
// 好：只触发合成
element.style.transform = 'translateX(100px)';

4. Cookie 的属性有哪些？ ​

问题：Cookie 的属性有哪些？

答案：

Cookie 属性 ​

属性说明示例
name=value键值对session=abc123
domain作用域domain=.example.com
path路径path=/admin
expires过期时间expires=Thu, 01 Jan 2025
max-age有效期（秒）max-age=3600
secure仅 HTTPSsecure

安全属性 ​

Set-Cookie: session=abc123; HttpOnly; Secure; SameSite=Strict; Path=/; Max-Age=3600
  • HttpOnly：防止 XSS 攻击窃取 Cookie
  • Secure：仅通过 HTTPS 传输
  • SameSite：防止 CSRF 攻击

三、浏览器安全 ​

5. XSS 攻击是什么？如何防御？ ​

问题：XSS 攻击是什么？如何防御？

答案：

核心定义 ​

XSS（跨站脚本攻击）是攻击者向网页注入恶意脚本，在用户浏览器中执行。

攻击类型 ​

类型说明示例
存储型恶意脚本存储在服务器评论区注入 <script>
反射型恶意脚本通过 URL 传递search?q=<script>alert(1)</script>
DOM 型通过 DOM 操作注入location.hash 解析执行

防御措施 ​

javascript
// 1. 转义输出（最核心）
function escapeHtml(str) {
  return str
    .replace(/&/g, '&amp;')
    .replace(/</g, '&lt;')
    .replace(/>/g, '&gt;')
    .replace(/"/g, '&quot;')
    .replace(/'/g, '&#x27;');
}

// 2. 使用框架的自动转义
// Vue 使用 {{ }} 自动转义，v-html 需手动过滤
// React JSX 自动转义

// 3. 设置 CSP（Content Security Policy）
// 限制脚本来源
<meta http-equiv="Content-Security-Policy" 
      content="default-src 'self'; script-src 'self'">

// 4. HttpOnly Cookie
Set-Cookie: session=abc; HttpOnly

6. CSRF 攻击是什么？如何防御？ ​

问题：CSRF 攻击是什么？如何防御？

答案：

核心定义 ​

CSRF（跨站请求伪造）是攻击者诱导用户在已登录状态下，向目标网站发送恶意请求。

攻击原理 ​

1. 用户登录了 bank.com（有有效 Cookie）
2. 用户访问了 evil.com
3. evil.com 包含一个隐藏表单，自动提交转账请求到 bank.com
4. 浏览器自动携带 bank.com 的 Cookie，请求成功

防御措施 ​

方法说明
CSRF Token请求中携带随机 Token，服务端验证
SameSite Cookie限制跨站请求携带 Cookie
验证 Referer检查请求来源
自定义 Header使用非标准 Header（如 X-Requested-With）
javascript
// CSRF Token 实现
// 1. 服务端生成 Token 并放入表单
<input type="hidden" name="_csrf" value="random-token-123">

// 2. 客户端提交时携带 Token
fetch('/api/transfer', {
  method: 'POST',
  headers: { 'X-CSRF-Token': 'random-token-123' }
});

// 3. 服务端验证 Token

8. 浏览器缓存策略是什么？ ​

问题：浏览器缓存策略是什么？

答案：

缓存决策流程 ​

请求资源
  ↓
检查强缓存（Cache-Control/Expires）
  ├── 有效 → 使用缓存（200 from disk/memory cache）
  └── 无效 → 发送请求到服务器
              ↓
         检查协商缓存（ETag/Last-Modified）
              ├── 有效 → 304 Not Modified，使用缓存
              └── 无效 → 200 返回新资源

缓存头设置 ​

http
# HTML 文件 - 不缓存或协商缓存
Cache-Control: no-cache

# JS/CSS - 强缓存 + 文件名 hash
Cache-Control: public, max-age=31536000, immutable

# 图片 - 强缓存
Cache-Control: public, max-age=2592000

9. 常用的 Web API 有哪些？ ​

问题：常用的 Web API 有哪些？

答案：

常用 API 分类 ​

类别API用途
DOMquerySelector, addEventListener操作 DOM 和事件
网络fetch, XMLHttpRequest, WebSocket网络请求
存储localStorage, sessionStorage, IndexedDB数据存储
绘图Canvas, WebGL2D/3D 图形渲染
媒体Video, Audio, MediaRecorder音视频处理
地理Geolocation获取位置
通知Notification系统通知
WorkerWeb Worker, Service Worker后台线程
动画requestAnimationFrame流畅动画
IntersectionObserver元素可见性检测懒加载、无限滚动

使用示例 ​

javascript
// IntersectionObserver（懒加载）
const observer = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      const img = entry.target;
      img.src = img.dataset.src;
      observer.unobserve(img);
    }
  });
});

document.querySelectorAll('img[data-src]').forEach(img => {
  observer.observe(img);
});

// requestAnimationFrame（流畅动画）
function animate() {
  // 更新动画
  requestAnimationFrame(animate);
}
requestAnimationFrame(animate);
