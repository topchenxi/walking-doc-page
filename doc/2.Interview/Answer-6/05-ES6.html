一、let/const 与块级作用域 ​

1. let、const、var 的区别 ​

问题：let、const、var 的区别

答案：

核心定义：

  • var：ES5 声明变量的方式，具有函数作用域和变量提升特性
  • let：ES6 引入的块级作用域变量声明，不存在变量提升
  • const：ES6 引入的块级作用域常量声明，必须初始化且不可重新赋值

对比分析：

特性varletconst
作用域函数作用域块级作用域块级作用域
变量提升是（初始化为 undefined）否（存在暂时性死区）否（存在暂时性死区）
重复声明允许不允许不允许
重新赋值允许允许不允许
必须初始化否否是
挂载到全局对象是（浏览器中为 window）否否

代码示例：

javascript
// var 的变量提升和函数作用域
console.log(a); // undefined（变量提升）
var a = 10;

if (true) {
  var b = 20;
}
console.log(b); // 20（var 没有块级作用域）

// let 的块级作用域和暂时性死区
// console.log(c); // ReferenceError（暂时性死区）
let c = 30;

if (true) {
  let d = 40;
  console.log(d); // 40
}
// console.log(d); // ReferenceError（块级作用域外无法访问）

// const 的不可重新赋值特性
const e = 50;
// e = 60; // TypeError: Assignment to constant variable.

// const 声明的对象属性可修改
const obj = { name: '张三' };
obj.name = '李四'; // 可以修改属性
console.log(obj.name); // '李四'
// obj = {}; // TypeError: 不能重新赋值

常见误区：

  • 误认为 const 声明的值完全不可变：实际上 const 只是不允许重新赋值，对于引用类型（对象、数组），其属性/元素仍可修改
  • 误认为 let 和 var 只是作用域不同：实际上 let 还有暂时性死区、不允许重复声明等特性

2. var 的函数作用域和变量提升特性 ​

问题：var 的函数作用域和变量提升特性

答案：

核心定义：

  • 函数作用域：var 声明的变量在函数内部可见，函数外部无法访问
  • 变量提升：var 声明的变量会在代码执行前被提升到作用域顶部，但只提升声明，不提升赋值

原理解析： JavaScript 引擎在执行代码前会先进行编译阶段，在这个阶段会收集所有的变量声明和函数声明，并将它们"提升"到作用域顶部。var 变量提升后会被初始化为 undefined。

javascript
// 实际执行的代码顺序
var x;  // 声明被提升，初始化为 undefined
console.log(x); // undefined
x = 10; // 赋值保留在原位

// 函数作用域示例
function example() {
  var y = 20;
  if (true) {
    var z = 30; // 在 if 块内声明，但在整个函数内可见
    console.log(z); // 30
  }
  console.log(z); // 30（var 不受块级作用域限制）
}
// console.log(y); // ReferenceError（y 在函数外部不可访问）

常见问题：

javascript
// 经典面试题：循环中的 var
for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 100);
}
// 输出：3, 3, 3（因为 var 没有块级作用域，i 是同一个变量）

// 解决方案：使用 let
for (let j = 0; j < 3; j++) {
  setTimeout(() => console.log(j), 100);
}
// 输出：0, 1, 2（每次循环创建新的块级作用域）

注意事项：

  • 变量提升可能导致代码逻辑混乱，建议在变量实际声明的位置使用它
  • 函数声明也会被提升，且优先级高于变量声明

3. let 的块级作用域特性 ​

问题：let 的块级作用域特性

答案：

核心定义： 块级作用域是指变量在 {} 花括号包裹的代码块内有效，包括 if 语句、for 循环、while 循环等。

特性说明：

  1. 变量只在声明它的代码块内有效
  2. 外层代码块不受内层代码块的影响
  3. for 循环的循环变量只在循环体内有效
  4. 可以在内层作用域中声明同名变量（不会覆盖外层）
javascript
// if 块级作用域
if (true) {
  let a = 10;
  console.log(a); // 10
}
// console.log(a); // ReferenceError: a is not defined

// for 循环块级作用域
for (let i = 0; i < 3; i++) {
  let j = i * 2;
  console.log(j); // 0, 2, 4
}
// console.log(i); // ReferenceError
// console.log(j); // ReferenceError

// 嵌套作用域
let x = 1;
{
  let x = 2; // 内层作用域的同名变量
  console.log(x); // 2
}
console.log(x); // 1（外层变量不受影响）

实际应用：

javascript
// 避免全局变量污染
{
  let tempData = calculateData();
  process(tempData);
}
// tempData 不会泄漏到全局作用域

// IIFE 的替代方案
// ES5 使用 IIFE 创建块级作用域
(function() {
  var privateVar = 'ES5';
})();

// ES6 直接使用块级作用域
{
  let privateVar = 'ES6';
}

4. const 必须初始化且引用类型可修改属性 ​

问题：const 必须初始化且引用类型可修改属性

答案：

核心定义：

  • const 声明时必须立即初始化（赋值），否则会报错
  • const 声明的是只读引用，对于引用类型（对象、数组），其内部属性/元素可以修改

原理解析： const 保证的是变量指向的内存地址不变。对于基本类型（数字、字符串等），值直接存储在变量指向的地址中，所以值不可变。对于引用类型，变量存储的是指向对象的指针（引用），const 保证的是这个引用不变，但对象本身的内容可以修改。

javascript
// const 必须初始化
// const a; // SyntaxError: Missing initializer in const declaration
const b = 10; // 正确

// 基本类型不可修改
const num = 100;
// num = 200; // TypeError

// 引用类型：引用不可修改，但属性可修改
const arr = [1, 2, 3];
arr.push(4); // 可以修改数组内容
console.log(arr); // [1, 2, 3, 4]
// arr = [5, 6]; // TypeError: 不能重新赋值

const obj = { name: '张三' };
obj.name = '李四'; // 可以修改属性
obj.age = 25; // 可以添加新属性
console.log(obj); // { name: '李四', age: 25 }
// obj = {}; // TypeError

// 如果需要对象完全不可变，使用 Object.freeze()
const frozen = Object.freeze({ x: 1, y: 2 });
// frozen.x = 10; // 严格模式下会报错
console.log(frozen.x); // 1

常见误区：

  • 误认为 const 声明的对象完全不可变：实际上只是引用不变
  • 解决方案：使用 Object.freeze() 实现深度冻结（需要递归冻结嵌套对象）

5. 什么是块级作用域？为什么需要块级作用域？ ​

问题：什么是块级作用域？为什么需要块级作用域？

答案：

核心定义： 块级作用域是指在大括号 {} 内声明的变量只在该代码块内有效，外部无法访问。ES6 通过 let 和 const 引入了块级作用域。

为什么需要块级作用域：

  1. 避免内部变量覆盖外部变量
javascript
// ES5 的问题：内层变量覆盖外层变量
var name = '全局';
function test() {
  console.log(name); // undefined（变量提升导致）
  if (false) {
    var name = '局部';
  }
}
test();
  1. 避免循环变量泄漏为全局变量
javascript
// ES5：循环变量泄漏
for (var i = 0; i < 5; i++) {
  // 执行某些操作
}
console.log(i); // 5（i 泄漏到外部作用域）

// ES6：块级作用域
for (let j = 0; j < 5; j++) {
  // 执行某些操作
}
// console.log(j); // ReferenceError
  1. 替代 IIFE（立即执行函数表达式）
javascript
// ES5 使用 IIFE 避免污染全局
(function() {
  var temp = '临时数据';
  // 使用 temp
})();

// ES6 使用块级作用域
{
  let temp = '临时数据';
  // 使用 temp
}
  1. 解决异步回调中的变量捕获问题
javascript
// ES5：需要 IIFE 或 bind
for (var i = 0; i < 3; i++) {
  (function(index) {
    setTimeout(() => console.log(index), 100);
  })(i);
}

// ES6：直接使用 let
for (let i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 100);
}

6. 什么是暂时性死区（TDZ）？ ​

问题：什么是暂时性死区（TDZ）？

答案：

核心定义： 暂时性死区（Temporal Dead Zone，简称 TDZ）是指在块级作用域内，使用 let 或 const 声明的变量从进入作用域到实际声明之间的区域。在这个区域内访问变量会抛出 ReferenceError。

原理解析： ES6 明确规定，如果区块中存在 let 和 const 命令，这个区块对这些命令声明的变量，从一开始就形成了封闭作用域。凡是在声明之前就使用这些变量，就会报错。

javascript
// TDZ 示例
console.log(a); // undefined（var 变量提升）
var a = 10;

// console.log(b); // ReferenceError（TDZ）
let b = 20;

// console.log(c); // ReferenceError（TDZ）
const c = 30;

TDZ 特点：

  1. 只要作用域内存在 let/const，变量就绑定在该作用域，不受外部影响
  2. 变量在声明前不可访问，即使使用 typeof 也会报错
  3. TDZ 的本质是：在变量声明之前，变量尚未创建
javascript
// TDZ 与外部变量无关
let x = '外部';
{
  // console.log(x); // ReferenceError（TDZ，不受外部 x 影响）
  let x = '内部';
  console.log(x); // '内部'
}

// typeof 在 TDZ 中也会报错
// typeof y; // ReferenceError
let y = 100;

// 对比 var
typeof z; // 'undefined'（不会报错）
var z = 100;

实际影响：

javascript
// 函数参数也存在 TDZ
function foo(x = y, y = 2) {
  return [x, y];
}
// foo(); // ReferenceError: y is not defined

// 正确写法
function bar(y = 2, x = y) {
  return [x, y];
}
console.log(bar()); // [2, 2]

7. const 变量能否修改？const 对象属性能否修改？ ​

问题：const 变量能否修改？const 对象属性能否修改？

答案：

核心定义：

  • const 声明的基本类型变量不能修改
  • const 声明的引用类型变量，其引用不能修改，但对象的属性可以修改

原理解析： const 声明创建一个只读的引用。这意味着：

  • 对于基本类型（Number、String、Boolean 等），值存储在栈内存中，const 使这个值不可变
  • 对于引用类型（Object、Array 等），变量存储的是指向堆内存中对象的指针（引用地址），const 保证这个引用地址不变，但对象本身的内容可以修改
javascript
// 基本类型：完全不可修改
const num = 42;
// num = 100; // TypeError: Assignment to constant variable.

const str = 'hello';
// str = 'world'; // TypeError

// 引用类型：引用不可修改，内容可修改
const arr = [1, 2, 3];
arr.push(4);      // 正确
arr[0] = 10;      // 正确
console.log(arr); // [10, 2, 3, 4]
// arr = [5, 6];   // TypeError

const obj = { a: 1, b: 2 };
obj.a = 10;       // 正确
obj.c = 30;       // 正确（添加新属性）
delete obj.b;     // 正确（删除属性）
console.log(obj); // { a: 10, c: 30 }
// obj = {};       // TypeError

如何使对象完全不可变：

javascript
// 浅冻结
const shallowFrozen = Object.freeze({ x: 1, y: { z: 2 } });
shallowFrozen.x = 10;      // 无效
shallowFrozen.y.z = 20;    // 仍然可以修改嵌套属性

// 深冻结函数
function deepFreeze(obj) {
  Object.keys(obj).forEach(key => {
    if (typeof obj[key] === 'object' && obj[key] !== null) {
      deepFreeze(obj[key]);
    }
  });
  return Object.freeze(obj);
}

const deepFrozen = deepFreeze({ x: 1, y: { z: 2 } });
// deepFrozen.y.z = 20; // 严格模式下报错

8. 如何理解 JavaScript 中的变量作用域（var、let、const）？ ​

问题：如何理解 JavaScript 中的变量作用域（var、let、const）？

答案：

核心定义： 作用域是指变量可访问的范围。JavaScript 中的作用域经历了从函数作用域到块级作用域的演变。

作用域类型：

作用域类型声明方式说明
全局作用域var/let/const（最外层）整个程序可访问
函数作用域var仅在函数内部可访问
块级作用域let/const仅在 {} 代码块内可访问

作用域链： 当访问一个变量时，JavaScript 引擎会从当前作用域开始查找，如果找不到则向上一级作用域查找，直到全局作用域。

javascript
// 全局作用域
let global = '全局变量';

function outer() {
  // 函数作用域
  let outerVar = '外层函数变量';
  
  if (true) {
    // 块级作用域
    let blockVar = '块级变量';
    console.log(global);    // 可以访问全局变量
    console.log(outerVar);  // 可以访问外层变量
    console.log(blockVar);  // 可以访问块级变量
  }
  
  // console.log(blockVar); // ReferenceError：无法访问块级作用域的变量
}

// console.log(outerVar); // ReferenceError：无法访问函数作用域的变量

作用域对比：

javascript
// var：函数作用域 + 变量提升
function varExample() {
  if (true) {
    var x = 10;
  }
  console.log(x); // 10（var 不受块级作用域限制）
}

// let：块级作用域
function letExample() {
  if (true) {
    let y = 20;
  }
  // console.log(y); // ReferenceError
}

// const：块级作用域 + 不可重新赋值
function constExample() {
  if (true) {
    const z = 30;
  }
  // console.log(z); // ReferenceError
}

9. 箭头函数与普通函数的区别 ​

问题：箭头函数与普通函数的区别

答案：

对比分析：

特性普通函数箭头函数
this 指向动态绑定（调用时确定）词法绑定（定义时确定，继承外层）
构造函数可以作为构造函数（使用 new）不能作为构造函数
arguments有 arguments 对象没有 arguments 对象
prototype有 prototype 属性没有 prototype 属性
语法function() {}() => {}
new.target支持不支持
作为方法适合不适合（this 指向问题）

代码示例：

javascript
// 1. this 指向不同
const obj = {
  name: '张三',
  regularFunc: function() {
    console.log(this.name); // '张三'（this 指向 obj）
  },
  arrowFunc: () => {
    console.log(this.name); // undefined（this 指向全局/undefined）
  }
};
obj.regularFunc();
obj.arrowFunc();

// 2. 箭头函数不能作为构造函数
function Person(name) {
  this.name = name;
}
const p1 = new Person('李四'); // 正确

// const ArrowPerson = (name) => { this.name = name; };
// const p2 = new ArrowPerson('王五'); // TypeError: ArrowPerson is not a constructor

// 3. 没有 arguments 对象
function regularArgs() {
  console.log(arguments); // [Arguments] { '0': 1, '1': 2, '2': 3 }
}
regularArgs(1, 2, 3);

const arrowArgs = () => {
  // console.log(arguments); // ReferenceError
};
arrowArgs(1, 2, 3);

// 使用 rest 参数替代
const arrowArgs2 = (...args) => {
  console.log(args); // [1, 2, 3]
};
arrowArgs2(1, 2, 3);

// 4. 没有 prototype
console.log(regularArgs.prototype); // { constructor: f }
console.log(arrowArgs.prototype);   // undefined

注意事项：

  • 箭头函数不适合定义对象方法（this 不指向对象）
  • 箭头函数不适合需要动态 this 的场景（事件回调、构造函数等）

10. 箭头函数的 this 指向特性（不绑定 this） ​

问题：箭头函数的 this 指向特性（不绑定 this）

答案：

核心定义： 箭头函数不绑定自己的 this，而是捕获其所在上下文的 this 值作为自己的 this 值。这种机制称为词法 this（Lexical this）。

原理解析： 普通函数的 this 是在调用时确定的（动态绑定），而箭头函数的 this 是在定义时确定的（词法绑定），它继承自外层作用域的 this。

javascript
// 示例 1：对象方法中的箭头函数
const obj = {
  name: '对象',
  showName: function() {
    console.log(this.name); // '对象'（普通函数，this 指向 obj）
    
    setTimeout(() => {
      console.log(this.name); // '对象'（箭头函数继承外层 this）
    }, 100);
  }
};
obj.showName();

// 对比 ES5 写法
const obj2 = {
  name: '对象2',
  showName: function() {
    const self = this; // 保存 this
    setTimeout(function() {
      console.log(self.name); // '对象2'（使用闭包保存的 this）
    }, 100);
  }
};
obj2.showName();

// 示例 2：全局上下文
const globalFunc = () => {
  console.log(this); // 在浏览器中指向 window，严格模式下为 undefined
};
globalFunc();

实际应用：

javascript
// 常见场景：事件处理
class Counter {
  constructor() {
    this.count = 0;
  }
  
  increment() {
    this.count++;
  }
  
  setupButton() {
    // 使用箭头函数，this 指向 Counter 实例
    document.getElementById('btn').addEventListener('click', () => {
      this.increment(); // this 正确指向 Counter
    });
    
    // 如果使用普通函数
    // document.getElementById('btn').addEventListener('click', function() {
    //   this.increment(); // TypeError：this 指向 button 元素
    // });
  }
}

常见误区：

  • 误认为箭头函数的 this 总是指向全局对象：实际上取决于定义时的上下文
  • 误在对象方法中使用箭头函数：会导致 this 不指向对象

11. 箭头函数能否作为构造函数？ ​

问题：箭头函数能否作为构造函数？

答案：

答案：不能。

原因分析：

  1. 箭头函数没有 [[Construct]] 内部方法，无法使用 new 调用
  2. 箭头函数没有 prototype 属性，无法提供实例的原型
  3. 箭头函数的 this 是词法绑定的，无法指向新创建的实例
javascript
// 普通函数可以作为构造函数
function Person(name) {
  this.name = name;
}
Person.prototype.sayHello = function() {
  console.log('Hello, ' + this.name);
};

const p1 = new Person('张三');
p1.sayHello(); // 'Hello, 张三'
console.log(p1 instanceof Person); // true

// 箭头函数不能作为构造函数
const ArrowPerson = (name) => {
  this.name = name; // 这里的 this 不是新实例
};

// const p2 = new ArrowPerson('李四'); // TypeError: ArrowPerson is not a constructor

// 验证：箭头函数没有 prototype
console.log(Person.prototype); // { constructor: f, sayHello: f }
console.log(ArrowPerson.prototype); // undefined

// 验证：箭头函数没有 [[Construct]] 方法
console.log(typeof Person.prototype.constructor); // 'function'

替代方案：

javascript
// 方案 1：使用普通函数
function createPerson(name) {
  return { name, sayHello: () => console.log('Hello, ' + name) };
}

// 方案 2：使用 Class（底层仍是构造函数）
class ModernPerson {
  constructor(name) {
    this.name = name;
  }
  sayHello() {
    console.log('Hello, ' + this.name);
  }
}

12. 箭头函数没有 arguments 对象 ​

问题：箭头函数没有 arguments 对象

答案：

核心定义： 箭头函数内部不存在 arguments 对象，如果在箭头函数中访问 arguments，它会引用外层函数的 arguments。

替代方案：使用剩余参数（Rest Parameters）...args

javascript
// 普通函数有 arguments 对象
function regularFunc() {
  console.log(arguments); // [Arguments] { '0': 1, '1': 2 }
  console.log(arguments.length); // 2
}
regularFunc(1, 2);

// 箭头函数没有 arguments 对象
const arrowFunc = () => {
  // console.log(arguments); // ReferenceError: arguments is not defined
};
arrowFunc(1, 2);

// 箭头函数中使用外层函数的 arguments
function outerFunc() {
  const innerArrow = () => {
    console.log(arguments); // 引用 outerFunc 的 arguments
  };
  innerArrow();
}
outerFunc('a', 'b'); // [Arguments] { '0': 'a', '1': 'b' }

使用 rest 参数替代：

javascript
// ES5 写法
function sum() {
  let total = 0;
  for (let i = 0; i < arguments.length; i++) {
    total += arguments[i];
  }
  return total;
}
console.log(sum(1, 2, 3, 4)); // 10

// ES6 箭头函数 + rest 参数
const sumArrow = (...args) => {
  return args.reduce((total, num) => total + num, 0);
};
console.log(sumArrow(1, 2, 3, 4)); // 10

// rest 参数的好处：
// 1. 是真正的数组，可以使用数组方法
// 2. 语义更清晰
// 3. 支持箭头函数

注意事项：

  • 如果需要访问函数的所有参数，在箭头函数中必须使用 ...args
  • arguments 是类数组对象，不是真正的数组；而 rest 参数是真正的数组

13. 箭头函数没有 prototype ​

问题：箭头函数没有 prototype

答案：

// HTML 转义
function htmlEscape(strings, ...values) {
  const escape = (str) => {
    return String(str)
      .replace(/&/g, '&amp;')
      .replace(/</g, '&lt;')
      .replace(/>/g, '&gt;')
      .replace(/"/g, '&quot;');
  };
  
  let result = '';
  strings.forEach((str, i) => {
    result += str;
    if (i < values.length) {
      result += escape(values[i]);
    }
  });
  return result;
}

    const key = str.trim();

    } else {
      result += str;

}

class Range {
  constructor(start, end) {
    this.start = start;
    this.end = end;
  }
  
  [Symbol.iterator]() {
    let current = this.start;
    const end = this.end;
    return {
      next() {
        if (current <= end) {
          return { value: current++, done: false };
        }
        return { done: true };
      }
    };
  }
}

// 方式 2：使用 Generator 函数（更简洁）
class RangeGenerator {
  constructor(start, end) {
    this.start = start;
    this.end = end;
  }
  
  *[Symbol.iterator]() {
    for (let i = this.start; i <= this.end; i++) {
      yield i;
    }
  }
}

for (const num of range2) {
  console.log(num); // 1, 2, 3, 4, 5
}
javascript
// 方式 3：自定义数据结构迭代器
class LinkedList {
  constructor() {
    this.head = null;
  }
  
  add(value) {
    const node = { value, next: this.head };
    this.head = node;
  }
  
  [Symbol.iterator]() {
    let current = this.head;
    return {
      next: () => {
        if (current) {
          const value = current.value;
          current = current.next;
          return { value, done: false };
        }
        return { done: true };
      }
    };
  }
}

  yield 1;
  yield 2;
  yield 3;
}

gen.next(); // { value: 2, done: false }（暂停在第二个 yield）
gen.next(); // { value: 3, done: false }（暂停在第三个 yield）
gen.next(); // { value: undefined, done: true }

yield 与 return 的区别：

javascript
// return：结束函数执行
// yield：暂停函数执行，可以恢复

function* genWithReturn() {
  yield 1;
  return 2; // 结束执行
  yield 3; // 不会执行
}

const g = genWithReturn();
console.log(g.next()); // { value: 1, done: false }
console.log(g.next()); // { value: 2, done: true }
console.log(g.next()); // { value: undefined, done: true }

yield 表达式的返回值：

javascript
function* genWithInput() {

  console.log('b:', b);

}

    const data2 = yield fetch('/api/2').then(r => r.json());

  }
}

function reactive(obj) {
  return new Proxy(obj, {
    get(target, prop) {
      track(target, prop); // 收集依赖
      return Reflect.get(target, prop);
    },
    set(target, prop, value) {
      const result = Reflect.set(target, prop, value);
      trigger(target, prop); // 触发更新
      return result;
    }
  });
}

  console.log(`追踪属性：${prop}`);
}

  console.log(`触发更新：${prop}`);
}
