1. 什么是设计模式？有哪些分类？ ​

问题：什么是设计模式？有哪些分类？

答案：

核心定义 ​

设计模式是软件开发中反复出现的、经过验证的、可复用的解决方案，用于解决特定场景下的设计问题。

分类 ​

类型说明常见模式
创建型对象实例化机制单例、工厂、抽象工厂、建造者、原型
结构型类和对象的组合适配器、装饰器、代理、外观、组合
行为型对象间的通信观察者、策略、命令、模板方法、迭代器

二、创建型模式 ​

2. 单例模式的实现方式有哪些？ ​

问题：单例模式的实现方式有哪些？

答案：

核心定义 ​

单例模式确保一个类只有一个实例，并提供全局访问点。

JavaScript 实现 ​

javascript
// 方式 1：闭包实现
const Singleton = (function() {
  let instance = null;
  
  function createInstance() {
    return { data: 'singleton data' };
  }
  
  return {
    getInstance() {
      if (!instance) {
        instance = createInstance();
      }
      return instance;
    }
  };
})();

const s1 = Singleton.getInstance();
const s2 = Singleton.getInstance();
console.log(s1 === s2);  // true

// 方式 2：ES6 class 实现
class SingletonClass {
  constructor() {
    if (SingletonClass.instance) {
      return SingletonClass.instance;
    }
    SingletonClass.instance = this;
    return this;
  }
}

// 方式 3：Vuex/Redux Store（实际应用）
// const store = new Vuex.Store({...});  // 全局唯一实例

应用场景 ​

  • 全局状态管理（Vuex/Redux）
  • 日志记录器
  • 数据库连接池
  • 浏览器缓存管理

3. 工厂模式是什么？如何实现？ ​

问题：工厂模式是什么？如何实现？

答案：

核心定义 ​

工厂模式定义一个创建对象的接口，由子类决定实例化哪个类。

实现 ​

javascript
// 简单工厂
class Button {
  render() { console.log('Button'); }
}
class Input {
  render() { console.log('Input'); }
}

function createComponent(type) {
  switch(type) {
    case 'button': return new Button();
    case 'input': return new Input();
    default: throw new Error('Unknown type');
  }
}

const btn = createComponent('button');
btn.render();  // "Button"

// 工厂方法模式
class ComponentFactory {
  createComponent(type) {
    throw new Error('子类必须实现');
  }
}

class ButtonFactory extends ComponentFactory {
  createComponent() { return new Button(); }
}

class InputFactory extends ComponentFactory {
  createComponent() { return new Input(); }
}

4. 发布-订阅模式如何实现？ ​

问题：发布-订阅模式（观察者模式）如何实现？

答案：

核心定义 ​

发布-订阅模式定义对象间的一对多依赖关系，当一个对象状态改变时，所有依赖者都会收到通知。

实现 ​

javascript
class EventEmitter {
  constructor() {
    this.events = {};
  }
  
  // 订阅
  on(event, callback) {
    if (!this.events[event]) {
      this.events[event] = [];
    }
    this.events[event].push(callback);
    return this;
  }
  
  // 发布
  emit(event, ...args) {
    if (this.events[event]) {
      this.events[event].forEach(cb => cb.apply(this, args));
    }
    return this;
  }
  
  // 取消订阅
  off(event, callback) {
    if (this.events[event]) {
      this.events[event] = this.events[event].filter(
        cb => cb !== callback
      );
    }
    return this;
  }
  
  // 一次性订阅
  once(event, callback) {
    const wrapper = (...args) => {
      callback.apply(this, args);
      this.off(event, wrapper);
    };
    return this.on(event, wrapper);
  }
}

// 使用
const emitter = new EventEmitter();
emitter.on('click', (x, y) => {
  console.log(`Clicked at ${x}, ${y}`);
});
emitter.emit('click', 100, 200);  // "Clicked at 100, 200"

应用场景 ​

  • Vue 事件系统（$on/$emit）
  • Node.js EventEmitter
  • DOM 事件监听
  • 消息队列

5. 代理模式的实现与应用场景 ​

问题：代理模式的实现与应用场景

答案：

核心定义 ​

代理模式为其他对象提供一种代理以控制对这个对象的访问。

实现 ​

javascript
// 缓存代理
function createProxy(fn) {
  const cache = {};
  return function(...args) {
    const key = JSON.stringify(args);
    if (cache[key]) {
      console.log('从缓存获取');
      return cache[key];
    }
    const result = fn.apply(this, args);
    cache[key] = result;
    return result;
  };
}

const add = (a, b) => a + b;
const proxyAdd = createProxy(add);
proxyAdd(1, 2);  // 3（计算）
proxyAdd(1, 2);  // 3（缓存）

// 拦截代理（ES6 Proxy）
const target = { name: 'Alice', age: 25 };
const handler = {
  get(obj, prop) {
    console.log(`访问属性: ${prop}`);
    return prop in obj ? obj[prop] : undefined;
  },
  set(obj, prop, value) {
    console.log(`设置属性: ${prop} = ${value}`);
    obj[prop] = value;
    return true;
  }
};
const proxy = new Proxy(target, handler);
proxy.name;  // "访问属性: name" → "Alice"

应用场景 ​

  • 图片懒加载（虚拟代理）
  • 缓存代理
  • 权限控制（保护代理）
  • Vue 3 响应式系统（Proxy）

6. 装饰器模式如何实现？ ​

问题：装饰器模式如何实现？

答案：

核心定义 ​

装饰器模式在不改变原有对象的基础上，动态地给对象添加新功能。

实现 ​

javascript
// 函数装饰器
function loggingDecorator(fn) {
  return function(...args) {
    console.log(`调用前: ${fn.name}`, args);
    const result = fn.apply(this, args);
    console.log(`调用后: ${fn.name}`, result);
    return result;
  };
}

function add(a, b) { return a + b; }
const decoratedAdd = loggingDecorator(add);
decoratedAdd(1, 2);
// 输出: 调用前: add [1, 2]
//       调用后: add 3

// ES6 装饰器（类装饰器）
function readonly(target, key, descriptor) {
  descriptor.writable = false;
  return descriptor;
}

class Person {
  @readonly
  name = 'Alice';
}

7. 策略模式的应用场景 ​

问题：策略模式的应用场景

答案：

核心定义 ​

策略模式定义一系列算法，将每个算法封装起来，并使它们可以互换。

实现 ​

javascript
// 校验策略
const validators = {
  required: (value) => value !== '',
  email: (value) => /^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(value),
  minLength: (value, len) => value.length >= len,
  maxLength: (value, len) => value.length <= len
};

// 使用策略
function validate(rules, data) {
  const errors = [];
  for (const [field, ruleList] of Object.entries(rules)) {
    for (const rule of ruleList) {
      const [name, ...params] = rule.split(':');
      if (!validators[name](data[field], ...params)) {
        errors.push(`${field} 校验失败: ${name}`);
      }
    }
  }
  return errors;
}

const rules = {
  username: ['required', 'minLength:3'],
  email: ['required', 'email']
};
const data = { username: 'ab', email: 'invalid' };
console.log(validate(rules, data));
// ["username 校验失败: minLength", "email 校验失败: email"]

8. 观察者模式与发布-订阅模式的区别 ​

问题：观察者模式与发布-订阅模式的区别

答案：

对比表格 ​

维度观察者模式发布-订阅模式
耦合度高（观察者知道被观察者）低（通过事件中心解耦）
通信方式直接通知通过中间人（事件总线）
订阅者感知知道被观察对象不知道发布者
实现复杂度简单需要事件中心
javascript
// 观察者模式（直接通知）
class Subject {
  constructor() { this.observers = []; }
  addObserver(observer) { this.observers.push(observer); }
  notify(data) {
    this.observers.forEach(obs => obs.update(data));
  }
}

// 发布-订阅模式（通过事件中心）
class EventBus {
  constructor() { this.events = {}; }
  on(event, fn) { /* ... */ }
  emit(event, data) { /* ... */ }
}

补充说明：

前端设计模式重点掌握：单例模式、发布-订阅模式、代理模式、策略模式、装饰器模式。结合实际框架（如 Vue 的响应式系统使用代理模式）理解会更深刻。
