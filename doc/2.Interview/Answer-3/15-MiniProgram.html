多端小程序 ​

一、框架对比 ​

1. uni-app 与 Taro 的区别 ​

问题：uni-app 与 Taro 的区别

答案： 核心回答：uni-app 基于 Vue，Taro 基于 React，两者都支持多端编译。

方面uni-appTaro
框架VueReact
语法Vue 语法React 语法
平台微信/支付宝/抖音等微信/支付宝/京东等
生态DCloud京东
学习成本Vue 开发者React 开发者

代码示例：

html
<!-- uni-app -->
<template>
    <view class="container">
        <text>{{ msg }}</text>
        <button @click="handleClick">点击</button>
    </view>
</template>

<script>
export default {
    data() {
        return { msg: 'Hello' }
    },
    methods: {
        handleClick() {
            uni.showToast({ title: '点击' });
        }
    }
}
</script>

2. 条件编译 ​

问题：条件编译

答案： 核心回答：条件编译使用特定注释在不同平台编译不同代码。

代码示例：

javascript
// #ifdef uni-app
uni.showToast({ title: 'uni-app' });
// #endif

// #ifdef MP-WEIXIN
wx.showToast({ title: '微信' });
// #endif

// #ifdef H5
alert('H5环境');
// #endif

// 样式条件编译
/* #ifdef MP-WEIXIN */
color: red;
/* #endif */

/* #ifdef H5 */
color: blue;
/* #endif */

// JSON 条件编译
{
    "uni-app": {},
    "mp-weixin": {}
}

二、分包加载 ​

3. 分包加载 ​

问题：分包加载

答案： 核心回答：分包加载将小程序分成主包和多个分包，优化首屏加载速度。

代码示例：

json
// 主包 app.json
{
    "pages": [
        "pages/index/index",
        "pages/user/user"
    ],
    "subPackages": [
        {
            "root": "packageA",
            "pages": [
                "pages/pkg1/pkg1",
                "pages/pkg2/pkg2"
            ]
        },
        {
            "root": "packageB",
            "pages": [
                "pages/pkg3/pkg3"
            ]
        }
    ]
}

三、云开发 ​

4. 云函数 ​

问题：云函数

答案： 核心回答：云函数是运行在云端的无状态函数。

代码示例：

javascript
// cloudfunctions/getUser/index.js
const cloud = require('wx-server-sdk');
cloud.init({ env: cloud.DYNAMIC_CURRENT_ENV });

exports.main = async (event, context) => {
    const { userId } = event;
    
    const db = cloud.database();
    const res = await db.collection('users')
        .where({ _id: userId })
        .get();
    
    return {
        success: true,
        data: res.data
    };
};

// 客户端调用
wx.cloud.callFunction({
    name: 'getUser',
    data: { userId: 'xxx' }
}).then(res => {
    console.log(res.result);
});

四、性能优化 ​

5. setData 优化 ​

问题：setData 优化

答案： 核心回答：减少 setData 数据量、使用局部更新、避免频繁调用。

代码示例：

javascript
// 优化前
this.setData({
    list: newList  // 全量更新
});

// 优化后：局部更新
const list = this.data.list;
const index = newItem.index;
list[index] = newItem;
this.setData({
    'list[' + index + ']': newItem  // 只更新单项
});

// 合并 setData
// 多次 setData 合并为一次
this.setData({ a: 1 });
this.setData({ b: 2 });
// 改为
this.setData({ a: 1, b: 2 });

// 使用数据预存
data: {
    largeData: []
},
onLoad() {
    // 先设置数据再渲染
    this.setData({ largeData: hugeArray });
}

6. 渲染性能优化 ​

问题：渲染性能优化

答案： 核心回答：减少视图层级、使用懒加载、优化长列表。

代码示例：

html
<!-- 静态内容使用 block -->
<block wx:for="{{list}}">
    <view class="item">{{item.name}}</view>
</block>

<!-- 避免不必要的容器嵌套 -->
<!-- 优化前 -->
<view class="container">
    <view class="wrapper">
        <view class="content">{{text}}</view>
    </view>
</view>

<!-- 优化后 -->
<view class="content">{{text}}</view>

<!-- 长列表使用虚拟列表 -->
<!-- 使用wx:key提高渲染性能 -->
<view wx:for="{{list}}" wx:key="id">
    <!-- 内容 -->
</view>

<!-- 启用懒加载 -->
<img src="{{item.src}}" mode="aspectFill" lazy-load />
