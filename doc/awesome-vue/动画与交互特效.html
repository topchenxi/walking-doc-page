动画与交互特效 ​

通用动画与特效库 ​

  • Three.js ⭐ 112k — JavaScript 3D 图形库，用于创建 3D 场景、游戏和复杂动画效果，支持 WebGL 渲染
  • Animate.css ⭐ 82k — 纯 CSS 动画库，提供丰富的预定义动画效果，即插即用，跨浏览器兼容
  • Anime.js ⭐ 47k — 轻量级 JavaScript 动画引擎，支持 CSS 属性、SVG、DOM 属性和 JavaScript 对象动画，提供强大的时间轴控制
  • Swiper ⭐ 41k — 现代移动端触摸滑动库，支持硬件加速过渡、轮播图和手势操作
  • Lottie Web ⭐ 31k — Bodymovin 动画渲染库，支持 After Effects 导出的 JSON 动画文件，可在 Web、iOS、Android 平台播放高质量动画
  • Particles.js ⭐ 30k — 轻量级 JavaScript 粒子效果库，用于创建炫酷的粒子背景动画
  • AOS ⭐ 27k — Animate On Scroll 滚动动画库，CSS3 驱动的滚动触发动画，可与 Vue 集成使用
  • tsparticles ⭐ 25k — 轻量级粒子动画库，支持多种粒子效果和交互功能，是 particles.js 的继任者
  • GSAP ⭐ 24k — GreenSock 高性能动画平台，专业级 JavaScript 动画库，支持 CSS、SVG、Canvas、WebGL 动画
  • ScrollReveal ⭐ 21k — 零依赖滚动触发动画库，元素进入或离开视口时自动触发动画，支持丰富的配置选项和序列化动画
  • Popmotion ⭐ 20k — 功能强大的 JavaScript 动画库，支持关键帧、弹簧物理和惯性动画，适用于任何 JS 环境
  • Mo.js ⭐ 14k — 图形动画工具包，专为 Web 提供优雅的图形动画和交互效果，适合制作复杂的视觉动画
  • Framer Motion ⭐ 12k — 声明式动画库，提供流畅的页面过渡和手势交互，主要用于 React 生态
  • canvas-confetti ⭐ 12k — 高性能 Canvas 五彩纸屑动画库，支持自定义粒子形状、颜色、速度和发射角度，体积仅 10KB
  • Barba.js ⭐ 12k — 创建流畅的页面过渡效果，让网站像单页应用般运行，减少页面加载延迟和 HTTP 请求
  • Tween.js ⭐ 10.1k — JavaScript/TypeScript 补间动画引擎，结合优化的 Robert Penner 方程，支持平滑的数值属性过渡动画
  • Vivus ⭐ 10k — 零依赖 SVG 绘制动画库，支持 delayed、sync、oneByOne 等多种动画模式，让 SVG 呈现手绘效果
  • Magic CSS ⭐ 6.5k — CSS3 动画特效库，提供数十种炫酷的 CSS3 过渡动画效果，包含透视、翻转、缩放等多种动画类型
  • Galacean Engine ⭐ 5.8k — 蚂蚁集团开源的移动端优先高性能 Web 交互引擎，支持 2D/3D/动画/物理，基于 WebGL 和 glTF 构建，提供在线编辑器
  • Motion DevTools ⭐ 2.5k — Vue 3 声明式动画库，提供直观的 composable API，支持 spring 物理动画、手势动画和 SVG 路径动画，是 motion-vue 的新名称
  • vue-flip-motion ⭐ 10 — 基于 FLIP 动画技术的 Vue 组件，通过数据驱动触发平滑的位置/尺寸变化动画，减少布局抖动，支持嵌套动画。
  • dotLottie Web ⭐ 865 — 基于 Rust + WASM 的高性能 Lottie 与 dotLottie 动画播放器，提供官方 Vue3 组件包，渲染性能优于传统 lottie-web，适用于复杂动画播放场景

Vue 动画与过渡组件 ​

  • Inspira UI ⭐ 4.6k — 专为 Vue 3 和 Nuxt 设计的动效组件库，提供 100+ 高质量动画组件，包括背景特效、按钮交互、文字动画、3D 效果等，基于 TailwindCSS 和 motion-v 构建
  • vueg ⭐ 4.5k — 为 Vue 应用添加页面间的转场特效插件，支持多种页面过渡动画，兼容 vue-router
  • vue-slide-up-down ⭐ 2.5k — Vue 组件，实现高度平滑过渡的展开/收起动画，无需依赖第三方动画库，API 简洁易用
  • vue2-animate ⭐ 1.4k — Animate.css 的 Vue.js 移植版本，为 Vue 2/3 提供内置过渡动画效果
  • vue-particles ⭐ 1.4k — Vue.js 粒子背景组件，支持 SSR 和 Nuxt.js，可自定义粒子颜色、数量、形状和运动速度
  • vue-parallax ⭐ 1.2k — Vue 视差滚动组件，基于滚动位置实现视差动画效果，提升页面视觉层次感
  • vue-loading-overlay ⭐ 1.2k — Vue 全屏加载指示器组件，支持 Spinner、Dots、Bars 多种加载图标样式，可自定义颜色
  • v-wave ⭐ 1.5k — Vue 3 的 Material Design 波纹点击效果指令，支持自定义颜色、持续时间、缓动函数，取代传统的 vue-ripple 方案
  • Motion One Vue ⭐ 1k — 5kb 的 Vue 3 和 Nuxt 3 动画库，基于 Motion One，支持弹簧动画、独立变换和硬件加速渲染
  • Vue Moveable ⭐ 961 — Moveable 的 Vue.js 包装器，支持拖拽、缩放、旋转、扭曲等交互操作
  • vue2-transitions ⭐ 778 — 可复用的 Vue 2 过渡组件集合，提供多种预定义动画效果
  • vue-waves ⭐ 600 — 实现 Material Design 波纹点击效果的 Vue 指令，为按钮和交互元素添加点击反馈动画
  • vue-ripple ⭐ 600 — Vue 2 的波纹动画指令组件，点击时产生水波纹扩散效果，提升用户交互体验
  • Vue Tsparticles ⭐ 1.5k — tsParticles 的 Vue 3 官方绑定，轻松创建粒子背景、星空、五彩纸屑和烟花等炫酷视觉效果，支持 50+ 粒子预设
  • nxui ⭐ 167 — 基于 Vue3 与 Tailwind CSS 的精美动画组件集合，含 231 个动画组件并独家移植全部 Paper Shaders WebGL 特效，支持暗色模式与 CLI 按需添加

轮播与滑动组件 ​

  • vue-awesome-swiper ⭐ 8.5k — Swiper 轮播组件的 Vue 封装，支持 Vue 2/3，提供丰富的轮播和触摸交互功能
  • vue-fullpage.js ⭐ 4.2k — fullPage.js 的 Vue 封装，创建全屏滚动网站，支持锚点导航、键盘控制和移动端触摸滑动
  • vue-stack-grid ⭐ 1.5k — Vue 瀑布流网格布局组件，支持 Masonry 风格的响应式卡片排列
  • vue-waterfall ⭐ 800 — Vue 瀑布流布局组件，支持懒加载和动态内容添加
  • Hooper ⭐ 708 — 专为 Vue.js 设计的无障碍轮播组件，支持触控、键盘、鼠标滚轮导航、RTL 布局和垂直滑动
  • SuperSlide2 — 经典的中文轮播/滑动插件，基于 jQuery，支持焦点图、TAB 切换、无缝滚动等多种幻灯片效果，广泛用于国内网站

用户引导与页面导航 ​

  • Driver.js ⭐ 25k — 轻量级无依赖页面引导库，用于高亮聚焦页面元素和展示自定义提示框
  • Intro.js ⭐ 23k — 开源用户引导库，用于构建交互式分步产品导览和功能介绍
  • Shepherd.js ⭐ 13k — 灵活可定制的用户引导库，支持自定义样式、主题和多步骤交互式导览
  • Hopscotch ⭐ 5.7k — LinkedIn 出品的轻量级产品导览框架，使用 JSON 配置即可创建交互式分步引导教程
  • Rough Notation ⭐ 4.5k — 轻量级手绘风格注释动画库，支持下划线、方框、圆圈、高亮等多种注释样式，仅 3.8KB

音频与音频可视化 ​

  • Howler.js ⭐ 25k — 现代 Web 音频库，兼容 Web Audio API 和 HTML5 Audio，支持跨浏览器音频播放
  • Wavesurfer.js ⭐ 10k — 基于 Web Audio API 和 Canvas 的交互式音频波形可视化库，支持音频播放和波形渲染
  • vue-audio-visual ⭐ 1.5k — Vue HTML5 音频可视化组件库，提供 AVBars、AVWaveform、AVCircle 等组件，将音频节奏转化为动态视觉效果
  • vue-audio-player ⭐ 800 — 同时支持 Vue2 和 Vue3 的音频播放器组件，功能简洁实用，支持进度条拖拽、播放速率控制，兼容 PC 和移动端

3D 与 WebGL ​

  • TresJs ⭐ 3.6k — 使用 Vue 组件声明式构建 ThreeJS 场景，支持 Vue 3 Composition API 和 TypeScript
  • Vue 3D Model ⭐ 2.5k — 基于 Three.js 的 Vue 3D 模型查看器组件，支持多种 3D 模型格式
  • three-vue-tres ⭐ 1.8k — Three.js + Vue3 + Tres.js 的 3D 可视化框架，支持 TypeScript、模型导入交互和三维标注功能
  • visualization-collection-vue ⭐ 910 — 前端视觉效果集合应用，包含 CSS 动效、Canvas 动画、Three.js 3D、AI 应用等上百个案例（Vue 版本）
  • VueGL ⭐ 682 — 使用 Three.js 响应式渲染 3D WebGL 图形的 Vue 组件库
  • Webgl-Data-Demo ⭐ 640 — 基于 Vue、Three.js、ECharts 的数据可视化展示项目，包含三维模型导入交互、三维模型标注等功能
  • frontend-park ⭐ 611 — 基于 Vue3 + Three.js 的智慧园区 3D 可视化项目，支持模型控制、场景交互和动态数据展示

滚动特效库 ​

  • ScrollMagic ⭐ 15k — 滚动画布控制库，通过场景管理实现滚动驱动的时间轴动画，配合 GSAP 实现电影级滚动交互效果
  • Locomotive Scroll ⭐ 8.4k — 平滑滚动库，提供视差效果、滚动速度和方向检测，Vue 项目中打造高端品牌页面丝滑滚动体验的首选
  • vue-scroll-reveal ⭐ 162 — 封装 ScrollReveal 的 Vue 指令，元素滚动进入视口时触发渐显、位移等动画，支持 reset/nodesktop/nomobile 修饰符和自定义动画参数。
  • vue-scrollama ⭐ 476 — Vue3 滚动驱动交互组件（scrollytelling），基于 scrollama 封装，用于实现滚动触发步骤动画与数据叙事页面

粒子特效系统 ​

  • tsParticles ⭐ 8.4k — 粒子动画生成库，支持星空、烟花、雪花、五彩纸屑等 50+ 预设，提供 Vue 3 官方组件，高度可定制

加载动画与骨架屏 ​

  • Vue Content Loader ⭐ 3k — SVG 骨架屏组件，提供 Facebook/Instagram 风格的占位动画，支持自定义形状和颜色，提升页面加载体验
  • Vue Skeleton Loading ⭐ 1k — Vue 3 骨架屏组件套件，提供多种预设布局（卡片/列表/表格），支持主题切换和自定义动画速度
  • Spin.js ⭐ 9.3k — 纯 CSS 加载动画库，不依赖图片和外部 CSS，Vue 项目中通过指令或组件轻松集成旋转加载效果
  • vue-content-placeholders ⭐ 1.6k — Vue 组件化假内容/骨架屏渲染库，通过组合式组件模拟 Facebook 式加载占位内容，支持动画和圆角样式，提升数据加载时的用户体验。

文字动画效果 ​

  • Splitting.js ⭐ 5.2k — 轻量级文字拆分动画库，将文字按字符/单词/行分割为独立元素，配合 CSS 制作逐字动画，Vue 集成友好

截图与录屏回放 ​

  • rrweb ⭐ 20k — Web 端录制与回放工具，像素级记录用户操作并完整复现，适用于 Vue 应用的用户行为分析
  • vue-screen-capture ⭐ 23 — 基于 html2canvas 的 Vue 截图与标注组件，可对指定 DOM 元素生成截图图片并支持简单标注，适合页面快照与内容分享场景。
