安全、认证与权限 ​

数据验证 ​

  • Ajv ⭐ 28k — 高性能JSON Schema验证器，支持JSON Schema draft-07及更高版本，支持自定义关键字和异步验证
  • Joi ⭐ 20k — 强大的JavaScript对象schema验证库，支持链式API定义复杂验证规则
  • Class Validator ⭐ 10k — 基于装饰器的TypeScript/JavaScript类属性验证库，支持嵌套对象验证和自定义验证器，广泛用于NestJS等框架
  • intl-tel-input ⭐ 7.8k — 国际电话号码输入与验证插件，支持200多个国家，自动格式化与验证
  • Superstruct ⭐ 7k — 简洁直观的数据验证库，支持自定义类型和嵌套对象验证，适用于API参数校验
  • Fastest Validator ⭐ 7k — 高性能JavaScript验证库，每秒可执行数百万次验证，支持多种内置验证器和数据清理
  • Vorms ⭐ 5k — 轻量级、高性能的前端表单验证库，支持React/Vue，零依赖仅3KB gzip
  • Vest ⭐ 2.6k — 声明式验证框架，语法风格类似Mocha/Jest，支持Vue/React/Svelte

加密与安全 ​

  • jsonwebtoken ⭐ 22.5k — JSON Web Token的JavaScript实现，支持JWT签名、验证和解析，Web认证的核心基础库
  • crypto-js ⭐ 16k — JavaScript加密标准库，支持AES、DES、Triple DES、Rabbit、SHA等多种加密算法
  • @zxcvbn-ts/core ⭐ 15k — 密码强度评估库（TypeScript重写版），基于真实密码数据集估算破解时间，支持多语言字典
  • DOMPurify ⭐ 12k — 高性能DOM-only XSS净化器，用于清理HTML、MathML和SVG内容，防止跨站脚本攻击
  • OpenPGP.js ⭐ 5.9k — JavaScript版OpenPGP协议实现，支持加密、解密、签名和密钥管理，遵循RFC 9580标准
  • bcrypt.js ⭐ 5.8k — JavaScript BCrypt密码哈希算法实现，纯JavaScript编写无需原生编译，用于安全存储用户密码
  • node-forge ⭐ 5.3k — 原生JavaScript密码学工具集，包含AES/DES/RC4加密、RSA/ECC密钥、X.509证书、PKI、TLS等
  • SJCL ⭐ 5k — 斯坦福大学开发的JavaScript加密库，支持AES加密、SHA-256哈希和HMAC，体积小且经过安全审计
  • jsrsasign ⭐ 2.4k — 纯JavaScript密码学库，支持RSA/ECDSA/DSA签名验证、X.509证书管理、JWT/JWS令牌处理
  • jose ⭐ 2.2k — 全功能JWT、JWS、JWE、JWK实现库，支持多种加密和签名算法，适用于浏览器和Node.js
  • noble-hashes ⭐ 2k — 经过独立安全审计的哈希函数库，支持SHA2、SHA3、BLAKE3、RIPEMD等算法及HMAC、HKDF、Scrypt、Argon2等KDF
  • elliptic ⭐ 1.8k — 快速椭圆曲线加密纯JavaScript实现，支持secp256k1/ed25519/curve25519等曲线、ECDSA签名和ECDH密钥交换
  • tweetnacl-js ⭐ 1.6k — 高性能JavaScript加密库，提供NaCl加密实现，支持公钥加密、数字签名、哈希计算和安全随机数生成
  • jsencrypt ⭐ 1.5k — JavaScript RSA加密解密库，基于OpenSSL生成的公钥/私钥对进行加解密操作
  • js-md5 ⭐ 1.5k — 轻量级MD5哈希计算JavaScript库，支持字符串、ArrayBuffer和TypedArray类型输入
  • md5 ⭐ 1.5k — Node.js环境MD5哈希计算库，支持流式处理和大文件分块计算
  • sm-crypto ⭐ 1.5k — 国密算法JavaScript实现，支持SM2非对称加密、SM3摘要算法、SM4对称加密等中国商用密码标准
  • vue-dompurify-html ⭐ 800 — Vue v-html指令的安全替代方案，基于DOMPurify自动清洗HTML内容，防止XSS攻击
  • Helmet.js ⭐ 10.8k — Express 安全中间件，通过设置 HTTP 安全头保护 Vue SSR/Nuxt 应用免受 XSS、点击劫持等常见 Web 攻击

认证与授权 ​

  • Better Auth ⭐ 28.1k — 全面的TypeScript认证与授权框架，支持Vue，内置2FA、多租户、OAuth插件生态
  • CASL ⭐ 6.6k — 同构授权JavaScript库，支持前端和后端权限管理，可与Vue集成，实现细粒度资源访问控制
  • node-casbin ⭐ 2.8k — 强大的访问控制库，支持ACL/RBAC/ABAC等多种授权模型，适用于Node.js和浏览器环境
  • vuex-persist ⭐ 2.5k — TypeScript就绪的Vuex插件，支持localStorage、sessionStorage和IndexedDB等多种存储方式
  • pinia-plugin-persistedstate ⭐ 2.4k — 可配置的Pinia状态持久化插件，支持自定义存储、序列化器和状态过滤
  • vuex-persistedstate ⭐ 2.4k — 持久化Vuex状态，在页面刷新后保持应用状态
  • Vue-Access-Control ⭐ 2k — 基于Vue的前端访问控制方案，提供按钮级权限控制和动态路由权限管理
  • vue-auth ⭐ 2k — Vue.js 3.x和2.x认证支持库，提供路由守卫、令牌刷新和社交登录集成
  • vue-authenticate ⭐ 1.5k — 轻量级身份验证库，支持本地登录/注册和GitHub、Facebook、Google等OAuth提供商
  • vue-recaptcha ⭐ 1.5k — Google reCAPTCHA的Vue组件，支持v2和v3版本，用于在Vue应用中集成人机验证，防止恶意提交
  • vue-keycloak-js ⭐ 1.3k — Vue.js集成Keycloak的认证插件，支持OpenID Connect、OAuth2和企业级SSO单点登录
  • @sidebase/nuxt-auth ⭐ 3.5k — Nuxt 3 专属认证模块，基于 Auth.js 构建，原生支持 OAuth2、Credentials、Magic Link 等 80+ 认证提供商，提供完整的 Session 管理和 SSR 支持
  • vue-password-strength-meter ⭐ 1.1k — 基于zxcvbn的交互式密码强度检测Vue组件，支持密码显示/隐藏切换、自定义样式和实时反馈
  • vue-simple-password-meter ⭐ 1.1k — 超轻量级密码强度检测组件，纯原生JS实现，压缩后不到1KB，支持Vue 2和Vue 3
  • SuperTokens ⭐ 15.2k — 开源用户认证解决方案，支持邮箱密码、社交登录、无密码等多种认证方式，提供 Vue SDK 和自托管部署选项
  • Logto ⭐ 10.5k — 现代化的身份认证基础设施，基于 OIDC 协议，提供 Vue/Nuxt SDK、多租户支持和完整的用户管理界面

  • disable-devtool ⭐ 1.5k — 用于禁用浏览器开发者工具的JavaScript库，防止代码被调试和审查，支持多种检测模式
  • Vue Simple ACL ⭐ 900 — 简单灵活的Vue ACL插件，支持角色权限管理和RBAC模式，兼容Vue 2和Vue 3
  • vue-acl ⭐ 600 — 简单易用的Vue ACL插件，支持基于角色的权限管理和路由拦截
  • Casbin ⭐ 19.2k — 强大的开源权限管理库，支持 ACL、RBAC、ABAC 等多种访问控制模型，提供多语言实现和 JavaScript/Vue 集成方案

安全审计与扫描 ​

  • OWASP ZAP ⭐ 13.5k — OWASP 开源 Web 安全扫描器，支持自动扫描和被动扫描，可集成到 CI/CD 中对 Vue 应用进行安全漏洞检测
  • Snyk ⭐ 5.2k — 开源安全平台 CLI 工具，自动检测 Vue 项目依赖中的已知安全漏洞和许可证问题，支持实时监控和修复建议
  • Dependency-Track ⭐ 3.2k — OWASP 出品的持续组件分析平台，支持 SBOM 导入和漏洞告警，Vue 项目中用于第三方依赖的风险监控

隐私与合规工具 ​

  • CMP (Consent Management) ⭐ 4.1k — 轻量级 GDPR/CCPA Cookie 同意管理插件，纯 JavaScript 实现，零依赖，可轻松集成到 Vue.js 应用中管理用户隐私偏好
  • OWASP Dependency Check ⭐ 6.8k — OWASP 依赖安全检查工具，通过 CVE 数据库比对 Vue 项目依赖，自动生成安全报告并标注重度漏洞
