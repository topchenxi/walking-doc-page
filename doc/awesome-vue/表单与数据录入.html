表单与数据录入 ​

数据验证库 ​

  • Zod ⭐ 40.6k — TypeScript 优先的 Schema 验证库，提供强大的类型推断和验证规则，可与 VeeValidate、FormKit 等表单库无缝集成
  • Valibot ⭐ 15k — 轻量级 TypeScript Schema 验证库，体积仅为 Zod 的三分之一，支持模块化导入和完整的类型推断，适合 Vue 3 项目
  • Formily ⭐ 12.5k — 阿里巴巴开源的跨平台表单解决方案，支持 React/React Native/Vue 2/Vue 3，提供 JSON Schema 驱动的动态表单、联动逻辑和校验引擎
  • ArkType ⭐ 12k — TypeScript 优先的类型验证库，提供编译时和运行时类型检查，性能优于 Zod，适合高性能表单场景
  • Regle ⭐ 1k — 无头模型验证库，Vuelidate 的现代替代品，完整 TypeScript 类型推断、支持 Zod/Valibot/ArkType Schema，专为 Vue 3 设计
  • vorms ⭐ 800 — 基于 Vue 3 Composition API 的表单状态管理库，受 React Hook Form 启发，提供高性能的表单验证和状态管理
  • Vue Reactive Form ⭐ 600 — 轻量级、类型安全的 Vue 3 表单验证库，利用 Vue 响应式系统，支持 Standard Schema(Zod/Yup/Valibot)，无头 UI 设计
  • Yup ⭐ 23k — 经典的 Object Schema 验证库，VeeValidate 等 Vue 表单库的主力 Schema 引擎，支持链式验证、条件验证和自定义消息
  • Validator.js ⭐ 24k — 强大的字符串验证和清理库，支持 200+ 验证规则，可用于 Vue 表单自定义验证逻辑，广泛应用于后端和前端验证场景

低代码表单生成框架 ​

  • X Render ⭐ 8k — 阿里巴巴开源的中后台「表单/表格/图表/流程编排」开箱即用解决方案，JSON Schema 驱动渲染，支持可视化设计器
  • Form Create ⭐ 7k — 强大的低代码动态表单组件，通过 JSON 数据驱动表单渲染，适配移动端，支持可视化设计器
  • Vue Form Making ⭐ 5.5k — 开源的 Vue 表单设计器，支持拖拽方式快速生成表单，提供丰富的组件、灵活的布局和强大的表单验证功能
  • SurveyJS ⭐ 4.7k — 开源 Vue.js 表单和调查构建器，支持拖拽式设计、条件逻辑分支、CSS 主题编辑器和动态 JSON Schema 驱动
  • Everright-formEditor ⭐ 2k — 可视化低代码表单设计器/编辑器/生成器，支持拖拽操作，适配 Element-Plus 和 Vant
  • Avue Form Design ⭐ 1.2k — 基于 Avue 的可视化表单设计器，通过拖拽操作快速构建表单，支持自定义字段和丰富的配置选项

表单完整解决方案 ​

  • Vue Form Generator ⭐ 3k — Vue 表单生成器组件，通过 JSON Schema 或对象定义动态生成表单，支持多种字段类型、验证规则和布局选项
  • VueFormulate ⭐ 2k — 全功能的 Vue 表单处理库，提供声明式表单语法、内置验证、错误处理和丰富的表单元素类型
  • Vue Form Wizard ⭐ 1.5k — Vue 多步骤表单向导组件，支持步骤验证、进度指示和自定义步骤内容
  • vue-hooks-form ⭐ 1.5k — 受 React Hook Form 启发的 Vue 表单库，基于 Composition API 设计，提供高性能的无渲染表单验证方案
  • Vue Hook Form ⭐ 1k — 基于 Zod 原生支持的 Vue 表单 Hook 库，最小化重新渲染，仅约 10KB 压缩，UI 无关设计

Markdown 与 JSON 编辑器 ​

  • ByteMD ⭐ 5k — 字节跳动开源的 Markdown 编辑器组件，基于 Vue/React/Svelte，轻量且功能丰富
  • md-editor-v3 ⭐ 3.8k — Vue 3 Markdown 编辑器，支持全屏、暗色主题、快捷键、代码高亮、预览主题、LaTeX 公式和 Mermaid 图表
  • json-editor-vue ⭐ 1k — Vue 2.6/2.7/3 & Nuxt 2/3 同构 JSON 编辑器、查看器、格式化和验证器

图表可视化 ​

  • Vue ApexCharts ⭐ 1.3k — Vue 2 的 ApexCharts 组件封装，用于构建现代化的交互式 SVG 图表，支持柱状图、折线图、饼图等
  • v-charts ⭐ 6.8k — 饿了么前端团队开源的基于 ECharts 的 Vue 图表组件，提供简洁的图表配置方式和统一的视觉风格

动画工具 ​

  • Auto Animate (FormKit) ⭐ 13.6k — 零配置即插即用的动画工具库，只需一行代码即可为 DOM 元素添加平滑过渡动画，支持 Vue/React/Solid/Svelte
  • @vueuse/motion ⭐ 2.5k — Vue 3 Composables 动画库，VueUse 生态成员，提供声明式动画 API、弹簧动画、手势驱动和 SSR 兼容
  • vue3-lottie ⭐ 1.7k — Vue 3 的 Lottie 动画组件，支持 After Effects 导出的 JSON 动画播放，提供丰富的动画控制选项
  • vue-starport ⭐ 1.8k — 跨路由共享组件的动画过渡库，由 Vue 核心团队成员 antfu 创建，实现组件在路由间平滑过渡

输入掩码与格式化 ​

  • Vue Text Mask ⭐ 8.2k — Vue 输入掩码库（Text Mask 的 Vue 封装），用于格式化用户输入内容，如电话号码、日期、信用卡号等
  • Maska ⭐ 2k — 零依赖的输入掩码库，支持 Vue 3/Svelte/Alpine.js/原生 JS，提供数字模式、动态掩码、反向掩码等功能
  • Vue Tel Input ⭐ 1.5k — 国际电话号码输入框组件，支持国家代码选择、自动格式化、类型验证和国际电话输入
  • Vue Phone Number Input ⭐ 1k — 国际电话号码输入框组件，支持 200+ 国家/地区代码、实时格式化和手机号码验证，提供原生浏览器电话控件
  • simple-keyboard ⭐ 2.4k — 可定制、响应式的 JavaScript 虚拟键盘，官方提供 Vue 集成示例，适用于自助终端与触屏设备的输入场景

图片裁剪与上传 ​

  • Vue Upload Component ⭐ 2.7k — Vue.js 文件上传组件，支持拖拽上传、批量上传、进度显示、断点续传等功能
  • Vue Advanced Cropper ⭐ 1.1k — 高级图片裁剪库，支持自定义裁剪器、移动端适配、缩放旋转和多种裁剪模式
  • Vue FilePond ⭐ 1k — FilePond 文件上传组件的 Vue 封装，功能强大且界面美观，支持图片预览、裁剪、压缩等高级特性
  • Vue File Agent ⭐ 1k — 功能完整的文件上传组件，支持拖拽、粘贴上传、文件类型过滤、大小限制和上传状态管理
  • Vue Cropperjs ⭐ 966 — Cropper.js 的 Vue 封装组件，支持图片裁剪、旋转、缩放和实时预览，兼容 Vue 2/3

日期选择器 ​

颜色选择器 ​

  • EasyQRCodeJS ⭐ 2k — 功能丰富的跨浏览器二维码生成库，支持多种编码格式、Logo 嵌入、样式定制和 Canvas/SVG 渲染
  • vue-qrcode-reader ⭐ 2.2k — Vue 3 二维码扫描器组件，支持摄像头实时扫描和文件上传识别，提供灵活的扫描区域配置
