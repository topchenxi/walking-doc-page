数据可视化与图表 ​

数据可视化 ​

  • D3.js ⭐ 108k — 数据驱动文档可视化库，通过操作 DOM 元素实现数据到图形的映射，提供数据绑定、SVG 渲染和强大的数据转换能力，是众多可视化库的底层基础
  • Chart.js ⭐ 67k — 基于 HTML5 Canvas 的轻量级图表库，支持 8 种基础图表类型，体积小巧约 60KB，提供响应式设计和动画效果
  • Apache ECharts ⭐ 57k — Apache 基金会开源的可视化图表库，提供 60+ 图表类型，支持大数据量渲染、移动端适配和丰富的交互功能
  • Recharts ⭐ 20k — 基于 React 和 D3 的声明式图表库，支持丰富的图表类型和响应式设计，可通过适配方案在 Vue 项目中使用
  • Rough.js ⭐ 20k — 手绘风格图形库，体积小巧约 9KB 压缩后，支持 Canvas 和 SVG 渲染，可绘制线条、曲线、多边形等基础图形并添加手绘风格填充效果，可集成到 Vue 项目中
  • Plotly.js ⭐ 18k — 基于 D3.js 和 stack.gl 的高级图表库，支持 40+ 图表类型包括 3D 图、统计图、科学图表和 SVG 地图，提供缩放、平移等交互功能，可集成到 Vue 项目中
  • Luckysheet ⭐ 16k — 开源在线电子表格，功能强大配置简单，支持公式计算、数据透视表、图表、协同编辑和 Excel 导入导出，可集成到 Vue 项目中
  • @antv/g2 ⭐ 16k — 蚂蚁集团 AntV 可视化语法引擎，基于图形语法理论构建，提供声明式图表语法和高度可定制的可视化能力
  • ApexCharts ⭐ 15k — 基于 SVG 的现代交互式图表库，支持 20+ 图表类型包括柱状图、折线图、面积图、饼图、散点图、热力图等，提供丰富的动画和主题定制
  • Nivo ⭐ 15k — 基于 React 和 D3 的富图表库，提供 30+ 图表类型，可通过封装集成到 Vue 项目，支持 SVG/Canvas/HTML 渲染
  • vega ⭐ 12k — 声明式可视化语法库，通过 JSON 配置定义交互式图形，支持复杂数据转换和可视化组合，是 Vega-Lite 的底层引擎
  • LogicFlow ⭐ 10k — 滴滴开源的流程图编辑框架，支持自定义节点、边样式和插件扩展，适用于 BPMN 流程设计、审批流程等场景
  • DataV ⭐ 10k — 基于 Vue 的数据可视化大屏组件库，提供丰富的图表组件和可视化效果，适合搭建数据大屏展示系统
  • @antv/f2 ⭐ 6k — 蚂蚁集团 AntV 移动端可视化库，基于 Canvas 渲染，专为移动端 H5 场景优化，体积小巧性能优秀
  • vega-lite ⭐ 5.3k — 基于 Vega 构建的简洁交互式图形语法库，通过简化的 JSON 声明式配置快速创建常见图表，支持数据聚合、筛选和交互选择
  • go-view ⭐ 5k — 低代码数据可视化大屏设计器，支持拖拽式配置、多种数据源接入和实时数据刷新，基于 Vue3 + Vite + ECharts 构建
  • @antv/g2plot ⭐ 5k — 基于 G2 的交互式图表库，提供响应式图表配置和优雅的可视化样式，开箱即用

  • @visactor/vchart ⭐ 2.3k — 字节跳动 VisActor 跨平台图表库，支持多种图表类型、3D 可视化和动画过渡，可集成到 Vue 项目中
  • vue-data-ui ⭐ 1.5k — 基于 Vue 3 的数据可视化 UI 组件库，包含 60+ 图表类型，支持响应式设计和主题定制
