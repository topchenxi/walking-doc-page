国际化与本地化 ​

通用国际化框架 ​

  • FormatJS ⭐ 15.5k — 国际化库集合，包含 react-intl 等核心库，基于 ICU Message 语法提供数字、日期、字符串的标准化格式化与复数规则支持
  • Vue I18n ⭐ 14.3k — Vue.js 官方国际化插件，支持 Vue 2/3，提供 Composition API 和 Legacy API，支持复数、日期时间格式化、消息编译和懒加载
  • petite-vue-i18n ⭐ 14.3k — Vue I18n 的轻量级子集，提供更小的打包体积，仅包含核心翻译功能，适合对包体积敏感的项目
  • i18next ⭐ 11.3k — 功能强大的 JavaScript 国际化框架，支持 Vue 集成，提供丰富的插件生态、按需加载和强大的格式化能力
  • Polyglot.js ⭐ 6.2k — Airbnb 出品的轻量级 i18n 库，支持 Vue 集成，提供简单的翻译插值和复数处理，体积小巧仅 2KB
  • MessageFormat ⭐ 5.1k — Unicode 官方 ICU 消息格式实现，支持复数、性别选择和嵌套消息语法，适用于复杂国际化场景
  • Globalize ⭐ 4.8k — 基于 Unicode CLDR 的 JavaScript 国际化库，支持 Vue.js，提供完整的本地化能力
  • next-intl ⭐ 3.1k — 国际化库，支持 Vue/Nuxt 集成，提供类型安全的翻译函数、消息格式化和按需加载
  • Rosetta ⭐ 2.2k — 超轻量级国际化库，体积不到 300 字节，支持 Vue 集成，提供简单的翻译函数和懒加载
  • Paraglide JS ⭐ 1.5k — 基于编译时的 i18n 库，支持 Vue 框架，可大幅减少打包体积，提供类型安全的翻译消息调用

状态管理集成方案 ​

  • typesafe-i18n ⭐ 3.4k — 完全类型安全的 TypeScript i18n 库，支持 Vue 框架，零依赖、高性能，提供编译时类型检查和自动补全
  • nanostores/i18n ⭐ 1k — 基于 Nano Stores 状态管理的轻量级 i18n 库，体积约 1KB，零依赖，支持 Vue、React、Svelte 等框架

i18n 路由方案 ​

  • Nuxt I18n ⭐ 2.3k — Nuxt 框架的国际化模块，集成 vue-i18n，支持路由本地化、翻译按需加载、SEO 标签翻译和多层级支持

开发工具与 IDE 集成 ​

  • i18n-ally ⭐ 6.2k — 全功能 VS Code 国际化扩展，支持 Vue、React、Angular 等 30+ 框架，提供内联注释、机器翻译、缺失翻译检测和批量翻译等功能
  • Vue I18n Extract ⭐ 550 — Vue I18n 翻译文本提取工具，自动从 Vue 组件模板中提取未翻译的 i18n 消息键值，帮助发现遗漏的翻译
  • vue-i18n-extract ⭐ 202 — 通过静态分析管理 vue-i18n 本地化的 CLI 工具，自动提取组件中的翻译 key 并生成缺失的翻译文件，帮助维护国际化项目。

第三方翻译平台集成 ​

  • Tolgee Vue ⭐ 4k — Tolgee Web 本地化平台的 Vue 3 组件库，支持应用内上下文翻译、截图标记翻译、机器翻译集成和协作翻译管理
  • inlang ⭐ 2.5k — 开源的本地化文件格式和工具生态系统，提供通用的 i18n 文件格式、翻译编辑器 Fink、VS Code 扩展 Sherlock，支持 Vue 项目集成

Gettext 与 Fluent 方案 ​

  • Vue Gettext ⭐ 550 — 基于 GNU Gettext 标准的 Vue.js 翻译方案，使用 .po/.pot 文件格式管理翻译，支持复数形式和变量插值
  • fluent-vue ⭐ 349 — Vue2/Vue3 的 Fluent 国际化插件，基于 Mozilla Project Fluent 语法，支持富文本插值、复数与选择语法，适合注重本地化质量的场景。

轻量级方案 ​

  • gettext.js ⭐ 3.7k — 轻量级（3KB 压缩后）GNU gettext 的 JavaScript 移植，支持浏览器和 Node.js，提供标准的 gettext/ngettext 函数和 .po/.mo 文件解析
  • vue-i18n-light ⭐ 2.2k — Vue 3 的轻量级 i18n 插件，支持嵌套键、回退语言、多语言消息格式，零依赖且 TypeScript 友好
  • i18next-vue ⭐ 1.3k — i18next 生态的 Vue 3 官方绑定，支持 Composition API 和模板指令，与庞大的 i18next 插件生态无缝集成

翻译管理平台 ​

  • Tolgee ⭐ 4.3k — 开源翻译管理平台，提供上下文翻译编辑器和 Vue SDK，支持协作翻译和自动翻译建议，适合团队化多语言管理
  • Weblate ⭐ 5.2k — 基于 Web 的持续本地化平台，支持版本控制集成和翻译记忆，Vue 项目的专业级多语言协作管理方案
  • Crowdin CLI ⭐ 1.5k — Crowdin 本地化管理 CLI 工具，支持 Vue 项目翻译文件的自动上传/下载和同步，与 CI/CD 流程无缝集成

机器翻译集成 ​

  • OpenAI Translate ⭐ 17.5k — 利用 OpenAI GPT 模型进行高质量翻译的 Node.js 库，可通过 Vue 后端集成实现 AI 驱动的多语言翻译和润色
  • DeepL Node ⭐ 1.4k — DeepL 翻译 API 的 Node.js 客户端，支持 30+ 语言的高质量翻译，Vue 项目中可通过后端集成获得专业级翻译
  • Google Translate API ⭐ 3k — Google Cloud Translation API 客户端，支持 100+ 语言翻译和语言检测，Vue 项目后端集成实时多语言翻译

多语言SEO方案 ​

  • Nuxt SEO Kit ⭐ 2.5k — Nuxt SEO 工具集，自动处理多语言元标签、结构化数据和 Open Graph，确保 Vue SSR 应用的多语言 SEO 最佳实践
  • vue-meta i18n ⭐ 4.2k — Vue Meta 管理插件，支持多语言页面标题和 meta 标签的动态切换，Vue SPA/SSG 多语言 SEO 的基础方案
  • vue-head ⭐ 984 — Vue 的 head 标签元信息管理插件，支持动态设置页面标题、meta 标签、Open Graph 社交分享标签与 script/style 注入，配合多语言页面优化 SEO。

时区与日期本地化 ​

  • Day.js ⭐ 48.7k — 2KB 的 Moment.js 替代方案，支持时区转换、日期格式化和相对时间计算，Vue 项目中日期本地化的轻量首选
  • Luxon ⭐ 16k — Moment.js 团队出品的现代日期时间库，原生支持时区和国际化，Vue 项目中处理复杂时区和日历场景
  • date-fns ⭐ 36.3k — 模块化的日期工具库，每个函数独立导入，支持 Tree Shaking 和国际化，Vue 3 项目中按需使用的日期方案
  • Moment.js ⭐ 48.2k — 经典的 JavaScript 日期时间处理库，提供解析、验证、操作和显示日期的完整 API，生态成熟但已进入维护状态

货币与数字格式化 ​

  • Intl.js ⭐ 2.8k — ECMAScript 国际化 API polyfill，为 Vue 项目提供统一的货币、数字和百分比格式化支持，兼容老旧浏览器
  • Numeral.js ⭐ 9.8k — 数字格式化和操作库，支持货币显示、百分比计算和单位换算，Vue 项目中处理数值展示的瑞士军刀
  • accounting.js ⭐ 4.9k — 轻量级货币格式化库，专注金额、税率和金融数值的格式化，Vue 电商和财务项目的专用格式化工具
